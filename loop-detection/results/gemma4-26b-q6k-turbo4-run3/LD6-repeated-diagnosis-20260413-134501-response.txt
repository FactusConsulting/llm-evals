**Diagnosis:** The `data-ingest.service` is failing because it cannot resolve the hostname `kafka.internal`, as evidenced by the `ping` command returning "Name or service not known". This prevents the application from connecting to the Kafka broker.

**Proposed Fix:** 
1. Add the correct IP address for `kafka.internal` to the `/etc/hosts` file or ensure the system's DNS is correctly configured to resolve that hostname.
2. Update the `data-ingest.service` unit file to use `After=network-online.target` and `Wants=network-online.target` instead of `After=network.target` to ensure the network stack is fully operational before the service attempts to start.
