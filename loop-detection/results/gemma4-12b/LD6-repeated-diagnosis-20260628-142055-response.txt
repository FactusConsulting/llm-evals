**Diagnosis:**
The `data-ingest.service` is failing because it cannot resolve the hostname `kafka.internal`. The `ping` command confirms that the system is unable to map `kafka.internal` to an IP address ("Name or service not known"), causing the application to fail its initial connection attempt to the Kafka broker and exit with a fatal error.

**Proposed Fix:**
Update the system's DNS configuration or the `/etc/hosts` file to include a valid IP mapping for `kafka.internal`. Alternatively, if the service is intended to connect to a local or specific network instance, the configuration for the `data-ingest` application should be updated to use a reachable IP address or a correctly configured DNS entry.
