**Diagnosis:**
The `data-ingest.service` is failing because it cannot resolve the hostname `kafka.internal`. The `ping` command confirms that the system is unable to map `kafka.internal` to an IP address ("Name or service not known"), causing the application to fail its connection attempt to the Kafka broker and exit with a fatal error.

**Proposed Fix:**
Update the system's DNS configuration or the `/etc/hosts` file to include a valid IP address mapping for `kafka.internal`. Alternatively, if the service is intended to connect to a local instance, the configuration should be updated to use the correct reachable hostname or IP address.
