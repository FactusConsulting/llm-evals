**Diagnosis:** The service is trapped in an infinite restart loop because it starts before DNS resolution is fully available. The unit file specifies `After=network.target`, which only waits for the basic network interface to initialize, not for DNS/network-online readiness. When the application attempts to resolve `kafka.internal`, DNS fails, causing a fatal connection error that triggers `Restart=always`.

**Proposed Fix:** Update the `[Unit]` section of `/etc/systemd/system/data-ingest.service` to wait for full network readiness by changing `After=network.target` to `After=network-online.target` and adding `Wants=network-online.target`. Save the file, run `systemctl daemon-reload`, and restart the service.
