Below is a script that performs the audit in one pass. Run it and paste the output, or connect a shell tool and I'll run it directly.

Two corrections to the suggested commands:
- `gh repo view --json refs` is not a valid field. The script lists branches with `gh api repos/<org>/<repo>/branches --paginate`.
- Plain `gh issue list` doesn't show which branch an issue is linked to. The script uses the open PR's `headRefName` for PR links and `gh issue develop --list` for issue links.

```bash
#!/usr/bin/env bash
set -euo pipefail
ORG=FactusConsulting
printf "| Repo | Branch | Linked issue/PR |\n|---|---|---|\n"

gh repo list "$ORG" --limit 1000 --json name,defaultBranchRef \
  --jq '.[] | "\(.name) \(.defaultBranchRef.name // "main")"' |
while read -r repo default; do
  mapfile -t branches < <(gh api "repos/$ORG/$repo/branches" --paginate --jq '.[].name')
  (( ${#branches[@]} > 1 )) || continue            # only repos with >1 branch

  # Open PRs: branch -> "PR #n"
  declare -A link=()
  while IFS=$'\t' read -r head num; do
    [[ -n "$head" ]] && link["$head"]+="${link[$head]:+, }PR #$num"
  done < <(gh pr list --repo "$ORG/$repo" --state open --limit 1000 \
             --json number,headRefName --jq '.[] | "\(.headRefName)\t\(.number)"')

  # Open issues: branches linked via "Development" sidebar
  while read -r inum; do
    while read -r b _; do
      [[ -n "$b" ]] && link["$b"]+="${link[$b]:+, }Issue #$inum"
    done < <(gh issue develop --list "$inum" --repo "$ORG/$repo" 2>/dev/null)
  done < <(gh issue list --repo "$ORG/$repo" --state open --limit 1000 --json number --jq '.[].number')

  for b in "${branches[@]}"; do
    [[ "$b" == "$default" ]] && continue          # skip the default branch
    printf "| %s | %s | %s |\n" "$repo" "$b" "${link[$b]:-none}"
  done
  unset link
done
```

It processes each repo once and prints the final table once. It treats each repo's actual default branch as "main", so repos that use `master` or `develop` are handled correctly. It uses `--limit 1000` rather than 50 so larger orgs aren't truncated.
