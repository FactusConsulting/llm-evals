Diagnosis: The service is stuck in a restart loop because the `data-ingest` application fails immediately upon startup because it cannot resolve the Kafka broker hostname (`kafka.internal`), resulting in a "connection refused" error. This is confirmed by the `ping` command output showing "Name or service not known."

Proposed Fix: Update the configuration used by the `data-ingest` service to replace the hostname `kafka.internal:9092` with the actual IP address of the Kafka broker.
