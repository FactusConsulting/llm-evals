**Diagnosis:**
The `data-ingest.service` is entering a restart loop because the application cannot establish a connection to the Kafka broker at `kafka.internal:9092`. Specifically, the `ping -c 1 kafka.internal` command reveals that the hostname `kafka.internal` is not being resolved by the system's DNS or hosts configuration ("Name or service not known").

**Proposed Fix:**
Update the system's host configuration (e.g., edit `/etc/hosts`) to map the `kafka.internal` hostname to the correct IP address of the Kafka broker, or ensure the internal DNS server is correctly configured to resolve this domain.
