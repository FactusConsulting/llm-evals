*   The `jwtSecret` is generated randomly in `init()`. What is the strategy for ensuring this secret remains consistent across application restarts in a production environment?
*   Since the Redis dependency is removed, what mechanism is in place to handle token revocation (e.g., user logout or security incidents)?
*   The token expiration time is hardcoded to 24 hours; is there a configuration path to adjust this lifetime?
*   The `GenerateRefreshToken` function exists, but there is no visible logic for how these refresh tokens are stored, validated, or used in the authentication flow.
*   In `AuthMiddleware`, if `strings.TrimPrefix` fails to match "Bearer ", how is the resulting token string handled before being passed to `ValidateToken`?
*   When `ValidateToken` returns an error, the middleware returns a generic 401. Can we refine the error handling to distinguish between token expiration, signature mismatch, or malformed input for better client diagnostics?
