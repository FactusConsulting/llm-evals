**Diagnosis:**
The `data-ingest.service` is entering a restart loop because it cannot establish a connection to the Kafka broker at `kafka.internal:9092`. Specifically, the `ping` command reveals that the hostname `kafka.internal` is not resolving to an IP address ("Name or service not known"), causing the application to fail during its initialization phase and exit with status 1.

**Proposed Fix:**
Update the `/etc/hosts` file on the host machine to include a valid IP address for the `kafka.internal` hostname, or update the DNS configuration to ensure the name resolves correctly.
