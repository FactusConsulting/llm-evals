**Diagnosis:**
The `data-ingest.service` is failing because the application cannot resolve the hostname `kafka.internal`. The `ping` command confirms this with the error `Name or service not known`, and the journal logs show the process exiting because it cannot connect to the Kafka broker.

**Proposed Fix:**
Add a static entry to the `/etc/hosts` file mapping `kafka.internal` to its corresponding IP address, or ensure the internal DNS server is correctly configured to resolve the `kafka.internal` domain.
