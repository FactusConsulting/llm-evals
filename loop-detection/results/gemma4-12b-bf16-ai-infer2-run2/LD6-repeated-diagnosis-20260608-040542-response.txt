**Diagnosis:**
The `data-ingest.service` is entering a restart loop because the application cannot resolve the hostname `kafka.internal`. The journal logs show a "connection refused" error followed by a fatal exit when attempting to connect to the Kafka broker. The `ping` command confirms this is a name resolution issue, as the system reports "Name or service not known" for `kafka.internal`.

**Proposed Fix:**
Update the system's host configuration (e.g., by adding an entry to `/etc/hosts`) or verify the DNS configuration in `/etc/resolv.conf` to ensure that the hostname `kafka.internal` correctly maps to the internal IP address of the Kafka broker.
