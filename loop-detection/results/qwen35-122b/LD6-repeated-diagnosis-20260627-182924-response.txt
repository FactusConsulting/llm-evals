

Diagnosis: The `data-ingest.service` is failing to start because it cannot resolve the hostname `kafka.internal`. The `ping` output confirms DNS resolution failure ("Name or service not known"), causing the application to exit with a fatal connection error, which triggers the systemd restart loop.

Fix: Configure DNS resolution for `kafka.internal` by adding the broker's IP address to `/etc/hosts` or correcting the system DNS settings. Additionally, modify the service unit file to use `After=network-online.target` instead of `network.target` to ensure network connectivity is fully established before the service starts.
