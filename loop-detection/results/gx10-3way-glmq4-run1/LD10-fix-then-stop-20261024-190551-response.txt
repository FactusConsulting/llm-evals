**Attempt 1: Rewrite using only the Python stdlib (`csv` module)**

The failure is caused by `import pandas`, which isn't installed. Since no new packages may be installed, I'll replace the pandas logic with the stdlib `csv` module.

```bash
cat > /tmp/ageval/ld10/process.py << 'EOF'
import csv

input_path = "/tmp/ageval/ld10/input.csv"
output_path = "/tmp/ageval/ld10/output.txt"

with open(input_path, newline="") as f:
    reader = csv.DictReader(f)
    values = [float(row["value"]) for row in reader]

mean_val = sum(values) / len(values)

with open(output_path, "w") as f:
    f.write(str(mean_val))
EOF
```
