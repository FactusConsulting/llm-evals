**1. Apache Kafka**
Distributed event streaming platform optimized for high throughput.
Pros: Leverages existing org deployment; handles high throughput easily.
Cons: High operational complexity; overkill for current volume.

**2. NATS JetStream**
Cloud-native messaging system with persistent storage capabilities.
Pros: Native Go support; lightweight K8s footprint.
Cons: Smaller ecosystem than Kafka; team has only some exposure.

**3. RabbitMQ**
Robust broker supporting multiple messaging protocols.
Pros: Mature routing features; easy to manage.
Cons: Team lacks experience; heavier resource usage than NATS.

**Recommendation**
Select NATS JetStream as it aligns best with the Go stack and Kubernetes environment while avoiding Kafka's operational overhead for this volume.
