**Diagnosis:** The root cause is a DNS resolution failure. The host cannot resolve the hostname `kafka.internal` (confirmed by `ping` returning "Name or service not known"), which causes the application to fail when attempting to connect to the Kafka broker.

**Fix:** Configure DNS resolution for `kafka.internal` on the host. Add a static entry mapping `kafka.internal` to the correct Kafka broker IP address in `/etc/hosts`, or correct the nameserver configuration in `/etc/resolv.conf`.
