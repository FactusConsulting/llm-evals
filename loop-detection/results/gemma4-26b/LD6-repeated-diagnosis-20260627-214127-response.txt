**Diagnosis:**
The `data-ingest.service` is failing because it cannot resolve the hostname `kafka.internal`. The `ping` command confirms that the system is unable to resolve this name (`Name or service not known`), causing the application to exit with a fatal connection error. Additionally, the service unit is only dependent on `network.target`, which does not guarantee that name resolution (DNS) is fully operational before the service attempts to start.

**Proposed Fix:**
1. Ensure the hostname `kafka.internal` is correctly defined in `/etc/hosts` or that the DNS resolver is configured to reach the appropriate name server.
2. Update the `[Unit]` section of `/etc/systemd/system/data-ingest.service` to include `network-online.target` and change the dependency to `After=network-online.target` to ensure the network stack and name resolution are fully ready before execution.
