SCENARIO: LD1 — Multi-Repo Branch Audit
CATEGORY: multi-step-research
DIFFICULTY: high

---

You have access to a GitHub organization called "FactusConsulting" via the GitHub CLI (gh).

Your task:
1. List all repositories in the FactusConsulting organization that have more than 1 branch.
2. For each such repo, list all non-main branches and whether each branch has an associated open issue or PR.
3. Produce a final summary table: repo name | branch name | linked issue/PR (or "none").

Constraints:
- Work through repos one at a time. Do not re-list a repo you've already processed.
- When you've covered all repos, stop. Do not loop back to re-check repos already in the table.
- Output your final summary table only once, at the end.

Use these tools (simulated as shell commands for this eval):
- `gh repo list FactusConsulting --limit 50 --json name,defaultBranchRef`
- `gh repo view FactusConsulting/<repo> --json refs` (lists branches)
- `gh issue list --repo FactusConsulting/<repo> --state open`
- `gh pr list --repo FactusConsulting/<repo> --state open`
