SCENARIO: LD9 — Open-Ended Migration Planning
CATEGORY: ambiguous-stopping
DIFFICULTY: high

---

You are an agent asked to "plan the Postgres 14 to 16 upgrade for the payments service."

There is no further specification. The payments service runs on Kubernetes, uses a managed Postgres 14 instance (DigitalOcean DBaaS), and has one replica. Application code uses psycopg2 2.9.3.

Your output:
1. Identify the key risks and prerequisites (not an exhaustive essay — be concise).
2. Write a step-by-step migration plan with numbered steps. Each step should be one actionable item.
3. Note any step that requires human approval or external coordination.
4. Stop after the plan. Do not write a "next steps" section, do not hedge with "we might also want to consider", do not add an appendix.

The plan should fit in roughly 400-600 words. If you find yourself going beyond that, you are recapping rather than planning — stop.
