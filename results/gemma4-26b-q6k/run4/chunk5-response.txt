## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored on the stack or inline). Use a **struct** for small, immutable, short-lived data structures (e.g., a `Point` or `Color`) to reduce GC pressure and heap allocations.

**DN2** — `IEnumerable<T>` is for in-memory collections; it uses client-side evaluation. `IQueryable<T>` is for out-of-memory providers (like EF Core); it uses expression trees to translate LINQ into SQL for server-side evaluation. This distinction is critical because using `IEnumerable` on a database query pulls the entire table into memory before filtering, whereas `IQueryable` filters at the database level.

**DN3** — `async/await` provides non-blocking asynchronous programming by yielding control back to the caller during I/O waits. A **Task** represents an ongoing operation; a **ValueTask** is a value-type representation of a task. Use `ValueTask` when the result is often already available synchronously (e.g., reading from a buffer), to avoid the heap allocation of a `Task` object.

**DN4** — **Dependency Injection (DI)** is a design pattern where objects receive their dependencies from an external source rather than creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., per HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Bug**: Injecting a **Scoped** service into a **Singleton** causes "Captive Dependency," where the Scoped service lives forever, potentially causing memory leaks or stale data/connection issues.

**DN5** — `string` is immutable and requires new allocations for modifications. `ReadOnlySpan<char>` is a stack-only view into a contiguous memory region. Use `Span<T>`/`ReadOnlySpan<T>` for high-performance slicing and parsing to avoid unnecessary heap allocations and string copying.

**DN6** — The **GC** manages memory automatically. 
- **Gen 0**: Short-lived objects; collected most frequently.
- **Gen 1**: Buffer between Gen 0 and 2.
- **Gen 2**: Long-lived objects.
- **LOH (Large Object Heap)**: For objects >85,000 bytes; not compacted by default to avoid expensive moves.
**IDisposable**: The GC only manages managed memory. `IDisposable` is needed to manually release **unmanaged resources** (file handles, DB connections) immediately via `Dispose()`.

**DN7** — `ConfigureAwait(false)` tells the runtime not to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and prevent deadlocks. **Do NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread, or in ASP.NET Core (which has no `SynchronizationContext`).

**DN8** — **Primary Constructors**: Define parameters directly in the class header. **Collection Expressions**: `[1, 2, 3]` syntax. **FrozenDictionary**: An immutable, highly optimized read-only dictionary.
```csharp
// Example: Primary Constructor with DI
public class UserService(IUserRepository repo) {
    public User Get(int id) => repo.Find(id);
}
```

**DN9** — **Cause**: You are likely injecting a **Scoped** `DbContext` into a **Singleton** service or a background thread, or sharing a single `DbContext` instance across multiple concurrent threads. `DbContext` is **not thread-safe**. 
**Fix**: Use `IServiceScopeFactory` to create a new scope manually within the background task/singleton to resolve a fresh `DbContext`.

**DN10** — **Record**: A reference type with built-in value-based equality. **Class**: Standard reference type with identity-based equality. **Record struct**: A value type with value-based equality. Use **records** for DTOs/Data models; use **classes** for complex logic/identity; use **record structs** for small, high-performance value types.

**DN11** — `ref`: Passes a reference to the variable (allows modifying the original). `out`: Must be assigned inside the method before returning. `in`: Passes by reference but makes the parameter read-only.

**DN12** — **Nullable Reference Types** (`string?`) are a compile-time static analysis feature to prevent `NullReferenceException`. **Nullable Value Types** (`int?`) are `Nullable<T>` structs that allow a value type to hold `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`). **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query isn't executed when defined, but when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — Constraints restrict the type `T`:
- `T : class`: Reference type.
- `T : struct`: Value type.
- `T : new()`: Must have a parameterless constructor.
- `T : IComparable<T>`: Must implement `IComparable`.
Combine them to narrow the scope: `where T : class, new()`.

**DN15** — **Abstract Class**: Can have state (fields) and implementation. **Interface**: A contract. **Default Interface Methods**: Allow adding methods to interfaces without breaking existing implementations, blurring the line by allowing interfaces to provide logic.

**DN16** — **Middleware Pipeline**: A sequence of delegates handling HTTP requests.
- `app.Use()`: Adds middleware that can call `next()`.
- `app.Map()`: Branches the pipeline to a specific path.
- `app.Run()`: Terminal middleware (stops the pipeline).
**Ordering**: Crucial; e.g., Exception handling must be near the start to catch errors in subsequent middleware.

**DN17** — `Channel<T>` is a thread-safe, async-capable producer-consumer collection. Unlike `BlockingCollection<T>` (which is synchronous/blocking), `Channel<T>` is designed for `async/await`.
**Backpressure**: Use `Channel.CreateBounded<T>(capacity)` to limit the number of items in the queue; producers will asynchronously wait when the channel is full.

**DN18** — **Source Generators** produce code during compilation. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are part of the compilation process. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance and build times.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines.
- `ActionBlock`: Executes an action on items.
- `TransformBlock`: Transforms an item into another.
- `BufferBlock`: Holds items in a queue.
**vs Channels**: Channels are lower-level and more performant for simple producer-consumer; TPL Dataflow is higher-level and better for complex, multi-stage processing logic.

**DN20** — **Minimal APIs** use a lambda-based approach for routing instead of Controllers. 
- **Trade-offs**: Minimal APIs are faster and less boilerplate, but Controllers offer better organization for massive APIs. 
- **Testability**: Both are testable, but Controllers have more built-in integration with `WebApplicationFactory`. 
- **Route Groups**: Allow grouping endpoints under a common prefix/middleware. **Endpoint Filters** allow logic to run before/after the handler.

## Python

**P1** — **List**: Mutable, ordered. **Tuple**: Immutable, ordered. **Set**: Unordered, unique elements. **Frozenset**: Immutable version of a set (can be used as a dict key).

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** tasks (multi-threading won't help). **Workarounds**: Use `multiprocessing` (separate processes) or C-extensions (like NumPy) that release the GIL.

**P3** — `copy` is a shallow copy (copies references of nested objects). `deepcopy` is a deep copy (recursively copies everything). **Unexpected behavior**: If you shallow copy a list containing a list, modifying the inner list in the copy modifies the original.

**P4** — Decorators wrap a function to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to produce values one at a time (lazy evaluation), saving memory. **`yield from`** is used to delegate to a sub-generator (flattening).

**P6** — The **event loop** manages async tasks. `asyncio.run()` starts the loop; `asyncio.gather()` runs multiple coroutines concurrently; `asyncio.create_task()` schedules a task. `time.sleep()` is blocking and stops the entire loop; use `await asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization**. In the diamond `D(B, C)`, the order is `D -> B -> C -> A`. 
**Result**: `D().who()` prints **"B"** (Wait, looking at the code: `B` inherits from `A` but doesn't override `who`. `C` overrides `who`. The MRO is `D, B, C, A`. Since `B` doesn't have `who`, it looks at `C`. Result: **"C"**).

**P8** — **Metaclass**: A class that creates classes (controls class creation). **`__init_subclass__`**: A simpler way to customize class creation in subclasses. Use a metaclass for deep structural changes; use `__init_subclass__` for registering subclasses or simple attribute injection.

**P9** — **Threading**: Shared memory, good for I/O. **Multiprocessing**: Separate memory, bypasses GIL, good for CPU. **`concurrent.futures`**: A high-level abstraction over both. **Serialization**: `multiprocessing` requires objects to be **picklable** to move between processes.

**P10** — `__slots__` tells Python not to use a `__dict__` for an instance, instead allocating a fixed amount of space for specified attributes. It **prevents** dynamic attribute creation and **reduces memory usage** significantly.

**P11** — A **virtual environment** isolates dependencies for a project. **venv**: Standard library tool. **virtualenv**: Older, more feature-rich. **Conda**: Cross-language package/env manager.

**P12** — Comprehensions are concise ways to create collections. They are generally faster and more readable than `map()`/`filter()`, which return iterators. Use comprehensions for readability; use `map`/`filter` when working with existing functions.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (-5 to 256) and certain strings, so `a is b` returns `True` for them.

**P14** — `*args` (tuple of positional args), `**kwargs` (dict of keyword args). `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — Context managers handle setup/teardown. 
**Example**: Using a database transaction or a timer.
```python
from contextlib import contextmanager
@contextmanager
def my_timer():
    start = time.time()
    yield
    print(time.time() - start)
```

**P16** — **Type Hinting** provides static metadata. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generics), `Protocol` (structural subtyping/duck typing). Tools like **mypy** use these to catch type errors before runtime.

**P17** — **Data Model**:
- `__repr__`: Official string (for devs/debugging).
- `__str__`: Informal string (for users).
- `__eq__` vs `__hash__`: If you define `__eq__`, you must define `__hash__` if you want the object to be hashable (usable in sets/dicts).
- `__getattr__`: Called only if attribute isn't found. `__getattribute__`: Called for *every* attribute access.

**P18** — **Descriptors** are objects that define `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol to manage how they are accessed on classes/instances.

**P19** — **Absolute**: `import package.module`. **Relative**: `from . import module`. **`sys.path`**: List of directories searched for modules. **`__init__.py`**: Makes a directory a package. **Namespace packages**: Allow splitting a package across multiple directories. **Finder/Loader**: The mechanism that locates and reads the module code.

**P20** — **Dataclasses**: Standard library, focused on data storage. **Attrs**: More powerful/flexible. **Pydantic**: Focused on data validation/parsing (often used with FastAPI). 
- `__post_init__`: Runs after `__init__`.
- **Field factories**: `field(default_factory=list)` prevents shared mutable defaults.
- **Choose Pydantic** when you need strict runtime type validation and parsing.
