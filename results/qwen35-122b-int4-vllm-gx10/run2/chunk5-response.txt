

DN1 — **Class vs Struct:** Classes are reference types (allocated on heap), structs are value types (allocated on stack or inline). Structs are copied on assignment; classes share references. Use structs for small, immutable, value-based data (e.g., coordinates, complex numbers) to reduce GC pressure. Avoid structs for large data or mutable state.

DN2 — **IEnumerable vs IQueryable:** `IEnumerable<T>` executes in-memory (LINQ to Objects). `IQueryable<T>` builds an expression tree translated to SQL (LINQ to SQL/EF). Use `IQueryable` for database queries to filter/sort server-side. Using `IEnumerable` on a DB context pulls all data to memory before filtering, causing performance issues.

DN3 — **Async/Await & Task vs ValueTask:** `async/await` compiles to a state machine. `Task` is a heap-allocated object representing an operation. `ValueTask` is a struct that avoids allocation if the operation completes synchronously. Use `ValueTask` for high-frequency async methods (e.g., caching, I/O) to reduce GC pressure.

DN4 — **Dependency Injection:** DI injects dependencies rather than creating them. Lifetimes: **Transient** (new instance per request), **Scoped** (one per HTTP request), **Singleton** (one per app lifetime). **Bug:** Injecting a Scoped service into a Singleton causes a "Captive Dependency," where the Scoped service lives as long as the Singleton, potentially holding stale DB connections or memory.

DN5 — **string vs ReadOnlySpan<char>:** `string` is immutable, heap-allocated, and null-terminated. `ReadOnlySpan<char>` is a stack-only view over contiguous memory (no allocation). Use `Span<T>` for high-performance parsing, slicing, or string manipulation to avoid allocations and improve cache locality.

DN6 — **GC & IDisposable:** GC manages memory via generations: Gen 0 (short-lived), Gen 1 (medium), Gen 2 (long-lived). LOH holds objects >85KB. `IDisposable` is needed for unmanaged resources (files, DB connections, handles) because the GC doesn't know when to release them deterministically. Use `using` statements.

DN7 — **ConfigureAwait(false):** Default `await` captures the `SynchronizationContext` (e.g., UI thread, ASP.NET request context). `ConfigureAwait(false)` resumes on any thread pool thread. Use `false` in library code for performance. Do NOT use in UI/ASP.NET Core (pre-3.0) code where context-specific execution (e.g., updating UI) is required.

DN8 — **.NET 8/9 Features:** **Primary Constructors:** Parameters on class definition injected into fields. **Collection Expressions:** `[1, 2, ..list]` for array/list creation. **FrozenDictionary:** Immutable, optimized for read-only lookups.
*Example:* `public class UserService(ILogger<UserService> logger) : IUserService { ... }`

DN9 — **ObjectDisposedException Diagnosis:** Likely caused by a `DbContext` (Scoped) being captured in a Singleton service or BackgroundService, or an async operation continuing after the request scope ends. **Fix:** Ensure `DbContext` is Scoped. If using BackgroundService, inject `IServiceScopeFactory` to create a scope per operation.

DN10 — **Record vs Class:** `record` provides value-based equality (structural) and immutability support (`with` expressions). `class` provides reference equality. `record struct` is a value-type record. Use `record` for DTOs, API models, and immutable data; `class` for domain entities with identity.

DN11 — **ref, out, in:** `ref` passes existing variable by reference (must initialize). `out` passes by reference (must assign inside method). `in` passes by reference as read-only (prevents copying large structs). Use `in` for large structs passed to methods to avoid copy overhead.

DN12 — **Nullable Reference Types:** `string?` tells the compiler a reference might be null, enabling static analysis warnings. `int?` is `Nullable<int>`, a value type wrapper allowing null for value types. NRTs are compile-time checks; `Nullable<T>` is runtime storage.

DN13 — **LINQ:** Language Integrated Query. **Method Syntax:** `list.Where(x => x > 5)` (fluent, lambda). **Query Syntax:** `from x in list where x > 5 select x` (SQL-like). **Deferred Execution:** Query isn't executed until enumerated (e.g., `ToList()`).

DN14 — **Generic Constraints:** Limit types for `T`. `class` (reference), `struct` (value), `new()` (public parameterless constructor), `IComparable<T>` (interface). Combine for strict requirements, e.g., `where T : class, IComparable<T>` ensures T is a reference type that can be sorted.

DN15 — **Abstract vs Interface:** Abstract class can have state (fields) and implementation. Interface defines a contract (no state pre-C# 8). **Default Interface Methods (C# 8+):** Allow implementation in interfaces, enabling versioning without breaking implementations. Use abstract for shared base logic; interface for capabilities.

DN16 — **Middleware Pipeline:** Ordered execution of request handlers. `app.Use()` passes to next middleware. `app.Map()` branches based on path. `app.Run()` terminates the pipeline. Exception middleware (`app.UseExceptionHandler`) wraps the pipeline to catch and handle errors globally.

DN17 — **Channel<T>:** Async producer-consumer queue. Bounded channels (`Channel.CreateBounded`) limit capacity, forcing producers to wait (backpressure) when full. Better than `BlockingCollection` for async/await scenarios as it doesn't block threads.

DN18 — **Source Generators:** Compile-time code generation (Roslyn). Faster than reflection (no runtime cost) and safer than IL weaving. **Incremental Generators:** Cache results and only re-run on changes, improving build performance compared to legacy `ISourceGenerator`.

DN19 — **TPL Dataflow:** High-level pipeline library. `ActionBlock` (sink), `TransformBlock` (map), `BufferBlock` (queue). Handles backpressure and linking blocks. `Channels` are lower-level and more flexible; Dataflow is easier for complex pipeline orchestration.

DN20 — **Minimal APIs:** `app.MapGet` style endpoints without Controllers. Less boilerplate, faster startup. **Trade-offs:** Harder to unit test (integration tests preferred), less built-in OpenAPI support (requires Swashbuckle), fewer filters. **Endpoint Filters:** Middleware-like logic applied to specific endpoints.

P1 — **List vs Tuple, Set vs Frozenset:** List is mutable, Tuple is immutable. Set is mutable and unordered, Frozenset is immutable and hashable. Use Frozenset as dictionary keys or set elements.

P2 — **GIL:** Global Interpreter Lock prevents multiple native threads from executing Python bytecode simultaneously. Affects CPU-bound multithreading. Workarounds: `multiprocessing` (true parallelism), C-extensions (release GIL), `asyncio` (I/O bound concurrency).

P3 — **Deep vs Shallow Copy:** `copy` creates a new object but references nested objects (shallow). `deepcopy` recursively copies nested objects. **Example:** `list2 = copy(list1)`; modifying `list2[0]` affects `list1[0]` if `list1[0]` is a mutable object.

P4 — **Decorators:** Wrapper function that modifies behavior.
```python
import time, functools
def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__}: {time.time()-start}")
        return res
    return wrapper
```

P5 — **Generators:** Functions that yield values one at a time, saving memory. `yield` pauses execution. `yield from` delegates to another generator. Use for large datasets or infinite streams instead of loading lists.

P6 — **Asyncio:** Single-threaded event loop. `asyncio.run()` starts loop. `gather()` waits for multiple tasks. `create_task()` schedules a coroutine. `time.sleep()` blocks the loop; use `await asyncio.sleep()` to yield control.

P7 — **MRO:** Method Resolution Order uses C3 Linearization. Order: D -> B -> C -> A. `D().who()` searches D (no), B (no), C (yes, returns "C"). Diamond inheritance resolves ambiguity by prioritizing left-to-right in base classes.

P8 — **Metaclass:** Class of a class. Controls class creation. `__init_subclass__` is simpler for subclass hooks (e.g., registration). Metaclass is for complex class modification (e.g., ORM model creation). Use `__init_subclass__` unless you need to intercept class definition itself.

P9 — **Multiprocessing vs Threading:** Threads share memory (GIL limited). Processes have separate memory (true parallelism). `concurrent.futures` abstracts both. Multiprocessing requires pickling arguments/return values (serialization overhead). Use Processes for CPU-bound, Threads for I/O-bound.

P10 — **__slots__:** Declares fixed attributes, preventing `__dict__` creation. Saves memory (no per-instance dict) and prevents dynamic attribute assignment. Use for memory-intensive classes with fixed attributes.

P11 — **Virtual Environment:** Isolated Python environment for dependencies. `venv` (stdlib), `virtualenv` (faster, older), `conda` (package manager + env, handles non-Python libs). Always use venv to avoid global package conflicts.

P12 — **Comprehensions:** Concise syntax for creating lists/dicts/sets. `[x for x in list]`. Faster than loops. `map/filter` are functional; comprehensions are more Pythonic and readable. Prefer comprehensions for simple transformations.

P13 — **== vs is:** `==` checks value equality. `is` checks identity (same memory address). **Interning:** Python caches small integers (-5 to 256) and some strings, so `a is b` may be True for them even if created separately.

P14 — **args/kwargs:** `*args` collects positional args, `**kwargs` collects keyword args. `/` marks positional-only parameters (before it). `*` marks keyword-only parameters (after it). Enforces API clarity.

P15 — **Context Managers:** `with` statement ensures setup/teardown. `__enter__`/`__exit__` (class) or `@contextmanager` (generator). **Example:** Database transaction commit/rollback, ensuring connection closes even on error.

P16 — **Type Hinting:** Static type checking. `Union[A, B]` (A or B), `Optional[A]` (A or None), `Literal[1]` (fixed value), `Protocol` (structural typing). `mypy`/`pyright` analyze code without running it to catch errors early.

P17 — **Data Model:** Dunder methods define behavior. `__repr__` (debug), `__str__` (user). `__eq__` defines equality. Defining `__eq__` sets `__hash__` to None (unhashable) unless explicitly overridden, preventing use in sets/dicts.

P18 — **Descriptors:** Objects defining `__get__`, `__set__`, `__delete__`. Control attribute access. `property`, `classmethod`, `staticmethod` are built-in descriptors. Use for validation, computed attributes, or lazy loading.

P19 — **Import System:** `sys.path` searches for modules. Absolute (`import pkg.mod`), Relative (`from . import mod`). `__init__.py` marks packages. Namespace packages allow splitting packages across directories. Finders locate modules; Loaders execute them.

P20 — **Dataclasses:** Boilerplate reduction for classes. `__post_init__` for init logic. `frozen=True` for immutability. **Pydantic:** Adds validation and serialization (JSON). Choose Pydantic for API models requiring validation; dataclasses for internal data structures.
