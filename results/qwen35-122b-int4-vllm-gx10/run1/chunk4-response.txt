

G1 — **Slice vs. Array & Append**
An **array** is a fixed-size value type (e.g., `[5]int`). A **slice** is a dynamic view over an array (struct with pointer, length, capacity). Slices are reference types; arrays are values.
When appending to a slice that exceeds capacity, Go allocates a new, larger underlying array, copies existing data, and updates the slice header to point to the new array.

G2 — **`var` vs `:=`**
`var x int` explicitly declares a variable with a type. `x := 0` infers the type from the right-hand side and declares the variable.
You **cannot** use `:=` in the following cases:
1.  At the package level (global scope).
2.  If the variable is already declared in the current scope (unless shadowing in a nested block).
3.  If the type cannot be inferred (e.g., `x :=` with no value).

G3 — **Goroutines & GMP Model**
A **goroutine** is a lightweight thread managed by the Go runtime (KB stack vs. MB OS thread).
**GMP Model:**
*   **G (Goroutine):** The execution context.
*   **M (Machine):** The OS thread.
*   **P (Processor):** Logical processor managing Gs on Ms.
The scheduler multiplexes many Gs onto fewer Ms, handling blocking syscalls and work-stealing between Ps.

G4 — **Channels**
Channels are typed conduits for communication between goroutines.
*   **Unbuffered:** Send blocks until a receiver is ready (synchronous).
*   **Buffered:** Send blocks only when the buffer is full.
Sending to a **full buffered channel** blocks the sender until space becomes available. Closing a channel allows receivers to detect closure.

G5 — **Context Package**
Used for cancellation signals, deadlines, and request-scoped values across API boundaries.
**Example:**
```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
client.Do(req) // Cancels if >5s
```

G6 — **Interfaces & `interface{}`**
Go uses **implicit satisfaction** (duck typing); a type implements an interface by implementing its methods. Java/C# require explicit declaration.
`interface{}` (or `any`) holds any value. It is **powerful** for generic containers but **dangerous** because it loses type safety, requiring runtime type assertions which can panic.

G7 — **Memory Model & Visibility**
This is unsafe because there is no synchronization. The compiler or CPU may reorder writes (`ready = true` before `data = "hello"`), or the reader may see `ready = true` before `data` is updated due to caching.
**Fix:** Use `sync/atomic` for `ready`, `sync.Mutex`, or channels to establish a "happens-before" relationship.

G8 — **Mutex vs RWMutex & sync.Map**
*   **Mutex:** Exclusive lock (read/write).
*   **RWMutex:** Allows multiple readers OR one writer.
*   **sync.Map:** Optimized for read-heavy workloads with high contention or disjoint keys.
**Trade-off:** `sync.Map` avoids lock contention but has higher memory overhead and complexity. Use standard `map` + `Mutex` for most cases.

G9 — **Go Modules**
*   **go.mod:** Declares module path and dependency versions.
*   **go.sum:** Stores cryptographic checksums for dependency integrity.
*   **go mod tidy:** Adds missing requirements and removes unused ones.
*   **MVS:** Selects the minimum version of a module that satisfies all version constraints in the dependency graph.

G10 — **Defer**
`defer` schedules a function call to run after the surrounding function returns. Multiple defers execute in **LIFO** (Last In, First Out) order.
**Gotcha:** In a loop, `defer` captures the loop variable by reference. If the variable changes, all defers see the final value. Fix: pass the variable as an argument to the deferred function.

G11 — **Pointers**
A pointer holds a memory address. The zero value is `nil`.
To create a pointer to a struct literal: `p := &MyStruct{Field: value}`.

G12 — **init() Function**
`init()` is a special function called automatically before `main()`.
*   Runs after package variables are initialized.
*   A package can have multiple `init()` functions.
*   Order within a package is undefined; order across packages follows import dependency order.

G13 — **make vs new**
*   **new(T):** Allocates zeroed memory for type T, returns `*T`. Works for all types.
*   **make(T):** Initializes slices, maps, and channels. Returns the initialized value `T` (not a pointer).

G14 — **Error Handling**
Go uses explicit error returns. The `error` interface requires an `Error() string` method.
**Idiom:** `if err != nil { return err }`.
*   **errors.Is:** Checks if an error is a specific target (handles wrapping).
*   **errors.As:** Checks if an error is a specific type (handles wrapping).
*   **==:** Only works for exact error matches (ignores wrapping).

G15 — **Composite Types & Zero Values**
*   **Map:** `nil`
*   **Slice:** `nil`
*   **Channel:** `nil`
*   **Struct:** Zero value of each field (e.g., 0, false, nil).

G16 — **Race Conditions**
A race occurs when two goroutines access shared data concurrently, and at least one writes.
**`-race` flag:** Uses dynamic analysis to detect data races at runtime.
**Fix:** Protect shared data with `sync.Mutex` or use channels to pass data ownership.

G17 — **Select Statement**
`select` waits on multiple channel operations. Like `switch`, but for channels.
*   If multiple cases are ready, one is chosen **randomly**.
*   **Timeout:** Use `case <-time.After(duration):` to handle timeouts.

G18 — **Escape Analysis**
The compiler decides whether to allocate variables on the **stack** (fast, freed on return) or **heap** (managed by GC).
**Escapes:** Pointers returned from functions, closures capturing variables, large allocations.
**Inspect:** `go build -gcflags="-m"`. Matters for GC pressure and performance.

G19 — **Reflection**
`reflect` allows runtime inspection of types and values.
*   **reflect.Type:** Metadata about the type.
*   **reflect.Value:** The actual data.
**Cost:** High overhead, prevents compiler optimizations. Justified for plugins, serialization, or generic code before Go 1.18. Prefer generics now.

G20 — **go:embed**
`//go:embed` includes files into the binary at compile time.
*   **Single:** `var f string`
*   **Dir:** `var d embed.FS`
*   **Limitations:** Files must exist at build time; cannot modify at runtime.
*   **io/fs.FS:** `embed.FS` implements this interface for standard library usage.

R1 — **Ownership**
Ownership ensures memory safety without garbage collection.
**Rules:**
1.  Each value has one owner.
2.  When the owner goes out of scope, the value is dropped.
3.  Ownership can be transferred (moved), not copied (for non-Clone types).

R2 — **String vs &str**
*   **String:** Owned, heap-allocated, mutable.
*   **&str:** Borrowed string slice (view), immutable, points to UTF-8 data.
**Signatures:** Use `&str` for input (flexible), `String` for output (ownership).

R3 — **Borrowing & Borrow Checker**
Borrowing creates references.
**Rules:**
1.  You can have either one mutable reference (`&mut T`) OR any number of immutable references (`&T`).
2.  References must always be valid (no dangling pointers).
The borrow checker enforces this at compile time.

R4 — **Result, Option & ? Operator**
*   **Result<T, E>:** Success (T) or Error (E).
*   **Option<T>:** Some(T) or None.
*   **? Operator:** Propagates errors/None to the caller.
**Example:**
```rust
fn read_file(path: &str) -> Result<String, io::Error> {
    fs::read_to_string(path)
}
```

R5 — **Box, Rc, Arc**
*   **Box<T>:** Single ownership, heap allocation.
*   **Rc<T>:** Reference counting, single-threaded shared ownership.
*   **Arc<T>:** Atomic reference counting, thread-safe shared ownership.
Use `Box` for recursion/heap, `Rc` for graph structures (single thread), `Arc` for concurrency.

R6 — **Traits**
Traits define shared behavior (similar to interfaces).
*   **Go:** Implicit satisfaction.
*   **Rust:** Explicit `impl Trait for Type`.
*   **dyn Trait:** Dynamic dispatch (vtable, runtime cost).
*   **T: Trait:** Static dispatch (monomorphization, zero cost).

R7 — **Lifetimes**
Lifetimes ensure references are valid. The function fails because the compiler doesn't know if the return reference comes from `x` or `y`.
**Fix:**
```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

R8 — **Send & Sync**
*   **Send:** Type can be transferred across thread boundaries.
*   **Sync:** Type can be shared across threads (`&T` is Send).
**Rc<T>:** Not `Send` (not thread-safe ref count).
**Arc<T>:** Uses atomic operations for ref count, making it `Send` and `Sync`.

R9 — **Async/Await**
Async functions return a **Future** (state machine). They are **lazy** (do nothing until polled).
**Executor:** Polls futures to completion (e.g., Tokio).
**Vs Go:** Go uses preemptive OS threads (scheduler handles blocking). Rust uses cooperative polling (user-space scheduler).

R10 — **Unsafe**
`unsafe` bypasses borrow checker and type safety.
**3 things:**
1.  Dereference raw pointers.
2.  Call unsafe functions.
3.  Access mutable static variables.
**Justified:** FFI, low-level optimization, implementing unsafe traits.

R11 — **Pattern Matching**
`match` deconstructs values.
*   **match:** Must be exhaustive (all cases covered).
*   **if let:** Matches single pattern, ignores others.
Compiler enforces exhaustiveness to prevent logic errors.

R12 — **Vec vs Array**
*   **Array:** Fixed size, stack allocated `[T; N]`.
*   **Vec:** Dynamic size, heap allocated.
**Push:** When capacity is exceeded, `Vec` allocates new memory (usually 2x), copies/moves elements, and frees old memory.

R13 — **Enums**
Rust enums are **sum types** (can hold data). C/Java enums are integers.
**Option<T>:** `Some(T)` or `None`. Replaces null to prevent null pointer exceptions.

R14 — **impl Block**
Defines methods for a type.
*   **&self:** Immutable borrow.
*   **&mut self:** Mutable borrow.
*   **self:** Consumes ownership.
**Associated fn:** Defined on the type itself (e.g., `String::new()`), not an instance.

R15 — **Derive Macro**
Automatically implements traits.
**Common:** `Debug`, `Clone`, `PartialEq`, `Serialize`.
**Cannot derive:** When fields don't implement the trait (e.g., a struct containing a raw pointer cannot derive `Clone` safely).

R16 — **Cow (Clone on Write)**
`Cow<'a, T>` holds either a borrowed reference (`&'a T`) or an owned value (`T`).
**Useful:** When data is mostly read (borrowed) but occasionally modified (cloned). Avoids allocation if no mutation occurs.

R17 — **Module System**
*   **mod:** Declares a module.
*   **use:** Imports items.
*   **pub:** Exports visibility.
**2018:** `mod.rs` replaced by `mod.rs` or `mod_name.rs`. `crate` root is explicit. File system maps to module hierarchy.

R18 — **Pin**
`Pin<T>` ensures a value is not moved in memory.
**Needed:** For self-referential structs and async `Future`s (which may hold references to themselves).
**Unpin:** Marker trait indicating a type is safe to move (most types implement this).

R19 — **Macros**
*   **Declarative (`macro_rules!`):** Pattern matching, compile-time expansion.
*   **Procedural:** Code generation (derive, attributes).
**Hygiene:** Macro variables are scoped to the macro invocation, preventing name collisions with caller code.

R20 — **Zero-Cost Abstractions**
Code generated is as efficient as hand-written C.
*   **Iterators:** Inlined loops, no runtime overhead.
*   **Generics:** Monomorphization (specialized code per type).
*   **Traits:** Static dispatch (vtable only if `dyn Trait` used).
No runtime cost for abstraction layers.
