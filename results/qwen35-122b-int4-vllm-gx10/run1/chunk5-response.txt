

DN1 — **Class vs Struct:** Classes are reference types (allocated on heap), structs are value types (allocated on stack or inline). Use structs for small, immutable, performance-critical data structures (e.g., `Point`, `Complex`) to avoid heap allocation and GC pressure. Avoid structs for large data or mutable state.

DN2 — **IEnumerable vs IQueryable:** `IEnumerable<T>` executes queries in-memory (LINQ to Objects). `IQueryable<T>` builds an expression tree executed by the provider (e.g., SQL Server via EF Core). This matters for performance: `IQueryable` filters data on the database server, reducing network traffic; `IEnumerable` pulls all data to memory before filtering.

DN3 — **Async/Await & Task vs ValueTask:** `async/await` compiles to a state machine that suspends execution until a task completes. `Task` is a reference type (allocates memory); `ValueTask` is a struct (no allocation if completed synchronously). Use `ValueTask` for high-frequency methods that often complete synchronously to reduce GC pressure.

DN4 — **Dependency Injection:** DI is a pattern for injecting dependencies rather than creating them internally. Lifetimes: **Transient** (new instance per request), **Scoped** (one instance per HTTP request), **Singleton** (one instance per app lifetime). **Bug:** Injecting a Scoped service into a Singleton creates a "Captive Dependency," causing the Scoped service to live as long as the Singleton (potentially disposing DbContext too early or leaking state).

DN5 — **string vs ReadOnlySpan<char>:** `string` is immutable and heap-allocated. `ReadOnlySpan<char>` is a stack-only view over contiguous memory. Use `Span<T>` for high-performance string manipulation (parsing, slicing) without allocations. It cannot be stored in fields or boxed.

DN6 — **GC & IDisposable:** .NET GC uses generational collection (Gen 0: short-lived, Gen 1: medium, Gen 2: long-lived). Large Object Heap (LOH) stores objects >85KB. `IDisposable` is needed for deterministic cleanup of unmanaged resources (files, DB connections) because the GC is non-deterministic regarding when it collects memory.

DN7 — **ConfigureAwait(false):** Default `await` captures the `SynchronizationContext` (e.g., UI thread or legacy ASP.NET). `ConfigureAwait(false)` resumes on any thread pool thread. Use it in library code to avoid deadlocks and improve performance. Do **not** use it in UI code or ASP.NET Core (pre-3.0) where context is required for request data.

DN8 — **.NET 8/9 Features:** **Primary Constructors** allow constructor parameters on the class definition. **Collection Expressions** (`[1, 2, 3]`) replace `new[]`. **FrozenDictionary** is an immutable, high-performance dictionary.
*Example:*
```csharp
public class MyService(MyDbContext ctx) : IService {
    public void DoWork() => ctx.SaveChanges();
}
// DI registers MyService automatically via primary constructor
```

DN9 — **ObjectDisposedException Diagnosis:** Likely cause: `DbContext` registered as Singleton or a Scoped service captured in a Singleton (Captive Dependency). `DbContext` is not thread-safe. **Fix:** Ensure `DbContext` is registered as Scoped (`AddDbContext`). Ensure no Singleton holds a reference to a Scoped `DbContext`.

DN10 — **Record vs Class:** `record` provides value-based equality and immutability (with `with` expressions). `class` provides reference equality. `record struct` is a value-type record. Choose `record` for DTOs/immutable data; `class` for entities with behavior/mutable state.

DN11 — **ref, out, in:** `ref` passes by reference (must be initialized). `out` passes by reference (must be assigned inside method). `in` passes by reference (read-only). Use `ref` to modify, `out` for multiple return values, `in` for large structs passed read-only to avoid copying.

DN12 — **Nullable Reference Types:** `?` on reference types (e.g., `string?`) enables compile-time warnings for potential nulls (`#nullable enable`). `int?` is `Nullable<int>`, a value type wrapper. NRT is static analysis; `int?` is a runtime type.

DN13 — **LINQ:** Language Integrated Query. **Method Syntax:** `list.Where(x => x > 5)` (lambda). **Query Syntax:** `from x in list where x > 5 select x` (SQL-like). **Deferred Execution:** Query logic runs only when enumerated (e.g., `foreach`, `ToList()`).

DN14 — **Generic Constraints:** Restrict type arguments. `where T : class` (ref type), `where T : struct` (val type), `where T : new()` (public ctor), `where T : IComparable<T>` (interface). Combine for specific needs: `where T : class, IDisposable`.

DN15 — **Abstract vs Interface:** Abstract class can have state/implementation; single inheritance. Interface is a contract; multiple inheritance. **Default Interface Methods (C# 8+):** Interfaces can now have method implementations, blurring the line but still not allowing state.

DN16 — **Middleware Pipeline:** Middleware components handle requests/responses. `app.Use()` adds middleware (must call `next()`). `app.Map()` branches the pipeline based on path. `app.Run()` is terminal (no `next`). Order matters (first added = first executed). Exception middleware wraps the pipeline to catch errors.

DN17 — **Channel<T>:** Async producer-consumer queue. `BlockingCollection<T>` is synchronous. **Bounded Channel:** Limits capacity; producers block or fail when full (backpressure). Example: `Channel.CreateBounded<T>(100)`.

DN18 — **Source Generators:** Compile-time code generation (C# 9+). Faster than reflection (no runtime overhead) and safer than IL weaving (compile-time). **Incremental Generators:** Only re-run when inputs change, improving build performance. Preferred for high-performance libraries (e.g., JSON serializers).

DN19 — **TPL Dataflow:** Library for dataflow pipelines. `ActionBlock` (consume), `TransformBlock` (map), `BufferBlock` (queue). Links blocks via `LinkTo`. Compared to Channels: Dataflow is higher-level with built-in throttling/propagation; Channels are lower-level primitives.

DN20 — **Minimal APIs:** Top-level statements, no controllers/classes. **Trade-offs:** Simpler/faster startup vs. less structure/testability than Controllers. **Route Groups:** `app.MapGroup("/api")`. **Endpoint Filters:** Middleware-like logic per endpoint. OpenAPI support is automatic but less configurable than SwaggerGen on Controllers.

P1 — **List vs Tuple / Set vs Frozenset:** List (mutable, ordered), Tuple (immutable, ordered). Set (mutable, unique, unordered), Frozenset (immutable, hashable). Use frozenset as dict keys or set elements.

P2 — **GIL:** Global Interpreter Lock allows only one thread to execute Python bytecode at a time. Affects CPU-bound multithreading. Workarounds: `multiprocessing` (separate processes), C-extensions (release GIL), `asyncio` (I/O concurrency).

P3 — **Deepcopy vs Copy:** `copy` (shallow) copies the container but references nested objects. `deepcopy` recursively copies everything. **Issue:** Shallow copying a list of lists modifies the inner lists in both copies.

P4 — **Decorators:** Functions that wrap other functions.
```python
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time()-start}")
        return res
    return wrapper
```

P5 — **Generators:** Functions using `yield` return an iterator (lazy evaluation). List returns all items at once (eager). `yield from` delegates to a sub-generator. Use generators for large datasets to save memory.

P6 — **Asyncio:** Event loop manages async tasks. `asyncio.run()` starts loop. `gather()` runs coroutines concurrently. `create_task()` schedules a task. `time.sleep()` blocks the loop; use `await asyncio.sleep()`.

P7 — **MRO:** Method Resolution Order uses C3 Linearization. Order: D -> B -> C -> A. `D().who()` searches D (no), B (no), C (yes). Prints **"C"**. Diamond inheritance resolves ambiguity by prioritizing left-to-right in base classes.

P8 — **Metaclass vs __init_subclass__:** Metaclass controls class creation (e.g., enforcing patterns). `__init_subclass__` is a hook called when a class is subclassed. Use `__init_subclass__` for simpler subclass registration; Metaclass for complex class manipulation.

P9 — **Multiprocessing vs Threading:** Threading (shared memory, GIL limited, I/O bound). Multiprocessing (separate memory, CPU bound). `concurrent.futures` abstracts both. Multiprocessing requires objects to be picklable (serialized).

P10 — **__slots__:** Declares fixed attributes, preventing `__dict__` creation. Saves memory and speeds up access. Use for memory-intensive classes with many instances. Prevents dynamic attribute assignment.

P11 — **Virtual Environment:** Isolated Python environment for dependencies. `venv` (stdlib), `virtualenv` (3rd party, faster), `conda` (pkg manager + env). Use to avoid dependency conflicts between projects.

P12 — **Comprehensions:** Concise syntax for creating lists/dicts/sets (`[x for x in y]`). Faster than `map/filter`. Prefer comprehensions for readability and performance unless complex logic requires a loop.

P13 — **== vs is:** `==` checks value equality. `is` checks identity (same memory address). **Interning:** Python caches small integers (-5 to 256) and some strings. `a is b` is True for small ints because they point to the same cached object.

P14 — **args/kwargs:** `*args` collects positional args into tuple. `**kwargs` collects keyword args into dict. `/` enforces positional-only params. `*` enforces keyword-only params.

P15 — **Context Managers:** `with` statement ensures setup/teardown. Class: implement `__enter__`/`__exit__`. Function: use `@contextmanager` (generator). Example: Database transaction commit/rollback, acquiring locks.

P16 — **Type Hinting:** Static type annotations (`def f(x: int) -> str:`). `Union`, `Optional`, `Literal`, `TypeVar`, `Protocol`. `mypy`/`pyright` check types without running code, catching errors early.

P17 — **Data Model:** `__repr__` (debug), `__str__` (user). `__eq__` (value), `__hash__` (dict key). Defining `__eq__` without `__hash__` makes the object unhashable (cannot be dict key) unless `__hash__` is explicitly set to `None` or redefined.

P18 — **Descriptors:** Objects defining `__get__`, `__set__`, `__delete__`. Control attribute access. `property`, `classmethod`, `staticmethod` are built-in descriptors. Used for validation, computed properties, or access control.

P19 — **Import System:** Uses `sys.path` to find modules. **Absolute:** `import pkg.module`. **Relative:** `from . import module`. `__init__.py` marks packages. **Namespace:** No `__init__.py`, allows splitting packages across directories. Finders locate modules; Loaders execute them.

P20 — **Dataclasses:** Boilerplate reduction (`@dataclass`). `__post_init__` runs after init. `frozen=True` makes immutable. **Pydantic:** Adds validation/serialization (JSON). Choose Pydantic for API models/validation; Dataclasses for internal data structures.
