## .NET / C#

**DN1** — `class` is a reference type (stored on the heap), supporting inheritance. `struct` is a value type (stored on the stack or inline in the containing type), supporting value semantics. Use `struct` for small, immutable data structures (typically < 16 bytes) that have no identity and are frequently created/destroyed to reduce GC pressure.

**DN2** — `IEnumerable<T>` is an in-memory sequence; LINQ queries are executed in the application memory. `IQueryable<T>` is an abstraction for a data provider (like EF Core); it builds an expression tree that is translated into a provider-specific language (like SQL). This distinction matters because `IQueryable` allows for "server-side" filtering, preventing the transfer of massive datasets from the DB to the app.

**DN3** — `async/await` uses a state machine to suspend execution of a method without blocking the calling thread, allowing the thread to return to the pool until the awaited task completes. `Task` is a class representing an asynchronous operation. `ValueTask<T>` is a struct used to reduce allocations when an operation might complete synchronously. Use `ValueTask` when the result is often already available (e.g., reading from a buffer) to avoid heap allocation of a `Task` object.

**DN4** — DI is a pattern where dependencies are provided to a class rather than the class creating them. 
- **Transient**: New instance every time it is requested.
- **Scoped**: New instance once per client request (e.g., per HTTP request).
- **Singleton**: One instance created once and shared globally.
**Bug**: Injecting a **Scoped** service into a **Singleton** causes "Captive Dependency." The Scoped service is held alive by the Singleton for the entire application lifetime, which can lead to memory leaks or, more commonly, `ObjectDisposedException` if the Scoped service (like a `DbContext`) is disposed at the end of a request but the Singleton tries to use it later.

**DN5** — `string` is an immutable heap-allocated object. `ReadOnlySpan<char>` is a stack-only view into a contiguous region of memory (heap, stack, or unmanaged). `Span<T>` allows for high-performance, zero-copy slicing and manipulation of memory. Use `Span<T>` for parsing or string manipulation to avoid creating multiple substring objects on the heap, significantly reducing GC pressure.

**DN6** — The GC manages memory by reclaiming heap space. 
- **Gen 0**: Short-lived objects (newly allocated).
- **Gen 1**: Buffer between Gen 0 and Gen 2.
- **Gen 2**: Long-lived objects.
- **LOH (Large Object Heap)**: For very large objects (>85,000 bytes); not compacted by default, which can lead to fragmentation.
`IDisposable` is used to release **unmanaged** resources (file handles, DB connections, sockets) immediately. The GC only manages managed memory; it doesn't know how to "close" a file handle promptly.

**DN7** — `ConfigureAwait(false)` tells the runtime that the continuation (the code after `await`) does not need to run on the original `SynchronizationContext` (e.g., the UI thread or the ASP.NET request context). 
- **Use it**: In library/infrastructure code to improve performance and prevent deadlocks.
- **Don't use it**: In application-level code where you *need* to access context-specific data (like `HttpContext.Current` in legacy ASP.NET or UI elements in WPF).

**DN8** — **Primary Constructors**: Parameters defined directly in the class header. **Collection Expressions**: `[]` syntax for initializing arrays/lists. **FrozenDictionary**: A highly optimized, immutable dictionary for read-heavy scenarios.
```csharp
// Primary Constructor with DI
public class UserService(IUserRepository repo) 
{
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9** — **Cause**: `DbContext` is not thread-safe. Under high load, multiple threads are likely trying to use the same `DbContext` instance simultaneously. This happens if the `DbContext` is registered as a `Singleton` or if a single `Scoped` instance is being shared across multiple asynchronous tasks/threads incorrectly.
**Fix**: Ensure `DbContext` is registered as `Scoped` (the default). Ensure you are not manually starting background threads that outlive the HTTP request scope without creating a new `IServiceScope`.

**DN10** — `record` is a reference type with built-in value-based equality. `record struct` is a value type with value-based equality. 
- **Use `record`**: For DTOs or immutable data models where identity is based on properties.
- **Use `record struct`**: For small, high-performance value types that need equality logic.
- **Use `class`**: When you need inheritance, identity (reference equality), or mutable state.

**DN11** — `ref`: Passes a variable by reference (allows modifying the original variable). `out`: Passes a variable by reference, but the method *must* assign a value before returning. `in`: Passes a variable by reference but makes it read-only (prevents modification).

**DN12** — **Nullable Reference Types (`?`)**: A compiler-level feature to help prevent `NullReferenceException` by tracking nullability via static analysis. It does *not* change the runtime behavior. **Nullable Value Types (`int?`)**: A runtime feature (`Nullable<T>`) that wraps a value type to allow it to hold a `null` state.

**DN13** — LINQ (Language Integrated Query) allows querying collections using a language-specific syntax. 
- **Method Syntax**: Uses extension methods and lambdas (`.Where(x => x > 0)`).
- **Query Syntax**: Uses a SQL-like declarative syntax (`from x in list where x > 0 select x`).
**Deferred Execution**: The query is not executed when defined, but rather when the results are actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — Constraints restrict the types that can be used for generics.
- `T : class`: T must be a reference type.
- `T : struct`: T must be a non-nullable value type.
- `T : new()`: T must have a public parameterless constructor.
- `T : IComparable<T>`: T must implement `IComparable<T>`.
**Combine**: `where T : class, new()` ensures T is a reference type that can be instantiated.

**DN15** — `abstract class` can have state (fields) and implementation. `interface` defines a contract. **C# 8+ Change**: Default interface methods allow interfaces to provide a default implementation for a method, reducing the need to update all implementing classes when a new method is added. This blurs the line, but abstract classes still hold state, while interfaces cannot.

**DN16** — The middleware pipeline is a sequence of delegates that handle requests/responses.
- `app.Use()`: Adds a delegate that can call the next middleware.
- `app.Map()`: Branches the pipeline based on a request path.
- `app.Run()`: A terminal middleware that does not call the next one.
**Ordering**: Order is critical (e.g., `UseExceptionHandler` must be early to catch errors from later middleware). **Exception Handling**: Middleware uses `try-catch` blocks to intercept exceptions thrown by subsequent components in the pipeline.

**DN17** — `Channel<T>` is a high-performance, async-native library for producer-consumer scenarios. `BlockingCollection<T>` is a thread-safe collection that uses blocking/waiting (synchronous). 
**Backpressure Example**:
```csharp
var channel = Channel.CreateBounded<int>(10); // Limit capacity to 10
// Producer
await channel.Writer.WriteAsync(1); 
// Consumer
int item = await channel.Reader.ReadAsync();
```
If the producer is faster than the consumer, `WriteAsync` will asynchronously wait once the 10 slots are full, preventing memory exhaustion.

**DN18** — **Source Generators** run during compilation to inspect code and generate additional C# files. 
- **vs Reflection**: Reflection happens at runtime (slow, uses metadata); Generators happen at compile-time (fast, zero runtime cost).
- **vs IL Weaving**: Weaving modifies existing bytecode; Generators add new source code.
**Incremental Generators** are preferred because they use a caching mechanism to only re-run when relevant parts of the syntax tree change, significantly improving IDE performance and build times.

**DN19** — **TPL Dataflow** is a library for building actor-based/pipeline processing systems.
- `ActionBlock`: Receives data and performs an action.
- `TransformBlock`: Receives data, transforms it, and passes it on.
- `BufferBlock`: A simple storage buffer between blocks.
**vs Channels**: `Channels` is a lower-level, highly optimized primitive for passing data between tasks. `TPL Dataflow` is a higher-level framework for building complex, structured processing graphs with built-in concurrency and buffering management.

**DN20** — **Minimal APIs** allow creating HTTP APIs with minimal code/boilerplate, bypassing the heavy Controller pattern.
- **Trade-offs**: Controllers offer better organization for massive APIs; Minimal APIs offer better performance and simplicity for microservices. Testability is similar; Middleware works the same.
- **Route Groups**: Allow grouping endpoints under a common prefix/configuration.
- **Endpoint Filters**: Allow injecting logic (like validation or auth) specifically for certain endpoints, similar to middleware but scoped to the endpoint.

## Python

**P1** — `list` is mutable (can change); `tuple` is immutable. `set` is mutable (unordered, unique elements); `frozenset` is the immutable version of a set.

**P2** — The **GIL** is a mutex that allows only one thread to execute Python bytecode at a time. It affects **CPU-bound** workloads (preventing true parallelism). **Workarounds**: Use `multiprocessing` (separate processes/memory), use C-extensions (which can release the GIL), or use alternative implementations like PyPy or the experimental "nogil" Python.

**P3** — `copy` creates a new object but inserts references to the items in the original. `deepcopy` creates a new object and recursively creates copies of all objects found in the original.
**Example**: If `a = [[1]]` and `b = copy.copy(a)`, then `b[0][0] = 2` will change `a[0][0]` to `2` because the inner list is shared.

**P4** — A decorator is a function that takes another function and extends its behavior without explicitly modifying it.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start}s")
        return result
    return wrapper
```

**P5** — **Generators** are iterators that use `yield` to produce values one at a time, pausing execution and saving state. They are memory-efficient because they don't store the whole list in RAM. `yield from` is used to delegate to a sub-generator (flattening nested generators).

**P6** — The **event loop** manages and distributes execution of asynchronous tasks.
- `asyncio.run()`: The main entry point to run the top-level entry point.
- `asyncio.gather()`: Runs multiple awaitables concurrently and waits for them to finish.
- `asyncio.create_task()`: Schedules a coroutine to run on the loop immediately, returning a Task object.
**Why not `time.sleep()`?** `time.sleep()` is a blocking call that halts the entire thread. Since the event loop runs on a single thread, calling `time.sleep()` stops the loop from processing any other tasks. Use `await asyncio.sleep()` instead.

**P7** — Python uses the **C3 Linearization** algorithm. It handles diamond inheritance by ensuring a class is only visited after all its parents.
**Output**: `C`.
**Reason**: `D` inherits from `B` then `C`. The MRO for `D` is `[D, B, C, A, object]`. When `D().who()` is called, it looks at `D` (not found), then `B` (not found), then `C`. `C` has a `who` method, so it executes that.

**P8** — A **metaclass** is a class of a class; it defines how a class behaves.
- `__init_subclass__`: A simpler way to customize class creation when a class is inherited.
- **Use `__init_subclass__`**: For simple registration or attribute modification of subclasses.
- **Use Metaclass**: For complex logic that requires modifying the class structure before it is even created (e.g., enforcing strict API constraints or modifying the class dictionary).

**P9** — 
- `threading`: Shared memory, good for I/O-bound tasks.
- `multiprocessing`: Separate memory/processes, bypasses GIL, good for CPU-bound tasks.
- `concurrent.futures`: A high-level abstraction for both (using `ThreadPoolExecutor` or `ProcessPoolExecutor`).
**Serialization**: `multiprocessing` requires data to be "pickled" (serialized) to be sent between processes. If an object cannot be pickled (e.g., a database connection or a lambda), it will fail.

**P10** — `__slots__` is a class attribute that tells Python not to use a dynamic `__dict__` for instance attributes, but instead allocate a fixed amount of space for a specific set of attributes.
- **Use it**: To save memory when creating millions of instances of a small class.
- **Prevents**: Adding new attributes to an instance that aren't in `__slots__`.
- **Impact**: Significant memory reduction and slightly faster attribute access.

**P11** — A **virtual environment** is an isolated directory containing a specific Python version and set of packages, preventing dependency conflicts between projects.
- `venv`: Built-in Python module for lightweight environments.
- `virtualenv`: A more feature-rich third-party alternative to `venv`.
- `conda`: A cross-language package and environment manager (handles non-Python dependencies too).

**P12** — **Comprehensions** provide a concise way to create collections.
- `[x for x in l]` (List), `{x: x**2 for x in l}` (Dict), `{x for x in l}` (Set).
- They are generally faster and more readable than `map()` and `filter()` for simple logic. Use `map`/`filter` when you already have a pre-defined function to apply.

**P13** — `==` checks for **equality** (value). `is` checks for **identity** (memory address).
**Object Interning**: Python optimizes memory by reusing objects for small integers (-5 to 256) and certain strings. This is why `a is b` might be `True` for `a=10, b=10`.

**P14** — `*args` collects extra positional arguments into a tuple. `**kwargs` collects extra keyword arguments into a dictionary.
- `/` (Positional-only): Arguments before `/` must be passed positionally.
- `*` (Keyword-only): Arguments after `*` must be passed as `key=value`.

**P15** — Context managers handle setup and teardown (e.g., locking, closing files).
- **`__enter__`/`__exit__`**: The class-based approach.
- **`@contextmanager`**: A decorator-based approach using a generator.
**Example**: A custom lock or a timer:
```python
from contextlib import contextmanager
@contextmanager
def simple_timer():
    start = time.time()
    yield
    print(f"Elapsed: {time.time() - start}")
```

**P16** — Type hinting provides static type information.
- `Union[int, str]`: Can be int OR str.
- `Optional[int]`: Can be int OR None.
- `Literal['a', 'b']`: Must be exactly 'a' or 'b'.
- `TypeVar`: A generic placeholder.
- `Protocol`: Structural subtyping (static duck typing).
**Mypy/Pyright** use these to perform static analysis, catching type errors before the code runs.

**P17** — **Dunder methods** (Double Underscore) implement Python's core logic.
- `__repr__`: Official string representation (for developers/debugging).
- `__str__`: User-friendly string representation (for `print`).
- `__eq__`: Defines equality logic.
- `__hash__`: Defines how to hash the object (required for dict keys).
- `__getattr__`: Called when an attribute is *not* found.
- `__getattribute__`: Called *every* time an attribute is accessed.
**Note**: If you define `__eq__` but not `__hash__`, the class becomes unhashable, and you cannot use it in a `set` or as a `dict` key.

**P18** — **Descriptors** are objects that define how attribute access is handled via `__get__`, `__set__`, and `__delete__`.
- `property` uses a descriptor to implement getters/setters.
- `classmethod` and `staticmethod` are descriptors that modify how the method is bound to the class or instance.

**P19** — Python's import system searches `sys.path` (a list of directories).
- **Absolute**: `import package.module`.
- **Relative**: `from . import module`.
- `__init__.py`: Makes a directory a package.
- **Namespace Packages**: Allow packages to be split across different directories/locations.
- **Finder/Loader**: The low-level mechanism where a *Finder* locates the module and a *Loader* reads the code into memory.
