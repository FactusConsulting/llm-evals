## .NET / C#

**DN1**: **Class** is a reference type (allocated on the heap), while a **struct** is a value type (usually allocated on the stack or inline). Use a struct for small, immutable data structures (e.g., a `Point` or `Color`) where the size is small (typically < 16 bytes) to reduce GC pressure.

**DN2**: `IEnumerable<T>` is for in-memory collections; filtering happens in the application memory. `IQueryable<T>` is for remote data sources (like SQL); it translates LINQ expressions into a provider-specific language (e.g., SQL) to filter data at the database level. This prevents pulling the entire table into memory.

**DN3**: `async/await` uses a state machine to yield control back to the caller while waiting for I/O, preventing thread blocking. `Task` is a class (heap allocation); `ValueTask` is a struct. Use `ValueTask` for methods that often complete synchronously to avoid unnecessary heap allocations.

**DN4**: DI is a pattern where dependencies are provided to a class rather than the class creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (HTTP request).
- **Singleton**: One instance for the app lifetime.
- **Bug**: "Captive Dependency"—injecting a Scoped service into a Singleton. The Scoped service is effectively promoted to a Singleton, potentially causing memory leaks or stale data (e.g., `DbContext` issues).

**DN5**: `string` is an immutable heap object. `ReadOnlySpan<char>` is a window into existing memory (stack, heap, or unmanaged). Use `Span<T>` to perform slicing and parsing without allocating new strings, significantly reducing GC overhead in high-performance scenarios.

**DN6**: The GC uses **Generations**: Gen 0 (short-lived), Gen 1 (buffer), and Gen 2 (long-lived). The **Large Object Heap (LOH)** handles objects > 85KB to avoid expensive memory compaction. `IDisposable` is needed for **unmanaged resources** (file handles, sockets) because the GC only manages memory, not external OS handles.

**DN7**: `ConfigureAwait(false)` tells the task not to marshal the continuation back to the original `SynchronizationContext` (e.g., the UI thread). Use it in library code to prevent deadlocks and improve performance. Do NOT use it in application code where you need to update UI elements.

**DN8**: 
- **Primary Constructors**: Define parameters directly in the class declaration.
- **Collection Expressions**: Use `[]` for arrays/lists (e.g., `int[] x = [1, 2, 3]`).
- **FrozenDictionary**: An immutable dictionary optimized for read-heavy workloads.
Example:
```csharp
public class UserService(IUserRepository repo) // Primary Constructor
{
    public string GetName(int id) => repo.Find(id).Name;
}
```

**DN9**: The `ObjectDisposedException` usually occurs because a `DbContext` (Scoped) is being accessed by multiple concurrent threads or a background task after the request scope has ended. **Fix**: Use `IServiceScopeFactory` to create a new scope for background work, ensuring the `DbContext` is created and disposed within that specific unit of work.

**DN10**: **Record** is a class with value-based equality. **Record struct** is a value type with value-based equality. Use `record` for DTOs/immutable data; `class` for behavior-heavy objects; `record struct` for small, high-performance value objects.

**DN11**: 
- `ref`: Pass by reference (read/write).
- `out`: Pass by reference; must be assigned before returning (write).
- `in`: Pass by reference; read-only (prevents copying large structs).

**DN12**: `T?` for reference types is a compiler-level hint to prevent `NullReferenceException` (static analysis). `int?` (Nullable value type) is actually `Nullable<T>`, a wrapper struct that allows a value type to be null.

**DN13**: **LINQ** (Language Integrated Query) provides a unified way to query data. **Method syntax** uses extension methods/lambdas; **Query syntax** looks like SQL. **Deferred execution** means the query is not executed until the result is iterated (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict the types `T` can be:
- `where T : class`: Must be a reference type.
- `where T : struct`: Must be a value type.
- `where T : new()`: Must have a public parameterless constructor.
- `where T : IComparable<T>`: Must implement the interface.
Combine them (e.g., `where T : class, new()`) to ensure the type is a reference type that can be instantiated.

**DN15**: **Abstract classes** can have state and implementation ("is-a"); **Interfaces** define a contract ("can-do"). Default interface methods (C# 8+) allow interfaces to provide a default implementation, allowing API evolution without breaking existing implementers.

**DN16**: Middleware is a chain of delegates. `Use()` executes logic and calls `next()`; `Map()` branches the pipeline based on the path; `Run()` is terminal (no `next()`). Order matters because requests flow sequentially; exception middleware must be placed first to catch errors from all subsequent middleware.

**DN17**: `Channel<T>` is a high-performance producer-consumer queue. Unlike `BlockingCollection`, it is fully `async`. **Bounded channels** limit capacity; when full, the producer asynchronously waits (backpressure), preventing memory exhaustion.

**DN18**: **Source Generators** produce C# code during compilation. Unlike reflection (runtime) or IL weaving (post-compile), they are type-safe and fast. **Incremental generators** cache results based on input changes, drastically improving IDE performance.

**DN19**: **TPL Dataflow** is a block-based actor model. `ActionBlock` (processes), `TransformBlock` (maps), `BufferBlock` (queues). Compared to `Channels`, Dataflow is higher-level, providing built-in orchestration for complex pipelines.

**DN20**: **Minimal APIs** define endpoints in `Program.cs` without controllers. They reduce boilerplate and startup time. Trade-offs: Controllers provide better organization for huge APIs. Route groups allow shared middleware/auth per group; endpoint filters allow AOP-style logic (validation/logging).

## Python

**P1**: **List** is mutable; **Tuple** is immutable. **Set** is a collection of unique elements; **Frozenset** is an immutable version of a set (can be used as a dictionary key).

**P2**: The **GIL** prevents multiple native threads from executing Python bytecodes at once. It affects CPU-bound workloads. Workarounds: Use `multiprocessing` (separate processes) or C-extensions (NumPy/Pandas) that release the GIL.

**P3**: `copy` (shallow) copies the container but references the original nested objects. `deepcopy` recursively copies everything. 
*Example*: `a = [[1]]`; `b = copy.copy(a)`; `b[0].append(2)` will modify `a` as well.

**P4**: A decorator is a function that wraps another function.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return res
    return wrapper
```

**P5**: **Generators** use `yield` to produce values one-at-a-time (lazy evaluation), saving memory. `yield from` delegates to another generator/iterable.

**P6**: `asyncio` uses a single-threaded event loop. `run()` starts the loop; `gather()` runs multiple coroutines concurrently; `create_task()` schedules a coroutine to run in the background. `time.sleep()` blocks the entire thread, stopping the loop; use `await asyncio.sleep()`.

**P7**: Python uses **C3 Linearization** for MRO. In diamond inheritance, it searches depth-first, left-to-right, but ensures no class is visited before its children. 
*Result*: `D().who()` prints `"C"` because `D` inherits from `B` then `C`. `B` is checked, then `C` is checked. `C` overrides `A`.

**P8**: A **metaclass** is the "class of a class" (defines how classes are created). `__init_subclass__` is a simpler way to customize subclassing without a full metaclass. 
- Metaclass: Enforcing strict API constraints across all subclasses.
- `__init_subclass__`: Registering a subclass in a global registry.

**P9**: 
- `threading`: I/O-bound tasks (GIL limits CPU).
- `multiprocessing`: CPU-bound tasks (bypasses GIL).
- `concurrent.futures`: High-level wrapper for both.
**Pickling**: `multiprocessing` requires objects to be "picklable" (serializable) to be sent between processes.

**P10**: `__slots__` tells Python not to create a `__dict__` for instances. It prevents adding dynamic attributes and significantly reduces memory usage per object.

**P11**: A **virtual environment** isolates dependencies per project. `venv` is the standard library tool; `virtualenv` is an extended version; `conda` manages both Python and non-Python binary dependencies.

**P12**: Comprehensions provide a concise way to create collections. They are generally faster and more readable than `map()` and `filter()`. Use `map/filter` only when using existing functions or for extreme laziness.

**P13**: `==` checks for **value equality**; `is` checks for **identity** (memory address). Python interns small integers (usually -5 to 256), so `a is b` is True for these because they point to the same cached object.

**P14**: `*args` collects positional args into a tuple; `**kwargs` collects keyword args into a dict. `/` marks positional-only arguments; `*` marks keyword-only arguments.

**P15**: Context managers manage resources. `__enter__` sets up, `__exit__` cleans up. `@contextmanager` is a decorator for generator-based managers. 
*Example*: A database transaction manager that commits on success and rolls back on exception.

**P16**: Type hinting provides static analysis. `Union` (A or B), `Optional` (A or None), `Literal` (exact value), `Protocol` (structural typing/interfaces). `mypy` uses these to find bugs before runtime.

**P17**: 
- `__repr__` (developer-facing), `__str__` (user-facing).
- `__eq__` (equality), `__hash__` (for dict keys).
- `__getattr__` (called if attribute isn't found), `__getattribute__` (called every time).
If you define `__eq__` but not `__hash__`, the object becomes unhashable (cannot be a set element or dict key).

**P18**: Descriptors are objects that define `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented as descriptors to intercept attribute access.

**P19**: Python searches `sys.path`. Absolute imports start from the root; relative imports use `.`. `__init__.py` makes a directory a package. Namespace packages (Python 3.3+) allow splitting a package across multiple directories without `__init__.py`.

**P20**: `dataclasses` automate `__init__`, `__repr__`, etc. `__post_init__` allows validation after creation. `frozen=True` makes them immutable. **Pydantic** is preferred over dataclasses when runtime type validation and data parsing (e.g., from JSON) are required.
