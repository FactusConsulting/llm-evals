## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored inline/on stack). Use a **struct** for small, immutable, short-lived data structures (e.g., a `Point` or `Color`) to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ to Objects); it iterates through the collection. **IQueryable<T>** is for out-of-memory providers (LINQ to SQL/EF); it builds an expression tree that is translated into a database query (e.g., `WHERE` clause). The distinction matters because `IEnumerable` pulls all data into memory before filtering, while `IQueryable` filters at the database level.

**DN3** — **async/await** uses a state machine to allow non-blocking asynchronous operations. A **Task** is a class (reference type) representing an ongoing operation. A **ValueTask** is a struct (value type) used when the result might already be available synchronously, avoiding a heap allocation. Use **ValueTask** in high-performance scenarios where the method often completes synchronously.

**DN4** — **Dependency Injection (DI)** is a design pattern where dependencies are provided to a class rather than the class creating them. **Transient**: new instance every time. **Scoped**: once per client request. **Singleton**: one instance for the app lifetime. **Bug**: Injecting a **Scoped** service into a **Singleton** (Captive Dependency) causes the Scoped service to live as long as the Singleton, potentially leading to stale data or disposed object errors.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view of a contiguous memory region. Use **Span<T>** for high-performance slicing and parsing to avoid creating multiple string substrings, which reduces heap allocations and GC pressure.

**DN6** — The **GC** manages memory automatically. **Gen 0** (newly allocated), **Gen 1** (buffer for Gen 0), **Gen 2** (long-lived). **Large Object Heap (LOH)** stores objects >85,000 bytes; it is not compacted by default to avoid expensive memory moves. **IDisposable** is needed to manually release unmanaged resources (file handles, sockets) because the GC only manages managed memory, not OS-level handles.

**DN7** — **ConfigureAwait(false)** tells the runtime not to force the continuation back onto the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in application code (like UI or ASP.NET Core) where you need to return to a specific context (like the UI thread).

**DN8** — **Primary constructors** allow parameters to be defined directly in the class header. **Collection expressions** (`[1, 2, 3]`) simplify array/list creation. **FrozenDictionary** is a read-only, highly optimized dictionary for lookups.
```csharp
// Minimal example with Primary Constructor
public class UserService(IUserRepository repo) {
    public string GetName(int id) => repo.Find(id).Name;
}
```

**DN9** — **Cause**: Multiple threads are likely sharing a single `DbContext` instance (which is not thread-safe). **Fix**: Ensure `DbContext` is registered as **Scoped** and do not use it across multiple threads. If running parallel tasks, use `IServiceScopeFactory` to create a new scope/context per task.

**DN10** — **record** is a class with value-based equality. **record struct** is a value type with value-based equality. Use **record** for DTOs/Data objects where identity is defined by data; use **class** when you need reference identity or complex inheritance.

**DN11** — **ref**: Pass by reference (read/write, must be initialized). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only, prevents copying large structs).

**DN12** — **Nullable reference types** (`string?`) are compiler hints to prevent null-reference exceptions. **Nullable value types** (`int?`) are actual `Nullable<T>` wrappers that allow a value type to represent `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query is not executed until you iterate over the results (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement comparison). Combine them: `where T : class, new()`.

**DN15** — **Abstract class** can have implementation and state; **Interface** is a pure contract (though C# 8+ allows default implementations). Default methods allow interfaces to evolve without breaking implementers, but abstract classes are still preferred for shared state/logic.

**DN16** — **Middleware** is a pipeline of components. **app.Use()** adds middleware that can call the next. **app.Map()** branches the pipeline. **app.Run()** is a terminal middleware. **Ordering** is critical: Exception handling must be near the start to catch errors in subsequent middleware.

**DN17** — **Channel<T>** is an async-native producer-consumer collection. **BlockingCollection<T>** is synchronous/thread-based. Use **Bounded Channels** (`Channel.CreateBounded<T>(capacity)`) to implement backpressure, where the producer waits if the channel is full.

**DN18** — **Source Generators** produce code at compile time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (post-compile modification), they are part of the compilation process. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving build times.

**DN19** — **TPL Dataflow** is an actor-based library. **ActionBlock** (consumer), **TransformBlock** (map), **BufferBlock** (queue). **Channels** are lighter and better for simple async streams; **TPL Dataflow** is better for complex, multi-stage processing pipelines with built-in buffering and concurrency limits.

**DN20** — **Minimal APIs** use a functional approach to define endpoints without Controllers. **Trade-offs**: Faster startup/less boilerplate, but harder to organize large-scale logic. **Route groups** organize endpoints by path; **Endpoint filters** allow cross-cutting concerns (like auth/validation) to be applied to specific routes.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is unordered and contains unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** is a mutex that allows only one thread to hold control of the Python interpreter at a time. It affects **CPU-bound** workloads. **Workarounds**: Use `multiprocessing` (separate interpreters) or C-extensions (releasing the GIL).

**P3** — **copy** (shallow) creates a new container but references the same nested objects. **deepcopy** creates a new container and recursively copies all nested objects. **Example**: If `a = [[1]]`, `b = a.copy()`, then `b[0].append(2)` changes `a` as well.

**P4** — **Decorators** wrap a function to extend behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily, one at a time, saving memory. Unlike a list, they don't store all values in memory. **yield from** is used to delegate to a sub-generator or iterable.

**P6** — **asyncio.run()** is the entry point; **asyncio.gather()** runs multiple coroutines concurrently; **asyncio.create_task()** schedules a coroutine to run in the background. You cannot use `time.sleep()` because it blocks the entire thread, stopping the event loop; use `asyncio.sleep()`.

**P7** — Python uses **C3 Linearization** for MRO. In the diamond `D(B, C)`, the order is `D -> B -> A -> C -> A`. `D().who()` prints **"C"** because `C` is searched before `A` in the MRO of `D`.

**P8** — A **metaclass** is a class of a class (it defines how classes are created). **__init_subclass__** is a simpler way to customize class creation without a full metaclass. Use `__init_subclass__` for simple registration; use a **metaclass** for complex logic like modifying class attributes or enforcing strict API contracts.

**P9** — **Threading** (I/O-bound), **Multiprocessing** (CPU-bound, bypasses GIL), **concurrent.futures** (high-level abstraction for both). **Multiprocessing** requires **pickling** (serializing) data to move it between processes, which can be slow for large objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This significantly reduces memory usage and prevents the creation of dynamic attributes.

**P11** — A **virtual environment** isolates dependencies for a project. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party tool; **conda** is a package/environment manager used heavily in data science for managing non-Python binaries.

**P12** — **Comprehensions** are more readable and often faster than `map()`/`filter()`. Use comprehensions for most cases; use `map`/`filter` when working with existing functions or complex logic.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). Small integers (-5 to 256) are **interned** (cached) by Python, so `a is b` returns `True` for them.

**P14** — `*args` collects extra positional arguments into a tuple; `**kwargs` collects extra keyword arguments into a dictionary. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context Managers** handle setup/teardown (e.g., closing files). Use `__enter__`/`__exit__` in a class or `@contextmanager` on a generator. **Example**: A database transaction manager that commits on success and rolls back on exception.

**P16** — **Type hinting** provides static type information. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1, 2]` (only 1 or 2), `TypeVar` (generic), `Protocol` (structural typing/duck typing). **Mypy/Pyright** use these to find type errors without running the code.

**P17** — `__repr__` is for developers (unambiguous); `__str__` is for users (readable). `__eq__` is for value equality; `__hash__` allows an object to be used in sets/dicts. `__getattr__` is a fallback for missing attributes; `__getattribute__` is called for *every* attribute access. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that define how attribute access works via `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors.

**P19** — **Absolute imports** start from the root; **relative imports** use dots (`.`). `sys.path` is the list of directories searched. `__init__.py` makes a directory a package. **Finders** locate modules; **Loaders** execute the code to create the module object.

**P20** — **Dataclasses** (std lib) are for simple data containers. **attrs** is more powerful. **Pydantic** is for data validation and parsing (essential for APIs). Use **Pydantic** when you need to ensure incoming data matches a schema; use **dataclasses** for internal logic.
