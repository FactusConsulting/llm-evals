## .NET / C#

**DN1** — **Class** is a reference type (allocated on the heap), while **struct** is a value type (usually allocated on the stack or inline). Use a **struct** for small, immutable data structures (typically < 16 bytes) that have no identity and are short-lived to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects); it iterates through the collection. **IQueryable<T>** is for out-of-memory providers (LINQ-to-SQL/EF); it uses expression trees to translate queries into provider-specific language (like SQL). This distinction matters because `IQueryable` allows for "server-side" filtering, whereas `IEnumerable` pulls all data into memory before filtering ("client-side").

**DN3** — **async/await** uses a state machine to allow non-blocking I/O. A **Task** represents an asynchronous operation and is a class (heap allocation). A **ValueTask** is a struct; use it when the result of an operation is often already available synchronously (e.g., reading from a cached buffer) to avoid the overhead of allocating a `Task` object on the heap.

**DN4** — **Dependency Injection (DI)** is a pattern where dependencies are provided to a class rather than the class creating them. 
- **Transient**: New instance every time it's requested.
- **Scoped**: One instance per client request (e.g., per HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Common Bug**: "Captive Dependency"—injecting a **Scoped** service into a **Singleton**. The Scoped service is now held alive as long as the Singleton, effectively turning it into a Singleton and potentially causing stale data or concurrency issues.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view into a contiguous region of memory (string, array, etc.). Use **Span<T>** for high-performance parsing or slicing to avoid creating multiple substring allocations on the heap.

**DN6** — The **GC** manages memory automatically. **Gen 0** is for new, short-lived objects; **Gen 1** is the buffer between Gen 0 and 2; **Gen 2** is for long-lived objects. The **Large Object Heap (LOH)** is for objects > 85,000 bytes, collected only during Gen 2 collections. **IDisposable** is needed because the GC only manages *managed* memory; you must manually release *unmanaged* resources (file handles, database connections, sockets) via `Dispose()`.

**DN7** — **ConfigureAwait(false)** tells the runtime that the continuation does not need to run on the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in application code (like UI or ASP.NET Core controllers) where you need to return to a specific context (like the UI thread).

**DN8** — **Primary Constructors** allow parameters to be defined directly in the class header. **Collection Expressions** (`[1, 2, 3]`) provide a unified syntax for arrays/lists. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Minimal example with Primary Constructor and DI
public class UserService(IUserRepository repo) {
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9** — The cause is likely a **Captive Dependency** or a **Concurrency Violation** where a single `DbContext` (which is not thread-safe) is being accessed by multiple threads simultaneously. This happens if a Scoped `DbContext` is injected into a Singleton or a background task. **Fix**: Use `IServiceScopeFactory` to create a new scope manually within the background task to ensure a fresh, thread-local `DbContext`.

**DN10** — **record** is a class with value-based equality. **record struct** is a value type with value-based equality. Use **record** for complex DTOs/objects; use **record struct** for small, high-performance data packets.

**DN11** — **ref**: Pass by reference (read/write); must be initialized. **out**: Pass by reference; must be assigned inside the method. **in**: Pass by reference; read-only (prevents modification).

**DN12** — **Nullable Reference Types** (`string?`) are compiler hints to help prevent `NullReferenceException`. They do not change the underlying type. **Nullable Value Types** (`int?`) are actually `Nullable<T>`, a wrapper that allows a value type to represent `null`.

**DN13** — **LINQ** (Language Integrated Query) allows querying collections. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses SQL-like keywords (`from...in`). **Deferred execution** means the query is not executed when defined, but only when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement comparison). Combine them to restrict `T` to a specific subset (e.g., `where T : class, new()`).

**DN15** — **Abstract class** can have state (fields) and implementation; it defines "what an object is." **Interface** defines "what an object can do" (contract). **Default interface methods** allow interfaces to provide a default implementation, blurring the line by allowing interfaces to behave more like abstract classes.

**DN16** — **Middleware** is a pipeline of components. **app.Use()** adds middleware that can call the next component. **app.Map()** branches the pipeline. **app.Run()** is a terminal middleware (stops the pipeline). **Ordering matters**: Exception handling middleware must be near the start to catch errors from subsequent components.

**DN17** — **Channel<T>** is an async-capable producer-consumer collection. **BlockingCollection<T>** is synchronous/blocking. Use **Bounded Channels** (`Channel.CreateBounded<T>(capacity)`) to implement backpressure: when the channel is full, the producer's `WriteAsync` will asynchronously wait until space is available.

**DN18** — **Source Generators** create code at compile-time. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are part of the compilation process. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE and build performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumer), **TransformBlock** (processor), and **BufferBlock** (queue). **Channels** are lighter and better for simple async streaming; **TPL Dataflow** is better for complex, multi-stage processing graphs with built-in buffering and parallelism.

**DN20** — **Minimal APIs** use a functional approach to define endpoints without Controllers. **Trade-offs**: They are faster and have less boilerplate, but can become messy in large apps. **Route groups** allow shared prefixes, and **Endpoint Filters** allow cross-cutting concerns (like validation) to be applied to specific routes.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is a collection of unique elements; **Frozenset** is an immutable version of a set.

**P2** — The **GIL** is a mutex that protects access to Python objects, preventing multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** workloads. **Workarounds**: Use `multiprocessing` to bypass the GIL by using separate memory spaces, or use C-extensions (like NumPy) that release the GIL during heavy computation.

**P3** — **copy** creates a shallow copy (new object, but references to nested objects remain the same). **deepcopy** creates a new object and recursively copies all nested objects. **Unexpected behavior**: If you have a list of lists, changing a nested list in a shallow copy will change it in the original.

**P4** — **Decorators** wrap a function to modify its behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values one by one, maintaining state, which is memory efficient. Unlike a **list**, they don't store all values in memory. **yield from** is used to delegate to a sub-generator (flattening).

**P6** — The **event loop** manages async tasks. **asyncio.run()** is the entry point; **asyncio.gather()** runs multiple tasks concurrently; **asyncio.create_task()** schedules a task to run in the background. You cannot use `time.sleep()` because it is a blocking call that stops the entire thread, preventing the event loop from processing other tasks.

**P7** — Python uses **C3 Linearization** for MRO. In a diamond inheritance (`D(B, C)`), Python looks at `D`, then `B`, then `C`, then `A`. In the code, `D().who()` prints **"C"** because `C` is searched before `A` in the MRO of `D`.

**P8** — A **metaclass** is a class that creates classes. Use **__init_subclass__** for simple class-level setup (like registering subclasses). Use a **metaclass** when you need to fundamentally alter how classes are constructed (e.g., enforcing strict API constraints or modifying attributes).

**P9** — **threading** is for I/O-bound tasks; **multiprocessing** is for CPU-bound tasks (bypasses GIL); **concurrent.futures** provides a high-level interface for both. **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be slow for large objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This significantly reduces memory usage and prevents the accidental creation of new attributes.

**P11** — A **virtual environment** isolates dependencies for a specific project. **venv** is the standard library tool; **virtualenv** is a faster, more feature-rich third-party alternative; **conda** is a package/environment manager used heavily in data science for managing non-Python binaries.

**P12** — **Comprehensions** are concise ways to create collections. They are generally more readable and faster than `map()` and `filter()`. Use comprehensions for most cases; use `map`/`filter` when you already have a pre-defined function.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (memory address). **Object interning** caches small integers (-5 to 256) and certain strings to save memory; this is why `a is b` can be True for small integers.

**P14** — `*args` collects extra positional arguments into a tuple; `**kwargs` collects extra keyword arguments into a dictionary. `/` marks parameters that must be **positional-only**; `*` marks parameters that must be **keyword-only**.

**P15** — **Context managers** handle setup/teardown (e.g., `with`). You can use `__enter__`/`__exit__` in a class or the `@contextmanager` decorator. Example: A database transaction manager.

**P16** — **Type hinting** improves code clarity and enables static analysis. `Union[int, str]` (int or str), `Optional[int]` (int or None), `Literal["a", "b"]` (only these values), `TypeVar` (generic types), and `Protocol` (structural/duck typing). **Mypy/Pyright** use these to find bugs without running the code.

**P17** — **\_\_repr\_\_** is for developers (unambiguous); **\_\_str\_\_** is for users (readable). **\_\_eq\_\_** is for value equality; **\_\_hash\_\_** allows an object to be a dictionary key. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that define how attribute access works via `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors.

**P19** — **Absolute imports** start from the project root; **relative** imports use `.` notation. `sys.path` is the list of directories searched for modules. `__init__.py` makes a directory a package. A **finder** locates the module, and a **loader** reads the code.

**P20** — **dataclasses** are for data storage; **attrs** is more powerful; **Pydantic** is for data validation/parsing. Use **Pydantic** when dealing with external data (APIs) where validation is critical. `__post_init__` runs after the constructor; `frozen=True` makes the dataclass immutable.
