## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap), while **struct** is a value type (stored inline/on the stack). Use a **struct** for small, immutable data structures (typically < 16 bytes) to reduce GC pressure and avoid heap allocation.

**DN2** — **IEnumerable<T>** is for in-memory collections; iterating it executes the logic in-memory. **IQueryable<T>** uses expression trees to translate LINQ into provider-specific queries (like SQL). This matters because `IQueryable` allows "filtering at the source" (database level), whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — **async/await** allows non-blocking asynchronous programming by yielding control back to the caller while waiting for an operation to complete via a state machine. A **Task** represents an ongoing operation. A **ValueTask** is a value-type wrapper used to reduce allocations when the result is often already available synchronously. Use `ValueTask` in high-performance paths where the operation frequently completes synchronously.

**DN4** — **Dependency Injection (DI)** is a pattern where objects receive their dependencies from an external source rather than creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., per HTTP request).
- **Singleton**: One instance for the lifetime of the app.
**Common Bug**: "Captive Dependency"—injecting a **Scoped** service into a **Singleton**. The Scoped service stays alive as long as the Singleton, effectively turning it into a Singleton and potentially causing stale data or concurrency issues.

**DN5** — **string** is a heap-allocated, immutable object. **ReadOnlySpan<char>** is a stack-allocated view into a contiguous memory region (string, array, or unmanaged memory). Use **Span<T>** for high-performance parsing/slicing to avoid creating multiple substring allocations on the heap.

**DN6** — The **GC** manages memory using generations: **Gen 0** (newly allocated), **Gen 1** (buffer), and **Gen 2** (long-lived). **Large Object Heap (LOH)** is for objects > 85,000 bytes, which are collected less frequently. **IDisposable** is needed because the GC only manages memory; it does not know how to release unmanaged resources like file handles or database connections.

**DN7** — **ConfigureAwait(false)** tells the runtime not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread to update the interface.

**DN8** — **Primary Constructors** allow parameters to be defined directly on the class header. **Collection Expressions** (`[1, 2, 3]`) simplify array/list creation. **FrozenDictionary** is a highly optimized, read-only dictionary.
```csharp
// Minimal example with DI
public class MyService(IDbContext db) // Primary constructor
{
    public void DoWork() => db.Execute();
}
```

**DN9** — **Cause**: Multiple threads are likely sharing a single `DbContext` instance (which is not thread-safe) or a Scoped `DbContext` is being accessed after its scope has closed. **Fix**: Use `IDbContextFactory` to create a new context per operation or ensure the `DbContext` is not shared across concurrent tasks. In DI, `DbContext` is typically registered as **Scoped**.

**DN10** — **record** provides value-based equality and is optimized for immutable data. **class** provides reference equality. A **record struct** is a value-type version of a record (value-based equality, stack-allocated). Use **record** for DTOs/Data models; use **class** for complex logic/identity-based objects.

**DN11** — **ref**: Pass by reference (read/write, must be initialized). **out**: Pass by reference (write-only, must be assigned inside the method). **in**: Pass by reference (read-only, prevents copying of large structs).

**DN12** — **Nullable reference types** (`string?`) are a compiler feature to prevent `NullReferenceException` by tracking nullability. **Nullable value types** (`int?`) are syntactic sugar for `Nullable<T>`, allowing a value type to hold a `null` state.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses a SQL-like structure (`from x in...`). **Deferred execution** means the query is not executed when defined, but only when the collection is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints** restrict the types allowed for `T`. 
- `T : class` (reference type).
- `T : struct` (value type).
- `T : new()` (must have a parameterless constructor).
- `T : IComparable<T>` (must implement comparison).
Combine them to narrow the scope: `where T : class, new()`.

**DN15** — **Abstract class** can have state (fields) and implementation. **Interface** is a contract. **Default interface methods** allow interfaces to provide a default implementation, reducing the need for abstract classes when adding new methods to existing interfaces without breaking implementers.

**DN16** — **Middleware** is a pipeline of components. **app.Use()** can call the next component; **app.Map()** branches the pipeline; **app.Run()** is a terminal middleware. **Ordering** is critical (e.g., Exception Handling must be first, then Auth, then Routing).

**DN17** — **Channel<T>** is an async-native producer-consumer collection. **BlockingCollection<T>** is a synchronous, thread-based collection. Use **Bounded Channels** to implement backpressure: if the channel is full, the producer's `WriteAsync` will asynchronously wait, preventing memory exhaustion.

**DN18** — **Source Generators** create code at compile-time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (post-compile modification), they are part of the compilation process. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumes data), **TransformBlock** (processes/transforms), and **BufferBlock** (holds data). **Channels** are lighter and better for simple producer-consumer; **Dataflow** is better for complex, branching processing graphs.

**DN20** — **Minimal APIs** are lightweight, high-performance endpoints. **Trade-offs**: They offer less structure than Controllers, making large apps harder to organize, but they are faster and have less overhead. **Route groups** organize endpoints, and **Endpoint Filters** act like middleware for specific routes.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is a mutable collection of unique elements; **Frozenset** is the immutable version.

**P2** — The **GIL** is a mutex that protects access to Python objects, preventing multiple threads from executing Python bytecodes at once. It affects **CPU-bound** workloads. **Workarounds**: Use `multiprocessing` to bypass the GIL by using separate memory spaces.

**P3** — **copy** (shallow) creates a new container but references the same nested objects. **deepcopy** creates a new container and recursively copies all nested objects. **Example**: If you shallow copy a list containing another list, modifying the inner list in the copy affects the original.

**P4** — Decorators wrap a function to extend behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily one by one, saving memory. Unlike a list, they don't store all values in RAM. **yield from** is used to delegate to a sub-generator (flattening).

**P6** — The **event loop** manages async tasks. **asyncio.run()** is the entry point; **asyncio.gather()** runs multiple coroutines concurrently; **asyncio.create_task()** schedules a coroutine to run in the background. You cannot use `time.sleep()` because it blocks the entire thread, stopping the event loop; use `asyncio.sleep()`.

**P7** — Python uses **C3 Linearization** for MRO. In `D(B, C)`, the order is `D -> B -> C -> A`. In the code, `D().who()` looks at `D` (no), then `B` (no), then `C` (yes). It prints **"C"**.

**P8** — A **metaclass** is a class that creates classes. **\_\_init\_\_subclass\_\_** is a simpler way to customize class creation. Use `__init_subclass__` for simple registry/setup; use a **metaclass** for deep manipulation of class attributes or enforcing strict API contracts.

**P9** — **Threading**: I/O-bound tasks (shared memory). **Multiprocessing**: CPU-bound tasks (separate memory). **concurrent.futures**: A high-level abstraction for both. **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be slow or fail for complex objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This significantly reduces memory usage and speeds up attribute access, but prevents adding new attributes at runtime.

**P11** — A **virtual environment** isolates dependencies for a project. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party tool; **conda** is a package/environment manager used heavily in data science for managing non-Python binaries.

**P12** — **Comprehensions** are concise ways to create collections. They are generally preferred over `map()` and `filter()` for readability. Use them when the logic is simple; use `map/filter` when applying existing functions.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (memory address). **Object interning** caches small integers and certain strings to save memory; this is why `a is b` might be true for small integers.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` forces arguments to be **positional-only**; `*` forces arguments to be **keyword-only**.

**P15** — **Context managers** handle setup/teardown (e.g., `with`). You can use a class with `__enter__`/`__exit__` or the `@contextmanager` decorator. Example: A database connection manager or a custom timer.

**P16** — **Type hinting** provides static type info. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generics), and `Protocol` (structural typing/duck typing). Tools like **mypy** use these to find bugs without running the code.

**P17** — **\_\_repr\_\_** is for developers (unambiguous); **\_\_str\_\_** is for users (readable). **\_\_eq\_\_** is value equality; **\_\_hash\_\_** allows an object to be used in sets/dicts. **\_\_getattr\_\_** is a fallback for missing attributes; **\_\_getattribute\_\_** is called for *every* attribute access. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that define `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors that manage how attributes are accessed or called.

**P19** — **Absolute imports** use the full path from the project root; **relative** uses `.` or `..`. **sys.path** is the list of directories searched for modules. `__init__.py` makes a directory a package. **Finders** locate modules; **Loaders** turn them into module objects.

**P20** — **Dataclasses** (std lib) are for simple data containers. **attrs** is more powerful/flexible. **Pydantic** is designed for **data validation** (parsing). Use **Pydantic** for API schemas/external data; use **dataclasses** for internal logic. `__post_init__` runs after the constructor.
