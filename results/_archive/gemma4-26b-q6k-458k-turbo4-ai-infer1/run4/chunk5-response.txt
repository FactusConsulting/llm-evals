## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored inline/on the stack). Use a **struct** for small, immutable, data-centric objects (typically < 16 bytes) to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects). **IQueryable<T>** is for expression trees (LINQ-to-SQL/EF). This matters because `IQueryable` allows the provider to translate the expression into a database query (SQL), whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — **async/await** uses a state machine to perform non-blocking I/O. A **Task** represents an ongoing operation; a **ValueTask** is a value-type wrapper for a Task. Use **ValueTask** when a method often completes synchronously to avoid the heap allocation of a `Task` object.

**DN4** — **Dependency Injection (DI)** is a design pattern for achieving Inversion of Control. **Lifetimes**: **Transient** (new instance every time), **Scoped** (once per client request), **Singleton** (one instance for the app lifetime). **Bug**: Injecting a **Scoped** service into a **Singleton** (Captive Dependency) causes the Scoped service to live as long as the Singleton, often leading to stale data or disposed DB contexts.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view into memory. Use **Span<T>** for high-performance slicing and parsing to avoid creating multiple string allocations on the heap.

**DN6** — The **GC** manages memory in **Generations**: **Gen 0** (newest/short-lived), **Gen 1** (buffer), **Gen 2** (long-lived). The **Large Object Heap (LOH)** holds objects > 85,000 bytes; it is not compacted by default, which can lead to fragmentation. **IDisposable** is required to manually release unmanaged resources (file handles, DB connections) that the GC does not track.

**DN7** — **ConfigureAwait(false)** tells the task not to attempt to marshal back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. **Do NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread to update elements.

**DN8** — **Primary Constructors** allow parameters directly on the class declaration. **Collection Expressions** use `[]` for concise initialization. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Example: Primary Constructor with DI
public class UserService(IUserRepository repo) 
{
    public void DoWork() => repo.GetUsers();
}
```

**DN9** — **Cause**: Multiple threads are likely sharing a single **Scoped** `DbContext` instance (e.g., via `Task.WhenAll` on a single service). **Fix**: Use `IDbContextFactory` to create a new context per operation, or ensure each thread/task creates its own scope.

**DN10** — **record** is a reference type with value-based equality. **record struct** is a value type with value-based equality. Use **record** for immutable DTOs; use **class** for complex logic/identity; use **record struct** for small, high-performance value types.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned before returning). **in**: Pass by reference (read-only). Use `in` for large structs to avoid copying while ensuring immutability.

**DN12** — **Nullable Reference Types** (`string?`) are compiler hints to prevent `NullReferenceException`. **Nullable Value Types** (`int?`) are actual `Nullable<T>` wrappers that allow a value type to represent `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** is fluent (`.Where()`); **Query syntax** is SQL-like (`from x in...`). **Deferred execution** means the query is not executed until the collection is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement comparison). Combine them to narrow the type requirements (e.g., `where T : class, new()`).

**DN15** — **Abstract class** defines "is-a" (can have state/fields). **Interface** defines "can-do" (contract). **Default interface methods** allow interfaces to provide implementation, reducing breaking changes when adding new methods to existing interfaces.

**DN16** — **Middleware** is a pipeline of components. **app.Use()** (calls next), **app.Map()** (branches), **app.Run()** (terminal). **Ordering** matters: Auth must come before Routing. **Exception handling** middleware should be placed at the start of the pipeline to catch errors from all subsequent steps.

**DN17** — **Channel<T>** is an async producer-consumer library. **BlockingCollection<T>** is synchronous. For backpressure, use a **Bounded Channel** (e.g., `Channel.CreateBounded<T>(capacity)`); the producer will asynchronously wait when the channel is full.

**DN18** — **Source Generators** create code at compile-time. Unlike **Reflection** (runtime overhead) or **IL Weaving** (post-compile), they are safe and fast. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumer), **TransformBlock** (mapper), **BufferBlock** (queue). **Channels** are lighter and better for simple async streams; **Dataflow** is better for complex, multi-stage processing with built-in buffering and parallelism.

**DN20** — **Minimal APIs** are lightweight, reducing boilerplate compared to **Controllers**. **Trade-offs**: Controllers offer better organization for massive APIs; Minimal APIs are faster for microservices. **Route groups** allow shared prefixes/middleware, and **Endpoint filters** allow cross-cutting concerns (like validation) at the endpoint level.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is unordered and contains unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, limiting CPU-bound multi-threading. **Workarounds**: Use `multiprocessing` to bypass the GIL via separate processes or use C-extensions (like NumPy) that release the GIL.

**P3** — **copy** is a shallow copy (references nested objects); **deepcopy** is a recursive copy. **Example**: If `a = [[1]]` and `b = copy.copy(a)`, then `b[0].append(2)` also changes `a[0]`.

**P4** — **Decorators** wrap a function to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily (one at a time), saving memory. **yield from** is used to delegate to a sub-generator (flattening).

**P6** — The **event loop** manages async tasks. **asyncio.run()** starts the loop; **asyncio.gather()** runs multiple tasks concurrently; **asyncio.create_task()** schedules a task to run in the background. **time.sleep()** is blocking and will freeze the entire event loop; use `await asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization** for MRO. In the diamond `D(B, C)`, the order is `D -> B -> C -> A`. Since `B` doesn't have `who`, it checks `C`. **Result**: `"C"`.

**P8** — **Metaclass** is a class that creates classes. **\_\_init\_subclass\_\_** is a simpler way to customize class creation. Use `__init_subclass__` for simple setup (e.g., registering subclasses); use a **metaclass** for deep control over class construction/metaprogramming.

**P9** — **Threading** (I/O bound), **Multiprocessing** (CPU bound). **concurrent.futures** provides a high-level interface for both. **Multiprocessing** requires **pickling** (serializing) data to send it between processes, which can be slow for large objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for instances, saving memory and preventing the dynamic creation of new attributes.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party tool; **conda** is a package/environment manager used heavily in data science for non-Python dependencies.

**P12** — **Comprehensions** are concise syntax for creating collections. They are generally faster and more "Pythonic" than `map()`/`filter()`, which are functional-style.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (-5 to 256) to save memory, which is why `a is b` returns `True` for those values.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword.

**P15** — **Context Managers** handle setup/teardown. Use `__enter__`/`__exit__` in a class or `@contextmanager` decorator. **Example**: A database transaction manager.

**P16** — **Type hinting** provides static analysis. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generics), and `Protocol` (structural/duck typing). **mypy** uses these to catch type errors before runtime.

**P17** — **\_\_repr\_\_** is for developers; **\_\_str\_\_** is for users. **\_\_eq\_\_** is for value equality; **\_\_hash\_\_** allows an object to be used in sets/dicts. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** implement the descriptor protocol (`__get__`, `__set__`, `__delete__`). `property`, `classmethod`, and `staticmethod` are all built-in descriptors.

**P19** — **Absolute imports** use the full path from the project root; **relative** use dots (`.`). `sys.path` is the search list; `PYTHONPATH` is an env var to extend it. `__init__.py` makes a directory a package. **Finders** locate modules; **Loaders** execute them.

**P20** — **Dataclasses** (std lib) are for data storage. **attrs** is more powerful; **Pydantic** is for runtime data validation/parsing. Use **Pydantic** for API/boundary validation; use **dataclasses** for internal logic. `__post_init__` handles logic after initialization.
