## .NET / C#

**DN1** — **Class** is a reference type (allocated on the heap), while **struct** is a value type (usually allocated on the stack or inline). Use a **struct** for small, immutable data structures (e.g., a `Point` or `Color`) to reduce GC pressure and heap allocations.

**DN2** — `IEnumerable<T>` is for in-memory collections (LINQ-to-Objects); it iterates through the collection. `IQueryable<T>` is for out-of-memory providers (LINQ-to-SQL/EF); it uses expression trees. This distinction matters because `IQueryable` allows the provider to translate the query into SQL, executing the filter on the database server rather than pulling all rows into memory.

**DN3** — `async/await` provides non-blocking asynchronous programming via a state machine. A `Task` is a class (reference type) representing an ongoing operation. A `ValueTask<T>` is a struct; use it when the result is often already available synchronously (e.g., reading from a cached buffer) to avoid the heap allocation of a `Task`.

**DN4** — **Dependency Injection (DI)** is a technique to achieve Inversion of Control. **Transient** services are created every time they are requested; **Scoped** services are created once per client request; **Singleton** services are created once for the app lifetime. A common bug is **Captive Dependency**: injecting a Scoped service into a Singleton, causing the Scoped service to live as long as the Singleton, potentially leading to stale data or disposed object errors.

**DN5** — `string` is a heap-allocated, immutable object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory. Use `Span<T>`/`ReadOnlySpan<T>` for high-performance parsing or slicing to avoid creating multiple string substrings, which reduces allocations and GC pressure.

**DN6** — The GC manages memory in generations: **Gen 0** (newly allocated, frequent collections), **Gen 1** (buffer), and **Gen 2** (long-lived). The **Large Object Heap (LOH)** handles objects >85,000 bytes and is not compacted by default. **IDisposable** is required to manually release **unmanaged resources** (file handles, DB connections) because the GC only manages managed memory, not OS-level handles.

**DN7** — `ConfigureAwait(false)` tells the runtime not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread to update the interface.

**DN8** — **Primary constructors** allow parameters in the class declaration. **Collection expressions** (`[]`) simplify array/list initialization. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Example: Primary constructor with DI
public class UserService(IUserRepository repo) {
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9** — The `ObjectDisposedException` under high concurrency usually means a `DbContext` (which is **Scoped**) is being accessed by multiple threads simultaneously. `DbContext` is **not thread-safe**. The fix is to ensure you aren't sharing a single Scoped instance across multiple `Task.Run` calls; instead, create a new scope or use a `IDbContextFactory`.

**DN10** — A **record** provides value-based equality and is a reference type. A **record struct** provides value-based equality but is a value type. Use `record` for DTOs/data containers where identity is defined by data; use `class` when you need reference identity or complex inheritance.

**DN11** — `ref` (pass by reference, must be initialized before passing), `out` (pass by reference, must be assigned inside the method), and `in` (pass by reference, read-only/cannot be modified).

**DN12** — **Nullable Reference Types** (`string?`) are compiler hints to prevent `NullReferenceException`. **Nullable Value Types** (`int?`) are syntactic sugar for `Nullable<T>`, a struct that wraps a value and a boolean.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`); **Query syntax** uses a SQL-like structure (`from x in...`). **Deferred execution** means the query is not executed when defined, but only when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — Constraints: `where T : class` (reference type), `where T : struct` (value type), `where T : new()` (must have parameterless constructor), `where T : IComparable<T>` (must implement comparison). You combine them like `where T : class, new()`.

**DN15** — An **abstract class** can have state (fields) and implementation. An **interface** is a contract. **Default interface methods** allow interfaces to provide a default implementation, blurring the line but still maintaining that interfaces cannot hold instance state.

**DN16** — The **middleware pipeline** processes requests sequentially. `app.Use()` adds middleware that can call the next; `app.Map()` branches the pipeline; `app.Run()` is a terminal middleware. Order matters (e.g., Auth must come before Routing). Exception handling middleware should be placed early in the pipeline to catch errors from subsequent steps.

**DN17** — `Channel<T>` is an async-capable producer-consumer collection. `BlockingCollection<T>` is synchronous/thread-based. For **backpressure**, use a **bounded channel** (`Channel.CreateBounded<T>(capacity)`); when the capacity is reached, the producer's `WriteAsync` will asynchronously wait, preventing memory exhaustion.

**DN18** — **Source Generators** produce code at compile time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (post-compile modification), they are part of the compilation process. **Incremental generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. `ActionBlock` (consumer), `TransformBlock` (processor), and `BufferBlock` (queue). Compared to `Channels`, `Dataflow` is more complex and better for heavy DAG (Directed Acyclic Graph) processing, while `Channels` are lighter for simple producer-consumer patterns.

**DN20** — **Minimal APIs** are lightweight, high-performance endpoints defined directly in `Program.cs`. They differ from **Controllers** by having less boilerplate. Trade-offs: Controllers are better for large, complex enterprise apps; Minimal APIs are better for microservices. **Route groups** organize endpoints, and **endpoint filters** allow cross-cutting concerns (like validation) to be applied to specific groups.

## Python

**P1** — A **list** is mutable and ordered; a **tuple** is immutable and ordered. A **set** is a mutable collection of unique elements; a **frozenset** is the immutable version of a set.

**P2** — The **GIL** is a mutex that allows only one thread to hold control of the Python interpreter at a time. It affects **CPU-bound** workloads (making threading ineffective for parallelism). Workarounds include using `multiprocessing` or writing C-extensions that release the GIL.

**P3** — `copy` is a **shallow copy** (new object, but nested objects are shared references); `deepcopy` creates a new object and recursively copies all nested objects. *Example:* If `a = [[1]]`, `b = copy(a)` results in `b[0][0] = 2` changing `a[0][0]` to `2`.

**P4** — Decorators wrap functions.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily, one at a time, saving memory. `yield from` is used to delegate to a sub-generator (flattening). Unlike a list, a generator does not store all elements in memory at once.

**P6** — The **event loop** manages async tasks. `asyncio.run()` starts the loop; `asyncio.gather()` runs multiple coroutines concurrently; `asyncio.create_task()` schedules a coroutine to run. You cannot use `time.sleep()` because it is **blocking**; it stops the entire thread, preventing the event loop from processing other tasks. Use `asyncio.sleep()`.

**P7** — Python uses **C3 Linearization** for MRO. In `D(B, C)`, it checks `D`, then `B`, then `C`, then `A`. In the code, `D().who()` looks at `D` (no `who`), then `B` (no `who`), then `C` (has `who`). It prints **"C"**.

**P8** — A **metaclass** is a class of a class (defines how a class is created). `__init_subclass__` is a simpler way to customize class creation during inheritance. Use `__init_subclass__` for simple registration; use a **metaclass** for deep structural changes to the class itself.

**P9** — `threading` (I/O bound), `multiprocessing` (CPU bound), `concurrent.futures` (high-level abstraction). `multiprocessing` requires **pickling** (serializing) data to send it between processes, which can be slow and requires objects to be picklable.

**P10** — `__slots__` tells Python not to use a `__dict__` for an instance, instead allocating a fixed amount of space for attributes. This **reduly memory usage** and speeds up attribute access, but prevents adding new attributes at runtime.

**P11** — A **virtual environment** isolates dependencies. `venv` is the standard library tool; `virtualenv` is a third-party alternative with more features; `conda` is a package/environment manager used heavily in data science for managing non-Python binaries.

**P12** — **Comprehensions** are more readable/Pythonic than `map()` and `filter()`. Use them for creating lists, dicts, or sets in a single line.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (typically -5 to 256) so that `a is b` returns `True` for them because they point to the same pre-allocated memory address.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dictionary. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context managers** handle setup/teardown (e.g., `with`). You can use `__enter__`/`__exit__` in a class or the `@contextmanager` decorator from `contextlib`. Example: A database transaction manager.

**P16** — **Type hinting** provides static analysis metadata. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1, 2]` (only 1 or 2), `TypeVar` (generics), and `Protocol` (structural typing/duck typing). Tools like `mypy` use these to catch type errors before runtime.

**P17** — `__repr__` is for developers (unambiguous); `__str__` is for users (readable). `__eq__` is for value equality; `__hash__` allows an object to be a dict key. `__getattr__` is called if an attribute isn't found; `__getattribute__` is called for *every* access. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that define `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol to manage attribute access.

**P19** — **Absolute imports** use the full module path; **relative imports** use `.` or `..`. `sys.path` is the list of directories searched for modules. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** reads the code.

**P20** — `dataclasses` is standard; `attrs` is more powerful; `Pydantic` is for **data validation**. `dataclasses` uses `__post_init__` for setup. Use **Pydantic** when you need to validate incoming JSON/API data against a schema.
