## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored inline/on the stack). Use a **struct** for small, immutable data structures (typically < 16 bytes) that have no identity and are short-lived to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ to Objects); it iterates over the collection in memory. **IQueryable<T>** is for out-of-memory providers (LINQ to SQL/EF); it builds an expression tree that is translated into a database query (SQL). This distinction matters because `IQueryable` allows the database to perform filtering/projection, whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — `async/await` uses a state machine to allow non-blocking I/O. **Task** is a class (reference type) representing an ongoing operation. **ValueTask** is a struct used when the result is often already available synchronously (e.g., reading from a cache), avoiding the heap allocation of a `Task` object.

**DN4** — **Dependency Injection (DI)** is a pattern where objects receive their dependencies from an external source. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Bug**: Injecting a **Scoped** service into a **Singleton** causes "Captive Dependency," where the Scoped service is held alive indefinitely by the Singleton, potentially leading to stale data or memory leaks.

**DN5** — `string` is an immutable heap-allocated object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous memory region. Use `Span<T>`/`ReadOnlySpan<T>` for high-performance slicing and parsing to avoid creating multiple substring allocations on the heap.

**DN6** — The GC uses generations to optimize performance: **Gen 0** (newly allocated), **Gen 1** (buffer between 0 and 2), **Gen 2** (long-lived). The **Large Object Heap (LOH)** is for objects >85,000 bytes; these are placed in Gen 2 immediately to avoid expensive copying. **IDisposable** is needed to manually release unmanaged resources (file handles, sockets) because the GC only manages managed memory, not OS handles.

**DN7** — `ConfigureAwait(false)` tells the runtime it does *not* need to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) where you need to update the UI thread, as it would attempt to run on a background thread.

**DN8** — **Primary Constructors** allow parameters directly on the class declaration. **Collection Expressions** (`[1, 2, 3]`) simplify array/list creation. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Example using Primary Constructor with DI
public class UserService(IUserRepository repo) 
{
    public async Task<User> GetUser(int id) => await repo.GetByIdAsync(id);
}
```

**DN9** — The `ObjectDisposedException` under high concurrency usually means multiple threads are attempting to use the same `DbContext` instance simultaneously. `DbContext` is **not thread-safe**. This happens if a Scoped `DbContext` is shared across tasks or if a Singleton is trying to use a Scoped context. **Fix**: Ensure each concurrent operation gets its own `DbContext` (e.g., via `IServiceScopeFactory`).

**DN10** — **Record** provides value-based equality and is typically used for DTOs. **Class** provides reference equality. **Record struct** is a value-type version of a record (stack-allocated, value equality). Use `record` for data-centric objects and `class` for behavior-centric objects.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only). Use `ref` for modifying existing variables, `out` for returning multiple values, and `in` for passing large structs without copying while preventing modification.

**DN12** — **Nullable Reference Types** (`string?`) are a compiler feature to prevent `NullReferenceException` via static analysis. **Nullable Value Types** (`int?`) are a runtime feature (`Nullable<T>`) that allows a value type to represent `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`); **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query is not executed when defined, but only when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement comparison). You combine them to narrow the type (e.g., `where T : class, new()`).

**DN15** — **Abstract class** can have state (fields) and implementation. **Interface** is a contract. **Default interface methods** allow interfaces to provide implementation, reducing breaking changes when adding methods to existing interfaces.

**DN16** — The **Middleware Pipeline** processes requests sequentially. `app.Use()` adds middleware that can call `next()`. `app.Map()` branches the pipeline. `app.Run()` is a terminal middleware. **Ordering** is critical (e.g., Exception Handling must be first to catch errors in subsequent middleware).

**DN17** — **Channel<T>** is an async-capable producer-consumer collection. **BlockingCollection<T>** is synchronous/thread-safe. For backpressure, use a **Bounded Channel** (e.g., `Channel.CreateBounded<T>(capacity)`); the producer will asynchronously wait when the channel is full, preventing memory exhaustion.

**DN18** — **Source Generators** produce code at compile time, making them faster than **Reflection** (runtime) and safer than **IL Weaving** (post-compile). **Incremental Generators** are preferred because they are more efficient, only re-running when specific inputs change, rather than the whole project.

**DN19** — **TPL Dataflow** is an actor-based library for building pipelines. `ActionBlock` (consumer), `TransformBlock` (processor), `BufferBlock` (queue). **Channels** are lighter and better for simple async streaming; **TPL Dataflow** is better for complex, multi-stage processing graphs.

**DN20** — **Minimal APIs** are lightweight, reducing boilerplate for simple services. **Trade-offs**: Controllers offer better structure for massive APIs; Minimal APIs are easier to test via `WebApplicationFactory` but can become messy without proper organization. **Route groups** allow shared prefixes/logic, and **Endpoint filters** act like middleware for specific routes.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is a collection of unique, unordered elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** ensures only one thread executes Python bytecode at a time, preventing race conditions in the interpreter. It affects **CPU-bound** tasks. **Workarounds**: Use `multiprocessing` to bypass the GIL or use C-extensions (like NumPy) that release the GIL during heavy computation.

**P3** — **Shallow copy** creates a new object but inserts references to the original elements. **Deepcopy** creates a new object and recursively copies all nested objects. **Example**: If a list contains another list, changing the inner list in a shallow copy affects the original.

**P4** — **Decorators** wrap a function to extend its behavior.
```python
import time, functools
def log_time(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values one by one, maintaining state, which is memory-efficient. **yield from** is used to delegate to a sub-generator (flattening). Unlike a list, they are lazy-evaluated.

**P6** — The **event loop** manages async tasks. `asyncio.run()` starts the loop; `asyncio.gather()` runs multiple tasks concurrently; `asyncio.create_task()` schedules a task to run in the background. `time.sleep()` is a blocking call that stops the entire thread, including the loop; use `await asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization** for MRO. In the example, `D` inherits from `B` then `C`. The order is `D -> B -> C -> A`. `D().who()` looks in `D` (no), then `B` (no), then `C` (yes). It prints **"C"**.

**P8** — A **metaclass** is a class of a class (it defines how classes are created). `__init_subclass__` is a simpler way to customize class creation without a full metaclass. Use `__init_subclass__` for simple attribute injection; use a **metaclass** for deep structural changes or registry patterns.

**P9** — **Threading** (I/O bound), **Multiprocessing** (CPU bound, bypasses GIL), **concurrent.futures** (high-level abstraction for both). **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be a bottleneck.

**P10** — `__slots__` tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This **saves memory** and speeds up attribute access but prevents adding new attributes at runtime.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich older alternative; **conda** is a package/environment manager often used in data science for managing non-Python binaries.

**P12** — **Comprehensions** are concise ways to create lists/dicts/sets. They are generally more "Pythonic" and faster than `map()`/`filter()` for simple operations, though `map`/`filter` can be more memory-efficient if used with iterators.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (-5 to 256) and certain strings so they point to the same memory address, making `is` return `True`.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context managers** handle setup/teardown.
```python
from contextlib import contextmanager
@contextmanager
def my_resource():
    print("Setup")
    yield "Resource"
    print("Teardown")
# Usage: with my_resource() as r: ...
```

**P16** — **Type hinting** improves code clarity. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1, 2]` (specific values), `TypeVar` (generics), `Protocol` (structural typing/duck typing). **Mypy/Pyright** use these to find type errors without running the code.

**P17** — `__repr__` is for developers (unambiguous); `__str__` is for users (readable). `__eq__` is for equality; `__hash__` is for using the object in a set/dict. If you define `__eq__` but not `__hash__`, the object becomes unhashable. `__getattr__` is called only if the attribute isn't found; `__getattribute__` is called for *every* access.

**P18** — **Descriptors** implement the descriptor protocol (`__get__`, `__set__`, `__delete__`). `property`, `classmethod`, and `staticmethod` are all built-in descriptors that manage how attribute access is handled.

**P19** — **Absolute imports** use the full path from the project root; **relative imports** use dots (`.`). `sys.path` is the list of directories searched for modules. `__init__.py` makes a directory a package. A **finder** locates the module, and a **loader** loads the code.

**P20** — **Dataclasses** (std lib) are for simple data storage. **attrs** is more powerful/feature-rich. **Pydantic** is designed for **data validation and parsing** (ideal for APIs). Use Pydantic when you need to enforce types on external input; use dataclasses for internal logic.
