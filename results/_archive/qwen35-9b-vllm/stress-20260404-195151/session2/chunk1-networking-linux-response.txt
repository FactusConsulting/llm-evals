N17 — NAT Gateway translates private IPs to public IPs. Static NAT maps one private IP to one public IP. Dynamic NAT maps a pool of private IPs to a pool of public IPs. PAT (Port Address Translation) maps multiple private IPs to one public IP using different ports.

N18 — ECMP distributes traffic across multiple equal-cost paths using hashing (e.g., source/dest IP, ports). Asymmetric flows (different paths for request/response) can break stateful firewalls because the firewall expects the reply to follow the same path.

N19 — The TCP window (64KB) is smaller than the Bandwidth-Delay Product (10MB), causing underutilization. RFC 1323 Window Scaling allows the window size to exceed 64KB (up to 1GB), enabling full bandwidth usage.

N20 — 802.1Q inserts a 4-byte tag (0x8100 + Priority + VID) into the Ethernet frame. On Linux: `ip link add link eth0 name eth0.10 type vlan id 10`. Wire format: Ethernet Header + 0x8100 + 4-byte VLAN Tag + Payload + FCS.

L1 — Hard links share the same inode and data; deleting one does not delete the data. Symbolic links are separate files pointing to a path; deleting the link does not affect the target.

L2 — `find /var/log -type f -size +100M`.

L3 — State D means the process is waiting for I/O (uninterruptible sleep). It cannot be killed with `kill -9` until the I/O completes.

L4 — Cgroups v1 uses separate hierarchies for resources. Cgroups v2 uses a unified hierarchy (cgroup2fs). Systemd prefers v2 for simplicity and unified control.

L5 — nftables is the modern, unified framework replacing iptables. The kernel handles both via netfilter hooks; iptables is a legacy frontend, while nftables is the backend.

L6 — The most likely cause is that deleted files are still open by processes (file descriptors), so `df` sees them as used, while `du` only counts files on disk.

L7 — UEFI firmware loads bootloader (GRUB) -> Kernel loads -> Initramfs mounts root filesystem -> Root filesystem mounted -> systemd starts and reaches target (e.g., multi-user).

L8 — `available` memory excludes non-reclaimable memory (huge pages, slab). High `buff/cache` does not guarantee high `available` if the cache is pinned or if `free` is near zero, causing OOM.

L9 — `ip netns` creates/manages network namespaces. Container runtimes (Docker/Podman) use namespaces to isolate network stacks (interfaces, routes, DNS) from the host.

L10 — SIGTERM (15) requests graceful shutdown (catchable). SIGKILL (9) forces immediate termination (not catchable). SIGQUIT (3) requests debugging info (catchable).

L11 — stdout (1), stderr (2), stdin (0). Redirect stderr to file, keep stdout: `command 2>file`.

L12 — `chmod 755` sets permissions to rwxr-xr-x. 7 = rwx (4+2+1), 5 = r-x (4+0+1).

L13 — Root (UID 0) has full system access. Sudo users (UID != 0) have elevated privileges only for specific commands or all commands via `sudo`.

L14 — A package manager installs software. Debian/Ubuntu uses `apt`/`dpkg`. RHEL/Fedora uses `dnf`/`yum`.

L15 — `/etc/fstab` defines filesystem mount points. Misconfiguration prevents the system from mounting the filesystem, potentially causing boot failure.

L16 — LVM manages storage. PV (Physical Volume) = disk partition. VG (Volume Group) = pool of PVs. LV (Logical Volume) = usable volume. Extend with `lvextend -L +10G /dev/vg/lv`.

L17 — I/O scheduler manages disk queue. `mq-deadline` for SSDs (latency). `bfq` for mixed workloads (fairness). `none` for NVMe (hardware scheduler). Change via `echo mq-deadline > /sys/block/sda/queue/scheduler`.

L18 — Load average counts processes in runnable + uninterruptible sleep states. High load + low CPU usage indicates I/O wait. Diagnose with `iostat -x 1` (check `%iowait`).

L19 — SELinux enforces Mandatory Access Control (MAC). Enforcing blocks access, Permissive logs it, Disabled ignores it. Troubleshoot with `sealert -a /var/log/audit/audit.log` or `audit2allow`.

L20 — Page faults occur when accessing non-present pages. Minor fault: page in RAM (swap out if needed). Major fault: page on disk (swap in). THP improves latency but can cause fragmentation; disable if fragmentation stalls performance.
