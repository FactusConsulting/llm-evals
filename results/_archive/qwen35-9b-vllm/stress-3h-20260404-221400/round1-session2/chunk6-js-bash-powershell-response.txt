## JavaScript / TypeScript (20 questions)

**JS1** — `var` has function scope, is hoisted, and allows redeclaration. `let` has block scope, is hoisted (temporal dead zone), and does not allow redeclaration. `const` has block scope, is hoisted, does not allow redeclaration, and requires initialization (binding is immutable). Hoisting moves declarations to the top of their scope before execution.

**JS2** — The event loop manages execution. The call stack executes synchronous code. The macrotask queue handles `setTimeout`, `setInterval`, and I/O. The microtask queue handles `Promise.then` and `queueMicrotask`. The loop processes the stack, then drains the microtask queue, then processes one macrotask, repeating until the queue is empty.

**JS3** — A closure is a function bundled with its lexical environment. Example: `function counter() { let c=0; return () => ++c; }`. The classic bug is using `var i` in a loop, where all closures share the same `i`. Fix: use `let i` (block scope) or an IIFE to capture the current value.

**JS4** — Promises represent async completion. `async/await` is syntactic sugar for Promises. Errors are handled via `try/catch`. `Promise.all` rejects on the first failure. `Promise.allSettled` returns an array of results (fulfilled/rejected) regardless of individual failures.

**JS5** — Interfaces define shapes (methods/properties) and are used for objects/classes. Types define primitives, unions, tuples, etc., and are used for values. Discriminated unions are unions of literal types with a property check (e.g., `type: 'success' | 'error'`) to narrow types.

**JS6** — JavaScript uses prototypal inheritance; objects link to prototypes via `[[Prototype]]`. `Object.create(proto)` creates an object with that prototype. ES6 classes are syntactic sugar that compile to prototype chains (class constructor -> prototype).

**JS7** — `this` refers to the execution context. Binding rules (priority): 1. Explicit (`bind`/`call`/`apply`), 2. Implicit (object method call), 3. Default (global/undefined), 4. New (constructor). `bind()` returns a new function with a bound `this`; it can be re-bound.

**JS8** — `WeakRef` creates a weak reference to an object (doesn't prevent GC). `FinalizationRegistry` runs a callback when the object is garbage collected. `WeakMap` keys must be objects because they are weakly held; if the key is GC'd, the entry is removed.

**JS9** — V8 optimizes via hidden classes (shape of object) and inline caching (optimizing hot paths). Deoptimization occurs when the shape changes (e.g., adding a property) or types change, forcing the engine to revert to slower execution.

**JS10** — Tree-shaking removes unused code. ES modules use static imports, allowing analysis. CommonJS uses dynamic `require`, preventing static analysis, so it cannot be tree-shaken effectively.

**JS11** — `null` is an empty object value; `undefined` is a missing value. `==` coerces types; `===` checks strict equality. `??` returns the right operand if the left is `null` or `undefined`. `?.` safely accesses nested properties (returns `undefined` if null).

**JS12** — `map` transforms elements; `filter` selects elements; `reduce` accumulates values. `reduce` with an initial value sets the starting accumulator. `flatMap` maps elements and flattens the result one level.

**JS13** — Template literals use backticks and expressions `${}`. Tagged templates pass raw strings to a function. Example: A SQL builder function that joins strings safely to prevent injection.

**JS14** — Destructuring extracts values. Object destructuring: `const { a } = obj`. Array destructuring: `const [a] = arr`. Defaults: `const { a = 1 } = obj`. Renaming: `const { a: b } = obj`. Rest operator `...` collects remaining elements.

**JS15** — `for...in` iterates over enumerable keys (properties). `for...of` iterates over values (iterables). Avoid `for...in` on arrays because it iterates over prototype chain properties, not just array indices.

**JS16** — Generics allow reusable types. Constraints (`extends`) limit types. Conditional types (`T extends U ? X : Y`) branch based on types. `infer` extracts a type from a conditional type. Example: `Array<T>` or `T extends U ? U : never`.

**JS17** — CommonJS uses `require`/`module.exports` (Node). ES Modules use `import`/`export` (Browser/Node). Node handles both via `package.json` `"type": "module"`.

**JS18** — TypeScript uses structural typing (shape matters). Excess property checks apply to object literals. `extends` checks structure; `satisfies` keeps the literal type. Variance (`in`/`out`) determines if a type is covariant or contravariant in generics.

**JS19** — `Proxy` wraps an object to intercept operations. `Reflect` provides standard operations. You intercept `get` (access), `set` (assignment), `apply` (calls). Example: A proxy that validates input before assignment.

**JS20** — `SharedArrayBuffer` provides shared memory. `Atomics` provides wait/notify operations. Web Workers communicate via shared memory. Ordering guarantees ensure memory consistency; `Atomics.wait` blocks until `Atomics.notify` is called.

**PS5** — Splatting `@params` expands a hashtable into named arguments. Passing a hashtable as a single argument keeps it as an object.

**PS6** — `Invoke-Command -ComputerName` runs a command remotely. `Enter-PSSession` creates an interactive session. Uses WinRM (default) or SSH.

**PS7** — Functions returning scalars in a pipeline behave as arrays. `Get-Items` returns an array. If it returns 0 items, it returns an empty array. Correct pattern: `return $result` (array).

**PS8** — `[scriptblock]` is a callable code block. Pass to remote sessions via `-ScriptBlock`. Double-hop (Kerberos) occurs when credentials are delegated. Solve with CredSSP or `-ArgumentList`.

**PS9** — `@()` creates an array. `[array]` casts an object to an array. Indexing `$null` throws an error; indexing an empty array returns `$null`.

**PS10** — `-eq` (numeric), `-like` (wildcard), `-match` (regex). Case-sensitive variants: `-ceq`, `-clike`. `-contains` checks array membership; `-in` checks list membership.

**PS11** — Modules are reusable code. Script (.psm1), Manifest (.psd1), Binary (.dll). `Import-Module` loads the module.

**PS12** — Interpolation uses `$var`. Single quotes `'...'` are literal. Here-strings `@"..."@` allow multi-line strings.

**PS13** — `Get-Member` explores objects. Properties are data; Methods are functions; NoteProperties are custom. `Select-Object` selects properties; `Where-Object` filters objects.

**PS14** — PowerShell classes (v5) are dynamic. C# classes are static with full inheritance. PowerShell classes have limited inheritance and no interfaces.

**PS15** — `CmdletBinding` enables advanced functions. `SupportsShouldProcess` adds `-WhatIf/-Confirm`. `DefaultParameterSetName` sets default groups. `ValueFromPipeline` allows pipeline input. `Begin`, `Process`, `End` blocks handle streaming.

**PS16** — Providers abstract data access. `Get-ChildItem` works across FileSystem, Registry, etc. Registry access: `HKLM:\`.

**PS17** — Runspaces manage threads. `[runspace]` is a thread; `[runspacepool]` manages them; `[powershell]` executes commands. `ForEach-Object -Parallel` (v7+) is easier than manual runspace management.

**PS18** — PSScriptAnalyzer enforces standards via rules. Rules have severity levels. Suppress with `# #`. Integrate with CI/CD via `Invoke-ScriptAnalyzer`.

**PS19** — `$using:` passes variables to background/parallel jobs. Serialization limits (CLIXML depth) affect complex objects.

**PS20** — DSC manages configuration state. Configurations define desired state; Resources implement actions; LCM applies them. Modern IaC (Ansible, Terraform) has largely replaced DSC.
