PS8 — `[scriptblock]` is executable code. Pass to remote session. Double-hop (Kerberos) requires CredSSP or `-ArgumentList` to pass credentials.

PS9 — `@()` creates an array; `[array]` casts to array. Force array: `@($var)`. Indexing `$null` throws; empty array returns nothing.

PS10 — `-eq` (numeric), `-like` (wildcard), `-match` (regex). Case-sensitive variants: `-ceq`, `-clike`. `-contains` checks array membership; `-in` checks collection membership.

PS11 — Module: `.psm1` (code), `.psd1` (manifest), Binary. `Import-Module` loads the module.

PS12 — Interpolation: `"${var}"`. Single quotes: literal. Here-string: `@"..."@` for multi-line.

PS13 — `Get-Member` explores objects. Properties (data), Methods (functions), NoteProperties (metadata). `Select-Object` picks properties; `Where-Object` filters.

PS14 — Classes (v5) are dynamic. C# classes are static with inheritance. PowerShell classes have limited inheritance/interfaces. Use classes for complex state.

PS15 — `CmdletBinding` enables advanced functions. `SupportsShouldProcess` adds `-WhatIf/-Confirm`. `ValueFromPipeline` allows piping objects. `Begin/Process/End` blocks handle lifecycle.

PS16 — Providers: `FileSystem`, `Registry`, `Certificate`. `Get-ChildItem` works across them. Access registry like file system: `Get-ItemProperty HKCU:\Software`.

PS17 — Runspaces: `[runspace]` (thread), `[runspacepool]` (pool), `[powershell]` (instance). `ForEach-Object -Parallel` (v7) is easier than manual runspace management.

PS18 — PSScriptAnalyzer enforces standards. Rules have severity levels. Suppress with `# #PSRule`. Integrate with CI/CD via `Invoke-ScriptAnalyzer`.

PS19 — `$using:` passes variables to remote/parallel. `$args` passes positional arguments. Serialization limits (CLIXML depth ~1000) affect complex objects.

PS20 — DSC: Configurations, Resources, LCM. Windows PowerShell vs PS7+ (PowerShell Core). Modern IaC: Ansible, Terraform, Pulumi.
