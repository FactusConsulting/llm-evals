## JavaScript / TypeScript (20 questions)

**JS1**
`var` is function-scoped and hoisted (initialized as `undefined`). `let` is block-scoped and not hoisted (temporal dead zone). `const` is block-scoped and cannot be reassigned (but properties can). Hoisting is the JavaScript mechanism of moving declarations to the top of their scope during compilation.

**JS2**
The event loop processes the call stack. When the stack is empty, it checks the microtask queue (Promises, `queueMicrotask`) before the macrotask queue (callbacks, `setTimeout`). Microtasks run to completion before any macrotask.

**JS3**
A closure is a function bundled with its lexical environment. Example: `function makeCounter() { let c = 0; return () => ++c; }`. The classic bug is `for (var i = 0; i < 3; i++) { setTimeout(() => console.log(i)) }`, which logs `3` three times. Fix: use `let` (block scope) or `i => { setTimeout(() => console.log(i)) }` (arrow function captures current `i`).

**JS4**
Promises represent async completion. `async/await` is syntactic sugar over Promises. Errors in `await` throw synchronously. `Promise.all` rejects if *any* promise rejects. `Promise.allSettled` waits for *all* to settle (fulfilled or rejected) without rejecting early.

**JS5**
Interfaces define shapes for objects/classes and support method overloading. Types define primitive or union types. Use interfaces for object shapes; types for primitives/complex unions. Discriminated unions use a literal type to distinguish union members (e.g., `{ type: 'circle' } | { type: 'square' }`).

**JS6**
JavaScript uses prototypes. `Object.create(proto)` creates an object with `proto` as its prototype. ES6 classes are syntactic sugar over prototype-based inheritance; `class extends B {}` creates a constructor function whose prototype is an instance of `B`.

**JS7**
`this` refers to the execution context. Binding rules (priority): 1. `new` (constructor), 2. `call/apply/bind`, 3. implicit (object method), 4. default (global/window). `bind()` returns a new function with `this` permanently bound. It can be re-bound, but the original binding is lost.

**JS8**
`WeakRef` allows weak references to objects (garbage collectable). `FinalizationRegistry` runs a callback when an object is GC'd. `WeakMap` keys must be objects (not primitives) because primitives are not tracked by the GC, making weak references impossible.

**JS9**
V8 optimizes via hidden classes (shape of object properties) and inline caching (caching type checks). Deoptimization occurs when assumptions break (e.g., adding a property to an object, changing types). Patterns: mutating objects, adding properties, changing types.

**JS10**
Tree-shaking removes unused code. ESM uses static imports, allowing analysis. CommonJS uses dynamic `require`, so bundlers cannot statically analyze usage, preventing effective tree-shaking.

**JS11**
`null` is an empty object; `undefined` is uninitialized. `==` coerces types (e.g., `null == undefined` is true); `===` checks strict equality. `??` returns the right operand if the left is `null` or `undefined`. `?.` safely accesses nested properties (returns `undefined` if null).

**JS12**
`map` transforms elements; `filter` selects elements; `reduce` aggregates. `reduce` takes an accumulator and callback. `flatMap` maps then flattens one level (useful for nested arrays).

**JS13**
Template literals use backticks `` ` `` and allow interpolation `${expr}`. Tagged templates pass raw strings to a function. Example: `sql` tag function joins strings safely to prevent SQL injection.

**JS14**
Destructuring extracts values. Object: `{ a } = obj`. Array: `[ a ] = arr`. Defaults: `{ a = 1 }`. Renaming: `{ a: b }`. Rest `...` collects remaining elements/properties into an array/object.

**JS15**
`for...in` iterates enumerable properties (including inherited ones). `for...of` iterates iterable values (array elements). Avoid `for...in` on arrays as it includes non-array properties and is slower.

**JS16**
Generics create reusable components. `extends` constrains types (e.g., `T extends string`). Conditional types `T extends U ? X : Y` branch based on type. `infer` extracts a type from a conditional (e.g., `Extract`).

**JS17**
CommonJS uses `require`/`module.exports` (dynamic). ESM uses `import`/`export` (static). Node.js supports both via `type` field in `package.json`. `"type": "module"` enables ESM syntax; otherwise, it defaults to CJS.

**JS18**
TypeScript is structural (types match by shape). Excess property checks apply to object literals passed to constructors/functions. `extends` checks structure; `satisfies` checks without excess property checks. Variance: `in` (contravariant) for inputs, `out` (covariant) for outputs.

**JS19**
`Proxy` creates a proxy object to intercept operations. `Reflect` provides standard behavior. Intercepts: `get` (access), `set` (assign), `apply` (call). Example: Logging property access or validating input.

**JS20**
`SharedArrayBuffer` allows shared memory between threads (Web Workers). `Atomics` provides atomic operations (wait/notify). Workers communicate via `postMessage` or shared memory. `Atomics.wait` blocks until notified; `Atomics.notify` wakes up waiters.

## Bash (20 questions)

**B1**
`$@` expands to each argument as a separate word. `$*` expands to all arguments as a single string. `"$@"` preserves word boundaries (safe). `"$*"` joins with spaces (unsafe for special chars).

**B2**
`set -e`: exit on error. `set -u`: error on unset variable. `set -o pipefail`: error if any command in pipeline fails.

**B3**
`$(cmd)` performs command substitution (output). `command` runs in subshell. `$((expr))` is arithmetic expansion. `expr` is an external command for string/math operations.

**B4**
Process substitution `<(cmd)` creates a named pipe (FIFO) so it can be read like a file. Example: `diff <(sort file1) <(sort file2)` compares sorted versions without creating temp files.

**B5**
Use `while IFS= read -r -d '' file; do ...; done < <(find . -print0)`. `for f in $(ls)` splits on whitespace, breaking filenames with spaces.

**B6**
`<<EOF` reads until EOF. `<<<` passes a string as stdin. `<<-` allows indentation of the delimiter.

**B7**
`cmd > file 2>&1`: stdout to file, then stderr to file. `cmd 2>&1 > file`: stderr to stdout (stdout), then stdout to file (stderr lost). `cmd &> file`: both to file. First two differ because redirection order matters.

**B8**
```bash
lock() {
    local lockfile="/tmp/mylock.$$"
    mkdir -p "$(dirname "$lockfile")"
    if ! mkdir "$lockfile" 2>/dev/null; then
        rm -f "$lockfile"
        return 1
    fi
    trap "rm -f '$lockfile'" EXIT INT TERM
}
```
`mkdir` is atomic on most filesystems, avoiding race conditions compared to `touch`.

**B9**
Single quotes `'...'`: literal, no expansion. Double quotes `"..."`: variable expansion, no glob. No quotes: glob expansion and variable expansion. Example: `echo 'a$b'` vs `echo "a$b"`.

**B10**
`[ -f file ]`, `[ -d dir ]`, `[ -r file ]`. `[ ]` uses word splitting; `[[ ]]` is a keyword, safer for globbing and doesn't split.

**B11**
`$?`: exit status of last command. `$$`: PID of current shell. `$!`: PID of last background process. `$#`: number of arguments passed to function/script.

**B12**
`function foo {}` and `foo() {}` are equivalent. Return values via `echo` or `return` (integer). Use `local` for variables.

**B13**
`PATH` is a colon-separated list of directories. Bash searches `PATH` for commands. Builtins are internal (e.g., `cd`); external are executables. Use `type` or `which` to check.

**B14**
`trap 'cmd' signal`. `EXIT`: cleanup. `ERR`: on error. `INT`: Ctrl+C. `TERM`: kill. Order: signals are handled asynchronously; `EXIT` runs last.

**B15**
`xargs` processes arguments from stdin. `find -print0 | xargs -0` handles spaces/newlines. `xargs -P` runs parallel processes.

**B16**
Arrays: `arr=(a b c)`. `arr[0]`. Length: `${#arr[@]}`. Associative: `declare -A arr`. `arr[key]=val`. Iterate with `for key in "${!arr[@]}"`.

**B17**
Subshell `(...)` creates a new shell (variables don't persist). Group `{ ... }` shares scope. Piping into `while` runs `while` in a subshell, losing variable changes.

**B18**
Signals: `SIGINT` (Ctrl+C), `SIGTERM` (kill), `SIGHUP` (hangup), `SIGKILL` (unblockable). Use `trap` to handle signals and cleanup background jobs (`wait`).

**B19**

```bash
split -l 1000 log.txt -d
find . -name "log-*" -print0 | xargs -0 -P 4 process_file
cat results_* > merged.log
```
Trade-off: parallelism vs resource usage. Handle errors by checking exit codes in `process_file` and aggregating.

**B20**
`exec` replaces the current shell with a command. `exec 3>file` redirects FD 3. Coprocess: `coproc name; read -p "Prompt" name`. Used for interactive background processes.

## PowerShell (20 questions)

**PS1**
`Write-Output` sends objects to the pipeline. `Write-Host` writes to the console (bypasses pipeline). Distinction matters for piping data to other commands.

**PS2**
Pipeline passes objects. `ForEach-Object` is a cmdlet (pipeline-aware). `foreach` is a statement (not pipeline-aware). Use `ForEach-Object` for object processing.

**PS3**
`[PSCustomObject]` creates a proper object with properties. `[hashtable]` is a dictionary-like object. Convert: `@{ } | ConvertFrom-Hashtable` or `[PSCustomObject]@{ }`.

**PS4**
Terminating errors stop execution. Non-terminating continue. `-ErrorAction Stop` forces terminating. `try/catch` catches terminating errors. `$ErrorActionPreference` sets default behavior.

**PS5**
Splatting `@params` passes a hashtable as named arguments. Passing a hashtable as a single argument treats it as a single object. Splatting expands keys as parameters.

**PS6**
`Invoke-Command` runs a script on remote. `Enter-PSSession` opens an interactive session. Uses WinRM (HTTP/HTTPS) or SSH (PowerShell 7+).

**PS7**
Functions returning arrays return an array object. If the function returns a scalar (e.g., string), it gets wrapped in an array. Correct pattern: `return $result` (ensure it's an array) or use `return $null` if empty.

**PS8**
`[scriptblock]` is a callable object. Pass to remote via `-ScriptBlock`. Double-hop: Kerberos ticket delegation fails. Solve with CredSSP (`-Credential`) or `-ArgumentList` (if simple).

**PS9**
`@()` creates an array. `[array]` is a type. Force single result: `@($result)`. Indexing `$null` throws; empty array returns nothing.

**PS10**
`-eq` (equal), `-ne` (not equal), `-like` (wildcard), `-match` (regex), `-contains` (array), `-in` (scalar check). Case-sensitive variants: `-ceq`, `-clike`. `-contains` checks array membership; `-in` checks scalar membership.

**PS11**
Module is a collection of functions/classes. `.psm1` is script module (code). `.psd1` is manifest (exports). Binary is compiled. `Import-Module` loads the module.

**PS12**
Interpolation: `"${variable}"`. Single quotes `'...'` no interpolation. Here-string: `@"..."@` for multi-line strings.

**PS13**
`Get-Member` lists properties/methods. `Properties` are data, `Methods` are actions, `NoteProperties` are metadata. `Select-Object` picks properties; `Where-Object` filters objects.

**PS14**
PowerShell classes are dynamic, not compiled like C#. No strict inheritance. Use classes for encapsulation/state; functions for logic.

**PS15**
`[CmdletBinding()]` enables advanced functions. `SupportsShouldProcess` adds `-WhatIf/-Confirm`. `ValueFromPipeline` allows piping objects. `Begin/Process/End` blocks handle streaming.

**PS16**
Providers abstract data access. `Get-ChildItem` works on FileSystem, Registry, etc. Registry: `Get-ChildItem HKCU:\Software`.

**PS17**
`[runspace]` is a thread. `[runspacepool]` manages them. `[powershell]` executes commands. `ForEach-Object -Parallel` (v7+) is easier than manual runspace management.

**PS18**
`PSScriptAnalyzer` enforces rules (e.g., `PSUseShouldProcess`). Severity: Info, Warning, Error. Suppress with `# #`. Integrate via CI/CD (e.g., GitHub Actions).

**PS19**
`$using:` passes variables to remote/background jobs. `$args` passes positional. Serialization limits (CLIXML depth) affect complex objects (e.g., nested arrays).

**PS20**
DSC manages configuration state. Configurations define desired state. Resources implement actions. LCM applies them. Modern IaC (e.g., Ansible, Terraform) often replaces DSC.
