## .NET / C# (20 questions)

**DN1**
Classes are reference types (allocated on heap, can be null, support inheritance). Structs are value types (allocated on stack or inline, cannot be null, no inheritance). Use structs for small, immutable data (e.g., coordinates, colors) to avoid heap allocation overhead and improve cache locality.

**DN2**
`IEnumerable<T>` executes queries in memory (LINQ to Objects). `IQueryable<T>` builds expression trees that are translated to SQL (LINQ to DB). This distinction matters because `IEnumerable` cannot be translated to SQL, so using it on a database context prevents efficient server-side filtering and causes data transfer issues.

**DN3**
`async/await` uses a state machine to suspend execution without blocking threads. `Task` is a reference type wrapper for an asynchronous operation. `ValueTask` is a union of `Task` and a result value, avoiding allocation if the operation completes synchronously. Use `ValueTask` in hot paths where the operation is often synchronous to reduce GC pressure.

**DN4**
Dependency Injection (DI) allows injecting dependencies rather than creating them. Lifetimes: **Transient** (new instance per request), **Scoped** (new instance per request scope, e.g., HTTP request), **Singleton** (one instance per app lifetime). Common bug: Injecting a Scoped service into a Singleton causes a memory leak because the Scoped service is never disposed when the request ends.

**DN5**
`string` is immutable and allocates memory. `ReadOnlySpan<char>` is a view over existing memory (no allocation). Use `Span<T>` (or `ReadOnlySpan`) for high-performance processing of buffers or strings where you want to avoid copying data, especially in tight loops or when dealing with unmanaged memory.

**DN6**
The GC manages memory in generations: **Gen 0** (short-lived), **Gen 1** (medium), **Gen 2** (long-lived). Objects age up generations. **Large Object Heap (LOH)** stores objects >85KB. `IDisposable` is needed because the GC only manages managed memory; it cannot automatically free unmanaged resources (files, handles) which require explicit cleanup via `Dispose`.

**DN7**
Default `await` captures the `SynchronizationContext` (e.g., UI thread) to resume. `ConfigureAwait(false)` suppresses this, resuming on any thread. Use `ConfigureAwait(false)` in library code to avoid deadlocks in UI apps. Do NOT use it in UI code if you need to update UI controls, as it bypasses the context.

**DN8**
**Primary Constructors:** Class parameters defined in the class declaration (C# 12/.NET 8+). **Collection Expressions:** `new List<int> { 1, 2 }`. **FrozenDictionary:** Immutable dictionary.
*Example:*
```csharp
public class MyService : IService
{
    public MyService(string name) { /* ... */ }
}
// Registration
builder.Services.AddMyService(new MyService("Default")); // Primary constructor usage
```

**DN9**
**Cause:** `DbContext` is typically Scoped. If high concurrency causes multiple requests to share a Singleton or if the `DbContext` is disposed prematurely (e.g., via `using` block scope mismatch), `ObjectDisposedException` occurs.
**Fix:** Ensure `AddDbContext` is configured with `Lifetime = ServiceLifetime.Scoped`. Verify no Singleton is holding a reference to the Scoped `DbContext`.

**DN10**
**Record:** Immutable by default, value-based equality, auto-generated `Equals/GetHashCode`. **Class:** Mutable, reference-based equality. **Record Struct:** Value type record. Choose **Record** for DTOs/immutable objects. Choose **Class** for mutable state. Choose **Record Struct** for small value types (e.g., `Point`).

**DN11**
**ref:** Read/write reference. **out:** Write-only (caller provides storage). **in:** Read-only reference (C# 7.2+). Use **in** for large structs to prevent accidental modification and improve performance. Use **out** when the method must initialize the value.

**DN12**
`string?` (nullable reference type) is a compile-time feature to suppress warnings about nulls. `int?` (nullable value type) is a struct (`Nullable<int>`) that can hold `null` at runtime. The former is about analysis; the latter is about runtime representation.

**DN13**
LINQ is Language Integrated Query. **Method syntax** is imperative (`list.Where(...)`). **Query syntax** is declarative (`from x in list where ...`). Both are equivalent. **Deferred execution** means the query isn't run until the result is enumerated (e.g., `ToList()`).

**DN14**
Constraints limit generic types. `class`: reference type. `struct`: value type. `new()`: parameterless constructor exists. `IComparable<T>`: implements interface. Combine constraints (e.g., `where T : class, new()`) to enforce multiple rules simultaneously.

**DN15**
**Abstract class:** Can have state, constructors, and multiple inheritance (no). **Interface:** No state (pre-C# 8), no constructors. **C# 8+ Interfaces** can have default method implementations, narrowing the distinction. Use Abstract for shared implementation/state. Use Interface for contracts.

**DN16**
**Middleware pipeline:** Request flows through `Use` -> `Map` (branching) -> `Run` (immediate). **Order matters:** earlier middleware runs first. **Exception handling:** Middleware can catch exceptions and return 500 responses. `UseExceptionHandler` wraps the pipeline.

**DN17**
**Channel<T>:** Bounded/Unbounded, supports backpressure (producer waits if full). **BlockingCollection<T>:** Unbounded, no backpressure. Use **Channel** for producer-consumer patterns where you need to prevent memory overflow (bounded queues).

**DN18**
**Source Generators:** Compile-time code generation. **Reflection:** Runtime inspection. **IL Weaving:** Runtime injection. **Incremental Generators:** Only recompile when source changes (faster builds). **ISourceGenerator:** Full recompilation. Incremental is preferred for performance in large solutions.

**DN19**
**TPL Dataflow:** High-level pipeline. **ActionBlock:** Sink. **TransformBlock:** Process data. **BufferBlock:** Buffer. **Channels:** Lower-level, more control, no built-in transformation logic. Use Dataflow for complex pipelines; Channels for simple queues.

**DN20**
**Minimal APIs:** `app.MapGet`, `app.MapPost`. No Controllers. **Trade-offs:** Faster startup, less boilerplate, but harder to test (less DI support), OpenAPI requires `AddOpenApi`. **Route Groups:** `app.MapGroup("/api")`. **Endpoint Filters:** Middleware-like logic for specific endpoints.

## Python (20 questions)

**P1**
**List:** Mutable sequence. **Tuple:** Immutable sequence. **Set:** Mutable unordered collection. **FrozenSet:** Immutable set. Use Tuple for fixed data; List for dynamic data. Use FrozenSet for hashable keys that shouldn't change.

**P2**
**GIL:** Locks bytecode execution to one thread per CPU core. Affects CPU-bound workloads (no true parallelism). Workarounds: **Multiprocessing** (bypasses GIL), **Asyncio** (I/O bound), or **C-extensions** (release GIL).

**P3**
**copy:** Shallow copy (nested objects share references). **deepcopy:** Deep copy (nested objects duplicated).
*Example:*
```python
a = [[1, 2], [3, 4]]
b = copy.copy(a)
b[0][0] = 99
print(a) # [[99, 2], [3, 4]] - Unexpected modification
```

**P4**
Decorators wrap functions.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start:.2f}s")
        return result
    return wrapper
```

**P5**
**Generators:** Lazy iteration using `yield`. Pauses execution state. **List:** Eager evaluation. **yield from:** Delegates to another iterable. Use generators for large datasets to save memory.

**P6**
**Event Loop:** Manages async tasks. **asyncio.run():** Starts loop. **asyncio.gather():** Waits for all tasks. **asyncio.create_task():** Schedules task. **time.sleep()** blocks the loop; use **asyncio.sleep()** instead.

**P7**
**MRO:** C3 Linearization. Order: `D, B, C, A, object`. `B` inherits `A`. `C` inherits `A` and overrides `who`. `D` inherits `B` then `C`. Lookup: `D` -> `B` (no `who`) -> `C` (has `who`). Result: `"C"`.

**P8**
**Metaclass:** Class of a class. **__init_subclass__:** Called when subclass is defined (cleaner for Python 3.6+). **Metaclass:** Used for runtime control of class creation. Use `__init_subclass__` for simple hooks (e.g., adding attributes). Use Metaclass for complex logic (e.g., enforcing abstract methods).

**P9**
**Threading:** Shared memory, GIL limited. **Multiprocessing:** Separate processes, true parallelism, requires pickling. **concurrent.futures:** Abstraction layer. Use **Threading** for I/O bound. Use **Multiprocessing** for CPU bound. Pickling fails for non-serializable objects (e.g., lambdas, file handles).

**P10**
**__slots__:** Prevents `__dict__` creation. Saves memory (no dynamic attributes). Prevents adding new attributes at runtime. Use for classes with many instances (e.g., data models).

**P11**
**Virtual Env:** Isolated Python environment. **venv:** Built-in. **virtualenv:** 3rd party (more features). **conda:** Manages packages + environments (binary dependencies). Use venv for standard Python projects; conda for data science with C libraries.

**P12**
**Comprehensions:** `[x for x in list]`. **map/filter:** Functional equivalents. Comprehensions preferred for readability and performance (often optimized). Use map/filter for functional pipelines.

**P13**
**==:** Value equality. **is:** Identity (same object). **Interning:** Python caches small integers (-5 to 256). `a is b` is True for these values even if created separately.

**P14**
**\*args:** Variable positional. **\*\*kwargs:** Variable keyword. **/**: Positional-only parameters (before `*`). **\*:** Keyword-only parameters (after `*`).
*Example:* `def f(a, /, b, *, c):`

**P15**
**Context Managers:** Manage resources (e.g., files). **__enter__/__exit__** (protocol). **@contextmanager** (generator-based). Example: `with lock:` or `with open_file():`.

**P16**
**Type Hinting:** Static analysis. **Union:** Multiple types. **Optional:** Union[None, T]. **Literal:** Exact values. **TypeVar:** Generic types. **Protocol:** Structural typing. Tools like **mypy** check these to catch errors before runtime.

**P17**
**__repr__** (dev/debug), **__str__** (user). **__eq__** (value equality). **__hash__** (hashing). If **__eq__** is defined without **__hash__**, **__hash__** is set to `None` (unhashable).

**P18**
**Descriptors:** Objects that control attribute access. **__get__/__set__/__delete__**. **property** uses a descriptor. **classmethod/staticmethod** use descriptors to bind methods to the class or instance.

**P19**
**Import System:** `sys.path` determines search order. **Relative:** `from . import`. **Absolute:** `from package import`. **__init__.py:** Makes directory a package. **Namespace packages:** No `__init__.py`. **Finder/Loader:** Mechanism to locate and load modules.

**P20**
**Dataclasses:** Stdlib, boilerplate reduction. **attrs:** More features (validators, converters). **Pydantic:** Validation + Serialization (JSON). **__post_init__** for initialization logic. **Frozen:** Immutable. Choose **Pydantic** for API validation/serialization; **Dataclasses** for internal data structures.
