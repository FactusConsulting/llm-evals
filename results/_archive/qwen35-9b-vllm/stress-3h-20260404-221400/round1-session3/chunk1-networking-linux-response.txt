**N15**

**N16**
TTL (Time To Live) limits packet lifespan to prevent loops. Traceroute sends packets with incrementing TTL values; each router decrements TTL and sends an ICMP Time Exceeded message when TTL reaches 0, revealing the hop.

**N17**
NAT Gateway translates private IPs to public IPs. Static NAT: 1-to-1 fixed mapping. Dynamic NAT: Pool of public IPs mapped to private IPs. PAT (Port Address Translation): Many-to-1 mapping using unique port numbers.

**N18**
ECMP distributes traffic across multiple equal-cost paths using hashing (e.g., source/dest IP/port). Asymmetric flows occur when return traffic takes a different path than the forward path, breaking stateful firewall rules which expect bidirectional traffic on the same path.

**N19**

LVM manages storage: Physical Volumes (PV) are raw disks/partitions. Volume Groups (VG) pool PVs. Logical Volumes (LV) are slices of VGs. Extend: `lvextend -L +10G /dev/vg/lv` followed by `resize2fs` (if ext4).

**L17**
I/O schedulers manage disk queue. mq-deadline: Low latency (SSDs). bfq: Fairness (mixed workloads). none: No scheduling (SSDs). Change: `echo mq-deadline > /sys/block/sda/queue/scheduler`.

**L18**
Load average counts runnable + uninterruptible processes. High I/O wait puts processes in uninterruptible sleep (D state), inflating load average without CPU usage. Diagnose with `top` (check %wa), `iostat` (check iowait), `netstat` (check network).

**L19**
SELinux enforces Mandatory Access Control (MAC). Enforcing blocks access, Permissive logs it, Disabled ignores it. Troubleshoot: Check `audit.log` for AVC denials, use `audit2allow` to generate a policy, or `setsebool` to relax specific booleans.

**L20**
Minor page fault: Page in RAM (TLB miss). Major page fault: Page not in RAM (disk swap). THP reduces TLB misses but causes fragmentation and latency spikes. Disable THP (`echo never > /sys/kernel/mm/transparent_hugepage/enable`) for latency-sensitive workloads (e.g., databases).
