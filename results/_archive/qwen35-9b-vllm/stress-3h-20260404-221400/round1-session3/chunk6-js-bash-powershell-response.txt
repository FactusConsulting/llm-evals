**JS1**
`var` is function-scoped, hoisted (initialized as `undefined`), and mutable. `let` is block-scoped, not hoisted (TDZ), and mutable. `const` is block-scoped, not hoisted, and immutable (reassignment forbidden). Hoisting moves declarations to the top of their scope, but `let`/`const` remain uninitialized until execution.

**JS2**
The event loop processes the call stack. When empty, it checks the microtask queue (Promises, `queueMicrotask`) before the macrotask queue (`setTimeout`, I/O). This ensures microtasks run before the next macrotask.

**JS3**
A closure is a function bundled with its lexical environment. Example: `function makeCounter() { let c = 0; return () => ++c; }`. The classic bug is `var i` in a loop closure; fix by using `let i` or `var i = i` inside the loop to create a new binding per iteration.

**JS4**
`Promise` represents async completion. `async/await` is syntactic sugar. Errors are caught via `try/catch`. `Promise.all` rejects if any promise rejects. `Promise.allSettled` waits for all, returning `{status, value}` for each regardless of rejection.

**JS5**
Interfaces define shapes (properties/methods) and are erased at runtime. Types define primitives, unions, tuples, etc. Use interfaces for object shapes; types for primitives/complex types. Discriminated unions are unions with a literal type and a distinguishing property (e.g., `type | { type: 'A' }`).

**JS6**
JavaScript uses prototypal inheritance. Objects inherit from a prototype. `Object.create(proto)` creates an object with that prototype. ES6 classes are syntactic sugar that compile to prototype chains under the hood.

**JS7**
`this` binding rules (priority): 1. Explicit binding (`call`, `apply`, `bind`). 2. `new` binding. 3. Implicit binding (default). 4. Strict mode default (`undefined`). `bind()` returns a new function with `this` permanently bound; it can be re-bound.

**JS8**
`WeakRef` holds a weak reference to an object (can be GC'd). `FinalizationRegistry` runs a callback when the object is GC'd. `WeakMap` keys must be objects because they are held weakly; primitives cannot be keys. This allows safe storage without preventing GC.

**JS9**
V8 optimizes via hidden classes (shape of object properties) and inline caching (cached property access). Deoptimization occurs when the hidden class changes (e.g., adding a property), forcing the engine to revert to slower execution paths.

**JS10**
Tree-shaking removes unused code. ES modules allow static analysis of imports/exports. CommonJS uses dynamic `require()`, so the bundler cannot determine usage, preventing effective tree-shaking.

**JS11**
`null` is an object (empty); `undefined` is uninitialized. `==` coerces types (e.g., `null == undefined` is true); `===` checks strict equality. `??` returns the right operand if the left is `null` or `undefined`. `?.` safely accesses nested properties.

**JS12**
`map()` transforms elements. `filter()` selects elements. `reduce()` aggregates elements. `reduce` with an initial value avoids the first element being the accumulator. `flatMap()` maps and flattens the result one level deep.

**JS13**

**JS14**
