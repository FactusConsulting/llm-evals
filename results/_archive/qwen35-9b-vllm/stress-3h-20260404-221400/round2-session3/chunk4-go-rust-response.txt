G1 — Easy: In Go, an **array** is a fixed-size sequence of elements stored contiguously in memory; it is a value type. A **slice** is a dynamic view into an underlying array, storing a pointer, length, and capacity; it is a reference type. When you **append** to a slice that has reached its capacity, Go allocates a new underlying array (typically 1.5x or 2x the current capacity), copies the existing elements, and updates the slice header to point to the new array.

G2 — Easy: `var x int` declares a variable `x` of type `int` and initializes it to the zero value (`0`). `x := 0` is a short declaration that initializes `x` to `0` and infers the type. You **cannot** use `:=` in package-level scope (outside functions) or if the left-hand side is already declared. `:=` is only allowed within function scopes for new variables.

G3 — Medium: A **goroutine** is a lightweight thread of execution managed by the Go runtime, whereas an OS thread is a heavy kernel resource. Goroutines are M:N scheduled (many goroutines mapped to fewer OS threads). The **GMP model** consists of: **G** (goroutine), **M** (machine/OS thread), and **P** (processor). The scheduler runs on P, manages Gs, and assigns Gs to Ms.

G4 — Medium: Channels allow goroutines to communicate. An **unbuffered channel** blocks the sender until a receiver is ready. A **buffered channel** holds up to `N` values. Sending to a **full buffered channel** blocks the sender until a receiver removes a value or the channel is closed.

G5 — Medium: The **context** package manages request-scoped values (cancelation, deadlines, values).
```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
// Use ctx in HTTP request:
resp, err := http.Get(ctx, "https://example.com")
```
This ensures the request is canceled if it exceeds 5 seconds.

G6 — Medium: Go interfaces are **implicit**; a type satisfies an interface if it implements the methods. Java/C# require explicit implementation. The **empty interface** `interface{}` (or `any`) accepts any type but requires type assertions to use, making it powerful for generic-like behavior but dangerous due to runtime panics on type mismatches.

G7 — Hard: This code is **unsafe** due to a data race. `ready` and `data` are not atomic or protected. The goroutine writes `data` and `ready` concurrently with the main loop reading them. **Correct alternatives**: Use a channel (`done <- struct{}{}`), `sync.WaitGroup`, or `sync.Mutex`/`atomic.Bool` to synchronize access.

G8 — Hard: **sync.Mutex** allows only one writer. **sync.RWMutex** allows multiple concurrent readers but exclusive writers. **sync.Map** is optimized for concurrent read-heavy workloads (no locking for reads, optimized writes). A regular map with a mutex is better for write-heavy or small datasets where `sync.Map` overhead is unnecessary.

G9 — Hard: **Go modules** manage dependencies. `go.mod` declares the module path and dependencies. `go.sum` stores checksums for security. `go mod tidy` cleans up unused dependencies and ensures versions match `go.mod`. **MVS** (Minimum Version Selection) selects the highest version of a dependency that satisfies all constraints in the dependency tree.

G10 — Medium: **Defer** schedules a function call to run when the surrounding function returns. Multiple defers execute in **LIFO** (Last-In, First-Out) order. A common **gotcha** is capturing loop variables: `defer` captures the variable, not its value at the time of deferral, so all defers in a loop may use the final loop value.

G11 — Easy: A **pointer** holds the memory address of a value. The zero value is `nil`. To create a pointer to a struct literal: `var p *MyStruct = &MyStruct{Field: "value"}`.

G12 — Easy: `init()` runs when a package is initialized, before `main()`. A package can have multiple `init()` functions (e.g., in different files). They execute in **declaration order** (top-to-bottom).

G13 — Easy: **make** allocates and initializes slices, maps, and channels (e.g., `make(map[string]int)`). **new** allocates a zero value and returns a pointer (e.g., `new(int)`). `make` works only for slices/maps/channels; `new` works for any type.

G14 — Easy: Errors are values implementing the `error` interface (`Error() string`). The idiomatic check is `if err != nil`. `errors.Is` checks if an error wraps a specific target error; `errors.As` type-asserts a wrapped error to a specific type. `==` checks identity (same pointer), not content.

G15 — Easy: Composite types: **map** (key-value), **slice** (dynamic array), **channel** (communication), **struct** (named fields). Zero values: map/slice/channel are `nil`; struct fields are their respective zero values (e.g., `0`, `""`, `false`).

G16 — Medium: A **race condition** occurs when two goroutines access shared data concurrently without synchronization. The `-race` flag enables the ThreadSanitizer to detect this. **Fix**: Protect shared data with `sync.Mutex` or use channels for communication.
```go
var mu sync.Mutex
// mu.Lock(); data = x; mu.Unlock()
```

G17 — Medium: **select** chooses a ready channel case, similar to `switch` but for channels. If multiple cases are ready, one is chosen **randomly**. To implement a **timeout**, use a `select` with a `timer` channel alongside the target channel.

G18 — Hard: **Escape analysis** determines if a variable lives on the stack or heap. If a variable is referenced outside the function (e.g., stored in a global or returned), it escapes to the heap. Inspect with `go build -gcflags="-m"`. It matters because heap allocation incurs GC overhead; stack allocation is faster.

G19 — Hard: **reflect** allows runtime introspection of types and values. `reflect.Type` describes a type; `reflect.Value` holds the value. Reflection is **slow** (dynamic dispatch). It is justified for generic libraries (pre-1.18) or dynamic configuration, but avoided in performance-critical paths in favor of generics or code generation.

G20 — Hard: **go:embed** embeds files at compile time. It supports single files, directories, and file systems (`io/fs.FS`). Limitations: paths must be relative to the package root, and the file must exist at build time. It interacts with `io/fs.FS` by creating a virtual filesystem in memory.

R1 — Easy: **Ownership** means each value has a single owner responsible for its memory. The three rules: 1. Each value has one owner. 2. When the owner goes out of scope, the value is dropped. 3. When a value is copied, the ownership is moved (not copied).

R2 — Easy: **String** is an owned, heap-allocated UTF-8 string. **&str** is a borrowed slice of UTF-8 bytes. Use **String** when you need to own the data (e.g., return value). Use **&str** for function arguments to avoid unnecessary allocations and copying.

R3 — Medium: **Borrowing** allows accessing data without ownership. **&T** (immutable) allows reading; **&mut T** (mutable) allows reading and writing. Rules: 1. Only one mutable reference at a time. 2. No aliasing (cannot have two mutable or one mutable + one immutable reference simultaneously).

R4 — Medium: **Result<T, E>** holds `Ok(T)` or `Err(E)`. **Option<T>** holds `Some(T)` or `None`. The **? operator** propagates errors (returns early if `Err`).
```rust
fn read_file(path: &str) -> Result<String, std::io::Error> {
    std::fs::read_to_string(path)?
}
```

R5 — Medium: **Box<T>** is a heap-allocated pointer (single owner). **Rc<T>** is a reference-counted pointer (single thread). **Arc<T>** is an atomic reference-counted pointer (multi-thread). Use **Box** for recursive types or large data. Use **Rc** for single-threaded shared ownership. Use **Arc** for concurrent shared ownership.

R6 — Medium: **Traits** define behavior. Go interfaces are implicit; Rust traits are explicit. **dyn Trait** (trait objects) use vtables (dynamic dispatch). **T: Trait** (generics) use monomorphization (static dispatch). Generics are preferred for performance; trait objects for heterogeneous collections.

R7 — Hard: This fails because the compiler cannot guarantee that `x` or `y` outlive the function return. The references are tied to the function arguments, but the return type is a reference to one of them. **Fix**: Add a lifetime parameter: `fn longest<'a>(x: &'a str, y: &'a str) -> &'a str`.

R8 — Hard: **Send** means a type can be transferred across threads. **Sync** means it can be shared between threads. **Rc<T>** is not `Send` because its reference count is not atomic. **Arc<T>** is `Send` and `Sync` because it uses atomic reference counting.

R9 — Hard: Rust **async/await** uses state machines (Futures). A **Future** is a type that can be polled for completion. An **executor** (e.g., Tokio) drives Futures. Unlike Go's M:N scheduling, Rust async is often 1:1 with OS threads (unless using cooperative scheduling), but the runtime manages the state of suspended tasks.

R10 — Medium: **unsafe** blocks allow bypassing safety checks. You can: 1. Dereference raw pointers. 2. Call FFI functions. 3. Implement unsafe traits. It is justified for FFI, low-level optimizations, or when interfacing with unsafe C libraries.

R11 — Easy: **Pattern matching** (`match`) exhaustively checks all cases. **if let** checks a specific pattern and ignores others. The compiler enforces **exhaustiveness**: all possible cases must be handled, or a `..` wildcard must be used.

R12 — Easy: **Vec<T>** is a dynamic array on the heap. **[T; N]** is a fixed-size array on the stack. When a **Vec** exceeds capacity, it reallocates a larger buffer (typically 1.5x or 2x) and copies the old elements.

R13 — Easy: Rust **enums** are tagged unions (data + tag). C/Java enums are usually just integer constants. **Option<T>** is an enum with `Some(T)` and `None`. Rust has no null because `Option` handles the "absence of value" explicitly, preventing null pointer dereferences.

R14 — Easy: **impl** defines methods for a type. `&self` (read-only), `&mut self` (read-write), `self` (takes ownership). **Associated functions** (e.g., `String::new()`) do not take `self` and are used for constructors or utility methods.

R15 — Easy: **Derive macros** generate code automatically. Common traits: `Debug`, `Clone`, `PartialEq`, `Serialize`. You **cannot** derive if the struct has private fields (for `Clone`/`PartialEq`), or if the type is not `Copy` (for `Clone`), or if the struct is generic in a way that prevents code gen.

R16 — Medium: **Cow<'a, T>** (Clone on Write) holds a reference if the data is immutable, but clones it if it needs to be mutated. It avoids unnecessary allocations when the data is read-only. Example: `Cow::Borrowed(s)` vs `Cow::Owned(s.to_string())`.

R17 — Medium: **mod** declares a module. **use** imports items. **pub** makes items public. In Rust 2015, `mod` matched filenames strictly. In Rust 2018, `mod` declarations are more flexible, and `use` paths resolve based on the module tree rather than just file names.

R18 — Hard: **Pin<T>** prevents a value from being moved in memory. It is needed for **self-referential structs** or **async/await** (Futures) because the compiler might move a Future, invalidating internal references. **Unpin** is a trait to allow moving a pinned value.

R19 — Hard: **Declarative macros** (`macro_rules!`) are text substitution. **Procedural macros** (derive, attribute, function-like) are Rust functions that generate code. **Hygiene** ensures macros do not pollute the global scope or capture variables unintentionally.

R20 — Hard: **Zero-cost abstractions** mean high-level code compiles to the same machine code as hand-written C. **Iterators** avoid virtual dispatch. **Generics** use monomorphization (compile specific types). **Traits** use static dispatch (resolved at compile time), avoiding runtime overhead.
