## Networking

**N1 — Easy:** A Layer 2 switch operates at the Data Link layer and forwards frames based on MAC addresses. A Layer 3 switch operates at the Network layer; it performs all L2 functions but can also route packets between different VLANs/subnets using IP addresses.

**N2 — Easy:** 
*   **Network Address:** 10.0.0.0 (The /20 mask is 255.255.240.0; the block size is 16 in the third octet).
*   **Broadcast Address:** 10.0.15.255.

**N3 — Medium:** The TCP three-way handshake consists of: 1. Client sends **SYN**, 2. Server responds with **SYN-ACK**, 3. Client sends **ACK**. If the final ACK is lost, the server remains in the `SYN_RECV` state. The server will eventually timeout and retransmit the SYN-ACK. The client, believing the connection is open, may send data, which the server will accept if the sequence numbers align, effectively completing the handshake.

**N4 — Medium:** 
*   **SNAT (Source NAT):** Changes the source IP of a packet. *Example:* A home router replacing private internal IPs with one public IP to access the internet.
*   **DNAT (Destination NAT):** Changes the destination IP of a packet. *Example:* Port forwarding, where a request to a public IP on port 80 is redirected to an internal web server's private IP.

**N5 — Medium:** 
1. The certificate's Common Name (CN) or Subject Alternative Name (SAN) does not match the URL used to access the site.
2. The DNS record is pointing to the wrong server (e.g., a default landing page of a hosting provider).
3. A load balancer or reverse proxy is presenting a default/wrong certificate instead of the one specific to the target host.

**N6 — Medium:** A VLAN (802.1Q) is a Layer 2 broadcast domain limited to 4,096 IDs. A VxLAN (Virtual Extensible LAN) is a Layer 3 overlay that encapsulates L2 Ethernet frames in UDP packets, supporting up to 16 million IDs (VNIs). Choose VxLAN for massive multi-tenancy (cloud environments) or when L2 adjacency is needed across L3 boundaries.

**N7 — Hard:** This is **asymmetric routing**. The kernel uses the default gateway (eth0) for all traffic not destined for the local subnet of the receiving interface. 
**Fix:** Use Policy-Based Routing (PBR). Create a separate routing table for eth1 and a rule to use that table for traffic originating from eth1's IP:
`echo "200 eth1_table" >> /etc/iproute2/rt_tables`
`ip rule add from 192.168.1.5 table eth1_table`
`ip route add default via 192.168.1.1 dev eth1 table eth1_table`

**N8 — Hard:** BGP selects the best path based on these attributes (in order):
1. **Weight** (Highest, Cisco proprietary)
2. **Local Preference** (Highest)
3. **Locally Originated** (Prefer paths started by the router)
4. **AS Path Length** (Shortest)
5. **Origin Type** (IGP > EGP > Incomplete)
6. **MED (Multi-Exit Discriminator)** (Lowest)

**N9 — Hard:** Encapsulation adds overhead, reducing the space available for the inner payload.
*   Physical MTU: 1500 bytes.
*   VxLAN overhead: 50 bytes (Outer IP + UDP + VxLAN header).
*   IPsec overhead: Approx 50–70 bytes (depending on encryption/auth algorithms).
*   **Math:** $1500 - 50 - 60 = 1390$ bytes. The inner payload (MTU) should be set to $\approx 1390$ to avoid fragmentation.

**N10 — Medium:** ARP (Address Resolution Protocol) maps a known Layer 3 IP address to a Layer 2 MAC address. **Gratuitous ARP** is an unsolicited ARP response; it is used to announce an IP address to the network (detecting IP conflicts) or to update the ARP caches of other hosts after a MAC address change (e.g., during a VRRP/Keepalived failover).

**N11 — Easy:** Public IPs are globally unique and routable over the internet. Private IPs are used within local networks and are not routable on the public internet.
**RFC 1918 Ranges:** 
1. `10.0.0.0/8`
2. `172.16.0.0/12`
3. `192.168.0.0/16`

**N12 — Easy:** DNS (Domain Name System) translates human-readable names to IP addresses.
*   **A record:** Maps a hostname to an IPv4 address.
*   **AAAA record:** Maps a hostname to an IPv6 address.
*   **CNAME record:** An alias that maps one hostname to another hostname.

**N13 — Easy:** DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses. The **DORA** process:
1. **Discover:** Client broadcasts to find a server.
2. **Offer:** Server offers an IP address.
3. **Request:** Client requests to lease that specific IP.
4. **Acknowledge:** Server confirms the lease.

**N14 — Easy:** 
*   **Hub:** L1 (Physical). Broadcasts all data to all ports.
*   **Switch:** L2 (Data Link). Forwards data to specific ports based on MAC addresses.
*   **Router:** L3 (Network). Routes data between different networks based on IP addresses.

**N15 — Easy:** Half-duplex allows communication in both directions, but only one at a time (like a walkie-talkie). Full-duplex allows simultaneous bidirectional communication. Modern Ethernet links use **full-duplex**.

**N16 — Medium:** TTL (Time to Live) is a counter that prevents packets from looping infinitely; it is decremented by 1 at every hop. **Traceroute** sends packets with increasing TTLs (1, 2, 3...). Each router drops the packet when TTL reaches 0 and sends back an ICMP "Time Exceeded" message, allowing the sender to identify each hop.

**N17 — Medium:** A NAT gateway allows instances in a private subnet to initiate outbound traffic to the internet while blocking unsolicited inbound traffic.
*   **Static NAT:** 1:1 mapping of a private IP to a public IP.
*   **Dynamic NAT:** Maps a private IP to a public IP from a pool of available addresses.
*   **PAT (Port Address Translation):** Maps many private IPs to a single public IP using unique source ports.

**N18 — Hard:** ECMP distributes packets across multiple paths of equal cost to increase bandwidth and redundancy. It uses a **hash** of the "5-tuple" (Src IP, Dst IP, Src Port, Dst Port, Protocol) to ensure all packets of a single flow take the same path. **Asymmetric flows** occur when the return path differs from the forward path; stateful firewalls will drop these packets because they haven't seen the initial SYN/handshake on that specific interface.

**N19 — Hard:** The problem is that the **TCP Window Size** (the amount of data sent before requiring an ACK) is smaller than the **Bandwidth-Delay Product (BDP)**. The sender stops and waits for ACKs, leaving the pipe underutilized. **TCP Window Scaling (RFC 1323)** adds a scale factor to the window size field in the TCP header, allowing the window to grow beyond 64KB (up to 1GB), filling the BDP.

**N20 — Hard:** 802.1Q adds a 4-byte tag to the Ethernet frame. On Linux, you create sub-interfaces: `ip link add link eth0 name eth0.10 type vlan id 10`. 
**Frame Format:** [Destination MAC] [Source MAC] [**TPID (0x8100)**] [**TCI (Priority/VLAN ID)**] [EtherType] [Payload] [FCS].

## Linux

**L1 — Easy:** A **hard link** is an additional pointer to the same inode (the actual data on disk); deleting the original file doesn't remove the data. A **symbolic link** (symlink) is a separate file that contains a path to another file; if the original file is deleted, the symlink becomes "broken."

**L2 — Easy:** `find /var/log -type f -size +100M`

**L3 — Medium:** State D is **uninterruptible sleep**, usually occurring when a process is waiting for I/O (e.g., a hung NFS mount). Because the process is waiting for a kernel-level response and cannot be interrupted, it **cannot** be killed by `kill -9` until the I/O operation completes or times out.

**L4 — Medium:** cgroups v1 had separate hierarchies for each controller (CPU, memory), leading to complexity and inconsistency. cgroups v2 provides a **unified hierarchy**, where a process belongs to one group for all controllers. `systemd` prefers v2 because it simplifies resource management and provides better consistency for containerization.

**L5 — Medium:** `nftables` is the modern replacement for `iptables`. It uses a more efficient virtual machine-like bytecode and a cleaner syntax. The kernel handles both via the `nf_tables` subsystem; the `iptables-nft` binary translates legacy iptables commands into nftables bytecode.

**L6 — Medium:** A process has deleted a large file, but it still has the file handle open. `df` reports disk usage based on the filesystem's block map (which still counts the open file), while `du` traverses the directory tree (where the file is gone). **Fix:** Restart the process or truncate the file via `/proc/<pid>/fd/`.

**L7 — Hard:** 
1. **UEFI:** Initializes hardware, reads NVRAM to find the bootloader.
2. **Bootloader (GRUB):** Loads the kernel and `initramfs` into memory.
3. **Kernel:** Initializes CPU/RAM, mounts `initramfs` as a temporary root.
4. **initramfs:** Loads essential drivers (storage/filesystem) to mount the real root filesystem.
5. **Root:** The real `/` is mounted; the kernel executes `/sbin/init` (systemd).
6. **systemd:** Starts services and reaches the defined `target` (e.g., `multi-user.target`).

**L8 — Hard:** `available` memory accounts for reclaimable slab and page cache. However, if memory is heavily fragmented or pinned (e.g., by HugePages or locked memory), the kernel cannot reclaim it fast enough to satisfy a request, triggering the OOM killer. Tunables include `vm.min_free_kbytes` (forces the kernel to keep more memory free) and `vm.swappiness` (controls how aggressively it swaps).

**L9 — Medium:** `ip netns` manages **Network Namespaces**. It isolates the network stack (interfaces, routing tables, firewall rules). Container runtimes (like Docker/containerd) use this to give each container its own isolated network environment, allowing multiple containers to use port 80 on the same host.

**L10 — Medium:** 
*   **SIGTERM (15):** Polite request to terminate; allows cleanup. (Catchable)
*   **SIGKILL (9):** Immediate termination by the kernel. (Not catchable)
*   **SIGQUIT (3):** Request to terminate and produce a core dump. (Catchable)

**L11 — Easy:** `stdin` (0) is input, `stdout` (1) is standard output, `stderr` (2) is error output.
**Redirect stderr to file, keep stdout on terminal:** `command 2> error.log`

**L12 — Easy:** `chmod 755` sets permissions:
*   **7 (Owner):** Read (4) + Write (2) + Execute (1) = Full access.
*   **5 (Group):** Read (4) + Execute (1) = Read/Execute.
*   **5 (Others):** Read (4) + Execute (1) = Read/Execute.

**L13 — Easy:** The **root user** is the system superuser (UID 0) with unrestricted access to all files and commands. A **sudo user** is a normal user who is granted permission (via `/etc/sudoers`) to execute specific commands as root.

**L14 — Easy:** A package manager automates the installation, upgrading, and removal of software and its dependencies.
*   **Debian/Ubuntu:** `apt` (or `dpkg`).
*   **RHEL/Fedora:** `dnf` (or `yum`/`rpm`).

**L15 — Easy:** `/etc/fstab` contains static information about filesystems and where they should be mounted at boot. If an entry is misconfigured (e.g., wrong UUID or mount option), the system may fail to boot and drop into **emergency mode**.

**L16 — Medium:** LVM provides a flexible way to manage disk space.
*   **PV (Physical Volume):** The raw disk or partition.
*   **VG (Volume Group):** A pool of PVs.
*   **LV (Logical Volume):** A "virtual partition" carved from a VG.
**Extend:** `lvextend -L +10G /dev/vg/lv` followed by `resize2fs /dev/vg/lv` (for ext4) or `xfs_growfs /mountpoint` (for XFS).

**L17 — Hard:** The I/O scheduler manages the order of block device requests.
*   **mq-deadline:** Prioritizes reads over writes to reduce latency. Best for general purpose.
*   **bfq (Budget Fair Queuing):** Provides proportional bandwidth; best for interactive desktop use.
*   **none:** No scheduling; best for NVMe/SSDs where the device handles its own queuing.
**Change at runtime:** `echo none > /sys/block/sda/queue/scheduler`

**L18 — Hard:** Load average is the average number of processes in a **runnable** or **uninterruptible** state. I/O wait (State D) inflates load because the process is technically "waiting" but still counted.
**Diagnosis:**
*   **CPU:** `top` or `htop` (look for `%user`, `%sys`).
*   **Disk:** `iostat -xz 1` (look for `%util` and `await`).
*   **Network:** `sar -n DEV 1` or `nload`.

**L19 — Hard:** SELinux uses **labels** (Type Enforcement) to restrict access based on policy, regardless of root privileges.
*   **Enforcing:** Blocks unauthorized access and logs it.
*   **Permissive:** Allows unauthorized access but logs it.
*   **Disabled:** No enforcement.
**Troubleshoot port:** Use `semanage port -a -t <type> -p tcp <port>` to add the non-standard port to the allowed policy for that daemon.

**L20 — Hard:** When the CPU accesses a virtual address not in the TLB/Page Table, a **page fault** occurs.
*   **Minor:** The page is in RAM but not mapped to the process's MMU.
*   **Major:** The page must be loaded from disk (swap or file).
**THP (Transparent Huge Pages):** Reduces TLB misses by using 2MB pages instead of 4KB. It can improve performance for large memory footprints but cause "latency spikes" during allocation (compaction). Disable it for databases (e.g., Redis, MongoDB) via `/sys/kernel/mm/transparent_hugepage/enabled`.
