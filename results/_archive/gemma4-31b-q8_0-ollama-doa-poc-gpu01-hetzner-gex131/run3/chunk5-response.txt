## .NET / C#

**DN1 — Easy:** A `class` is a reference type (allocated on the heap), while a `struct` is a value type (usually allocated on the stack or inline). Use a `struct` for small, immutable data structures that represent a single value (e.g., `Point`, `ComplexNumber`) to reduce GC pressure and improve memory locality.

**DN2 — Easy:** `IEnumerable<T>` is for in-memory collections; it uses client-side filtering. `IQueryable<T>` is for remote data sources (like databases); it builds an expression tree that is translated into a provider-specific query (e.g., SQL). This distinction is critical because `IEnumerable` would pull the entire table into memory before filtering, whereas `IQueryable` filters at the database level.

**DN3 — Medium:** `async/await` allows asynchronous programming by transforming a method into a state machine, freeing the calling thread while waiting for I/O. A `Task` is a class representing an ongoing operation (heap allocated). A `ValueTask` is a struct that can return a result synchronously without allocating a `Task` object on the heap. Use `ValueTask` in high-frequency methods where the result is often already available (e.g., reading from a cached buffer).

**DN4 — Medium:** Dependency Injection (DI) is a pattern where dependencies are provided to a class rather than created internally. 
- **Transient:** Created every time they are requested.
- **Scoped:** Created once per client request (connection).
- **Singleton:** Created once for the lifetime of the application.
**Common Bug:** "Captive Dependency"—injecting a Scoped service into a Singleton. The Scoped service is effectively promoted to a Singleton, which can lead to memory leaks or `ObjectDisposedException` (e.g., with `DbContext`).

**DN5 — Medium:** `string` is an immutable heap object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory (heap, stack, or unmanaged). Use `Span<T>`/`ReadOnlySpan<T>` for high-performance parsing or slicing of strings/arrays to avoid creating multiple substring allocations.

**DN6 — Medium:** The GC uses a generational approach to optimize collection. **Gen 0** (short-lived), **Gen 1** (buffer), and **Gen 2** (long-lived). The **Large Object Heap (LOH)** handles objects > 85KB to avoid expensive memory compaction. `IDisposable` is needed for **unmanaged resources** (file handles, sockets, DB connections) because the GC only manages memory, not external OS handles.

**DN7 — Hard:** `ConfigureAwait(false)` tells the awaiter that the continuation does not need to run on the original `SynchronizationContext` (e.g., the UI thread or the ASP.NET request context). Use it in library code to avoid deadlocks and improve performance. Do NOT use it in application code where you must update UI elements or access request-specific context.

**DN8 — Hard:** 
- **Primary Constructors:** Parameters defined directly in the class declaration.
- **Collection Expressions:** Using `[]` for array/list initialization.
- **FrozenDictionary:** A highly optimized, read-only dictionary for scenarios where the set is created once and read many times.
```csharp
// Primary Constructor with DI
public class OrderService(IDbContext db) 
{
    public async Task Process() => await db.SaveChangesAsync();
}
```

**DN9 — Hard:** The cause is likely a "fire-and-forget" async call or a background task attempting to use a `DbContext` after the HTTP request has completed and the DI container has disposed of the Scoped `DbContext`. 
**Fix:** Await all tasks within the request scope, or use `IServiceScopeFactory` to create a manual scope within the background task.

**DN10 — Medium:** A `record` is a class with built-in value-based equality. A `record struct` is a value type with value-based equality. Use `record` for immutable DTOs; `record struct` for small, high-performance value objects; and `class` for objects with identity and mutable state.

**DN11 — Easy:** 
- `ref`: Passes by reference; variable must be initialized before passing.
- `out`: Passes by reference; variable must be assigned inside the method.
- `in`: Passes by reference but makes it read-only (prevents copying large structs).

**DN12 — Easy:** Nullable Reference Types (`string?`) are a compile-time static analysis feature to prevent `NullReferenceException`. They do not change the runtime type. Nullable Value Types (`int?`) are actual wrappers (`Nullable<T>`) that allow a value type to represent a null state.

**DN13 — Easy:** LINQ (Language Integrated Query) provides a consistent way to query data. **Method syntax** uses extension methods (`.Where()`), while **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query is not executed when defined, but when the sequence is iterated (e.g., via `foreach` or `.ToList()`).

**DN14 — Easy:** Constraints restrict the types that can be used as generic arguments.
- `where T : class`: Reference type.
- `where T : struct`: Value type.
- `where T : new()`: Must have a public parameterless constructor.
- `where T : IComparable<T>`: Must implement the interface.
Combine them (e.g., `where T : class, IEntity, new()`) to ensure the type meets all required architectural contracts.

**DN15 — Easy:** An `abstract class` can provide implementation and maintain state; an `interface` defines a contract. **Default Interface Methods** (C# 8+) allow interfaces to provide a default implementation, blurring the line by allowing interfaces to evolve without breaking existing implementations.

**DN16 — Medium:** The middleware pipeline is a series of delegates called in sequence.
- `app.Use()`: Can call the next middleware in the pipeline.
- `app.Map()`: Branches the pipeline based on the request path.
- `app.Run()`: A terminal middleware that stops the pipeline.
**Ordering:** Critical (e.g., `UseRouting` must come before `UseAuthorization`). Exception middleware is placed early in the pipeline to catch exceptions from all subsequent middleware.

**DN17 — Medium:** `Channel<T>` is a high-performance, async producer-consumer queue. Unlike `BlockingCollection<T>`, which blocks threads, `Channel<T>` uses `async/await`. 
**Backpressure:** Use a **Bounded Channel**. When the channel is full, `WriteAsync` will asynchronously wait (suspend) until space becomes available, preventing the producer from overwhelming the consumer.

**DN18 — Hard:** Source Generators inspect code during compilation and generate additional C# source files. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are fully type-safe and visible to the compiler. **Incremental Generators** are preferred because they use a caching pipeline to only re-generate code for the specific parts of the syntax tree that changed, significantly improving IDE performance.

**DN19 — Hard:** TPL Dataflow is a library for building actor-like pipelines.
- `ActionBlock`: Processes messages (sink).
- `TransformBlock`: Transforms input to output (map).
- `BufferBlock`: Acts as a queue.
Compared to `Channels`, Dataflow provides higher-level orchestration (linking blocks, handling completion propagation) whereas Channels are lower-level primitives for simple queuing.

**DN20 — Hard:** Minimal APIs allow creating endpoints without the overhead of Controllers. 
- **Trade-offs:** Faster startup and less boilerplate, but can become disorganized in large apps. 
- **OpenAPI:** Fully supported via `Microsoft.AspNetCore.OpenApi`.
- **Route Groups:** `app.MapGroup("/api")` allows shared prefixes and middleware.
- **Endpoint Filters:** Allow running logic before/after the endpoint handler (similar to Action Filters).

## Python

**P1 — Easy:** A `list` is mutable and ordered; a `tuple` is immutable and ordered. A `set` is a mutable collection of unique elements; a `frozenset` is an immutable version of a set (and thus hashable).

**P2 — Easy:** The GIL is a mutex that allows only one thread to execute Python bytecode at a time. It affects **CPU-bound** workloads. Workarounds include using the `multiprocessing` module (separate processes), writing extensions in C/Rust, or using Python 3.13's experimental "free-threaded" mode.

**P3 — Medium:** `copy` (shallow) creates a new object but inserts references to the items found in the original. `deepcopy` recursively copies everything. 
**Example:** If you have a list of lists `[[1], [2]]`, a shallow copy's inner lists are the same objects as the original. Modifying `copy[0][0] = 99` will change the original list.

**P4 — Medium:** Decorators are functions that wrap other functions to modify their behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return result
    return wrapper
```

**P5 — Medium:** Generators use `yield` to produce values lazily one at a time, returning an iterator instead of a full list in memory. `yield from` is used to delegate the generation of values to another iterable or generator.

**P6 — Medium:** The event loop manages asynchronous tasks. 
- `asyncio.run()`: Entry point that starts the loop.
- `asyncio.gather()`: Runs multiple awaitables concurrently and waits for all to finish.
- `asyncio.create_task()`: Schedules a coroutine to run on the loop immediately.
`time.sleep()` is blocking; it stops the entire thread, including the event loop. Use `await asyncio.sleep()`.

**P7 — Hard:** Python uses the **C3 Linearization** algorithm for MRO. In diamond inheritance, it ensures a class is always visited before its parents and parents are visited in the order specified in the class definition. 
**Result:** `D().who()` prints `"C"`. The MRO is `D -> B -> C -> A`. Since `B` doesn't define `who`, it checks `C`, which does.

**P8 — Hard:** A metaclass is the "class of a class"—it defines how a class is constructed. 
- `__init_subclass__`: A simpler hook to customize subclass creation without a full metaclass.
- **Use Case (Metaclass):** Enforcing strict API constraints or automatically registering all subclasses in a global registry.
- **Use Case (__init_subclass__):** Adding a common attribute to all subclasses of a base class.

**P9 — Hard:** 
- `threading`: Shared memory, GIL limited; best for I/O-bound tasks.
- `multiprocessing`: Separate memory, bypasses GIL; best for CPU-bound tasks.
- `concurrent.futures`: High-level API (`ThreadPoolExecutor`, `ProcessPoolExecutor`) for both.
**Serialization:** `multiprocessing` requires objects to be **pickled** (serialized) to be sent between processes, which can be slow or fail for complex objects (like open file handles).

**P10 — Medium:** `__slots__` tells Python not to use a dynamic dictionary (`__dict__`) for instance attributes. It prevents the creation of new attributes at runtime. **Impact:** Significantly reduces memory usage per instance and slightly increases attribute access speed.

**P11 — Easy:** A virtual environment is an isolated directory containing a specific Python binary and set of libraries. 
- `venv`: Standard library tool.
- `virtualenv`: Older, more feature-rich alternative.
- `conda`: Manages both Python and non-Python binary dependencies (common in Data Science).

**P12 — Easy:** Comprehensions provide a concise way to create lists, dicts, and sets. They are generally more readable and faster than `map()` and `filter()`. Use `map`/`filter` when you already have a pre-defined function to apply.

**P13 — Easy:** `==` checks for **value equality**; `is` checks for **identity** (same memory address). **Object Interning** is an optimization where Python reuses objects for small integers (-5 to 256) and certain strings, which is why `a is b` can be True for small ints.

**P14 — Easy:** `*args` collects extra positional arguments into a tuple; `**kwargs` collects keyword arguments into a dictionary. 
- `/`: Arguments before this must be positional-only.
- `*`: Arguments after this must be keyword-only.

**P15 — Easy:** Context managers handle setup and teardown.
- `__enter__/__exit__`: Class-based implementation.
- `@contextmanager`: Generator-based implementation using `yield`.
**Example:** A database transaction manager that commits on success and rolls back on exception.

**P16 — Medium:** Type hinting provides static analysis for better tooling and bug detection.
- `Union[A, B]`: Either A or B.
- `Optional[A]`: A or None.
- `Literal["read", "write"]`: Exactly one of these values.
- `TypeVar`: For generic types.
- `Protocol`: For structural typing (static duck typing).
`mypy`/`pyright` scan the code without running it to find type mismatches.

**P17 — Medium:** 
- `__repr__` (for developers/debugging) vs `__str__` (for end-users).
- `__eq__` (equality) vs `__hash__` (for use in sets/dicts). If `__eq__` is defined, `__hash__` is set to `None` unless explicitly implemented.
- `__getattr__` (called only if attribute isn't found) vs `__getattribute__` (called for every attribute access).

**P18 — Hard:** Descriptors are objects that define `__get__`, `__set__`, or `__delete__`. They allow custom logic for attribute access. `property` is a descriptor that implements getters/setters. `classmethod` and `staticmethod` are descriptors that modify how the function is bound to the class or instance.

**P19 — Hard:** 
- **Absolute:** `import package.module`. **Relative:** `from . import module`.
- `sys.path`: List of directories Python searches for modules.
- `PYTHONPATH`: Environment variable to add directories to `sys.path`.
- `__init__.py`: Marks a directory as a package (optional in Python 3.3+ for namespace packages).
- **Finder:** Locates the module. **Loader:** Loads the module into memory.

**P20 — Hard:** `dataclasses` (std lib) automate boilerplate for data-holding classes. `attrs` is a more powerful predecessor. `Pydantic` adds runtime type validation and parsing.
- `__post_init__`: Logic to run after the generated `__init__`.
- `field(default_factory=list)`: Prevents mutable default argument bugs.
- `frozen=True`: Makes the instance immutable.
**Choice:** Use `dataclasses` for internal data structures; use `Pydantic` for data coming from external sources (APIs/JSON) where validation is required.
