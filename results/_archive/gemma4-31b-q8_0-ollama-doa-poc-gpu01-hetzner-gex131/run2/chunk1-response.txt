## Networking

**N1 — Easy:** A Layer 2 switch operates at the Data Link layer and forwards frames based on MAC addresses. A Layer 3 switch operates at the Network layer; it performs all L2 functions but can also route packets between different IP subnets using IP addresses.

**N2 — Easy:** 
*   **Network Address:** 10.0.0.0 (The /20 mask is 255.255.240.0; the block size is 16 in the third octet).
*   **Broadcast Address:** 10.0.15.255.

**N3 — Medium:** The TCP three-way handshake consists of: 1. Client sends **SYN**, 2. Server responds with **SYN-ACK**, 3. Client sends **ACK**. If the final ACK is lost, the server remains in the `SYN_RECV` state. The server will eventually timeout and retransmit the SYN-ACK. The client, believing the connection is open, may send data, which the server will accept if it's within the window, effectively completing the handshake implicitly.

**N4 — Medium:** 
*   **SNAT (Source NAT):** Changes the source IP of a packet. *Example:* A home router replacing private internal IPs with one public IP to access the internet.
*   **DNAT (Destination NAT):** Changes the destination IP of a packet. *Example:* Port forwarding, where a request to a public IP on port 80 is redirected to an internal web server's private IP.

**N5 — Medium:** 
1.  **CN/SAN Mismatch:** The certificate was issued for `api.example.com`, but the request was made to `example.com`.
2.  **DNS Misconfiguration:** DNS points the hostname to an IP address of a server hosting a different site/certificate.
3.  **Incorrect SNI:** The client did not send the Server Name Indication (SNI) extension, and the server served a default certificate that doesn't match the host.

**N6 — Medium:** A VLAN (802.1Q) is a Layer 2 broadcast domain limited to 4,096 IDs. A VxLAN (Virtual Extensible LAN) is a Layer 3 overlay that encapsulates L2 Ethernet frames in UDP packets, supporting up to 16 million IDs (VNIs). Choose VxLAN for massive multi-tenancy (cloud) or when you need to extend L2 adjacency across L3 boundaries.

**N7 — Hard:** This is **asymmetric routing**. The kernel uses the default gateway (eth0) for all traffic not matching a local route, regardless of which interface received the packet. 
**Fix:** Use Policy-Based Routing (PBR). Create a separate routing table for eth1 and add a rule:
`ip route add 192.168.1.0/24 dev eth1 table 100`
`ip rule add from 192.168.1.5 table 100`

**N8 — Hard:** BGP selects the best path based on these attributes (in order):
1.  **Weight** (Cisco proprietary, local to router).
2.  **Local Preference** (Highest preferred, local to AS).
3.  **Locally Originated** (Next hop is 0.0.0.0).
4.  **AS Path Length** (Shortest path preferred).
5.  **Origin Type** (IGP > EGP > Incomplete).
6.  **MED (Multi-Exit Discriminator)** (Lowest preferred).

**N9 — Hard:** 
*   **Physical MTU:** 1500 bytes.
*   **VxLAN Overhead:** 50 bytes (Outer IP + UDP + VxLAN header).
*   **IPsec Overhead:** Typically ~50-70 bytes (ESP header, IV, Padding, ICV).
*   **Math:** $1500 - 50 (\text{VxLAN}) - 70 (\text{IPsec}) = 1380$ bytes.
The maximum inner payload (MTU) should be set to $\approx 1380$ to avoid fragmentation.

**N10 — Medium:** ARP (Address Resolution Protocol) maps a known Layer 3 IP address to a Layer 2 MAC address. **Gratuitous ARP** is an unsolicited ARP response; it is used to announce an IP address to the network to detect IP conflicts or update ARP caches after a failover (e.g., VRRP/Keepalived).

**N11 — Easy:** Public IPs are globally unique and routable on the internet. Private IPs are used within local networks and are not routable on the public internet.
**RFC 1918 Ranges:** 
1.  `10.0.0.0/8`
2.  `172.16.0.0/12`
3.  `192.168.0.0/16`

**N12 — Easy:** DNS (Domain Name System) translates human-readable names to IP addresses.
*   **A record:** Maps a hostname to an IPv4 address.
*   **AAAA record:** Maps a hostname to an IPv6 address.
*   **CNAME record:** An alias that maps one hostname to another hostname.

**N13 — Easy:** DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses. The **DORA** process:
1.  **Discover:** Client broadcasts to find a server.
2.  **Offer:** Server offers an IP address.
3.  **Request:** Client requests the offered IP.
4.  **Acknowledge:** Server confirms the lease.

**N14 — Easy:** 
*   **Hub:** L1 (Physical). Broadcasts all data to all ports.
*   **Switch:** L2 (Data Link). Forwards data to specific MAC addresses.
*   **Router:** L3 (Network). Routes data between different networks using IP addresses.

**N15 — Easy:** Half-duplex allows communication in both directions, but only one at a time (like a walkie-talkie). Full-duplex allows simultaneous bidirectional communication. Modern Ethernet links use **full-duplex**.

**N16 — Medium:** TTL (Time to Live) is a counter that decrements at every hop to prevent packets from looping infinitely. **Traceroute** sends packets with increasing TTLs (1, 2, 3...). Each router decrements the TTL to 0 and sends back an ICMP "Time Exceeded" message, revealing its identity.

**N17 — Medium:** A NAT gateway allows devices in a private network to access the internet without having public IPs.
*   **Static NAT:** 1-to-1 mapping of a private IP to a public IP.
*   **Dynamic NAT:** Maps a private IP to a public IP from a pool of available addresses.
*   **PAT (Port Address Translation):** Maps many private IPs to a single public IP using different source ports.

**N18 — Hard:** ECMP distributes traffic across multiple paths of equal cost. It uses a **hash** of the "5-tuple" (Src IP, Dst IP, Src Port, Dst Port, Protocol) to ensure a single flow always takes the same path. **Asymmetric flows** occur when the return path differs from the forward path; stateful firewalls will drop these packets because they lack the "session state" for the return traffic.

**N19 — Hard:** The problem is that the **TCP Window Size** (the amount of data sent before an ACK is required) is smaller than the **Bandwidth-Delay Product (BDP)**. The sender stops and waits for ACKs, leaving the pipe underutilized. **TCP Window Scaling (RFC 1323)** adds a scale factor to the window size field in the TCP header, allowing windows up to 1GB instead of 64KB.

**N20 — Hard:** 802.1Q adds a 4-byte tag to the Ethernet frame containing the VLAN ID. 
**Linux Config:** Create sub-interfaces: `ip link add link eth0 name eth0.10 type vlan id 10` (repeat for 20, 30).
**Frame Format:** [Dest MAC][Src MAC][**802.1Q Tag (TPID + TCI/VLAN ID)**][Type/Length][Payload][FCS].

## Linux

**L1 — Easy:** A **hard link** is a direct pointer to the file's inode; it is indistinguishable from the original file and persists if the original name is deleted. A **symbolic link** (symlink) is a special file that contains a path to another file; if the original file is deleted, the symlink becomes "broken."

**L2 — Easy:** `find /var/log -type f -size +100M`

**L3 — Medium:** State D is **Uninterruptible Sleep**, usually occurring when a process is waiting for I/O (e.g., NFS mount or disk failure). It cannot be killed by `kill -9` because the process is not currently checking for signals; it will only terminate once the kernel call returns or the system reboots.

**L4 — Medium:** cgroups v1 had separate hierarchies for each controller (CPU, Memory), leading to complexity. cgroups v2 uses a **unified hierarchy**, ensuring a process is in the same group for all controllers. `systemd` prefers v2 because it simplifies resource management and provides better consistency.

**L5 — Medium:** `nftables` is the modern replacement for `iptables`, featuring a more efficient VM-based architecture and a cleaner syntax. The kernel handles both via the `nf_tables` subsystem; the `iptables-nft` binary acts as a translation layer that converts legacy iptables commands into nftables bytecode.

**L6 — Medium:** A process has deleted a large file, but still holds an **open file descriptor** to it. The disk space is not reclaimed until the process closes the file or terminates. `du` scans the directory tree (and doesn't see the deleted file), while `df` reports actual block usage from the filesystem.

**L7 — Hard:** 
1.  **UEFI:** Initializes hardware, reads NVRAM to find the bootloader.
2.  **Bootloader (GRUB):** Loads the kernel and `initramfs` into memory.
3.  **Kernel:** Initializes CPU/Memory, mounts `initramfs` as a temporary root.
4.  **Initramfs:** Loads essential drivers (storage/filesystem) to mount the real root filesystem.
5.  **Root:** The real root is mounted; the kernel executes `/sbin/init` (systemd).
6.  **systemd:** PID 1 starts services and reaches the target (e.g., `multi-user.target`).

**L8 — Hard:** `available` memory accounts for reclaimable slab and page cache. However, if memory is heavily fragmented or if "pinned" pages (non-reclaimable) are high, the kernel cannot allocate a contiguous block for a request, triggering the OOM killer. 
**Tunables:** `vm.swappiness` (controls preference for swapping vs reclaiming cache) and `vm.min_free_kbytes` (forces the kernel to keep a minimum amount of free RAM).

**L9 — Medium:** `ip netns` manages **Network Namespaces**. It provides an isolated instance of the network stack (interfaces, routing tables, firewall rules). Container runtimes (like Docker/containerd) use this to give each container its own isolated network environment.

**L10 — Medium:** 
*   **SIGTERM (15):** Request for termination; catchable/ignorable (allows graceful shutdown).
*   **SIGKILL (9):** Immediate termination by kernel; **cannot** be caught or ignored.
*   **SIGQUIT (3):** Request for termination and core dump; catchable.

**L11 — Easy:** `stdin` (0) is input, `stdout` (1) is standard output, `stderr` (2) is error output.
**Redirect stderr to file, keep stdout on terminal:** `command 2> error.log`

**L12 — Easy:** `chmod 755` sets permissions:
*   **7 (Owner):** Read (4) + Write (2) + Execute (1) = Full access.
*   **5 (Group):** Read (4) + Execute (1) = Read/Execute.
*   **5 (Others):** Read (4) + Execute (1) = Read/Execute.

**L13 — Easy:** The **root user** is the system superuser (UID 0) with unrestricted access to all files and commands. A **sudo user** is a normal user who is granted permission (via `/etc/sudoers`) to execute specific commands as root.

**L14 — Easy:** A package manager automates the installation, upgrading, and removal of software and its dependencies.
*   **Debian/Ubuntu:** `apt` (or `dpkg`).
*   **RHEL/Fedora:** `dnf` (or `yum`/`rpm`).

**L15 — Easy:** `/etc/fstab` contains static information about filesystems and where they should be mounted at boot. If an entry is misconfigured (e.g., wrong UUID or mount option), the system may fail to boot and drop into **emergency mode**.

**L16 — Medium:** LVM provides a flexible way to manage disk space.
*   **PV (Physical Volume):** A raw disk or partition.
*   **VG (Volume Group):** A pool of PVs.
*   **LV (Logical Volume):** A "virtual partition" carved from a VG.
**Extend:** `lvextend -L +10G /dev/vg/lv` followed by `resize2fs /dev/vg/lv` (for ext4) or `xfs_growfs /mountpoint` (for XFS).

**L17 — Hard:** The I/O scheduler manages the order of block device requests.
*   **mq-deadline:** Prioritizes reads over writes to reduce latency; good for general use.
*   **bfq (Budget Fair Queuing):** Provides proportional bandwidth; best for interactive desktop use.
*   **none:** No scheduling; best for NVMe/SSDs where the device handles its own queuing.
**Change at runtime:** `echo none > /sys/block/sda/queue/scheduler`

**L18 — Hard:** Load average is the average number of processes in a **runnable** or **uninterruptible** state. I/O wait (State D) inflates this because the process is "waiting" but still counted.
**Diagnosis:** 
*   **CPU:** `top` or `htop` (look for `%user`, `%sys`).
*   **Disk:** `iostat -xz 1` (look for `%util` and `await`).
*   **Network:** `sar -n DEV 1` or `iftop`.

**L19 — Hard:** SELinux uses **labels** (contexts) on files, processes, and ports to enforce Mandatory Access Control (MAC).
*   **Enforcing:** Blocks unauthorized access and logs it.
*   **Permissive:** Allows unauthorized access but logs it.
*   **Disabled:** No enforcement.
**Troubleshoot port:** Use `semanage port -a -t <type> -p tcp <port>` to add the port to the allowed policy for that daemon.

**L20 — Hard:** When a process accesses a virtual address not in the MMU, a **page fault** occurs.
*   **Minor:** Page is in RAM but not mapped to the process's page table.
*   **Major:** Page must be loaded from disk (swap or file).
**THP (Transparent Huge Pages):** Reduces TLB misses by using 2MB pages instead of 4KB. It can improve performance for large memory footprints but cause "latency spikes" during allocation (compaction). Disable it for databases (e.g., Redis, MongoDB) via `/sys/kernel/mm/transparent_hugepage/enabled`.
