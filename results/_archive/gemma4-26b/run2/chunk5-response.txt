## .NET / C#

**DN1**
`class` is a reference type (allocated on the heap); `struct` is a value type (usually allocated on the stack). Use a `struct` for small, immutable data structures that have a short lifetime and no identity, typically under 16 bytes, to reduce GC pressure.

**DN2**
`IEnumerable<T>` performs in-memory filtering (client-side). `IQueryable<T>` builds an expression tree that is translated into SQL (server-side). This distinction matters because `IEnumerable` pulls all records into memory before filtering, which can crash an application with large datasets, whereas `IQueryable` lets the database do the heavy lifting.

**DN3**
`async/await` allows a thread to yield control back to the caller while waiting for an I/O operation to complete, preventing thread starvation. `Task` represents an asynchronous operation; `ValueTask` is a value-type wrapper around `Task` (or a result). Use `ValueTask` when the operation is likely to complete synchronously to avoid unnecessary heap allocations.

**DN4**
Dependency Injection (DI) is a pattern where objects receive their dependencies from an external source rather than creating them.
- **Transient**: New instance every time it is requested.
- **Scoped**: One instance per client request (e.g., per HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Bug**: Injecting a **Scoped** service into a **Singleton** causes the Scoped service to live as long as the Singleton (Captive Dependency), which can lead to stale data or `ObjectDisposedException`.

**DN5**
`string` is an immutable heap-allocated object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous memory region. Use `Span<T>` for high-performance parsing/slicing to avoid creating new string allocations (reducing GC pressure).

**DN6**
The GC manages memory automatically. **Gen 0**: Short-lived objects; **Gen 1**: Buffer for objects surviving Gen 0; **Gen 2**: Long-lived objects. **LOH (Large Object Heap)**: Objects >85,000 bytes are allocated here directly to avoid expensive copying; they are not compacted by default. `IDisposable` is needed to manually release **unmanaged** resources (file handles, DB connections) because the GC only knows how to reclaim managed memory.

**DN7**
`ConfigureAwait(false)` tells the runtime not to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to prevent deadlocks and improve performance. **Do NOT** use it in application-level code (like UI or ASP.NET Core controllers) if you need to access context-specific data (like `HttpContext.Current` in legacy .NET or UI elements in WinForms).

**DN8**
- **Primary Constructors**: Define parameters directly in the class header.
- **Collection Expressions**: `int[] arr = [1, 2, 3];`
- **FrozenDictionary**: An immutable, highly optimized read-only dictionary.
```csharp
// Example: Primary Constructor with DI
public class UserService(IUserRepository repo) {
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9**
**Cause**: The `DbContext` is being shared across threads. `DbContext` is not thread-safe.
**Fix**: Ensure each asynchronous operation/request uses its own scope.
**Interaction**: In DI, `DbContext` is typically registered as **Scoped**. If a background task or a singleton uses the same `DbContext` instance concurrently, one thread may dispose of it or modify its state while another is reading, causing `ObjectDisposedException`.

**DN10**
`record` is a reference type with value-based equality. `record struct` is a value type with value-based equality. Use `record` for immutable data transfer objects (DTOs) and `record struct` for small, high-performance, stack-allocated data.

**NET11**
- `ref`: Passes by reference; allows modifying the original variable.
- `out`: Passes by reference; the method **must** assign a value before returning.
- `in`: Passes by reference; the value is **read-only** (prevents copying large structs).
Use `ref` for mutation, `out` for returning multiple values, and `in` for performance with large structs.

**DN12**
Nullable Reference Types (`string?`) are a compile-time static analysis feature to prevent `NullReferenceException`. They do **not** change the underlying type (it's still a reference type). Nullable Value Types (`int?`) are syntactic sugar for `Nullable<int>`, which is a structural change allowing a value type to hold a "null" state.

**DN13**
LINQ (Language Integrated Query) allows querying collections using SQL-like syntax. **Method Syntax** uses extension methods and lambdas; **Query Syntax** uses a declarative keyword-based approach. **Deferred Execution** means the query is not executed when defined, but when the results are actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14**
Constraints restrict the types allowed in generics:
- `T : class`: Must be a reference type.
- `T : struct`: Must be a non-nullable value type.
- `T : new()`: Must have a public parameterless constructor.
- `T : IComparable<T>`: Must implement the interface.
Combine them to ensure type safety and access to specific members (e.g., `where T : class, new()`).

**DN15**
An `abstract class` can have state (fields) and implementation; an `interface` defines a contract. **Default Interface Methods** allow interfaces to provide a default implementation, reducing breaking changes when adding methods to interfaces, blurring the line but not removing the distinction (interfaces still cannot hold instance state/fields).

**DN16**
The middleware pipeline processes HTTP requests sequentially.
- `app.Use()`: Adds a delegate that can call the next middleware.
- `app.Map()`: Branches the pipeline based on a path.
- `app.Run()`: A terminal middleware (no `next()` call).
**Ordering**: Crucial; e.g., `UseAuthentication` must come before `UseAuthorization`. **Exception Handling**: Usually the first middleware in the pipeline to catch errors from all subsequent steps.

**DN17**
`Channel<T>` is an async-capable, high-performance queue. `BlockingCollection<T>` is a synchronous, thread-safe collection.
**Example (Backpressure)**:
```csharp
var channel = Channel.CreateBounded<int>(10); // Limit capacity
// Producer:
await channel.Writer.WriteAsync(item); // Will await if channel is full
// Consumer:
await foreach (var item in channel.Reader.ReadAllAsync()) { ... }
```

**DN1/18**
**Source Generators** produce C# code during compilation. Unlike **Reflection** (runtime inspection) or **IL Weaving** (modifying binaries post-compile), they are part of the compiler. **Incremental Generators** are preferred because they only re-run when relevant inputs change, significantly improving IDE/build performance.

**DN19**
TPL Dataflow is a library for building actor-based pipelines.
- `ActionBlock`: Executes an action on incoming items.
- `TransformBlock`: Transforms an input to an output.
- `BufferBlock`: A buffer that holds items.
**Comparison**: `Channels` are better for simple, high-performance producer-consumer streams; `Dataflow` is better for complex, multi-stage processing pipelines with built-in buffering and concurrency controls.

**DN20**
**Minimal APIs** use a lambda-based approach instead of Controllers.
- **Pros**: Less boilerplate, faster startup, great for microservices.
- **Cons**: Can become messy for large apps; harder to organize than Controllers.
- **Features**: `RouteGroups` allow shared prefixes/middleware; `EndpointFilters` allow logic to run before/after an endpoint (similar to Action Filters).

## Python

**P1**
`list` is mutable; `tuple` is immutable. `set` is a mutable collection of unique elements; `frozenset` is an immutable version of a set (can be used as a dictionary key).

**P2**
The GIL is a mutex that protects access to Python objects, preventing multiple threads from executing Python bytecodes at once. It affects **CPU-bound** workloads (multithreading won't provide speedup). **Workarounds**: Use `multiprocessing` (separate memory spaces) or C-extensions that release the GIL.

**P3**
`copy` (shallow) creates a new collection object but populates it with references to the original elements. `deepcopy` creates a new collection and recursively copies all objects found in the original.
**Example**: If `list_a = [[1]]` and `list_b = copy(list_a)`, then `list_b[0].append(2)` modifies `list_a[0]`.

**P4**
Decorators wrap a function to extend behavior.
```python
import time
def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Execution time: {time.time() - start}s")
        return result
    return wrapper
```

**P5**
Generators use `yield` to return values one at a time, maintaining state. Unlike a list, they are **lazy** and don't store the whole collection in memory. `yield from` is used to delegate the generator's operations to a sub-generator (flattening).

**P6**
- `asyncio.run()`: Entry point to run the main coroutine.
- `asyncio.gather()`: Runs multiple coroutines concurrently and waits for all to finish.
- `asyncio.create_task()`: Schedules a coroutine to run on the loop immediately.
**Warning**: `time.sleep()` is blocking; it stops the entire thread, preventing the event loop from processing other tasks. Use `await asyncio.sleep()`.

**P7**
Python uses the **C3 Linearization** algorithm.
**Result**: `D().who()` prints `"C"`.
**Reason**: In `D(B, C)`, the MRO searches `D` $\to$ `B` $\to$ `C` $\to$ `A`. Since `C` overrides `who` and is encountered before `A` in the search path, `C.who` is executed.

**P/8**
A **metaclass** is a class of a class; it defines how a class behaves. `__init_subclass__` is a simpler way to customize class creation without the complexity of a metaclass.
- **Use `__init_subclass__`**: For simple registration or attribute injection in subclasses.
- **Use Metaclass**: When you need to modify the class creation process itself (e.g., changing the class dictionary).

**P9**
- `threading`: Best for **I/O-bound** tasks (shared memory).
- `multiprocessing`: Best for **CPU-bound** tasks (bypasses GIL).
- `concurrent.futures`: High-level interface for both.
**Serialization**: `multiprocessing` requires objects to be **pickled** (serialized) to be sent between processes. Complex objects (like open file handles) cannot be pickled.

**P10**
`__slots__` tells Python not to use a `__dict__` for each instance, instead allocating a fixed amount of space for specified attributes.
- **Use when**: You have millions of small objects.
- **Prevents**: Adding new attributes at runtime.
- **Impact**: Significant reduction in memory footprint.

**P11**
A **virtual environment** isolates project dependencies.
- `venv`: Built-in Python module for lightweight environments.
- `virtualenv`: A more powerful, third-party alternative to `venv`.
- `conda`: A package and environment manager that handles non-Python dependencies (great for Data Science).

**P12**
Comprehensions are concise syntax for creating collections. They are generally more readable and faster than `map()`/`filter()`. Use them for simple transformations; use `map`/`filter` when you already have a pre-defined function to apply.

**P13**
`==` checks for **equality** (value); `is` checks for **identity** (memory address). **Object interning** caches small integers (usually -5 to 256) and certain strings. Thus, `a is b` is True if both variables point to the same cached object in memory.

**P14**
`*args` captures extra positional arguments as a tuple; `**kwargs` captures extra keyword arguments as a dictionary.
- `/`: Marks parameters before it as **positional-only**.
- `*`: Marks parameters after it as **keyword-only**.

**P15**
Context managers handle setup/teardown.
```python
from contextlib import contextmanager
@contextmanager
def database_transaction():
    print("Begin")
    yield
    print("Commit")
# Usage: with database_transaction(): ...
```
**Example**: Managing a database connection or a temporary directory.

**P16**
Type hinting provides metadata for static analysis.
- `Union[int, str]`: Can be int or str.
- `Optional[int]`: Can be int or `None`.
- `Literal["a", "b"]`: Must be exactly "a" or "
- `TypeVar`: Generic placeholder.
- `Protocol`: Structural subtyping (duck typing).
`mypy` uses these to catch type errors before runtime.

**P17**
- `__repr__`: Official string representation (for developers/debugging).
- `__str__`: User-friendly string representation.
- `__eq__` vs `__hash__`: If you define `__eq__`, you must define `__hash__` if you want the object to be hashable (e.g., for use in a `set`).
- `__getattr__` (called if attribute not found) vs `__getattribute__` (called for *every* access).

**P18**
A **descriptor** is an object attribute access logic defined via `__get__`, `__set__`, or `__delete__`.
- `property`, `classmethod`, and `staticmethod` are all implemented as descriptors that manage how the underlying function is accessed and bound to the class or instance.

**P19**
- **Absolute**: `from package.module import func`.
- **Relative**: `from .module import func`.
- `sys.path`: List of strings that determines the search path for modules.
- `__init__.py`: Makes a directory a package.
- **Namespace Packages**: Allow splitting a package across multiple directories/locations.
- **Finder/Loader**: The Finder locates the module; the Loader reads the module's content.

**P20**
- `dataclasses`: Standard library, lightweight, focuses on data storage.
- `attrs`: More powerful, handles more edge cases, more configuration.
- `Pydantic`: Focuss on **data validation** and parsing (runtime enforcement).
**Features**: `__post_init__` runs after `__init__`; `field(default_factory=list)` prevents mutable default argument bugs.
**Choice**: Use **Pydantic** when you are consuming external JSON/API data and need to ensure types are correct at runtime.
