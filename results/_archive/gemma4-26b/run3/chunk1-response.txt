## Networking

**N1** — A Layer 2 switch forwards frames based on MAC addresses within a single broadcast domain. A Layer 3 switch can perform inter-VLAN routing by forwarding packets based on IP addresses, acting like a router for local networks.

**N2** — IP: 10.0.5.37/20. Mask: 255.255.240.0.
Network Address: **10.0.5.0**
Broadcast Address: **10.0.5.255**

**N3** — 1. Client sends `SYN`. 2. Server responds with `SYN-ACK`. 3. Client sends `ACK`. If the final `ACK` is lost, the server will eventually time out and close the connection, while the client may believe the connection is established until it fails to receive data or a response.

**N/A** — **SNAT** (Source NAT) changes the source IP of a packet (e.g., a private host accessing the internet via a gateway). **DNAT** (Destination NAT) changes the destination IP (e.g., port forwarding a public IP to a private web server).

**N5** — 1. The SSL certificate was issued for a different domain name. 2. The server is serving a self-signed certificate without the correct SAN (Subject Alternative Name). 3. An intermediate proxy/WAF is intercepting the traffic and presenting its own certificate.

**N6** — **VLAN** (802.1Q) uses a 12-bit ID (max 4096 IDs) to segment a single L2 domain. **VxLAN** is a MAC-in-UDP encapsulation (L2 over L2/L3) using a 24-bit VNI (max 16 million IDs). Choose VxLAN for large-scale cloud environments or multi-tenant overlays where 4096 VLANs are insufficient.

**N7** — The issue is **asymmetric routing**. The kernel receives a packet on `eth1` but uses the default gateway on `eth0` to reply. To fix this, use **Policy-Based Routing (PBR)**:
1. Create a new routing table: `echo "200 custom_table" >> /etc/iproute2/rt_tables`.
2. Add a route to that table: `ip route add 192.168.1.0/24 dev eth1 table custom_table`.
3. Add a rule to use that table for traffic from `eth1`: `ip rule add from 192.168.1.5 table custom_table`.

**N8** — BGP selects paths based on: 1. Weight (Cisco proprietary), 2. Local Preference, 3. Locally originated, 4. AS_Path length, 5. Origin type (IGP < EGP < Incomplete), 6. MED (Multi-Exit Discriminator).

**N9** — Encapsulation overhead reduces available payload.
Overhead: VXLAN (50 bytes) + IPsec (approx. 50-70 bytes).
If Physical MTU = 1500:
Inner Payload $\approx 1500 - 50 (\text{VXLAN}) - 50 (\text{IPsec}) - 20 (\text{Outer IP}) - 8 (\text/UDP}) = 1372$ bytes.
*Note: Significant fragmentation occurs if the inner packet exceeds the tunnel's effective MTU.*

**N10** — **ARP** maps an IP address to a MAC address. **Gratuitous ARP** is an ARP broadcast where the source and destination IP are the same; it is used to detect IP conflicts and update neighbor ARP caches when a NIC changes its MAC or IP.

**N11** — Public IPs are routable on the global internet; Private IPs are non-routable and used within local networks.
RFC 1918 ranges:
1. `10.0.0.0/8`
2. `172.16.0.0/12`
3. `192.168.0.0/16`

**N12** — **DNS** (Domain Name System) resolves hostnames to IPs.
**A**: IPv4 address.
**AAAA**: IPv6 address.
**CNAME**: An alias pointing one domain name to another.

**N13** — **DHCP** (Dynamic Host Configuration Protocol) automates IP assignment.
**DORA**: 1. **D**iscover (Client searches for server), 2. **O**ffer (Server offers IP), 3. **R**equest (Client requests offered IP), 4. **A**cknowledge (Server confirms).

**N14** — **Hub**: Layer 1 (broadcasts to all). **Switch**: Layer 2 (forwards to specific MAC). **Router**: Layer 3 (forwards based on IP).

**N15** — **Half-duplex**: One direction at a time (collision possible). **Full-duplex**: Simultaneous two-way communication. Modern Ethernet uses **Full-duplex**.

**N16** — **TTL** (Time to Live) prevents infinite loops by decrementing at each hop. **Traceroute** sends packets with incrementing TTLs (1, 2, 3...); when TTL reaches 0, the router returns an ICMP "Time Exceeded" message, revealing its IP.

**N17** — A **NAT Gateway** allows private hosts to access the internet.
**Static NAT**: 1:1 mapping (fixed private to fixed public).
**Dynamic NAT**: 1:1 mapping from a pool of public IPs.
**PAT**: Many-to-one mapping using different source ports to distinguish flows.

**N18** — **ECMP** distributes traffic across multiple paths with equal routing metrics. Common strategy: **5-tuple hash** (Src IP, Dst IP, Src Port, Dst Port, Protocol). **Problem**: If a firewall is stateful, asymmetric flows (request on Path A, response on Path B) will cause the firewall to drop the "unrecognized" return traffic.

**N19** — The **Bandwidth-Delay Product (BDP)** defines the amount of data "in flight" needed to saturate the link. Here, 10MB is needed, but the 64KB window limits throughput to $\text{Window Size} / \text{RTT}$. **TCP Window Scaling** adds a scale factor to the window size field in the TCP header, allowing windows much larger than 6/16 bits.

**N20** — **802.1Q** inserts a 4-byte tag into the Ethernet frame containing the VLAN ID.
**Linux Config**: Create sub-interfaces (e.g., `eth0.10`, `eth0.20`, `eth0.30`) using `ip link`.
**Frame Format**: [Dest MAC][Src MAC][802.1Q Tag (VLAN ID)][EtherType][Payload][FCS].

## Linux

**L1** — A **Hard link** is a pointer to the same inode (same data, same file). A **Symbolic link** is a special file containing a path to another file (can cross filesystems, can point to non-existent files).

**L2** — `sudo find /var/log -type f -size +100M`

**L3** — **D state** means the process is waiting for I/O (usually disk or network) and cannot be interrupted by signals. You **cannot** kill it with `kill -9` because the process is not processing signals until the I/O completes.

**L4** — **cgroups v1** uses a hierarchical structure with separate trees for each controller (CPU, memory, etc.). **cgroups v2** uses a unified hierarchy, making resource accounting more consistent. **systemd** prefers v2 because it simplifies resource management and avoids the "split-view" problem of v1.

**L5** — **nftables** is the successor to **iptables**, offering a more efficient,-rule-based engine with better performance and a cleaner syntax. The kernel handles both via the `nf_tables` subsystem, which can translate iptables-style rules into nftables instructions.

**L6** — A file was deleted but is still being held open by a running process. Use `lsof +L1` to find it.

**L7** — 1. **UEFI** initializes hardware. 2. **Bootloader** (e.g., GRUB) loads the kernel. 3. **Kernel** initializes drivers. 4. **initramfs** provides temporary drivers/FS to mount the real root. 5. **Root FS** is mounted. 6. **systemd** (PID 1) starts user-space services/targets.

**L8** — `available` memory is low because `buff/cache` is "reclaimable" but not "free." If the kernel cannot reclaim cache fast enough to satisfy an allocation, or if the application is consuming memory faster than the kernel can free cache, OOM occurs. Tunables: `vm.swappiness` (controls preference for swapping vs. dropping cache) and `vm.vfs_cache_pressure`.

**L9** — `ip netns` creates **Network Namespaces**, which provide isolated network stacks (separate routing tables, interfaces, etc.). Container runtimes (like Docker) use them to ensure containers cannot sniff or interfere with other containers' traffic.

**L10** — **SIGTERM (15)**: Requests termination (can be caught/handled). **SIGKILL (9)**: Forces immediate termination (cannot be caught). **SIGQUIT (3)**: Requests termination and produces a core dump (can be caught).

**L11** — `stdout` (standard output), `stderr` (error output), `stdin` (standard input).
To redirect stderr to a file while showing stdout: `command 2> error.log`.

**L12** — `chmod 755`:
**7 (Owner)**: Read (4) + Write (2) + Execute (1).
**5 (Group)**: Read (4) + Execute (1).
**5 (Others)**: Read (4) + Execute (1).

**L13** — **Root** is the superuser with unrestricted access to all files and commands. A **sudo** user is a regular user granted specific permissions to execute commands with root privileges via the `/etc/sudoers` policy.

**L14** — **Debian/Ubuntu**: `apt`. **RHEL/Fedora**: `dnf` (or `yum`).

**L15** — `/etc/fstab` defines how disk partitions are mounted. A misconfiguration (e.g., wrong UUID or wrong mount options) can cause the system to fail to boot or enter emergency mode.

**L20** — **LVM** manages disk space via:
**PV (Physical Volume)**: Raw partitions/disks.
**VG (Volume Group)**: A pool of PVs.
**LV (Logical Volume)**: Virtual partitions carved from the VG.
**Extend**: `lvextend -L +1G /dev/vg/lv --resizefs`.

**L17** — **mq-deadline**: Prioritizes reads over writes (good for SSDs). **bfq**: Complex fairness-based scheduler (good for desktop/interactive). **none**: No scheduling (best for high-speed NVMe).
**Change**: `echo mq-deadline > /sys/block/sdX/queue/scheduler`.

**L18** — Load average measures the number of processes in **runnable** or **uninterruptible** (I/O) states. High load with low CPU suggests I/O wait (disk/network bottleneck).
**Diagnosis**: `top`/`htop` (check `%wa`), `iostat` (check disk utilization), `iotop` (find heavy I/O processes), `netstat`/`ss` (check network congestion).

**L19** — **SELinux** uses labels (contexts) on files/processes to enforce access.
**Modes**: **Enforcing** (blocks), **Permissive** (logs only), **Disabled** (off).
**Troubleshoot**: Check `/var/log/audit/audit.log` for `AVC` denials. Use `semanage port -a -t <type> -p tcp <port>` to allow the new port.

**L20** — **Minor fault**: Page is in memory but not mapped to the process. **Major fault**: Page must be fetched from disk. **THP** (Transparent Huge Pages) uses 2MB pages instead of 4KB to reduce TLB misses. **Disable THP** if the application (like Redis or MongoDB) suffers from high latency spikes due to "compaction" or memory fragmentation.
