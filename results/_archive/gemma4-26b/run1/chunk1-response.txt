## Networking

**N1** — A Layer 2 switch forwards frames based on MAC addresses within a single broadcast domain. A Layer 3 switch can perform inter-VLAN routing by inspecting IP addresses and forwarding packets between different subnets/broadcast domains.

**N2** — IP: 10.0.5.37/20. Mask: 255.255.240.0.
Network Address: **10.0.5.0**
Broadcast Address: **10.0.5.255**

**N3** — 1. Client sends `SYN`. 2. Server responds with `SYN-ACK`. 3. Client sends `ACK`. If the final `ACK` is lost, the server will not receive the confirmation and will retransmit `SYN-ACK` until it reaches a timeout/retry limit, eventually closing the half-open connection.

**N4** — **SNAT (Source NAT):** Changes the source IP of a packet (e.g., a private host accessing the internet via a gateway). **DNAT (Destination NAT):** Changes the destination IP (e.g., a load balancer directing traffic to a specific backend server).

**N/A** — (Note: N5 was provided as a prompt for 3 causes, but no question ID was assigned to the prompt itself. I will treat the prompt as the question).
1. The certificate was issued for a different domain (e.g., `wrongdomain.com`).
2. The certificate is missing the `Subject Alternative Name` (SAN) for the requested host.
3. A man-in-the-middle/proxy is intercepting the traffic with its own certificate.

**N6** — **VLAN (802.1Q):** A Layer 2 technology to partition a physical switch into multiple logical networks. **VxLAN:** A Layer 3 encapsulation protocol (MAC-in-UDP) used to create overlay networks. Choose **VxLAN** when you need to scale beyond 4096 VLANs or need to stretch Layer 2 networks across Layer 3 boundaries (SDN/Cloud).

**N7** — The issue is **asymmetric routing**. The kernel receives a packet on `eth1` but looks up the route for the destination in the default routing table, which points to `eth0`.
**Fix:** Use **Policy-Based Routing (PBR)**. Create a new routing table (e.g., `rt2`) with a specific gateway for `eth1` and use `ip rule` to direct traffic from `eth1`'s source IP to use `rt2`.

**N8** — BGP selects paths based on: 1. Weight (Cisco proprietary), 2. Local Preference, 3. Locally Originated, 4. AS Path Length, 5. Origin Type (IGP < EGP < Incomplete), 6. MED (Multi-Exit Discriminator), 7. eBGP over iBGP.

**N9** — Encapsulation overhead increases.
**Math:** Physical MTU (1500) - IPsec Overhead (approx 50-70 bytes) - VxLAN Overhead (50 bytes) = ~1380-1400 bytes.
*Calculation:* $1500 - (\text{IPsec overhead}) - (\text{UDP/IP/Eth overhead for VxLAN})$. If we assume 50 bytes for IPsec and 50 for VxLAN, max payload $\approx 1400$ bytes.

**N10** — **ARP** maps IP addresses to MAC addresses. **Gratuitous ARP** is an ARP broadcast where the source/destination IP is the host's own IP; it solves IP conflicts (detecting if someone else took my IP) and updates neighbor ARP caches during interface changes/failovers.

**N11** — Public IPs are routable on the global internet; Private IPs are for local networks only.
**RFC 1918 Ranges:**
1. `10.0.0.0/8`
2. `172.16.0.0/12`
3. `192.168.0.0/16`

**N12** — **DNS** translates domain names to IPs.
**A Record:** Maps hostname to IPv4.
**AAAA Record:** Maps hostname to IPv6.
**CNAME:** An alias that maps one hostname to another hostname.

**N13** — **DHCP** automates IP assignment. **DORA:** 1. **D**iscover (Client searches for server), 2. **O**ffer (Server proposes IP), 3. **R**equest (Client accepts IP), 4. **A**cknowledge (Server confirms).

**N14** — **Hub:** Layer 1 (Physical); broadcasts all traffic to all ports. **Switch:** Layer 2 (Data Link); forwards based on MAC. **Router:** Layer 3 (Network); forwards based on IP.

**N15** — **Half-duplex:** One direction at a time (like a walkie-talkie). **Full-duplex:** Simultaneous two-way communication. Modern Ethernet uses **Full-duplex**.

**N16** — **TTL (Time to Live)** prevents packets from looping infinitely by decrementing at each hop. **Traceroute** sends packets with increasing TTL values (1, 2, 3...); when TTL hits 0, the router returns an "ICMP Time Exceeded" message, revealing its IP.

**N17** — A **NAT Gateway** allows private hosts to access the internet.
**Static NAT:** 1:1 mapping (fixed).
**Dynamic NAT:** Mapping from a pool of public IPs.
**PAT (Port Address Translation):** Many private IPs mapped to one public IP using unique source ports.

**N18** — **ECMP** distributes traffic across multiple paths with equal routing metrics. **Strategies:** 5-tuple hash (Src/Dst IP, Src/Dst Port, Protocol). **Problem:** If a flow is hashed to Path A but the return traffic is hashed to Path B, a stateful firewall on Path B might drop the packet because it lacks the session state.

**N/19** — The **Bandwidth-Delay Product (BDP)** is the amount of data "in flight" required to fill the pipe. If BDP > TCP Window Size, the sender stops and waits for ACKs, causing low throughput. **Window Scaling** allows the window size to exceed 64KB by using a scale factor in the TCP header.

**N20** — 802.1Q adds a 4-byte "tag" to the Ethernet frame containing the VLAN ID.
**Linux Config:** Create sub-interfaces (e.g., `eth0.10`, `eth0.20`).
**Frame Format:** [Dest MAC][Src MAC][802.1Q Tag (VLAN ID)][EtherType][Payload][FCS].

## Linux

**L1** — A **Hard Link** is a pointer to the same inode (same data); deleting the original doesn't break the link. A **Symbolic Link** (symlink) is a file containing a path to another file; if the original is moved/deleted, the link breaks.

**L2** — `sudo find /var/log -type f -size +100M`

**L3** — **D state** means the process is waiting for I/O (usually disk or network) and cannot be interrupted by signals. You **cannot** kill it with `kill -9` because the process is stuck in the kernel waiting for a hardware response; you must resolve the underlying I/O issue or reboot.

**L4** — **cgroups v1** uses a separate hierarchy for every controller (CPU, memory, etc.). **cgroups v2** uses a unified hierarchy. **systemd** prefers v2 because it simplifies resource management and provides a consistent view of the process tree.

**L5** — **iptables** uses a framework of tables/chains; **nftables** is the successor with a more efficient, programmable VM-based execution. The kernel handles both via the `nf_tables` subsystem, which can translate/interact with legacy iptables rules.

**L6** — **Deleted files still held open by a process.** A process is writing to a file that was unlinked from the directory, so `du` (which scans directory entries) doesn't see it, but `df` (which tracks block usage) sees the space is still occupied.

**L7** — 1. **UEFI** initializes hardware. 2. **Bootloader** (e.g., GRUB) loads the kernel. 3. **Kernel** initializes drivers/subsystems. 4. **initramfs** provides temporary drivers to mount the real root. 5. **Root FS** is mounted. 6. **systemd** (PID 1) starts services/targets.

**L8** — `available` memory is low because `buff/cache` is "reclaimable" but not "free." If the kernel cannot reclaim it fast enough (due to heavy I/O or pinned pages), the system runs out of usable memory. **Tunables:** `vm.swappiness` (controls preference for swapping) and `vm.vfs_cache_pressure` (controls reclaiming of dentries/inodes).

**L9** — `ip netns` creates **Network Namespaces**, which provide isolated network stacks (separate routing tables, interfaces, etc.). Container runtimes (like Docker) use namespaces to ensure a container's network traffic is isolated from the host and other containers.

**L10** — **SIGTERM (15):** Request termination (can be caught/handled). **SIGKILL (9):** Immediate termination (cannot be caught). **SIGQUIT (3):** Request termination and core dump (can be caught).

**L11** — `stdout` (standard output), `stderr` (error output), `stdin` (standard input).
**Redirect stderr to file, keep stdout on terminal:** `command 2> error.log`

**L12** — `755` means: **7** (Owner: Read/Write/Execute), **5** (Group: Read/Execute), **5** (Others: Read/Execute).

**L13** — The **root** user has absolute, unrestricted access to the entire system. A **sudo** user is a regular user granted specific administrative privileges via the `/etc/sudoers` configuration.

**L14** — A tool to manage, install, update, and remove software.
**Debian/Ubuntu:** `apt`. **RHEL/Fedora:** `dnf` (or `yum`).

**L15** — `/etc/fstab` defines how disk partitions/filesystems are mounted at boot. If misconfigured (e.g., a typo in a UUID), the system may fail to boot or drop into an emergency shell.

**L16** — **LVM** manages disk space via abstraction. **PV (Physical Volume):** Raw partition/disk. **VG (Volume Group):** Pool of PVs. **LV (Logical Volume):** Virtual partition carved from a VG.
**Extend LV:** `lvextend -L +1G /dev/vg/lv && resize2fs /dev/vg/lv` (for ext4).

**L17** — **mq-deadline:** Good for SSDs/fast storage (prioritizes reads). **bfq:** Complex, good for desktop/interactive use (fairness). **none:** No scheduling (best for NVMe/high-speed devices).
**Change at runtime:** `echo none > /sys/block/sdX/queue/scheduler`.

**L18** — Load average measures the number of processes in **R** (running/runnable) or **D** (uninterruptible) states. High load with low CPU suggests **I/O Wait** (disk/network bottleneck).
**Diagnosis:** `top`/`htop` (check CPU vs %wa), `iostat` (check disk latency), `nload`/`iftop` (check network).

**L19** — **SELinux** uses labels (contexts) on files/processes to enforce access rules.
**Modes:** **Enforcing** (blocks), **Permissive** (logs only), **Disabled** (off).
**Troubleshoot:** Use `ausearch -m avc -ts recent` to find denials, then use `semanage fcontext` to label the new port/file.

**L20** — **Page Fault:** CPU tries to access a memory page not currently in the MMU. **Minor:** Page is in RAM but not mapped to the process. **Major:** Page must be fetched from disk (swap/filesystem).
**THP:** Aggregates small pages into large ones to reduce TLB misses. **Disable THP** if it causes "latency spikes" or "memory fragmentation" in database workloads (e.g., Redis/PostgreSQL).
