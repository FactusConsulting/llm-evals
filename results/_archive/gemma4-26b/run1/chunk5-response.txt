## .NET / C#

**DN1**
`class` is a reference type (stored on the heap); `struct` is a value type (usually stored on the stack). Use a `struct` for small, immutable data structures (typically < 16 bytes) that have a short lifetime and no identity, to reduce GC pressure.

**DN2**
`IEnumerable<T>` performs in-memory filtering (client-side) via LINQ-to-Objects. `IQueryable<T>` builds an expression tree that is translated into a provider-specific language (e.g., SQL) for server-side filtering. The distinction matters because `IEnumerable` can cause "N+1" problems or massive over-fetching of data from a database.

**DN3**
`async/await` allows a thread to yield control back to the caller/pool while waiting for an I/O-bound task to complete, preventing thread starvation. `Task` represents an asynchronous operation. `ValueTask` is a value-type wrapper for a task. Use `ValueTask` when the result is often available synchronously (e.g., from a cache) to avoid the heap allocation of a `Task` object.

**DN4**
Dependency Injection (DI) is a design pattern where objects receive their dependencies from an external source rather than creating them internally.
- **Transient**: New instance every time it is requested.
- **Scoped**: One instance per client request (e.g., per HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Bug**: Injecting a **Scoped** service into a **Singleton** causes "Captive Dependency," where the Scoped service is kept alive indefinitely by the Singleton, potentially leading to stale data or memory leaks.

**DN5**
`string` is a heap-allocated, immutable array of characters. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory (string, array, or unmanaged memory). Use `Span<T>` for high-performance parsing/slicing to avoid creating new string allocations (substrings) on the heap, significantly reducing GC pressure.

**DN6**
The GC manages memory by reclaiming objects no longer in use.
- **Gen 0**: Short-lived objects (newly allocated).
- **Gen 1**: Buffer zone for objects surviving Gen 0.
- **Gen 2**: Long-lived objects.
- **LOH (Large Object Heap)**: Objects > 85,000 bytes are placed here; they are not compacted by default, which can lead to fragmentation.
`IDisposable` is used to manually release **unmanaged** resources (file handles, DB connections) because the GC only manages managed memory.

**DN7**
`ConfigureAwait(false)` tells the runtime that the continuation does not need to resume on the original `SynchronizationContext` (e./g., the UI thread).
- **Use it**: In library/infrastructure code to prevent deadlocks and improve performance.
- **Do NOT use it**: In application-level code where you need to access UI elements or context-specific data (like `HttpContext.Current`).

**DN8**
- **Primary Constructors**: Define parameters directly in the class header.
- **Collection Expressions**: `int[] arr = [1, 2, 3];` (cleaner syntax).
- **FrozenDictionary**: An immutable, highly optimized read-only dictionary.
```csharp
// Example: Primary Constructor with DI
public class UserService(IUserRepository repo) : IUserService {
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9**
**Cause**: `DbContext` is Scoped by default. If multiple concurrent requests/threads share the same `DbContext` instance (e.g., via a Singleton service or manual scope mismanagement), the internal state/tracking becomes corrupted.
**Fix**: Ensure the service consuming the `DbContext` is also Scoped, or use `IServiceScopeFactory` to create a new scope manually within the background task.

**DN10**
`record` is a reference type with built-in value-based equality. `record struct` is a value type with value-based equality. Use `record` for DTOs/Data models where identity doesn't matter but equality does. Use `record struct` for small, high-performance value types.

**DN11**
- **ref**: Passes by reference; allows modifying the original variable.
- **out**: Passes by reference; must be assigned a value before the method returns.
- **in**: Passes by reference; read-only (prevents copying of large structs).
Use `ref` for modification, `out` for returning multiple values, and `in` for performance optimization of large structs.

**DN12**
Nullable Reference Types (`string?`) are a compile-time static analysis feature to prevent `NullReferenceException`. They do **not** change the underlying type (it's still a reference type). Nullable Value Types (`int?`) are syntactic sugar for `Nullable<int>`, which is a real wrapper struct that allows a value type to hold a `null` state.

**DN1: (LINQ)**
LINQ (Language Integrated Query) provides a uniform way to query data.
- **Method Syntax**: Uses extension methods and lambdas (`.Where(x => ...)`).
- **Query Syntax**: Uses a SQL-like declarative style (`from x in list...`).
**Deferred Execution**: The query is not executed when defined, but when the results are actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14**
Constraints restrict the type `T`:
- `where T : class`: Must be a reference type.
- `where T : struct`: Must be a value type.
- `where T : new()`: Must have a public parameterless constructor.
- `where T : IComparable<T>`: Must implement the interface.
Combine them to ensure type safety and access to specific members (e..g, `where T : class, new()`).

**DN15**
An `abstract class` can have state (fields) and implementation; an `interface` defines a contract. Since C# 8, interfaces can have **default implementations**, meaning they can now provide method bodies, blurring the line. However, interfaces still cannot hold instance state (fields).

**DN16**
The middleware pipeline processes HTTP requests sequentially.
- `app.Use()`: Adds a delegate that can call the next middleware.
- `app.Map()`: Branches the pipeline based on a URL path.
- `app.Run()`: A terminal middleware that does not call `next()`.
**Ordering**: Crucial; e.g., `UseRouting` must come before `UseEndpoints`. **Exception Handling** must be the first middleware in the pipeline to "catch" exceptions from all subsequent layers.

**DN17**
`Channel<T>` is a high-performance, async-compatible queue. `BlockingCollection<T>` is a thread-safe collection that blocks threads (synchronous).
**Example (Backpressure)**:
```csharp
var channel = Channel.CreateBounded<int>(10); // Limit capacity to 10
// Producer: await channel.Writer.WriteAsync(item); // Will wait if full
// Consumer: await foreach (var item in channel.Reader.ReadAllAsync()) { ... }
```

**DN18**
**Source Generators** produce C# code during compilation. Unlike **Reflection** (runtime inspection) or **IL Weaving** (post-compile modification), they are part of the compilation process, making them type-safe and performant. **Incremental Generators** are preferred because they only re-run when relevant inputs change, significantly improving IDE and build performance.

**DN19**
TPL Dataflow is a library for building actor-based pipelines.
- `ActionBlock`: Executes an action on incoming data.
- `TransformBlock`: Takes input, processes it, and produces output.
- `BufferBlock`: A queue that holds items.
**Comparison**: `Channels` are better for simple, high-throughput producer-consumer patterns; `TPL Dataflow` is better for complex, multi-stage processing graphs with complex routing/buffering logic.

**DN20**
**Minimal APIs** use a lambda-based approach to define endpoints without the overhead of Controllers.
- **Pros**: Less boilerplate, faster startup, great for microservices.
- **Cons**: Can become messy in large apps; harder to organize than Controllers.
- **Features**: `Route Groups` allow shared logic/middleware for a set of endpoints; `Endpoint Filters` allow intercepting requests/responses (similar to Action Filters).

## Python

**P1**
`list` is mutable; `tuple` is immutable. `set` is a mutable collection of unique elements; `frozenset` is an immutable version of a set (can be used as a dictionary key).

**P2**
The GIL is a mutex that protects access to Python objects, preventing multiple threads from executing Python bytecodes at once. It affects **CPU-bound** workloads (multithreading won't provide speedup). **Workarounds**: Use `multiprocessing` (separate memory spaces), use C-extensions (like NumPy) that release the GIL, or use `asyncio` for I/O-bound tasks.

**P3**
`copy` creates a shallow copy (new container, but references to the same objects inside). `deepcopy` creates a new container and recursively copies all objects found in the original.
**Example**: If `list_a = [[1]]`, `list_b = copy(list_a)`. Changing `list_b[0][0] = 2` will also change `list_a[0][0]` because the inner list is the same object.

**P4**
Decorators wrap a function to modify its behavior.
```python
import time
def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Execution time: {time.time() - start}s")
        return result
    return wrapper

@timer_decorator
def my_func(): time.sleep(1)
```

**P5**
Generators use `yield` to return values one at a time, maintaining state, which is memory-efficient for large datasets. `yield from` is used to delegate to a sub-generator (flattening). Unlike a list, a generator does not store all elements in memory.

**P6**
`asyncio.run()`: Entry point to run the main coroutine. `asyncio.gather()`: Runs multiple coroutines concurrently and waits for all to finish. `asyncio.create_task()`: Schedules a coroutine to run on the loop without waiting immediately.
**Warning**: `time.sleep()` is **blocking**; it stops the entire event loop thread. Use `await asyncio.sleep()` instead.

**P7**
Python uses the **C3 Linearization** algorithm.
**Result**: `D().who()` prints `"C"`.
**Reasoning**: In diamond inheritance, Python searches the MRO. For `D(B, C)`, the MRO is `[D, B, C, A, object]`. Since `C` overrides `who`, and `C` appears in the M/R/O before `A`, the method in `C` is found first.

**P8**
- **Metaclass**: A class that defines how a class is constructed. Use for deep structural changes to class creation.
- **`__init_subclass__`**: A simpler hook called when a class is subclassed. Use for registering subclasses or modifying attributes without the complexity of a metaclass.
**Use case**: Metaclass for enforcing API constraints across all classes; `__init_subclass__` for a plugin system.

**P9**
- **multiprocessing**: Bypasses GIL by using separate processes (CPU-bound).
- **threading**: Shared memory, subject to GIL (I/O-bound).
- **concurrent.futures**: High-level abstraction for both.
**Serialization**: `multiprocessing` requires objects to be "pickled" (serialized) to be sent between processes. If an object cannot be pickled, `multiprocessing` will fail.

**P10**
`__slots__` tells Python not to use a `__dict__` for each instance, but to allocate a fixed amount of space for a specific set of attributes.
- **Use when**: You have millions of small objects.
- **Prevents**: Dynamic attribute creation.
- **Impact**: Significant memory reduction and slightly faster attribute access.

**P1/P11**
A **virtual environment** isolates project dependencies to prevent version conflicts.
- `venv`: Built-in Python module for lightweight environments.
- `virtualenv`: A more feature-rich, older alternative to `venv`.
- `conda`: A package and environment manager that handles non-Python dependencies (great for Data Science).

**P12**
Comprehensions are syntactic sugar for loops.
- `[x for x in list]` (List), `{x: x**2 for x in list}` (Dict), `{x for x in list}` (Set).
- `map()` and `filter()` are functional alternatives.
**Preference**: Use comprehensions for readability and when the logic is simple. Use `map/filter` when you already have a pre-defined function to apply.

**P13**
`==` checks for **equality** (value); `is` checks for **identity** (memory address).
**Interning**: Python caches small integers (usually -5 to 256) and certain strings in a lookup table. Thus, `a is b` returns `True` because they point to the exact same pre-allocated object in memory.

**P1/P14**
- `*args`: Collects extra positional arguments as a tuple.
- `**kwargs`: Collects extra keyword arguments as a dictionary.
- `/`: Marks parameters before it as **positional-only**.
- `*`: Marks parameters after it as **keyword-only**.

**P15**
Context managers handle setup/teardown (e.g., locking, cleanup).
```python
from contextlib import contextmanager

@contextmanager
def my_resource():
    print("Setup")
    yield "Resource"
    print("Teardown")

with my_resource() as r:
    print(r)
```
**Example**: A database transaction manager that commits on success and rolls back on error.

**P16**
Type hinting provides metadata for static analysis.
- `Union[int, str]`: Can be int or str.
- `Optional[int]`: Can be int or None.
- `Literal[1, 2]`: Must be exactly 1 or 2.
- `TypeVar`: Generic type placeholder.
- `Protocol`: Structural subtyping (duck typing).
`mypy` uses these to catch type errors before runtime.

**P17**
- `__repr__`: Official string representation (for developers/debugging).
- `__str__`: User-friendly string representation.
- `__eq__` vs `__hash__`: If you define `__eq__`, you **must** define `__hash__` if you want the object to be hashable (e.g., used in a set).
- `__getattr__` (called only if attribute is missing) vs `__getattribute__` (called for *every* access).

**P18**
A **descriptor** is an object attribute with `__get__`, `__set__`, or `__delete__` methods.
- `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol to intercept attribute access and modify how the method is bound to the instance or class.

**P19**
- **Absolute**: `from package.module import func`.
- **Relative**: `from .module import func`.
`sys.path` is the list of strings that determines the search path for modules. `PYTHONPATH` is an environment variable that adds directories to `sys.path`. `__init__.py` makes a directory a package. **Finders** locate modules; **Loaders** execute them.

**P20**
`dataclasses` is built-in and lightweight. `attrs` is more powerful/feature-rich. `Pydantic` is focused on **data validation** and parsing (crucial for APIs).
- `__post_init__`: Logic run after `__init__`.
- `field factories`: For mutable defaults (e.g., `default_factory=list`).
- **Choice**: Use `Pydantic` when you need to validate incoming JSON/external data; use `dataclasses` for internal data structures.
