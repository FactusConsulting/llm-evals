## .NET / C#

**DN1**: A **class** is a reference type (allocated on the heap), while a **struct** is a value type (usually allocated on the stack). Use a struct for small, short-lived, immutable data structures to reduce Garbage Collector (GC) pressure and avoid heap allocation overhead.

**DN2**: `IEnumerable<T>` provides a read-only cursor for forward-only iteration over a collection (in-memory). `IQueryable<T>` extends this by providing an expression tree that allows providers (like EF Core) to translate queries into SQL and execute them on the database server. This distinction prevents "over-fetching" data from the DB into application memory.

**DN3**: `async/await` uses a state machine to allow non-blocking I/O; when an `await` is hit, the thread is returned to the pool until the task completes. A `Task` is a class representing an ongoing operation; a `ValueTask` is a struct used to optimize cases where a method often returns synchronously, avoiding a heap allocation of a `Task object`. Use `ValueTask` in high-frequency paths where results are frequently cached or available immediately.

**DN4**: DI manages object lifetimes via a container. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., HTTP request).
- **Singleton**: One instance for the app lifetime.
**Bug**: Captive Dependency occurs when a Singleton depends on a Scoped service; the Scoped service effectively becomes a singleton, potentially leading to stale data or `ObjectDisposedException` if the scope closes while the singleton persists.

**DN5**: `string` is a heap-allocated immutable sequence of characters. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory. Using `Span<T>` allows slicing strings or arrays without creating new copies (zero-allocation), significantly improving performance in parsing and string manipulation.

**DN6**: The GC uses generations: **Gen 0** (new objects, collected most often), **Gen 1** (buffer between 0 and 2), and **Gen 2** (long-lived objects). The **Large Object Heap (LOH)** handles objects >85KB to avoid expensive memory compaction. `IDisposable` is needed because the GC only manages managed memory; it cannot automatically close file handles, database connections, or sockets (unmanaged resources).

**DN7**: By default, `await` captures the current `SynchronizationContext` (e.g., UI thread) to resume execution. `ConfigureAwait(false)` tells the runtime not to marshal back to the original context. Use it in library code to prevent deadlocks and improve performance. Do NOT use it when you need to update UI elements on the main thread.

**DN8**: 
- **Primary Constructors**: Define parameters directly in the class header.
- **Collection Expressions**: Concise syntax like `int[] arr = [1, 2, 3];`.
- **FrozenDictionary**: An immutable dictionary optimized for read-heavy scenarios.
```csharp
public class UserService(IUserRepository repo) // Primary Constructor
{
    public async Task<User> GetUser(int id) => await repo.GetByIdAsync(id);
}
```

**DN9**: This usually happens when an asynchronous operation (like a background task) attempts to use a `DbContext` after the HTTP request has finished and the DI container has disposed of the Scoped `DbContext`. **Fix**: Inject `IServiceScopeFactory`, create a manual scope using `CreateScope()`, and resolve the `DbContext` within that local scope.

**DN10**: A **record** is a reference type with built-in value-based equality; a **class** uses reference equality by default. A **record struct** provides record features but as a value type. Choose records for DTOs/POCOs where data integrity and equality are more important than identity.

**DN11**: 
- `ref`: Passes by reference; allows reading and writing back to the original variable.
- `out`: Must be assigned before returning; used to return multiple values from a method.
- `in`: Passes by reference but prevents modification (read-only), avoiding copies of large structs.

**DN12**: Nullable Reference Types (`string?`) provide static analysis warnings to prevent `NullReferenceException` at compile time via compiler hints. They do not change the runtime representation. In contrast, nullable value types (`int?`) are wrappers (`Nullable<T>`) that actually change the memory layout to track if a value exists.

**DN13**: LINQ (Language Integrated Query) enables querying collections. **Method syntax** uses extension methods (`.Where().Select()`); **Query syntax** looks like SQL (`from x in list...`). **Deferred execution** means the query isn't executed until you iterate over it (e.g., using `foreach` or `.ToList()`).

**DN14**: Constraints restrict generic types: `where T : class` (reference type), `struct` (value type), `new()` (must have parameterless constructor), `IComparable<T>` (must implement interface). Combine them for specific requirements, e.g., `where T : class, INewtonsoftJsonConvertible`.

**DN15**: An abstract class defines "is-a" identity and can hold state; an interface defines "can-do" behavior. Default Interface Methods allow adding new functionality to interfaces without breaking existing implementations by providing a default body.

**DN16**: Middleware is a chain of delegates called sequentially. 
- `app.Use()`: Can call next middleware or short-circuit.
- `app.Map()`: Branches the pipeline based on path.
- `app.Run()`: Terminal middleware (no one follows).
Ordering is critical because requests flow through them linearly; exception handling must be first to catch errors from all subsequent steps.

**DN17**: `Channel<T>` is a high-performance producer-consumer queue supporting async operations natively. Unlike `BlockingCollection`, it doesn't block threads. Bounded channels provide backpressure: if the channel is full, the producer asynchronously waits until space is available.

**DN18**: **Source Generators** generate C# code during compilation via Roslyn. Reflection happens at runtime; IL weaving modifies binary post-compile. **Incremental generators** are preferred over `ISourceGenerator` because they only re-run for changed files rather than the whole project, drastically improving IDE performance.

**DN19**: TPL Dataflow provides actor-like blocks: `ActionBlock` (consumes), `TransformBlock` (maps/transforms), and `BufferBlock` (queues). While Channels are simple queues, TPL Dataflow allows building complex directed graphs of processing stages with built-in concurrency limits.

**DN20**: Minimal APIs remove controller boilerplate by mapping routes directly in `Program.cs`. They offer faster startup and lower overhead. Trade-offs include less structure for very large apps. Route groups organize endpoints, and endpoint filters allow cross-cutting logic (validation/auth) per route.

## Python

**P1**: A **list** is mutable and ordered; a **tuple** is immutable and ordered. A **set** contains unique elements and is unordered; a **frozenset** is an immutable version of a set.

**P2**: The GIL prevents multiple native threads from executing Python bytecodes simultaneously. It affects CPU-bound workloads. Workarounds include using the `multiprocessing` module or writing C extensions that release the GIL.

**P3**: `copy` creates a shallow copy (references to nested objects remain shared); `deepcopy` recursively clones everything. Example: If you shallow copy a list containing lists, modifying a sub-list in the copy will modify it in the original.

**P4**: Decorators wrap functions to extend behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return res
    return wrapper
```

**P5**: Generators use `yield` to produce values lazily one at a time, saving memory compared to returning a full list. `yield from` allows a generator to delegate part of its operations to another generator/iterable.

**P6**: The event loop schedules and runs asynchronous tasks. `asyncio.run()` starts the loop; `gather()` runs multiple coroutines concurrently; `create_task()` schedules a coroutine for execution. `time.sleep()` is blocking and stops the entire thread, freezing the whole event loop. Use `await asyncio.sleep()`.

**P7**: Python uses the **C3 Linearization (MRO)** algorithm. In diamond inheritance, it ensures classes are visited once and child-before-parent. 
For `D(B, C)`, MRO is `[D, B, C, A]`. Since `B` does not define `who`, but `C` does, `D().who()` prints `"C"`.

**P8**: A **metaclass** is a class that creates other classes (a "class factory"). `__init_subclass__` is a simpler hook called when a class is subclassed. Use metaclasses for deep architectural changes (e.g., automatic API registration); use `__init_subclass__` for simple validation or registering subclasses in a registry list.

**P9**: 
- **Threading**: I/O bound; shared memory; limited by GIL.
- **Multiprocessing**: CPU bound; separate memory per process; bypasses GIL.
- **Concurrent.futures**: High-level wrapper for both via `ThreadPoolExecutor` and `ProcessPoolExecutor`.
Multiprocessing requires objects to be **picklable** (serializable) to move data between processes.

**P10**: `__slots__` tells Python not to create a `__dict__` for each instance. It prevents dynamic attribute addition and significantly reduces memory usage per object, which is critical when instantiating millions of small objects.

**P11**: A virtual environment isolates project dependencies. `venv` is the standard library tool; `virtualenv` is an older, more feature-rich alternative; `conda` manages non-Python binary dependencies as well.

**P12**: Comprehensions provide concise syntax for creating collections: `[x for x in ...]` (list), `{x for x in ...}` (set), `{k: v for ...}` (dict). They are generally faster and more readable than `map()` and `filter()`, though those can be preferred for simple existing function calls.

**P13**: `==` checks value equality; `is` checks identity (memory address). Object interning caches small integers (-5 to 256) and some strings so that multiple variables point to the same physical object, making `a is b` return True for these specific values.

**P14**: `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dictionary. `/` marks parameters before it as **positional-only**, while `*` marks parameters after it as **keyword-only**.

**P15**: Context managers handle setup/teardown via `with`. Using `__enter__`/`__exit__` is the class-based approach; `@contextmanager` uses a generator with `yield`. Example: A database transaction manager that commits on success or rolls back on exception.

**P16**: Type hinting provides static analysis hints. `Union` (A or B), `Optional` (T or None), `Literal` (specific constant values), `TypeVar` (generics), and `Protocol` (structural typing/interfaces). Tools like Mypy check these without executing code.

**P17**: Dunder methods define Python's data model. `repr` is for developers (debugging); `str` is for users. `eq` defines equality; `hash` allows use in sets/dicts. If you define `__eq__`, Python sets `__hash__` to `None` unless you redefine it, making the object unhashable.

**P18**: Descriptors are objects implementing `__get__`, `__set__`, or `__delete__`. They intercept attribute access. `@property` is a descriptor under the hood that implements `__get__` and optionally `__set__`.

**P19**: Absolute imports specify full paths from the root; relative imports use `.module`. `sys.path` lists search directories. `__init__.py` marks a directory as a package. A **finder** locates the module, and a **loader** loads its content into memory. Namespace packages allow one package to be split across multiple physical locations.

**P20**: `dataclasses` automate boilerplate (`__init__`, `__repr__`). Compared to `attrs` (more powerful) and Pydantic (runtime validation), dataclasses are lightweight stdlib tools. Use Pydantic when you need strict type coercion and runtime validation of external data (e.g., JSON APIs).
