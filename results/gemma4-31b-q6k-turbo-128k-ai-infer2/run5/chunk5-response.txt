## .NET / C#

**DN1**: A **class** is a reference type (allocated on the heap); a **struct** is a value type (usually allocated on the stack). Use a struct for small, immutable data structures (typically < 16 bytes) to reduce GC pressure and improve cache locality.

**DN2**: `IEnumerable<T>` represents a sequence in memory; filtering happens on the client side. `IQueryable<T>` represents a query expression that can be translated into SQL by a provider (like EF Core), meaning filtering happens at the database level. This distinction prevents fetching entire tables into RAM before filtering.

**DN3**: `async/await` uses a state-machine transformation to allow non-blocking I/O. A `Task` is a class representing an ongoing operation (heap allocated). A `ValueTask` is a struct used when a method often returns synchronously (e.g., from a cache), avoiding a heap allocation for the Task object.

**DN4**: DI allows decoupling components by injecting dependencies via constructors. Lifetimes: **Transient** (new instance every time), **Scoped** (once per request), **Singleton** (one instance forever). A common bug is the **Captive Dependency**, where a Singleton depends on a Scoped service; since the Singleton lives longer than the scope, it holds onto a disposed or stale Scoped service.

**DN5**: `string` is an immutable heap object. `ReadOnlySpan<char>` is a ref-struct providing a window into existing memory without allocating new strings during slicing (`Substring`). Use `Span<T>` for high-performance parsing and buffer management to eliminate unnecessary allocations.

**DN6**: The GC manages memory using generations: **Gen 0** (short-lived objects), **Gen 1** (buffer between 0 and 2), and **Gen 2** (long-lived). The **Large Object Heap (LOH)** handles objects > 85KB to avoid expensive compaction of large chunks. `IDisposable` is needed for unmanaged resources (file handles, sockets) because the GC only knows about managed memory.

**DN7**: `ConfigureAwait(false)` tells the task not to marshal back to the original `SynchronizationContext` (e.g., UI thread). Use it in library code to improve performance and prevent deadlocks. Do NOT use it in application code that needs to update UI elements directly after an await.

**DN8**: .NET 8/9 introduced **Primary Constructors** (parameters defined on class header), **Collection Expressions** (`int[] arr = [1, 2, 3]`), and **FrozenDictionary** (highly optimized read-only dictionary).
```csharp
public class OrderService(IOrderRepository repo, ILogger logger) // Primary Constructor
{
    public void Process() => logger.LogInformation("Processing...");
}
```

**DN9**: Likely cause: A `DbContext` instance is being shared across multiple threads or a background task is attempting to use a context whose scope has already been disposed by the request pipeline. Fix: Ensure `DbContext` is injected as Scoped and never passed into long-running background tasks; instead, inject `IServiceScopeFactory` to create a new scope manually inside the task.

**DN10**: A **record** provides built-in value-based equality for classes. A **record struct** combines record features with value-type semantics. Choose records for DTOs/immutable data; choose classes for behavior-heavy objects; choose record structs for small, immutable value types.

**DN11**: `ref`: passes reference; both input and output are modified. `out`: requires the method to assign a value before returning. `in`: passes by reference but prevents modification (read-only), used for performance with large structs.

**DN12**: Nullable Reference Types (`string?`) provide compile-time static analysis warnings to prevent `NullReferenceException`. They differ from nullable value types (`int?`), which are actual wrappers (`Nullable<T>`) that change the runtime type of the variable.

**DN13**: LINQ (Language Integrated Query) allows querying collections. **Method syntax** uses extension methods (`.Where()`); **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over it (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict generic types: `where T : class` (reference type), `where T : struct` (value type), `where T : new()` (must have parameterless constructor), `where T : IComparable<T>` (must implement interface). Combine them to ensure a type is both a class and implements specific interfaces.

**DN15**: An **abstract class** provides a base implementation; an **interface** defines a contract. Default Interface Methods allow adding logic to interfaces without breaking existing implementations, blurring the line between the two but still maintaining that classes support single inheritance while interfaces support multiple.

**DN16**: Middleware is a chain of delegates. `app.Use()` passes requests forward; `app.Map()` branches based on path; `app.Run()` terminates the pipeline. Order matters because middleware executes in sequence. Exception handling middleware must be placed first to wrap all subsequent calls in a try-catch block.

**DN17**: `Channel<T>` is a high-performance producer-consumer queue. Unlike `BlockingCollection`, it supports fully asynchronous operations (`ReadAsync`/`WriteAsync`). Bounded channels provide backpressure by blocking/awaiting the writer when the channel reaches its capacity limit.

**DN18**: Source Generators create C# code during compilation. Reflection happens at runtime; IL weaving modifies binary after compilation. **Incremental generators** are preferred as they only re-generate code for changed parts of the syntax tree, significantly speeding up IDE performance.

**DN19**: TPL Dataflow creates processing pipelines. `ActionBlock` (consumes), `TransformBlock` (transforms data), and `BufferBlock` (queues). Compared to Channels, Dataflow allows complex graphs (branching, joining) rather than simple linear queues.

**DN20**: Minimal APIs remove controller boilerplate, defining routes directly in `Program.cs`. Trade-offs: faster startup and less code, but can become disorganized if not using **Route Groups**. They support OpenAPI via Swagger and use **Endpoint Filters** for cross-cutting concerns like validation.

## Python

**P1**: A **list** is mutable; a **tuple** is immutable. A **set** contains unique elements; a **frozenset** is an immutable version of a set.

**P2**: The GIL prevents multiple native threads from executing Python bytecodes simultaneously. It affects CPU-bound workloads. Workarounds include using the `multiprocessing` module or writing extensions in C/Rust.

**P3**: `copy` (shallow) copies the object but references nested objects; `deepcopy` recursively clones everything. Example: If you shallow copy a list containing another list, modifying the inner list in the copy will also change it in the original.

**P4**: Decorators wrap functions to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter()-start:.4f}s")
        return res
    return wrapper
```

**P5**: Generators use `yield` to produce values lazily one at a time, saving memory compared to returning a full list. `yield from` allows a generator to delegate its operation to another iterable or generator.

**P6**: The event loop manages asynchronous tasks via cooperative multitasking. `asyncio.run()` starts the loop; `gather()` runs multiple coroutines concurrently; `create_task()` schedules a task for later execution. `time.sleep()` blocks the entire thread, stopping the loop and all other tasks.

**P7**: Python uses C3 Linearization (MRO). In diamond inheritance, it searches child $\to$ parent left-to-right. For `D(B, C)`, MRO is `[D, B, C, A]`. Since `C` overrides `who()` and comes before `A`, `D().who()` prints `"C"`.

**P8**: A metaclass is a class that defines how classes are created. Use `__init_subclass__` for simple customization of children; use a metaclass for deep control over class creation. Example: Metaclasses can enforce API constraints across all subclasses automatically.

**P9**: **Threading** is for I/O-bound tasks (shared memory); **Multiprocessing** is for CPU-bound tasks (separate memory). `concurrent.futures` provides a high-level wrapper for both (`ThreadPoolExecutor`/`ProcessPoolExecutor`). Multiprocessing requires **pickling** to serialize data sent between processes.

**P10**: `__slots__` tells Python not to create a `__dict__` for instances. It prevents dynamic attribute addition and significantly reduces memory usage per object by using fixed arrays instead of dictionaries.

**P11**: A virtual environment isolates project dependencies. `venv` is the standard library tool; `virtualenv` is an older, more feature-rich alternative; `conda` manages non-Python binary dependencies as well.

**P12**: Comprehensions provide concise syntax for creating collections. They are generally faster and more readable than `map()` or `filter()`, which are functional primitives. Prefer comprehensions for most logic unless you have pre-existing functions to pass into map/filter.

**P13**: `==` checks value equality; `is` checks identity (memory address). Small integers (-5 to 256) are interned by CPython, so `a is b` returns True because they point to the same cached singleton objects.

**P14**: `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dictionary. `/` marks parameters that MUST be positional; `*` marks everything following it as keyword-only.

**P15**: Context managers manage resources via `with`. Using `__enter__`/`__exit__` is the class-based approach; `@contextmanager` uses a generator. Example: Managing a database transaction (`begin` in enter, `commit/rollback` in exit).

**P16**: Type hinting provides static analysis metadata. `Union[int, str]` (either), `Optional[T]` (T or None), `Literal["A", "B"]` (specific values), `TypeVar` (generics), and `Protocol` (structural typing). Tools like `mypy` use these to find bugs before runtime.

**P17**: Dunder methods define Python's data model. `repr` is for developers; `str` is for users. `eq` defines equality; `hash` allows usage in sets/dicts. If you define `__eq__` but not `__hash__`, the object becomes unhashable and cannot be used as a dict key.

**P18**: Descriptors are objects with `__get__`, `__set__`, or `__delete__`. They intercept attribute access. `property` is a descriptor that implements `__get__` and `__set__`; `classmethod` and `staticmethod` are descriptors that modify how the function is bound to the class/instance.

**P19**: Absolute imports specify full paths from the root; relative imports use dots (`..`). `sys.path` determines search order. Namespace packages allow splitting one package across multiple directories by omitting `__init__.py`. Finders locate modules, and Loaders load them into memory.

**P20**: `dataclasses` reduce boilerplate for data-holding classes. `attrs` provides more power (validators); Pydantic adds strict runtime type validation and coercion. Use Pydantic when parsing external JSON/API data where validation is critical; use dataclasses for internal state.
