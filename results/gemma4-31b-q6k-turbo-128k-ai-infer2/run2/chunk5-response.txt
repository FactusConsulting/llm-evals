## .NET / C#

**DN1**: **Class** is a reference type (allocated on heap); **Struct** is a value type (usually allocated on stack). Use structs for small, short-lived, immutable data structures (e.g., Point, Vector) to reduce GC pressure.

**DN2**: `IEnumerable<T>` provides a read-only cursor over a collection in memory; execution happens locally. `IQueryable<T>` extends this by providing an expression tree that allows the provider (like EF Core) to translate queries into SQL and execute them on the database server. This prevents fetching entire tables into RAM ("over-fetching").

**DN3**: `async/await` uses a state machine to allow non-blocking I/O. While awaiting, the thread is returned to the pool. **Task** is a class representing an ongoing operation; **ValueTask** is a struct used when the result is often available synchronously (avoiding a heap allocation for the Task object). Use `ValueTask` for high-frequency methods where results are frequently cached or completed immediately.

**DN4**: DI manages object lifetimes:
*   **Transient**: New instance every time requested.
*   **Scoped**: One instance per client request (web request).
*   **Singleton**: One instance for the application lifetime.
*   **Bug**: A "Captive Dependency" occurs when a Singleton depends on a Scoped service. The Scoped service effectively becomes a Singleton, which can lead to stale data or `ObjectDisposedException`.

**DN5**: `string` is a heap-allocated immutable sequence of characters. `ReadOnlySpan<char>` is a window into existing memory (stack, heap, or unmanaged) without creating new string copies. Use `Span<T>` for high-performance parsing and slicing to eliminate unnecessary allocations.

**DN6**: GC uses generations to optimize collection: **Gen 0** (youngest, frequent), **Gen 1** (buffer), **Gen 2** (long-lived). Objects >85KB go to the **Large Object Heap (LOH)**, which is collected less frequently. `IDisposable` is needed because GC only manages memory; it cannot automatically close file handles, database connections, or sockets.

**DN7**: `ConfigureAwait(false)` tells the task not to marshal back to the original `SynchronizationContext` (e.g., UI thread). Use it in library code to prevent deadlocks and improve performance. Do NOT use it in app-level code that must update UI elements directly.

**DN8**:
*   **Primary Constructors**: Define parameters directly on the class header.
*   **Collection Expressions**: Using `[]` syntax for arrays/lists.
*   **FrozenDictionary**: A read-only dictionary optimized for extremely fast lookups after creation.
```csharp
public class OrderService(IRepository repo) { // Primary Constructor
    public void Process() => Console.WriteLine(repo.GetCount());
}
```

**DN9**: The cause is likely a "fire-and-forget" async call where the request scope ends before the background task finishes, disposing the `DbContext`. Fix: Ensure all tasks are awaited (`await`) or use an `IServiceScopeFactory` to create a manual scope for background work. EF Core's `DbContext` is scoped by default; it should never be shared across threads concurrently.

**DN10**: **Record** provides value-based equality (two records with same values are equal); **Class** uses reference equality. **Record struct** combines record semantics with value-type performance. Choose Records for DTOs/immutable data and Classes for entities with identity/behavior.

**DN11**: 
*   `ref`: Pass by reference; allows modifying the original variable.
*   `out`: Must be assigned inside the method; used to return multiple values.
*   `in`: Read-only reference; prevents copying large structs while ensuring they aren't modified.

**DN12**: Nullable Reference Types (`string?`) provide compile-time warnings if a value might be null. They do not change runtime behavior. Nullable Value Types (`int?`) are wrappers (`Nullable<T>`) that allow value types to represent null at runtime.

**DN13**: LINQ (Language Integrated Query) enables querying collections. **Method syntax** uses extension methods (`.Where()`); **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over the result (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict generic types:
*   `where T : class`: Reference type only.
*   `where T : struct`: Value type only.
*   `where T : new()`: Must have a parameterless constructor.
*   `where T : IComparable<T>`: Must implement specific interface.
Combine them (e.g., `where T : class, IDisposable`) to ensure the type supports both reference semantics and disposal.

**DN15**: An **Abstract Class** is a base for inheritance providing shared logic/state; an **Interface** defines a contract. Default Interface Methods (C# 8+) allow interfaces to provide a default implementation, reducing the need for abstract classes when adding new functionality to existing interfaces without breaking implementations.

**DN16**: Middleware are components in a request pipeline. `app.Use()` can call the next middleware; `app.Map()` branches based on path; `app.Run()` terminates the pipeline. Order matters because requests flow sequentially; exception handling middleware must be placed first to catch errors from all subsequent steps.

**DN17**: `Channel<T>` is a high-performance producer-consumer queue. Unlike `BlockingCollection`, it is fully async. Bounded channels provide backpressure by allowing the writer to asynchronously wait (`WaitToWriteAsync`) when the channel reaches its capacity limit.

**DN18**: Source Generators create C# code during compilation. They differ from reflection (runtime) and IL weaving (post-compile). **Incremental generators** use a cache to only re-process changed parts of the syntax tree, significantly improving IDE performance over standard `ISourceGenerator`.

**DN19**: TPL Dataflow provides blocks: `ActionBlock` (consumes), `TransformBlock` (maps input $\to$ output), `BufferBlock` (queue). Compared to Channels, Dataflow allows complex directed graphs/pipelines with built-in concurrency limits per block.

**DN20**: Minimal APIs remove controller overhead for simple endpoints. Trade-offs: faster startup and less boilerplate vs. harder organization in massive apps. Route groups allow shared prefixes/auth; endpoint filters act as "mini-middleware" specifically for those routes.

## Python

**P1**: **List** is mutable; **Tuple** is immutable. **Set** is an unordered collection of unique elements; **Frozenset** is an immutable version of a set.

**P2**: The GIL prevents multiple native threads from executing Python bytecodes simultaneously. It affects CPU-bound workloads. Workarounds include using the `multiprocessing` module or writing critical sections in C extensions.

**P3**: `copy` (shallow) creates a new object but references nested objects; `deepcopy` recursively copies everything. Example: A list containing lists `[[1]]`; a shallow copy's inner list still points to the original inner list. Changing it affects both.

**P4**: Decorators are wrappers that modify function behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time()-start:.4f}s")
        return res
    return wrapper
```

**P5**: Generators use `yield` to produce values one at a time lazily, saving memory compared to returning a full list. `yield from` allows a generator to delegate part of its operations to another iterable/generator.

**P6**: The event loop schedules tasks. `asyncio.run()` is the entry point; `gather()` runs multiple coroutines concurrently and waits for all; `create_task()` schedules a coroutine to run independently. `time.sleep()` blocks the entire thread, freezing the loop; `await asyncio.sleep()` yields control back to the loop.

**P7**: Python uses C3 Linearization (MRO). In diamond inheritance, it searches depth-first but ensures parents are visited after children. For `D(B, C)`, order is `[D, B, C, A]`. Since `B` doesn't define `who`, it checks `C`. Result: `"C"`.

**P8**: A metaclass is a class that creates classes. Use `__init_subclass__` for simple customization of child classes without the complexity of a metaclass. Metaclasses are used for deep API magic (e.g., Django models); `__init_subclass__` is better for registry patterns.

**P9**: 
*   **Threading**: I/O bound (shared memory, GIL limited).
*   **Multiprocessing**: CPU bound (separate memory, bypasses GIL).
*   **Concurrent.futures**: High-level wrapper for both via `ThreadPoolExecutor`/`ProcessPoolExecutor`.
Multiprocessing requires **pickling** (serialization) to send data between processes, which can fail for complex objects like lambdas or open files.

**P10**: `__slots__` tells Python not to create a `__dict__` for instances. It prevents dynamic attribute addition and significantly reduces memory usage per object by storing attributes in a fixed-size array.

**P11**: Virtual environments isolate project dependencies. `venv` is built-in; `virtualenv` provides more features/older support; `conda` manages non-Python binary dependencies (like C++ libraries) as well.

**P12**: Comprehensions provide concise ways to create collections. They are generally faster and more readable than `map()` and `filter()`, though the latter are useful when passing existing functions as arguments.

**P13**: `==` checks value equality; `is` checks identity (memory address). Small integers (-5 to 256) are interned by Python, so `a is b` returns True because they point to the same pre-allocated global object.

**P14**: `*args` collects positional args into a tuple; `**kwargs` collects keyword args into a dict. `/` marks parameters before it as **positional-only**; `*` marks parameters after it as **keyword-only**.

**P15**: Context managers manage resources via `with`. Using `@contextmanager` from `contextlib` allows using a generator (`yield`) instead of defining `__enter__`/`__exit__`. Example: A database transaction that commits on success or rolls back on exception.

**P16**: Type hinting improves static analysis. `Union[A, B]` (either), `Optional[T]` (T or None), `Literal["val"]` (specific value), `TypeVar` (generic types), `Protocol` (structural typing/interfaces). Mypy uses these to find bugs without running the code.

**P17**: Dunder methods define object behavior. `repr` is for developers (unambiguous); `str` is for users (readable). If you override `__eq__`, you must override `__hash__` if you want the object to be usable in sets or as dictionary keys. `__getattr__` runs only if attribute isn't found; `__getattribute__` runs every time.

**P18**: Descriptors are objects with `__get__`, `__set__`, and `__delete__`. They allow custom logic when accessing attributes. `@property` is a built-in descriptor that implements `__get__` (and optionally `__set__`).

**P19**: Absolute imports use full paths from the root; relative imports use `.`. `sys.path` defines search order. `__init__.py` marks directories as packages. **Finders** locate modules on disk; **Loaders** convert them into Python modules.

**P20**: `dataclasses` reduce boilerplate for data holders. `attrs` provides more power; Pydantic adds runtime validation and type coercion. Use Pydantic for API boundaries/parsing external JSON, and dataclasses for internal state where performance is prioritized over validation.
