## .NET / C#

**DN1**: **Class** is a reference type (allocated on heap); **Struct** is a value type (usually allocated on stack). Use structs for small, immutable data structures (e.g., Point, Color) to reduce GC pressure and improve cache locality.

**DN2**: `IEnumerable<T>` is an in-memory iterator; it filters data *after* loading from the database (client-side). `IQueryable<T>` represents a query expression tree; it translates filters into SQL via a provider (server-side). This distinction prevents "over-fetching" data from the DB.

**DN3**: `async/await` uses a state machine to yield control back to the caller while waiting for I/O, preventing thread blocking. A `Task` is a class (heap allocation); a `ValueTask` is a struct. Use `ValueTask` when the result is often available synchronously to avoid unnecessary allocations.

**DN4**: DI manages object lifetimes: **Transient** (new instance every time), **Scoped** (once per request), **Singleton** (one instance forever). A common bug is the **Captive Dependency**, where a Singleton depends on a Scoped service; since the Singleton lives longer, the Scoped service is kept alive indefinitely, potentially causing memory leaks or stale data (like a DbContext).

**DN5**: `string` is an immutable heap object. `ReadOnlySpan<char>` is a view over a contiguous region of memory (stack or heap) without copying. Use `Span<T>` for high-performance slicing and parsing to eliminate temporary string allocations.

**DN6**: The GC uses generations to optimize collection: **Gen 0** (short-lived objects), **Gen 1** (buffer between 0 and 2), **Gen 2** (long-lived). Objects >85KB go to the **Large Object Heap (LOH)** to avoid expensive compaction. `IDisposable` is needed because GC only handles managed memory; it doesn't know how to close file handles or database connections immediately.

**DN7**: `ConfigureAwait(false)` tells the task not to marshal back to the original `SynchronizationContext`. In UI apps, this prevents deadlocks by allowing the continuation to run on any thread. Use it in libraries; do NOT use it in application code that needs to update UI elements.

**DN8**: .NET 8/9 features: **Primary Constructors** allow defining parameters directly in the class header. **Collection Expressions** (`[]`) provide unified syntax for arrays/lists. **FrozenDictionary** is a read-only dictionary optimized for fast lookups.
```csharp
// Primary Constructor with DI example
public class UserService(IUserRepository repository) {
    public async Task<User> GetUser(int id) => await repository.GetByIdAsync(id);
}
```

**DN9**: The cause is likely an asynchronous operation attempting to use a `DbContext` after its scope has been disposed (e.g., firing a "fire-and-forget" task). Fix: Ensure all tasks are awaited within the request scope or create a new service scope using `IServiceScopeFactory`. EF Core `DbContext` must be Scoped because it is not thread-safe.

**DN10**: A **record** provides built-in value-based equality and non-destructive mutation (`with`). A **class** uses reference equality. A **record struct** combines record behavior with value-type performance. Choose records for DTOs/Value Objects; classes for complex business logic entities.

**DN11**: `ref`: passes by reference (can read/write). `out`: must be assigned before returning (used for multiple return values). `in`: passed by reference but read-only (performance optimization for large structs).

**DN12**: Nullable Reference Types (`string?`) provide static analysis warnings to prevent `NullReferenceException`; they don't change runtime behavior. Nullable Value Types (`int?`) are wrappers (`Nullable<T>`) that actually allow a null state at runtime.

**DN13**: LINQ allows querying collections. **Method syntax** uses extension methods (`.Where()`); **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over the result (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict generic types: `where T : class` (reference type), `struct` (value type), `new()` (must have parameterless constructor), `IComparable<T>` (must implement interface). Combine them when a type needs both specific capabilities and a specific memory layout (e.g., `where T : class, IDisposable`).

**DN15**: An **abstract class** can hold state and implementation; an **interface** defines a contract. Default Interface Methods (C# 8+) allow interfaces to provide default logic, blurring the line by allowing "traits" without forcing all implementing classes to write the same boilerplate.

**DN16**: Middleware is a chain of delegates. `app.Use()` passes control to next middleware; `app.Map()` branches based on path; `app.Run()` terminates the pipeline. Order matters because requests flow through sequentially. Exception handling middleware must be placed first to catch errors from subsequent steps.

**DN17**: `Channel<T>` is a high-performance producer-consumer queue. Unlike `BlockingCollection`, it is fully async. Bounded channels create backpressure: if the channel is full, the producer's `WriteAsync` will asynchronously wait until space is available.

**DN18**: Source Generators produce C# code during compilation via Roslyn. They avoid reflection overhead at runtime. **Incremental generators** are preferred over `ISourceGenerator` because they cache results and only re-run for changed parts of the syntax tree, significantly improving IDE performance.

**DN19**: TPL Dataflow creates actor-like pipelines. `ActionBlock` consumes data; `TransformBlock` modifies data; `BufferBlock` stores data. Compared to Channels, TPL Dataflow allows complex graphs (branching/merging) rather than simple linear queues.

**DN20**: Minimal APIs remove controller overhead for lightweight endpoints. Trade-offs: faster startup and less boilerplate, but can become disorganized in large apps. Route groups organize endpoints; endpoint filters provide cross-cutting concerns like validation or auth before reaching the handler.

## Python

**P1**: **List** is mutable; **Tuple** is immutable. **Set** is an unordered collection of unique elements; **Frozenset** is an immutable version of a set that can be used as a dictionary key.

**P2**: The GIL prevents multiple native threads from executing Python bytecodes simultaneously. It affects CPU-bound workloads. Workarounds include using the `multiprocessing` module (separate processes with their own GIL) or writing critical sections in C extensions.

**P3**: `copy` (shallow) copies the container but references nested objects. `deepcopy` recursively copies everything. Example: A list of lists `[[1]]`. A shallow copy's inner list is shared; changing it in one reflects in both.

**P4**: Decorators wrap functions to modify behavior.
```python
import time
from functools import wraps

def log_time(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return result
    return wrapper
```

**P5**: Generators use `yield` to produce values lazily, saving memory by not loading entire lists into RAM. `yield from` allows a generator to delegate part of its operations to another iterable or generator.

**P6**: The event loop schedules coroutines. `asyncio.run()` starts the loop; `gather()` runs multiple tasks concurrently and waits for all; `create_task()` schedules a task without blocking. `time.sleep()` blocks the whole thread/loop; use `await asyncio.sleep()` to yield control.

**P7**: Python uses C3 Linearization (MRO). In diamond inheritance, it searches depth-first but ensures parents are visited after children. For `D(B, C)`, MRO is `[D, B, C, A]`. Since `C` overrides `who`, and `B` does not, `D().who()` prints `"C"`.

**P8**: A metaclass is a "class factory" that defines how classes are created. Use `__init_subclass__` for simpler customization of child classes. Metaclasses: used for complex API constraints (e.g., Django models). `__init_subclass__`: used for simple registries of subclasses.

**P9**: **Threading**: I/O bound (shared memory, GIL limited). **Multiprocessing**: CPU bound (separate memory, bypasses GIL). **Concurrent.futures**: High-level abstraction over both via `ThreadPoolExecutor`/`ProcessPoolExecutor`. Multiprocessing requires objects to be "picklable" (serializable) to move between processes.

**P10**: `__slots__` tells Python not to create a `__dict__` for instances. It prevents dynamic attribute addition and significantly reduces memory usage per object by using fixed arrays instead of hash maps.

**P11**: Virtual environments isolate dependencies per project. `venv` is the standard library tool; `virtualenv` is an extended version with more features; `conda` manages both Python versions and non-Python binary packages.

**P12**: Comprehensions provide concise syntax for creating collections. They are generally faster and more readable than `map()` or `filter()`, though `map/filter` can be preferred when passing existing functions as arguments.

**P13**: `==` checks value equality; `is` checks identity (memory address). Small integers (-5 to 256) are interned by Python, so `a is b` returns True because they point to the same pre-allocated object in memory.

**P14**: `*args` collects positional args into a tuple; `**kwargs` collects keyword args into a dict. `/` marks parameters that *must* be positional; `*` marks parameters that *must* be keyword-only.

**P15**: Context managers manage resources via `with`. Class-based: define `__enter__` and `__exit__`. Generator-based: use `@contextmanager` decorator. Example: A database transaction lock where `__exit__` handles commit/rollback regardless of errors.

**P16**: Type hinting provides static analysis hints. `Union[A, B]` (either), `Optional[T]` (`T` or `None`), `Literal` (exact values), `TypeVar` (generics), `Protocol` (structural typing). Mypy/Pyright check these without running the code to find bugs early.

**P17**: Dunder methods implement the data model. `__repr__` is for developers; `__str__` is for users. `__eq__` defines equality; if you override it without `__hash__`, the class becomes unhashable (cannot be used as a set element). `__getattr__` runs only if attribute isn't found; `__getattribute__` runs every time.

**P18**: Descriptors are objects defining `__get__`, `__set__`, or `__delete__`. They allow custom logic when accessing attributes. `@property` is a built-in descriptor that implements `__get__` and optionally `__set__`.

**P19**: Absolute imports use full paths from the root; relative imports use `.`. `sys.path` determines search order. Namespace packages omit `__init__.py` to allow splitting one package across multiple directories. Finders locate modules on disk; Loaders load them into memory.

**P20**: `dataclasses` automate boilerplate (`__init__`, `__repr__`). `attrs` provides more power (validators, converters); Pydantic adds runtime type validation. Use Pydantic for API boundaries/JSON parsing where input data cannot be trusted.
