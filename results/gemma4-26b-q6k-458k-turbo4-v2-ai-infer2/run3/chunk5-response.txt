## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap), while **struct** is a value type (stored on the stack or inline). Use a **struct** for small, immutable, data-centric objects (typically < 16 bytes) to reduce GC pressure and allocation overhead.

**DN2** — `IEnumerable<T>` is a forward-only cursor for iterating over a collection in memory. `IQueryable<T>` represents a query provider (like EF Core) that translates LINQ expressions into SQL. The distinction matters because `IQueryable` allows for **server-side filtering** (SQL `WHERE`), whereas `IEnumerable` pulls all data into memory first, then filters locally.

**DN3** — `async/await` uses a state machine to allow non-blocking execution. A **Task** is a class (heap allocation) representing an asynchronous operation. A **ValueTask** is a struct (stack allocation) used when the result might already be available synchronously, reducing allocation overhead. Use `ValueTask` in high-frequency methods where the result is often cached or immediate.

**DN4** — **Dependency Injection (DI)** manages object lifetimes. **Transient**: new instance every time. **Scoped**: one instance per client request. **Singleton**: one instance for the app lifetime. A common bug is **Captive Dependency**: injecting a Scoped service into a Singleton, causing the Scoped service to live as long as the Singleton (effectively making it a Singleton).

**DN5** — `string` is an immutable heap-allocated object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous memory region (string, array, etc.). Use `Span<T>` to perform slicing and parsing without creating new string allocations, significantly improving performance and reducing GC pressure.

**DN6** — The **GC** manages memory in generations: **Gen 0** (newly allocated), **Gen 1** (survivors of Gen 0), **Gen 2** (long-lived). The **Large Object Heap (LOH)** is for objects > 85,000 bytes; it is not compacted by default. **IDisposable** is required for unmanaged resources (file handles, sockets) because the GC only manages memory, not the lifecycle of external OS resources.

**DN7** — `ConfigureAwait(false)` tells the runtime not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to prevent deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread to update controls.

**DN8** — **Primary constructors** allow parameters in the class declaration. **Collection expressions** use `[]`. **FrozenDictionary** is an immutable, highly optimized dictionary.
```csharp
// Example
public class UserService(IUserRepository repo) {
    private readonly IUserRepository _repo = repo;
    public IEnumerable<string> GetNames() => _repo.GetAll().Select(u => u.Name);
}
```

**DN9** — The cause is likely **thread-safety violation**: `DbContext` is not thread-safe and is designed for a single unit of work. Under high concurrency, multiple threads are likely sharing the same `DbContext` instance. **Fix**: Ensure `DbContext` is registered as **Scoped** and that you aren't manually sharing it across tasks or injecting it into a Singleton.

**DN10** — **Record** is a class with value-based equality. **Record struct** is a value type with value-based equality. Use `record` for DTOs/data models where identity is defined by data. Use `class` when you need reference identity or complex inheritance.

**DN11** — `ref`: Pass by reference (read/write, must be initialized). `out`: Pass by reference (write-only, must be initialized inside the method). `in`: Pass by reference (read-only, prevents modification).

**DN12** — **Nullable reference types** (`string?`) are a compiler feature to help prevent `NullReferenceException` via static analysis. **Nullable value types** (`int?`) are actual `Nullable<T>` structs that allow a value type to represent `null`.

**DN13** — **LINQ** (Language Integrated Query) allows querying collections. **Method syntax** uses extension methods (`.Where()`); **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query is not executed until you iterate over it (e.g., via `foreach` or `.ToList()`).

**DN14** — Constraints restrict generic types: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement interface). You combine them with `where T : class, new()`.

**DN15** — **Abstract classes** can have state (fields) and implementation. **Interfaces** define a contract. Since C# 8, interfaces can have **default implementations**, blurring the line, but interfaces still cannot hold instance state (fields).

**DN16** — The **middleware pipeline** processes requests sequentially. `app.Use()` adds middleware that can call `next()`. `app.Map()` branches the pipeline. `app.Run()` is a terminal middleware. **Ordering matters** (e.g., Exception handling must be first to catch errors in subsequent middleware).

**DN17** — `Channel<T>` is an async-capable producer-consumer queue. `BlockingCollection<T>` is synchronous/blocking. For **backpressure**, use a **Bounded Channel**: `Channel.CreateBounded<T>(capacity)`, which forces the producer to wait (asynchronously) when the capacity is reached.

**DN18** — **Source Generators** produce code at compile time, unlike **Reflection** (runtime) or **IL Weaving** (post-compile). **Incremental Generators** are preferred because they only re-run when the specific parts of the syntax tree they depend on change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. `ActionBlock` (consumer), `TransformBlock` (processor), `BufferBlock` (queue). Compared to `Channels`, Dataflow is more robust for complex, multi-stage, actor-like processing with built-in buffering and concurrency management.

**DN20** — **Minimal APIs** are lightweight, high-performance endpoints. **Trade-offs**: They have less boilerplate than Controllers but less built-in structure. Testability is similar if using DI, but Controllers provide better organization for large APIs. **Route groups** allow prefixing, and **Endpoint filters** act like middleware for specific endpoints.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is mutable and contains unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, limiting CPU-bound multi-threading. **Workarounds**: Use `multiprocessing` to bypass the GIL by using separate memory spaces, or use C-extensions (like NumPy) that release the GIL.

**P3** — `copy()` is a **shallow copy** (copies references to objects). `deepcopy()` is a **deep copy** (recursively copies everything). **Example**: If `a = [[1]]` and `b = a.copy()`, then `b[0][0] = 2` changes `a[0][0]` because the inner list is the same object.

**P4** — Decorators wrap functions.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily, one at a time, saving memory. `yield from` is used to delegate to a sub-generator (flattening nested generators).

**P6** — The **event loop** manages async tasks. `asyncio.run()` starts the loop; `asyncio.gather()` runs multiple tasks concurrently and waits for all; `asyncio.create_task()` schedules a task to run in the background. `time.sleep()` is **blocking** and stops the entire loop; use `await asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization**. In the example, `D` inherits from `B` then `C`. MRO: `D -> B -> C -> A`. `D().who()` looks at `D` (no), `B` (no), then `C` (yes). It prints **"C"**.

**P8** — A **metaclass** is a class that creates classes. `__init_subclass__` is a simpler hook for customizing class creation during inheritance. Use `__init_subclass__` for simple registration/setup; use a **metaclass** for deep structural changes to the class itself.

**P9** — **Threading**: I/O bound. **Multiprocessing**: CPU bound (bypasses GIL). **concurrent.futures**: High-level abstraction for both. **Multiprocessing** requires **pickling** (serialization) to move data between processes, which can be slow/restrictive.

**P10** — `__slots__` tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This **reduly memory usage** and speeds up attribute access, but prevents adding new attributes dynamically.

**P11** — A **virtual environment** isolates dependencies. `venv` is the standard library tool; `virtualenv` is a more feature-rich third-party alternative; `conda` is a cross-language package/env manager (great for data science).

**P12** — **Comprehensions** (`[x for x in...]`) are generally more readable and faster than `map()`/`filter()`. Use comprehensions for most cases; use `map`/`filter` when working with existing functions.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** reuses small integers/strings to save memory. `a is b` is True for small integers because they are pre-allocated in a single memory location.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters before it as **positional-only**; `*` marks parameters after it as **keyword-only**.

**P15** — **Context managers** handle setup/teardown. Use `__enter__`/`__exit__` or `@contextmanager`. Example: A database transaction manager.

**P16** — **Type hinting** provides static metadata. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1, 2]` (specific values), `TypeVar` (generics), `Protocol` (structural typing). `mypy` uses these to catch type errors before runtime.

**P17** — `__repr__` (dev-friendly), `__str__` (user-friendly), `__eq__` (equality), `__hash__` (for sets/dicts), `__getattr__` (fallback), `__getattribute__` (always called). If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** manage attribute access via `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol.

**P19** — **Absolute imports** use the full path; **relative** use `.` notation. `sys.path` is the search list. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** executes the code.

**P20** — `dataclasses` (std lib, simple), `attrs` (powerful, feature-rich), `Pydantic` (runtime validation). **Pydantic** is preferred for external data (APIs) because it performs strict type validation at runtime, whereas `dataclasses` is primarily for data storage.
