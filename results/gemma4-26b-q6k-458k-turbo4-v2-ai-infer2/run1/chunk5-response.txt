## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (usually stored on the stack or inline). Use a **struct** for small, immutable, data-centric types (e.g., a `Point` or `Color`) that have no identity beyond their values and are unlikely to be boxed.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects); **IQueryable<T>** is for out-of-memory providers (LINQ-to-SQL/EF). The distinction matters because `IQueryable` allows the provider to translate the expression tree into a database-specific query (SQL), whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — **async/await** uses a state machine to allow non-blocking execution. **Task** is a class representing an asynchronous operation (heap-allocated). **ValueTask** is a struct used to reduce allocations when the result is often available synchronously. Use **ValueTask** in high-frequency methods where the result is frequently already completed.

**DN4** — **Dependency Injection** is a pattern where objects receive their dependencies from an external source. **Lifetimes**: **Transient** (new instance every time), **Scoped** (once per client request), **Singleton** (one instance for the app lifetime). **Bug**: Injecting a Scoped service into a Singleton (Captive Dependency) causes the Scoped service to live as long as the Singleton, leading to stale data or concurrency issues.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a view into a contiguous memory region (stack, heap, or unmanaged). Use **Span<T>** for high-performance slicing and parsing to avoid the memory allocations and copying associated with `string.Substring`.

**DN6** — The **GC** manages memory automatically. **Gen 0** (new objects), **Gen 1** (buffer), **Gen 2** (long-lived). **LOH** (Large Object Heap) holds objects >85KB and is collected less frequently. **IDisposable** is needed to manually release unmanaged resources (file handles, DB connections) because the GC only manages managed memory.

**DN7** — **ConfigureAwait(false)** tells the runtime not to force the continuation back onto the original `SynchronizationContext` (e.g., the UI thread). Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it if you need to access UI elements or context-specific data (like `HttpContext`) after the `await`.

**DN8** — **Primary constructors** allow parameters directly in the class header. **Collection expressions** (`[1, 2, 3]`) simplify array/list creation. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
public class UserService(IUserRepository repo) { // Primary Constructor
    public User GetUser(int id) => repo.Find(id);
}
```

**DN9** — **Cause**: A `DbContext` is Scoped, but it is being captured by a long-running background task or a Singleton. **Fix**: Inject `IServiceScopeFactory`, create a new scope manually using `scopeFactory.CreateScope()`, and resolve the `DbContext` from that scope.

**DN10** — **Record** is a reference type with value-based equality. **Class** is a reference type with identity-based equality. **Record struct** is a value type with value-based equality. Use **records** for DTOs/data models; use **classes** for complex logic/identity; use **record structs** for small, high-performance data types.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only, prevents copying large structs).

**DN12** — **Nullable reference types** (`string?`) are compiler hints to prevent null dereferences. **Nullable value types** (`int?`) are actual `Nullable<T>` structs that can hold a null value.

**DN13** — **LINQ** is a way to query data. **Method syntax** uses extension methods (`.Where()`); **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over the results (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement interface). Combine them to narrow the allowed types (e.g., `where T : class, new()`).

**DN15** — **Abstract class** can have state and implementation; **Interface** is a contract. **Default interface methods** allow interfaces to provide a default implementation, making them behave more like abstract classes, blurring the distinction.

**DN16** — The **middleware pipeline** processes requests sequentially. **app.Use()** (executes logic and calls next), **app.Map()** (branches the pipeline), **app.Run()** (terminal middleware). **Ordering** is critical (e.g., Auth must come before Authorization). **Exception middleware** catches errors thrown in subsequent steps to provide a unified error response.

**DN17** — **Channel<T>** is an async-native producer-consumer library. **BlockingCollection<T>** is synchronous/blocking. Use **Bounded Channels** to implement backpressure: if the channel is full, the producer waits (asynchronously) instead of overwhelming the consumer.

**DN18** — **Source Generators** generate C# code at compile time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (modifying bytecode), they are type-safe and visible. **Incremental Generators** are preferred because they only re-run when specific parts of the syntax tree change, significantly improving build performance.

**DN19** — **TPL Dataflow** is an actor-based library. **ActionBlock** (consumer), **TransformBlock** (processor), **BufferBlock** (queue). Compared to **Channels**, TPL Dataflow is more complex and feature-rich (supporting linking and buffering), whereas Channels is lighter and more performant for simple pipelines.

**DN20** — **Minimal APIs** are lightweight, low-boilerplate alternatives to Controllers. **Trade-offs**: They are faster to write and have less overhead, but Controllers offer better organization for large APIs. They support the same middleware, filters, and OpenAPI integration. **Route groups** allow prefixing routes, and **endpoint filters** allow logic to run per-endpoint.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is unordered and contains unique elements; **Frozenset** is an immutable version of a set.

**P2** — The **GIL** ensures only one thread executes Python bytecode at a time. It affects **CPU-bound** workloads (making multi-threading ineffective for math/logic). **Workarounds**: Use `multiprocessing` to bypass the GIL via separate processes or use C-extensions (like NumPy) that release the GIL.

**P3** — **copy** (shallow) creates a new container but keeps references to the same nested objects. **deepcopy** creates a new container and recursively copies all nested objects. **Example**: If `a = [[1]]`, `b = a.copy()` means `b[0][0] = 2` also changes `a[0][0]`.

**P4** — 
```python
import time
def logger(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start}s")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values one by one (lazy evaluation), saving memory. **yield from** is used to delegate to a sub-generator, flattening nested generators.

**P6** — The **event loop** manages async tasks. `asyncio.run()` starts the loop; `asyncio.gather()` runs multiple tasks concurrently; `asyncio.create_task()` schedules a task to run in the background. You cannot use `time.sleep()` because it blocks the entire thread, preventing the loop from switching tasks.

**P7** — Python uses **C3 Linearization**. For `D(B, C)`, the MRO is `[D, B, C, A]`. The code prints **"C"** because `D` inherits from `B` and `C`, and `C` overrides `A`. The search order finds `C.who()` before `A.who()`.

**P8** — A **metaclass** is a class that defines how a class behaves. Use `__init_subclass__` for simple class-level setup (e.g., registering subclasses). Use a **metaclass** for deep manipulation of class creation (e.g., modifying attributes or enforcing strict rules).

**P9** — **Threading** (I/O bound), **Multiprocessing** (CPU bound), **concurrent.futures** (high-level abstraction for both). **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be slow and fails on non-serializable objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, saving significant memory. It also prevents the dynamic addition of new attributes.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library module; **virtualenv** is a more feature-rich third-party tool; **conda** is a package/environment manager used heavily in data science for non-Python dependencies.

**P12** — **Comprehensions** (`[x for x in...]`) are more readable and often faster than `map()` and `filter()`. Use comprehensions for most cases; use `map`/`filter` when working with existing functions or very large iterators where lazy evaluation is preferred.

**P13** — `==` checks **value equality**; `is` checks **identity equality** (same memory address). **Object interning** caches small integers and strings to save memory, which is why `a is b` can be `True` for small integers.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters before it as **positional-only**; `*` marks parameters after it as **keyword-only**.

**P15** — Context managers handle setup/teardown. Use `__enter__`/`__exit__` in a class or `@contextmanager` decorator. **Example**: A database transaction manager that rolls back on error.

**P16** — **Type hinting** provides static type information. `Union` (A or B), `Optional` (A or None), `Literal` (specific value), `TypeVar` (generic), `Protocol` (structural typing). **mypy/pyright** use these to find type errors without running the code.

**P17** — `__repr__` (developer-facing string), `__str__` (user-facing), `__eq__` (equality), `__hash__` (identity). `__getattr__` is called only if attribute isn't found; `__getattribute__` is called for *every* access. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** implement `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol to intercept attribute access.

**P19** — **Absolute imports** use the full path; **relative** use dots. `sys.path` is the search list. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** executes it.

**P20** — **dataclasses** (std lib, simple), **attrs** (powerful/flexible), **Pydantic** (validation-focused). **dataclasses** are for data storage; **Pydantic** is best for parsing/validating external data (like JSON APIs). Pydantic handles type coercion and complex validation automatically.
