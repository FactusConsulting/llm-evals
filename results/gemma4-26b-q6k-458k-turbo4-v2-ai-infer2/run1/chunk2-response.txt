## Kubernetes

**K1** — **Deployment** manages stateless applications and provides declarative updates to Pods. **StatefulSet** manages stateful applications, providing stable, unique network identifiers and persistent storage per Pod.

**K2** — A **ClusterIP** service uses `kube-proxy` (via iptables or IPVS) to intercept traffic sent to the Service's Virtual IP (VIP) and load balance it across the IP addresses of the backend Pods.

**K3** — **StorageClass** is a template for creating storage; **PersistentVolume (PV)** is the actual storage resource in the cluster; **PersistentVolumeClaim (PVC)** is a user's request for storage. They relate as: StorageClass $\rightarrow$ creates $\rightarrow$ PV $\rightarrow$ bound to $\rightarrow$ PVC.

**K4** — 1. `kubectl logs <pod>` (check application errors); 2. `kubectl describe pod <pod>` (check events/exit codes); 3. Check resource limits (OOMKilled); 4. Check liveness/readiness probe configurations.

**K5** — **CoreDNS** provides service discovery via DNS names. If CoreDNS pods are down, internal service-to-service communication via DNS names will fail, and external resolution will likely fail.

**K6** — The scheduler follows two phases: **Filtering** (removing nodes that don't meet requirements like CPU/RAM/Taints) and **Scoring** (ranking remaining nodes). Factors include: **Resource availability**, **Node Affinity/Selector**, and **Taints/Tolerations**.

**K7** — **Yes**, it will be scheduled (256Mi + 3.5GB = 3.75GB, which is $\le$ 4GB). However, if it uses 600Mi at runtime, it exceeds the 512Mi limit and will be **OOMKilled**.

**K8** — External LB $\rightarrow$ Ingress Controller (NGINX) $\rightarrow$ Ingress Resource (rules) $\rightarrow$ Service (ClusterIP) $\rightarrow$ Endpoints (Pod IPs) $\rightarrow$ Pod. `kube-proxy` manages the routing via iptables/IPVS.

**K9** — A **NetworkPolicy** controls L3/L4 traffic flow. By default, all pods can talk to all pods. Once a policy is applied to a pod, it enters "isolation" mode, and only traffic explicitly allowed by the policy is permitted.

**K10** — **RollingUpdate** replaces pods one-by-one to ensure zero downtime. **Recreate** kills all old pods before starting new ones. Choose **Recreate** when the application cannot handle two versions running simultaneously (e.g., a singleton database or legacy file locks).

**K11** — A **Namespace** provides logical isolation within a cluster. Default namespaces: `default`, `kube-system`, `kube-public`, and `kube-node-lease`.

**K12** — `kubectl describe` provides deep metadata. It shows: **Events** (recent lifecycle history), **Container Status** (restarts/exit codes), and **Mounts/Volumes** (which the `get` command does not).

**K13** — A **ConfigMap** stores non-confidential data. Methods: 1. As **Environment Variables**; 2. As **Files in a Volume**.

**K14** — **ClusterIP**: Internal only. **NodePort**: Exposes service on a static port on every Node's IP. **LoadBalancer**: Provisions a cloud provider's external load balancer.

**K15** — A **DaemonSet** ensures a copy of a Pod runs on every (or selected) node. Use it for system-level tasks like log collectors (Fluentd) or monitoring agents (Prometheus Node Exporter).

**K16** — **Taints** repel pods from nodes; **Node Affinity** attracts pods to nodes. **Use case**: Taint a node with a GPU to prevent general pods from using it; use Affinity to ensure a specific pod lands on that GPU node.

**K17** — An **Operator** is a custom controller that uses **Custom Resource Definitions (CRDs)** to manage complex, domain-specific applications. Unlike standard controllers, it encodes operational human knowledge (e.g., how to back up a specific database).

**K18** — etcd uses the **Raft** consensus algorithm. If quorum is lost, the cluster becomes read-only or fails. If 2/3 nodes are lost, you must restore from a known good snapshot/backup to a new etcd cluster.

**K19** — **Role/ClusterRole** defines permissions; **RoleBinding/ClusterRoleBinding** attaches those permissions to users/groups.
```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata: { name: pod-reader, namespace: dev }
rules:
- apiGroups: [""]
  resources: ["pods", "pods/log"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata: { name: dev-read-binding, namespace: dev }
subjects: [{ kind: User, name: "developer", apiGroup: "rbac.authorization.k8s.io" }]
roleRef: { kind: Role, name: pod-reader, apiGroup: "rbac.authorization.k8s.io" }
```

**K20** — With `ndots:5` (default), a query for `google.com` triggers searches for `google.com.default.svc.cluster.local`, etc. Fix: Set `dnsConfig.options` with `ndots: 1` in the Pod spec to minimize search attempts.

## Development

**D1** — **Merge** combines histories; **Rebase** rewrites history by moving your branch to the tip of the target. Avoid rebasing **public/shared branches** as it breaks history for others.

**D2** — **TCP** is connection-oriented/reliable (HTTP, SSH); **UDP** is connectionless/unreliable (DNS, VoIP).

**D3** — A **race condition** occurs when two threads access shared data simultaneously, and the outcome depends on the timing. *Example*: Two threads incrementing `counter++` at the same time might result in `counter` only increasing by 1 instead of 2.

**D4** — **Symmetric**: Same key for encryption/decryption (AES). **Asymmetric**: Public/Private key pair (RSA). In **TLS**, asymmetric encryption is used for the initial handshake to exchange a symmetric key, which is then used for the actual data transfer.

**D5** — A **layer** is an immutable filesystem change. **Caching** means Docker reuses layers from previous builds; best practice is to put frequently changing instructions (like `COPY . .`) at the bottom to maximize cache hits.

**D6** — 1. Check Application Logs (errors); 2. Check Service/Endpoints (is the backend reachable?); 3. Check Upstream/Dependency health; 4. Check Resource limits (is the app throttling?).

**D7** — **CAP**: Consistency, Availability, Partition Tolerance. **CP** (Consistency/Partition): Zookeeper (stops accepting writes if quorum is lost). **AP** (Availability/Partition): Cassandra (allows writes even if nodes are disconnected).

**D8** — **Horizontal**: Adding more instances (scale-out). **Vertical**: Adding more CPU/RAM to one instance (scale-up). Patterns: **Statelessness** and **Load Balancing** enable horizontal scaling.

**D9** — A variable used to change behavior. On Linux, set it via `export VAR=val` in the terminal, or persist it by adding `export VAR=val` to `~/.bashrc` or `~/.profile`.

**D10** — **JSON** is strict/machine-friendly; **YAML** is human-readable. **JSON advantage**: Faster parsing/standardization. **YAML advantage**: Readability/Comments.

**D11** — **REST API**: Interface using HTTP. **GET**: Retrieve; **POST**: Create; **PUT**: Replace/Update; **DELETE**: Remove.

**D12** — **Version pinning** (e.g., `lib==1.2.3`) ensures that every build uses the exact same dependency version, preventing "it works on my machine" bugs caused by silent updates.

**D13** — **Compiled**: Converted to machine code before execution (C++, Go). **Interpreted**: Executed line-by-line by a runtime (Python, JavaScript).

**D14** — **Forward Proxy**: Protects clients (hides client identity). **Reverse Proxy**: Protects servers (hides server identity). **Servers**: Nginx (SSL termination), HAProxy (Load balancing).

**D15** — **Deadlock**: A state where processes are stuck waiting for each other. **Coffman Conditions**: 1. Mutual Exclusion, 2. Hold and Wait, 3. No Preemption, 4. Circular Wait.

**D16** — **Eventual Consistency**: Data will be consistent "eventually." **Cassandra** uses tunable consistency: `ONE` (fastest), `QUORUM` (majority), or `ALL` (strongest).

**D17** — **mTLS**: Both client and server present certificates. **Handshake**: Client sends cert $\rightarrow$ Server verifies $\rightarrow$ Server sends cert $\rightarrow$ Client verifies. Used in **Service Meshes** (Istio) for Zero Trust.

**D18** — **Hash Table**: Maps keys to indices via a hash function. **Collision Resolution**: **Chaining** (linked list at index) or **Open Addressing** (finding next empty slot). **Complexity**: Avg: $O(1)$ for all; Worst: $O(n)$.

**D19** — **Circuit Breaker**: Prevents cascading failures. **Closed**: Normal flow. **Open**: Failures detected; stop all requests. **Half-Open**: Test if service recovered. Relates to **Retries** (don't retry if circuit is open) and **Exponential Backoff** (wait longer between retries).

**D20** — **Optimistic**: Assumes no conflict; uses versioning/timestamps (better for low contention). **Pessimistic**: Assumes conflict; uses locks like `SELECT FOR UPDATE` (better for high contention).
