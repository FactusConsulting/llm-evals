## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored on the stack or inline). Use a **struct** for small, immutable data structures (e.g., a `Point` or `Color`) to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects); **IQueryable<T>** is for out-of-memory providers (LINQ-to-SQL). The distinction matters because `IQueryable` translates expressions into provider-specific queries (like SQL), whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — **async/await** uses a state machine to allow non-blocking execution. A **Task** represents an ongoing operation (heap-allocated); a **ValueTask** is a struct used to avoid allocation when the result is often available synchronously. Use `ValueTask` in high-frequency methods where the result is frequently already completed.

**DN4** — **Dependency Injection (DI)** manages object lifetimes. **Transient**: new instance every time; **Scoped**: once per client request; **Singleton**: one instance for the app lifetime. **Bug**: Injecting a Scoped service into a Singleton creates a "Captive Dependency," where the Scoped service lives as long as the Singleton, potentially causing stale data or memory leaks.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a view into a contiguous memory region (stack or heap) without copying. Use **Span<T>** for high-performance slicing and parsing to avoid unnecessary allocations and GC pressure.

**DN6** — The **GC** manages memory in generations: **Gen 0** (newly allocated), **Gen 1** (buffer), **Gen 2** (long-lived). **Large Object Heap (LOH)** is for objects >85KB, which are treated as Gen 2 to avoid fragmentation. **IDisposable** is required to manually release unmanaged resources (files, sockets) because the GC only manages managed memory.

**DN7** — **ConfigureAwait(false)** tells the runtime not to force the continuation back onto the original `SynchronizationContext`. Use it in library code to prevent deadlocks. Do **NOT** use it in UI code (WPF/WinForms) where you need to return to the UI thread.

**DN8** — **Primary constructors** allow parameters in the class header. **Collection expressions** use `[]` syntax. **FrozenDictionary** is an immutable, read-optimized dictionary.
```csharp
public class UserService(IDbContext db) { // Primary Constructor
    public List<string> GetUsers() => db.Users.ToList();
}
var users = [ "Alice", "Bob" ]; // Collection expression
```

**DN9** — **Cause**: A `DbContext` is Scoped. If a background thread (not part of the request scope) tries to use a `DbContext` injected via DI, the request ends, the scope is disposed, and the background thread hits an `ObjectDisposedException`. **Fix**: Inject `IServiceScopeFactory` and create a new scope manually within the background task.

**DN10** — **record** provides value-based equality and is typically immutable. **class** provides reference-based equality. **record struct** is a value-type version of a record. Use `record` for DTOs/data containers and `class` for behavior-heavy objects.

**DN11** — **ref**: pass by reference (read/write); **out**: pass by reference (must be assigned in method); **in**: pass by reference (read-only).

**DN12** — **Nullable reference types** (`string?`) are compiler hints to prevent `NullReferenceException`. **Nullable value types** (`int?`) are actual wrappers (`Nullable<int>`) that allow a value type to hold `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** is fluent (`.Where()`); **Query syntax** is SQL-like (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over it (e.g., via `foreach` or `.ToList()`).

**DN14** — **Constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (parameterless constructor), `T : IComparable<T>` (comparable). Combine them to narrow the type (e.g., `where T : class, new()`).

**DN15** — **Abstract classes** can have state (fields) and implementation. **Interfaces** are contracts. **C# 8+** allowed default implementations in interfaces, blurring the line by allowing interfaces to provide logic.

**DN16** — **Middleware** is a pipeline. **app.Use()** calls the next middleware; **app.Map()** branches the pipeline; **app.Run()** is a terminal middleware. Order is critical (e.g., Auth must come before Authorization). Exception middleware catches errors in the subsequent pipeline.

**DN17** — **Channel<T>** is an async producer-consumer library. **BlockingCollection<T>** is synchronous. For backpressure, use a **Bounded Channel**: `Channel.CreateBounded<T>(capacity)`, which makes the producer wait (async) when the capacity is reached.

**DN18** — **Source Generators** produce code at compile time. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are visible to the compiler. **Incremental Generators** are preferred because they only re-run when relevant parts of the source change, improving build speed.

**DN19** — **TPL Dataflow** is for complex actor-like pipelines. **ActionBlock** (consumer), **TransformBlock** (processor), **BufferBlock** (queue). **Channels** are lighter and better for simple producer-consumer; **Dataflow** is better for complex Directed Acyclic Graphs (DAGs).

**DN20** — **Minimal APIs** are lightweight, low-boilerplate alternatives to Controllers. **Trade-offs**: Controllers offer better organization for large apps; Minimal APIs are faster/simpler for microservices. **Route groups** organize endpoints; **Endpoint filters** act like middleware for specific routes.

## Python

**P1** — **List** is mutable; **Tuple** is immutable. **Set** is a mutable collection of unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, limiting CPU-bound performance in a single process. **Workarounds**: Use `multiprocessing` or C-extensions (like NumPy) that release the GIL.

**P3** — **copy** is a shallow copy (new container, same object references). **deepcopy** is a recursive copy (new container and new objects). 
*Example*: `a = [[1]]; b = a.copy(); b[0][0] = 2` results in `a` being `[[2]]` because the inner list was not copied.

**P4** — Decorators wrap functions.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily (one at a time). **yield from** delegates to a sub-generator. Unlike lists, they don't store the whole sequence in memory.

**P6** — **asyncio.run()** starts the loop; **gather()** runs multiple coroutines concurrently; **create_task()** schedules a coroutine to run. You cannot use `time.sleep()` because it blocks the entire event loop; use `asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization**. For `D(B, C)`, the MRO is `D -> B -> C -> A`. In the code, `D().who()` looks at `D` (no `who`), then `B` (no `who`), then `C` (has `who`). It prints **"C"**.

**P8** — A **metaclass** is a class of a class. Use `__init_subclass__` for simple modifications to subclasses. Use a **metaclass** for deep control over class creation (e.g., registering classes automatically).

**P9** — **Threading** (I/O bound), **Multiprocessing** (CPU bound), **concurrent.futures** (high-level abstraction). **Multiprocessing** requires objects to be **pickled** (serialized) to be sent to other processes.

**P10** — **\_\_slots\_\_** prevents the creation of `__dict__` for instances, saving significant memory and preventing the addition of arbitrary attributes.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party alternative; **conda** is a package/env manager that handles non-Python binaries (data science).

**P12** — **Comprehensions** are concise and often faster than `map`/`filter`. Use them for readability when the logic is simple.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Interning** is Python's optimization of reusing small integers/strings to save memory.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters as **positional-only**; `*` marks them as **keyword-only**.

**P15** — **Context managers** handle setup/teardown.
```python
from contextlib import contextmanager
@contextmanager
def my_resource():
    print("Setup")
    yield "Resource"
    print("Teardown")
```

**P16** — **Type hinting** provides static metadata. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1]` (exactly 1), `TypeVar` (generic), `Protocol` (structural typing). **mypy/pyright** use these to find bugs without running code.

**P17** — `__repr__` (dev-friendly), `__str__` (user-friendly), `__eq__` (value equality), `__hash__` (for sets/dicts), `__getattr__` (called if attr not found), `__getattribute__` (called for *every* access). If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** implement `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors that manage how methods are accessed.

**P19** — **Absolute** imports use the full path; **Relative** use dots. `sys.path` is the search list. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** reads the code.

**P20** — **dataclasses** (std lib, simple), **attrs** (powerful), **Pydantic** (validation-heavy). Pydantic is preferred for data parsing/validation (e.g., API payloads). `__post_init__` runs after `__init__`. `frozen=True` makes it immutable.
