## .NET / C#

**DN1**: A `class` is a reference type (stored on the heap), while a `struct` is a value type (usually stored on the stack). Use a `struct` for small, immutable data structures (typically < 16 bytes) that represent a single value (e.g., `Point`, `ComplexNumber`) to reduce GC pressure.

**DN2**: `IEnumerable<T>` is for in-memory collections; it performs filtering/sorting on the client side (LINQ to Objects). `IQueryable<T>` is for remote data sources; it translates expressions into a provider-specific language (e.g., SQL) to execute filtering on the database server. This distinction prevents "over-fetching" data.

**DN3**: `async/await` allows non-blocking asynchronous operations by suspending the method until the awaited task completes, freeing the thread. `Task` is a class (heap allocated); `ValueTask` is a struct. Use `ValueTask` when the result is often available synchronously to avoid unnecessary allocations.

**DN4**: DI is a pattern where dependencies are provided to a class rather than created internally. 
- **Transient**: New instance every time.
- **Scoped**: One instance per request/scope.
- **Singleton**: One instance for the app lifetime.
- **Bug**: Injecting a Scoped service into a Singleton (Captive Dependency) causes the Scoped service to live as long as the Singleton, potentially leading to stale data or disposed `DbContext` errors.

**DN5**: `string` is an immutable heap object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory. Use `Span<T>`/`ReadOnlySpan<T>` for high-performance slicing and parsing to avoid creating multiple substring allocations.

**DN6**: The GC uses a generational approach: **Gen 0** (short-lived), **Gen 1** (buffer), **Gen 2** (long-lived). The **LOH (Large Object Heap)** stores objects > 85,000 bytes to avoid expensive compaction. `IDisposable` is needed for *unmanaged* resources (file handles, sockets) because the GC only manages memory, not external OS handles.

**DN7**: `ConfigureAwait(false)` tells the task not to marshal the continuation back to the original `SynchronizationContext` (e.g., UI thread). Use it in library code to improve performance and avoid deadlocks. Do NOT use it in application code that must update UI elements or access `HttpContext.Current`.

**DN8**: 
- **Primary Constructors**: Define parameters directly in the class declaration.
- **Collection Expressions**: `int[] x = [1, 2, 3];`
- **FrozenDictionary**: Immutable, highly optimized for read-heavy lookups.
Example:
```csharp
public class OrderService(IDbContext db) { // Primary Constructor
    public void Save() => db.SaveChanges();
}
```

**DN9**: Cause: A `DbContext` is being shared across multiple threads (e.g., `Task.WhenAll` calling methods that use the same scoped context). `DbContext` is NOT thread-safe. Fix: Create a new scope per concurrent task using `IServiceScopeFactory` to provide a dedicated `DbContext` per thread.

**DN10**: `record` is a class with built-in value-based equality. `record struct` is a value-type with value-based equality. Use `record` for DTOs/immutable data; `class` for behavior-heavy objects; `record struct` for small, high-performance value objects.

**DN11**: 
- `ref`: Pass by reference; must be initialized before passing; can be modified.
- `out`: Pass by reference; must be assigned inside the method; used for multiple return values.
- `in`: Pass by reference; read-only; used to avoid copying large structs.

**DN12**: Nullable Reference Types (`string?`) are a compile-time static analysis feature to prevent `NullReferenceException`. They do not change the runtime type. Nullable value types (`int?`) are `Nullable<T>` structs that actually change the type to allow a null state.

**DN13**: LINQ (Language Integrated Query) provides a consistent way to query data. **Method syntax** uses extension methods (`.Where()`); **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query is not executed until you iterate over the result (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict the types that can be used as generic arguments.
- `class`: Reference type.
- `struct`: Value type.
- `new()`: Must have a public parameterless constructor.
- `IComparable<T>`: Must implement the interface.
Combine them (e.g., `where T : class, new()`) to ensure the type is both a reference type and instantiable.

**DN15**: An `abstract class` can provide implementation and state; an `interface` defines a contract. Default Interface Methods (C# 8+) allow interfaces to provide a default implementation, blurring the line, but interfaces still cannot hold instance state (fields).

**DN16**: Middleware is a sequence of delegates. 
- `Use()`: Chains to the next middleware.
- `Map()`: Branches the pipeline based on the path.
- `Run()`: Terminates the pipeline (terminal middleware).
Ordering is critical (e.g., Exception Handling must be first to catch errors from subsequent steps).

**DN17**: `Channel<T>` is a high-performance producer-consumer queue. Unlike `BlockingCollection`, it is fully `async`. 
Example: `Channel.CreateBounded<T>(100)` creates a channel that blocks the producer (via `WriteAsync`) when the buffer is full, providing backpressure.

**DN18**: Source Generators inspect code during compilation and generate additional C# source files. Unlike reflection (runtime) or IL weaving (post-compile), they are type-safe and visible to the IDE. **Incremental Generators** are preferred because they cache results and only re-run on changed parts of the syntax tree, drastically improving IDE performance.

**DN19**: TPL Dataflow provides blocks for processing pipelines. 
- `ActionBlock`: Consumes and processes.
- `TransformBlock`: Consumes, transforms, and outputs.
- `BufferBlock`: Simple FIFO buffer.
Compared to `Channels`, Dataflow is better for complex directed graphs/meshes; Channels are better for simple, high-throughput producer-consumer pairs.

**DN20**: Minimal APIs remove the `Controller` boilerplate, using `app.MapGet(...)`. 
- **Trade-offs**: Faster startup and less code, but can become messy if not organized. 
- **Testability**: Use `WebApplicationFactory`. 
- **Route Groups**: `app.MapGroup("/api")` allows shared middleware/auth. 
- **Endpoint Filters**: Allow cross-cutting logic (like validation) before the handler runs.

## Python

**P1**: `list` is mutable; `tuple` is immutable. `set` is a mutable collection of unique elements; `frozenset` is an immutable version of a set (and thus hashable).

**P2**: The GIL is a mutex that allows only one thread to execute Python bytecode at a time. It affects CPU-bound workloads. Workarounds: Use `multiprocessing` (separate GILs per process) or C-extensions (e.g., NumPy) that release the GIL.

**P3**: `copy` (shallow) creates a new object but inserts references to the items in the original. `deepcopy` recursively copies everything. 
Example: A list of lists `[[1]]`. A shallow copy of the outer list still shares the inner list; modifying `copy[0][0]` changes the original.

**P4**: Decorators are functions that wrap other functions to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time()-start}s")
        return res
    return wrapper
```

**P5**: Generators use `yield` to produce values one at a time (lazy evaluation), saving memory compared to returning a full list. `yield from` is used to delegate to another generator or iterable.

**P6**: The event loop manages asynchronous tasks. 
- `asyncio.run()`: Entry point; creates loop and runs the main coroutine.
- `asyncio.gather()`: Runs multiple coroutines concurrently and waits for all.
- `asyncio.create_task()`: Schedules a coroutine to run in the background.
`time.sleep()` is blocking; it stops the entire thread, preventing the loop from switching tasks. Use `await asyncio.sleep()`.

**P7**: Python uses **C3 Linearization** for MRO. In diamond inheritance, it ensures a class is visited only after its children. 
In the example: `D` inherits from `B` then `C`. `B` inherits from `A`. The order is `D -> B -> C -> A`. Since `C` overrides `who()`, `D().who()` prints `"C"`.

**P8**: A metaclass is a "class of a class" that defines how classes are constructed. 
- `__init_subclass__`: Simpler way to customize class creation in subclasses (e.g., registering a plugin).
- Metaclass: Used for deeper modification (e.g., enforcing API constraints across all subclasses).

**P9**: 
- `threading`: Shared memory, GIL-limited; best for I/O.
- `multiprocessing`: Separate memory, bypasses GIL; best for CPU-bound.
- `concurrent.futures`: High-level wrapper for both via `ThreadPoolExecutor` and `ProcessPoolExecutor`.
Multiprocessing requires **pickling** (serialization) to send data between processes, which can be slow or fail for complex objects.

**P10**: `__slots__` tells Python not to use a dynamic `__dict__` for instance attributes. Use it for classes with millions of instances to significantly reduce memory usage and slightly increase attribute access speed. It prevents the creation of arbitrary new attributes at runtime.

**P11**: A virtual environment is an isolated Python installation. Use it to avoid dependency conflicts between projects. 
- `venv`: Standard library, lightweight.
- `virtualenv`: Older, more features.
- `conda`: Manages non-Python dependencies (C libraries, etc.) and environments.

**P12**: Comprehensions provide a concise way to create collections. 
- `[x for x in list if cond]` is equivalent to `filter` + `map`.
Prefer comprehensions for readability; use `map`/`filter` when working with existing functions or very large lazy iterators.

**P13**: `==` checks for equality (value); `is` checks for identity (memory address). **Object interning** caches small integers (usually -5 to 256) and certain strings, so `a is b` returns `True` for these because they point to the same pre-allocated object.

**P14**: `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. 
- `/`: Arguments before it must be positional-only.
- `*`: Arguments after it must be keyword-only.

**P15**: Context managers handle setup/teardown. 
- `__enter__`/`__exit__`: Class-based approach.
- `@contextmanager`: Generator-based approach using `yield`.
Example: A database transaction manager that commits on success and rolls back on exception.

**P16**: Type hinting provides static metadata. 
- `Union[int, str]`: Either type.
- `Optional[int]`: `Union[int, None]`.
- `Literal["R", "G", "B"]`: Exactly one of these values.
- `TypeVar`: Generic type.
- `Protocol`: Structural typing (static duck typing).
`mypy`/`pyright` analyze these to find bugs without running the code.

**P17**: Dunder methods define object behavior. 
- `__repr__` (for developers/debugging) vs `__str__` (for users).
- `__eq__` (equality) vs `__hash__` (for set/dict keys).
- `__getattr__` (called if attribute not found) vs `__getattribute__` (called for every access).
If you define `__eq__` but not `__hash__`, the class becomes unhashable (cannot be a dict key).

**P18**: Descriptors are objects that define `__get__`, `__set__`, or `__delete__`. They allow custom logic when accessing an attribute. `property` is a descriptor that manages getters/setters; `classmethod` and `staticmethod` are descriptors that modify how the function is bound to the class/instance.

**P19**: Python searches `sys.path` for modules. 
- **Absolute**: `import pkg.mod`. **Relative**: `from . import mod`.
- `__init__.py`: Marks a directory as a package (optional in Python 3.3+ for namespace packages).
- **Finder**: Locates the module. **Loader**: Loads the module into memory.

**P20**: `dataclasses` automate `__init__`, `__repr__`, and `__eq__`. 
- `__post_init__`: Logic after initialization.
- `field(default_factory=list)`: Prevents mutable default argument bugs.
- `frozen=True`: Makes the instance immutable.
**Pydantic** is preferred over `dataclasses` when runtime data validation and coercion (e.g., parsing JSON strings to ints) are required.
