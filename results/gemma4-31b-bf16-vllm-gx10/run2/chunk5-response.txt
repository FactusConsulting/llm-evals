## .NET / C#

**DN1**: `class` is a reference type (stored on heap); `struct` is a value type (usually stored on stack). Use a `struct` for small, immutable data structures (typically < 16 bytes) that represent a single value (e.g., `Point`, `ComplexNumber`) to reduce GC pressure.

**DN2**: `IEnumerable<T>` is for in-memory collections; it performs filtering/sorting on the client side (LINQ to Objects). `IQueryable<T>` is for remote data sources; it translates expressions into a provider-specific language (e.g., SQL) to execute filtering on the database server. Using `IEnumerable` for DB queries can lead to "over-fetching" (loading the whole table into RAM).

**DN3**: `async/await` allows non-blocking asynchronous operations by suspending the method execution until the awaited task completes, freeing the thread to do other work. `Task` is a class (heap allocated); `ValueTask` is a struct. Use `ValueTask` when the result is often available synchronously (e.g., reading from a cache) to avoid unnecessary heap allocations.

**DN4**: DI is a pattern where dependencies are provided to a class rather than created internally. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (web request).
- **Singleton**: One instance for the lifetime of the app.
**Bug**: Injecting a Scoped service into a Singleton (Captive Dependency). The Scoped service is effectively promoted to a Singleton, which can cause memory leaks or `DbContext` concurrency crashes.

**DN5**: `string` is an immutable heap object. `ReadOnlySpan<char>` is a stack-allocated view into a contiguous region of memory. Use `Span<T>`/`ReadOnlySpan<T>` for high-performance slicing and parsing to avoid creating multiple substring copies on the heap.

**DN6**: The GC uses a generational approach to optimize collection: **Gen 0** (short-lived), **Gen 1** (buffer), **Gen 2** (long-lived). The **LOH (Large Object Heap)** stores objects > 85,000 bytes to avoid expensive memory compaction. `IDisposable` is needed for **unmanaged resources** (file handles, DB connections) because the GC only manages memory, not external OS handles.

**DN7**: `ConfigureAwait(false)` tells the runtime not to marshal the continuation back to the original `SynchronizationContext` (e.g., the UI thread). Use it in library code to improve performance and avoid deadlocks. Do NOT use it in application code where you need to access UI elements or `HttpContext.Current`.

**DN8**: 
- **Primary Constructors**: Define parameters directly in the class declaration.
- **Collection Expressions**: `int[] x = [1, 2, 3];`
- **FrozenDictionary**: Immutable, highly optimized for read-heavy scenarios.
Example:
```csharp
public class OrderService(IDbContext db) { // Primary Constructor
    public void Save() => db.SaveChanges();
}
```

**DN9**: **Cause**: The `DbContext` is not thread-safe. High concurrency likely means a single `DbContext` instance is being shared across multiple threads (e.g., `Task.WhenAll` calling async methods that use the same scoped context). 
**Fix**: Ensure each concurrent operation has its own scope via `IServiceScopeFactory` or avoid parallelizing calls on a single context.

**DN10**: `record` is a class with built-in value-based equality. `record struct` is a value-type with value-based equality. Use `record` for DTOs/immutable data; `class` for behavior-heavy objects; `record struct` for small, high-performance value objects.

**DN11**: 
- `ref`: Variable must be initialized; passed by reference (read/write).
- `out`: Variable doesn't need initialization; must be assigned inside the method (write).
- `in`: Passed by reference but read-only (performance for large structs).

**DN12**: Nullable Reference Types (`string?`) are a **compile-time** static analysis feature to prevent `NullReferenceException`. They do not change the runtime behavior. Nullable Value Types (`int?`) are a **runtime** wrapper (`Nullable<T>`) that allows value types to represent null.

**DN13**: LINQ (Language Integrated Query) provides a consistent way to query data. **Method syntax** uses extension methods (`.Where()`); **Query syntax** looks like SQL (`from x in...`). **Deferred execution** means the query is not executed when defined, but when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14**: Constraints restrict the types that can be used as generic arguments:
- `class`: Reference type.
- `struct`: Value type.
- `new()`: Must have a public parameterless constructor.
- `IComparable<T>`: Must implement the interface.
Combine them (e.g., `where T : class, new()`) when you need an object that is both a reference type and can be instantiated.

**DN15**: `abstract class` can have state (fields) and partial implementation; `interface` defines a contract. **Default Interface Methods** allow interfaces to provide a default implementation, blurring the line by allowing interfaces to evolve without breaking existing implementations.

**DN16**: Middleware is a sequence of delegates that handle requests/responses. 
- `Use()`: Can call the next middleware in the chain.
- `Map()`: Branches the pipeline based on the URL path.
- `Run()`: Terminal middleware (stops the chain).
**Ordering**: Exception handling middleware must be placed first to catch errors from all subsequent middleware.

**DN17**: `Channel<T>` is a high-performance async producer-consumer queue. Unlike `BlockingCollection<T>`, it is fully `async` (non-blocking). 
**Backpressure**: Use a `BoundedChannel`. When the channel is full, the producer's `WriteAsync` will asynchronously wait until space is available.

**DN18**: Source Generators inspect code during compilation and generate additional C# source files. Unlike reflection (runtime) or IL weaving (post-compile), they are type-safe and visible to the IDE. **Incremental Generators** are preferred because they cache results and only re-run on changed parts of the syntax tree, preventing IDE lag.

**DN19**: TPL Dataflow provides blocks for processing pipelines. 
- `ActionBlock`: Consumes data and performs an action.
- `TransformBlock`: Consumes data, transforms it, and outputs it.
- `BufferBlock`: Simple FIFO queue.
Compared to `Channels`, Dataflow is higher-level, providing built-in orchestration and linking of blocks.

**DN20**: Minimal APIs remove the `Controller` boilerplate for small services. 
- **Trade-offs**: Faster startup and less code, but can become messy if not organized. 
- **Route Groups**: `app.MapGroup("/api")` allows shared middleware/auth for a set of endpoints. 
- **Endpoint Filters**: Allow running logic before/after the handler (similar to Action Filters).

## Python

**P1**: `list` is mutable; `tuple` is immutable. `set` is a mutable collection of unique elements; `frozenset` is an immutable version of a set (and thus hashable).

**P2**: The GIL is a mutex that allows only one thread to execute Python bytecode at a time. It affects **CPU-bound** workloads. Workarounds: Use `multiprocessing` (separate GILs per process) or C-extensions (e.g., NumPy) that release the GIL.

**P3**: `copy` (shallow) creates a new object but inserts references to the items in the original. `deepcopy` recursively copies everything. 
**Example**: A list of lists `[[1]]`. A shallow copy of the outer list still shares the inner list. Modifying `copy[0][0] = 2` will change the original list.

**P4**: Decorators are functions that wrap other functions to modify their behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time()-start}s")
        return res
    return wrapper
```

**P5**: Generators use `yield` to produce values one at a time (lazy evaluation), saving memory compared to returning a full list. `yield from` is used to delegate to another generator or iterable.

**P6**: The event loop manages asynchronous tasks. 
- `asyncio.run()`: Entry point; creates loop and runs the main coroutine.
- `asyncio.gather()`: Runs multiple coroutines concurrently and waits for all to finish.
- `asyncio.create_task()`: Schedules a coroutine to run in the background.
`time.sleep()` is blocking; it stops the entire thread, preventing the event loop from switching to other tasks. Use `await asyncio.sleep()`.

**P7**: Python uses **C3 Linearization** for MRO. It ensures a consistent order and avoids visiting the same class twice. In the diamond example, `D` inherits from `B` then `C`. Since `B` doesn't implement `who`, it looks at `C` before going back to `A`. 
**Result**: Prints `"C"`.

**P8**: A metaclass is a "class of a class" that defines how classes are constructed. 
- `__init_subclass__`: Simpler way to customize class creation in subclasses (e.g., registering a plugin).
- `metaclass`: Used for deeper modification (e.g., modifying attributes of the class object itself during creation).

**P9**: 
- `threading`: Shared memory, GIL limited. Use for I/O-bound tasks.
- `multiprocessing`: Separate memory, bypasses GIL. Use for CPU-bound tasks.
- `concurrent.futures`: High-level API for both (ThreadPoolExecutor/ProcessPoolExecutor).
**Pickling**: `multiprocessing` requires data to be serialized (pickled) to be sent between processes, which can be slow or fail for complex objects (like lambdas).

**P10**: `__slots__` tells Python not to use a `__dict__` for instances, instead allocating a fixed amount of space for specified attributes. Use it for classes with millions of instances to significantly reduce memory usage and slightly increase attribute access speed.

**P11**: A virtual environment is an isolated Python installation. It prevents dependency conflicts between projects. 
- `venv`: Built-in, lightweight.
- `virtualenv`: Older, more features.
- `conda`: Manages non-Python dependencies (C libraries, etc.) and environments.

**P12**: Comprehensions provide a concise way to create collections. 
- `[x for x in list if cond]` is equivalent to `filter` + `map`.
Prefer comprehensions for readability; use `map`/`filter` only if you already have the functions defined or are working with very large lazy iterators.

**P13**: `==` checks for **equality** (value); `is` checks for **identity** (memory address). Python interns small integers (usually -5 to 256) and certain strings to save memory, which is why `a is b` can be True for small ints.

**P14**: `*args` collects extra positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. 
- `/`: Arguments before it must be positional-only.
- `*`: Arguments after it must be keyword-only.

**P15**: Context managers handle setup/teardown. 
- `__enter__/__exit__`: Class-based approach.
- `@contextmanager`: Generator-based approach using `yield`.
**Example**: A database transaction manager that commits on success and rolls back on exception.

**P16**: Type hinting provides static metadata. 
- `Union[int, str]`: Either type.
- `Optional[int]`: `int` or `None`.
- `Literal["R", "G", "B"]`: Exactly one of these values.
- `TypeVar`: Generic type.
- `Protocol`: Structural typing (static duck typing).
`mypy`/`pyright` analyze these hints without running the code to find type errors.

**P17**: Dunder methods define object behavior. 
- `__repr__` (for developers/debugging) vs `__str__` (for users).
- `__eq__` (equality) vs `__hash__` (for set/dict keys).
- `__getattr__` (called if attribute not found) vs `__getattribute__` (called for every access).
If you define `__eq__` but not `__hash__`, the class becomes unhashable (cannot be a dict key).

**P18**: Descriptors are objects that define `__get__`, `__set__`, or `__delete__`. They allow custom logic when accessing an attribute. `property` is a descriptor that manages getters/setters; `classmethod` and `staticmethod` are descriptors that modify how the function is bound to the class/instance.

**P19**: 
- **Absolute**: `import package.module`.
- **Relative**: `from . import module`.
- `sys.path`: List of directories Python searches for modules.
- `__init__.py`: Marks a directory as a package (optional in Python 3.3+ for namespace packages).
- **Finder**: Locates the module. **Loader**: Loads the module into memory.

**P20**: `dataclasses` automate `__init__`, `__repr__`, and `__eq__`. 
- `__post_init__`: Logic to run after the generated `__init__`.
- `field(default_factory=list)`: Prevents mutable default argument bugs.
- `frozen=True`: Makes the instance immutable.
**Pydantic** is preferred over `dataclasses` when **runtime data validation** and coercion (e.g., parsing JSON strings into ints) are required.
