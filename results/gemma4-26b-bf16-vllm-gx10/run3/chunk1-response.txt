## Networking

**N1** — A Layer 2 switch forwards frames based on MAC addresses within a single broadcast domain. A Layer 3 switch can perform inter-VLAN routing by forwarding packets based on IP addresses, acting like a router but with hardware-accelerated (ASIC) switching.

**N2** — Mask /20 is `255.255.240.0`. 
Network Address: `10.0.0.0` (Wait, calculation: 10.0.5.37. The subnet mask /20 means the first 20 bits are fixed. 5 in binary is `0101`. The mask covers the 4th bit of the 3rd octet. `0101` & `1111 0000` = `0000`. So, `10.0.0.0`). 
*Correction:* 10.0.5.37/20: The 3rd octet is 5. The mask is 255.255.240.0. $5 \text{ AND } 240 = 0$. 
Network: `10.0.0.0`. 
Broadcast: `10.0.15.255`.

**N3** — 1. Client sends `SYN`. 2. Server responds `SYN-ACK`. 3. Client sends `ACK`. If the final `ACK` is lost, the server will eventually time out and retransmit the `SYN-ACK`. Once the client receives the retransmitted `SYN-ACK`, it will re-send the `ACK`.

**N4** — **SNAT (Source NAT):** Changes the source IP of a packet. *Example:* A private host accessing the internet via a router's public IP. 
**DNAT (Destination NAT):** Changes the destination IP of a packet. *Example:* Port forwarding where an external request to a router is redirected to an internal web server.

**N5** — 1. The certificate was issued for a different domain (e.g., `wrong.com` instead of `example.com`). 2. A Man-in-the-Middle (MitM) attack is intercepting traffic. 3. The client is accessing the server via an IP address instead of the hostname.

**N6** — **VLAN (802.1Q):** A Layer 2 technology to partition a physical switch into multiple logical broadcast domains. **VxLAN:** A Layer 3 encapsulation protocol that tunnels Layer 2 frames over Layer 3 UDP packets. Choose VxLAN when you need to scale beyond 4096 VLANs or need to stretch Layer 2 networks across Layer 3 boundaries (common in data centers/SDN).

**N7** — **Why:** The system uses the default gateway (eth0) for all non-local traffic. When a packet arrives on eth1, the reply is sent to the default gateway on eth0 because the destination is not in the eth1 subnet. 
**Fix:** Use Policy-Based Routing (PBR). Create a new routing table for eth1, add a route to that table via 192.168.1.1, and use `ip rule add from 192.168.1.5 table <table_id>` to force traffic from eth1 to use that table.

**N8** — BGP selects the best path using a specific hierarchy. 
Order: 1. Weight (Cisco proprietary), 2. Local Preference, 3. Locally originated (Next Hop 0.0.0.0), 4. AS_Path length, 5. Origin type (IGP < EGP < Incomplete), 6. MED (Multi-Exit Discriminator).

**N9** — Encapsulation adds overhead, reducing the effective payload. 
**Math:** 
Physical MTU: 1500 bytes. 
IPsec overhead (approx): ~50-70 bytes. 
VxLAN overhead: 50 bytes (Outer IP + UDP + VxLAN header). 
Total overhead $\approx 120$ bytes. 
Max inner payload $\approx 1500 - 120 = 1380$ bytes.

**N10** — **ARP (Address Resolution Protocol):** Maps an IP address to a MAC address. **Gratuitous ARP:** An unrequested ARP response sent by a host to update neighbors' ARP tables. It solves problems like IP conflict detection and updating tables during a Failover/HA event (e.g., VIP move).

**N11** — Public IPs are routable on the internet; Private IPs are for local networks only. 
**RFC 1918 Ranges:** 
1. `10.0.0.0/8` 
2. `172.16.0.0/12` 
3. `192.168.0.0/16`

**N12** — **DNS:** Domain Name System (resolves names to IPs). 
**A record:** Maps hostname to IPv4. 
**AAAA record:** Maps hostname to IPv6. 
**CNAME:** An alias that maps one hostname to another hostname.

**N13** — **DHCP:** Dynamic Host Configuration Protocol. 
**DORA:** 1. **D**iscover (Client broadcasts to find server), 2. **O**ffer (Server offers IP), 3. **R**equest (Client requests offered IP), 4. **A**cknowledge (Server confirms).

**N14** — **Hub:** Layer 1 (Physical); broadcasts all traffic to all ports. 
**Switch:** Layer 2 (Data Link); forwards based on MAC addresses. 
**Router:** Layer 3 (Network); forwards based on IP addresses.

**N15** — **Half-duplex:** Data can move in both directions, but only one way at a time. 
**Full-duplex:** Data can move in both directions simultaneously. 
Modern Ethernet uses **Full-duplex**.

**N16** — **TTL (Time to Live):** A counter in the IP header that prevents infinite loops; each router decrements it by 1. **Traceroute:** Sends packets with increasing TTL values (1, 2, 3...). When TTL reaches 0, the router drops the packet and sends an ICMP "Time Exceeded" message, revealing its identity.

**N17** — A NAT gateway allows private hosts to access the internet. 
**Static NAT:** 1-to-1 mapping of a private IP to a public IP. 
**Dynamic NAT:** A pool of public IPs assigned to private IPs on a first-come, first-served basis. 
**PAT (Port Address Translation):** Many private IPs mapped to a single public IP using unique source ports.

**N18** — **ECMP:** Distributes traffic across multiple paths with the same routing metric. 
**Hashing:** Usually based on the "5-tuple" (Src IP, Dst IP, Src Port, Dst Port, Protocol). 
**Problem:** Stateful firewalls track connections. If ECMP hashes different packets of the same flow to different paths, the second path's firewall will drop the packet because it has no state for that connection.

**N19** — **Problem:** The TCP window size is too small to keep the "pipe" full. The sender stops to wait for ACKs before the full BDP is utilized. 
**Solution:** TCP Window Scaling (RFC 1323) adds a scale factor to the window size field in the TCP header, allowing the window to grow beyond the 64KB limit (up to ~1GB).

**N20** — **802.1Q:** Adds a 4-byte tag to the Ethernet frame containing the VLAN ID. 
**Linux Config:** Create sub-interfaces: `eth0.10`, `eth0.20`, `eth0.30`. 
**Frame format:** [Dest MAC][Src MAC][**802.1Q Tag (VLAN ID)**][Type/Length][Payload][FCS].

## Linux

**L1** — A **Hard link** is a direct pointer to the inode of a file (sharing the same inode); deleting the original doesn't delete the data. A **Symbolic link** (symlink) is a special file that contains a path string to another file; if the original is deleted, the link breaks.

**L2** — `find /var/log -type f -size +100M`

**L3** — **D state** means the process is waiting for I/O (usually disk or network) and cannot be interrupted by signals. You **cannot** kill it with `kill -9` because the process is not currently processing signals; it will only die once the kernel-level I/O operation completes or fails.

**L4** — **v1** uses a hierarchical tree of separate controllers (cpu, mem, etc.). **v2** uses a unified hierarchy where all controllers are managed under a single tree, allowing better resource grouping. **systemd** prefers **v2** because it provides a more consistent and efficient way to manage resource distribution across the entire system.

**L5** — **nftables** is the successor to **iptables**, offering a more efficient virtual machine-based execution and a cleaner syntax. The kernel handles both via the `nf_tables` subsystem, which can act as a backend for `iptables` commands (via `iptables-nft`).

**L6** — Deleted files that are still being held open by a running process. The space is not reclaimed until the process closes the file or terminates. Use `lsof +L1` to find them.

**L7** — 1. **UEFI/BIOS** initializes hardware. 2. **Bootloader** (GRUB) is loaded from EFI partition. 3. **Kernel** is loaded into memory. 4. **initramfs** is mounted to provide temporary drivers needed to mount the real root. 5. **Root FS** is mounted. 6. **systemd** (PID 1) starts and reaches the target (e.g., multi-user.target).

**L8** — `available` memory is an estimate of how much memory can be allocated without swapping. Even with high `buff/cache`, if the kernel determines that the cache is "dirty" or cannot be reclaimed quickly enough to satisfy immediate demands, `available` drops. 
**Tunables:** `vm.swappiness` (how aggressively to swap) and `vm.vfs_cache_pressure` (how aggressively to reclaim dentries/inodes).

**L9** — `ip netns` creates **Network Namespaces**, which provide isolated network stacks (interfaces, routing tables, firewall rules). Container runtimes (like Docker) use them to ensure each container has its own private network environment.

**L10** — **SIGTERM (15):** Request to terminate; can be caught/handled for graceful shutdown. 
**SIGQUIT (3):** Request to terminate and produce a core dump; can be caught. 
**SIGKILL (9):** Immediate termination by the kernel; **cannot** be caught or ignored.

**L11** — **stdout:** Standard output (1). **stderr:** Standard error (2). **stdin:** Standard input (0). 
**Redirect stderr to file, keep stdout on terminal:** `command 2> error.log`

**L12** — `chmod 755`: 
7 (Owner): Read (4) + Write (2) + Execute (1) = 7. 
5 (Group): Read (4) + Execute (1) = 5. 
5 (Others): Read (4) + Execute (1) = 5.

**L13** — The **root** user is the superuser with absolute control over the system. A user with **sudo** privileges is a regular user who has been granted permission to execute specific commands (or all commands) with root privileges via the `/etc/sudoers` file.

**L14** — A tool to install, update, and remove software. 
**Debian/Ubuntu:** `apt`. 
**RHEL/Fedora:** `dnf` (or `yum`).

**L15** — `/etc/fstab` defines how disk partitions and filesystems are mounted. If misconfigured, the system may fail to boot (dropping to emergency mode) or fail to mount critical drives.

**L16** — **LVM** abstracts physical storage into logical volumes. 
**PV (Physical Volume):** Raw disk/partition. 
**VG (Volume Group):** Pool of PVs. 
**LV (Logical Volume):** Partition-like entity carved from a VG. 
**Extend LV:** `lvextend -L +1G /dev/vg/lv && resize2fs /dev/vg/lv` (for ext4).

**L17** — **mq-deadline:** Prioritizes reads over writes to reduce latency. 
**bfq:** Budget Fair Queuing; focuses on interactive responsiveness and fairness. 
**none:** No scheduling (best for high-speed NVMe). 
**Change at runtime:** `echo mq-deadline > /sys/block/sdX/queue/scheduler`.

**L18** — **Load Average** measures the number of processes in a "runnable" or "uninterruptible" state. High load with low CPU means processes are stuck in **I/O wait** (uninterruptible sleep). 
**Diagnosis:** Use `top`/`htop` (look at `%wa`), `iostat` (check disk utilization), or `iotop` (find specific processes causing I/O).

**L19** — **SELinux** uses labels (contexts) on files/processes to enforce access rules. 
**Modes:** **Enforcing** (blocks), **Permissive** (logs but doesn't block), **Disabled** (off). 
**Troubleshoot:** Use `sealert` or check `/var/log/audit/audit.log`. To allow a non-standard port, use `semanage port -a -t <type> -p tcp <port>`.

**L20** — **Page Fault:** Occurs when a process accesses a memory page not currently in the MMU. 
**Minor:** Page is in memory but not mapped to the process. 
**Major:** Page must be fetched from disk (slow). 
**THP:** Automatically uses larger memory pages (e.g., 2MB instead of 4KB) to reduce TLB misses. **Disable it** if the application (like certain databases) manages its own memory or if THP causes "stalls" due to memory compaction overhead.
