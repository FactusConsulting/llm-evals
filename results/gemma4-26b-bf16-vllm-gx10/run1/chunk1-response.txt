## Networking

**N1** — A Layer 2 switch forwards frames based on MAC addresses within a single broadcast domain. A Layer 3 switch can perform inter-VLAN routing by forwarding packets based on IP addresses, acting like a router but with hardware-accelerated (ASIC) switching.

**N2** — Mask /20 is `255.255.240.0`.
Network Address: `10.0.0.0`
Broadcast Address: `10.0.15.255`

**N3** — 1. Client sends `SYN`. 2. Server responds `SYN-ACK`. 3. Client sends `ACK`. If the final `ACK` is lost, the server will eventually time out and retransmit the `SYN-ACK`. Once the client receives the retransmitted `SYN-ACK`, it will re-send the `ACK`.

**N4** — **SNAT (Source NAT):** Changes the source IP of a packet. *Example:* A private host accessing the internet via a NAT Gateway. **DNAT (Destination NAT):** Changes the destination IP of a packet. *Example:* A router forwarding traffic from a public IP to a specific internal web server.

**N5** — 1. The certificate was issued for a different domain (e.g., `wrong.com` instead of `example.com`). 2. The server is serving a self-signed certificate. 3. A Man-in-the-Middle (MitM) attack is intercepting the traffic.

**N6** — **VLAN:** A Layer 2 technology to partition a physical switch into multiple logical broadcast domains. **VxLAN:** A Layer 2 over Layer 3 encapsulation protocol (MAC-in-UDP). Choose VxLAN when you need to scale beyond 4096 VLANs or need to extend Layer 2 networks across Layer 3 boundaries (common in data centers/SDNs).

**N7** — **Why:** The system uses the default gateway (eth0) for all non-local traffic. Traffic from 192.168.1.0/24 arrives on eth1, but the reply is sent via the default route on eth0.
**Fix:** Use Policy-Based Routing (PBR). Create a new routing table, add a route to that table via eth1, and add an `ip rule` to direct traffic from 192.168.1.5 to use that specific table.

**N8** — BGP selects the best path using a specific hierarchy. Top 5 attributes: 1. Weight (Cisco proprietary), 2. Local Preference, 3. Locally originated (Next Hop 0.0.0.0), 4. AS Path Length, 5. Origin Type (IGP < EGP < Incomplete).

**N9** — Encapsulation adds overhead, reducing the available payload.
**Math:**
Physical MTU: 1500
IPsec Overhead (approx): ~50-70 bytes (varies by cipher/mode)
VxLAN Overhead: 50 bytes (Outer IP: 20, UDP: 8, VxLAN: 8, Outer Ethernet: 14)
Total Overhead: ~100-120 bytes.
Max Inner Payload $\approx 1500 - 120 = 1380$ bytes.

**N10** — **ARP (Address Resolution Protocol):** Maps an IP address to a MAC address. **Gratuitous ARP:** An unrequested ARP broadcast. It solves the problem of IP conflict detection and updates neighbor ARP caches when a NIC changes its MAC or an IP moves to a new interface (e.g., Failover/HA).

**N11** — Public IPs are routable on the internet; Private IPs are for local networks only.
**RFC 1918 Ranges:**
1. `10.0.0.0/8`
2. `172.16.0.0/12`
3. `192.168.0.0/16`

**N12** — **DNS:** Domain Name System (resolves names to IPs).
**A:** Maps hostname to IPv4.
**AAAA:** Maps hostname to IPv6.
**CNAME:** An alias that maps one hostname to another hostname.

**N13** — **DHCP:** Dynamic Host Configuration Protocol.
**DORA:** 1. **D**iscover (Client searches for server), 2. **O**ffer (Server offers IP), 3. **R**equest (Client requests offered IP), 4. **A**cknowledge (Server confirms).

**N14** — **Hub:** Layer 1 (Physical); broadcasts all traffic to all ports. **Switch:** Layer 2 (Data Link); forwards based on MAC. **Router:** Layer 3 (Network); forwards based on IP.

**N15** — **Half-duplex:** Only one party can transmit at a time (like a walkie-talkie). **Full-duplex:** Both parties can transmit and receive simultaneously. Modern Ethernet uses **Full-duplex**.

**N16** — **TTL (Time to Live):** Prevents packets from looping infinitely by decrementing at every hop. **Traceroute:** Sends packets with increasing TTL values (1, 2, 3...). Each router decrements TTL; when it hits 0, the router drops the packet and sends an ICMP "Time Exceeded" message, revealing its identity.

**N17** — A NAT gateway allows private hosts to access the internet.
**Static NAT:** 1-to-1 mapping of private IP to public IP.
**Dynamic NAT:** Mapping a private IP to a public IP from a pool.
**PAT (Port Address Translation):** Many private IPs mapped to a single public IP using unique source ports.

**N18** — **ECMP:** Distributes traffic across multiple paths with the same routing metric. **Hashing:** Usually based on the 5-tuple (Src IP, Dst IP, Src Port, Dst Port, Protocol). **Problem:** Stateful firewalls track connections; if ECMP hashes different packets of the same flow to different paths, the firewall on the second path will drop the packet because it has no state for that connection.

**N19** — **Problem:** The TCP window is too small to keep the "pipe" full. The sender stops to wait for ACKs before the full BDP is utilized.
**Solution:** TCP Window Scaling (RFC 1323) adds a scale factor to the window size field in the TCP header, allowing the window to grow beyond the 64KB limit (up to ~1GB).

**N20** — **802.1Q:** Adds a 4-byte tag to the Ethernet frame containing the VLAN ID.
**Linux Config:** Create sub-interfaces: `eth0.10`, `eth0.20`, `eth0.30`.
**Frame Format:** [Dest MAC][Src MAC][**802.1Q Tag (VLAN ID)**][Type/Length][Payload][FCS].

## Linux

**L1** — A **Hard Link** is a direct pointer to the inode (same file, different name); deleting the original doesn't delete the data. A **Symbolic Link** (symlink) is a special file containing a path to another file; if the original is deleted, the link breaks.

**L2** — `find /var/log -type f -size +100M`

**L3** — **D (Uninterruptible Sleep):** The process is waiting for I/O (usually disk or network) and cannot be interrupted by signals. **No**, `kill -9` will not work until the kernel receives the I/O response and moves the process to a killable state.

**L4** — **v1:** Uses a hierarchy of separate trees for different controllers (cpu, mem, etc.). **v2:** Uses a single unified hierarchy. **systemd** prefers **v2** because it provides a more consistent and efficient way to manage resource distribution across the entire system.

**L5** — **nftables** is the successor to **iptables**, offering a more efficient virtual machine-based execution and better syntax. The kernel handles both via the `nf_tables` subsystem, which can translate `iptables` commands into `nftables` rules.

**L6** — Deleted files that are still being held open by a running process. Use `lsof +L1` to find them.

**L7** — 1. **UEFI/BIOS** initializes hardware. 2. **Bootloader** (GRUB) is loaded. 3. **Kernel** is loaded into memory. 4. **initramfs** is mounted to provide temporary drivers/filesystems. 5. **Root filesystem** is mounted. 6. **systemd** (PID 1) starts and brings the system to the target state.

**L8** — `available` memory is not just `free` memory; it is `free` + `buff/cache` that can be *immediately* reclaimed. If the kernel cannot reclaim cache quickly enough (due to heavy I/O or dirty pages) or if the application's working set is larger than physical RAM, `available` drops. **Tunables:** `vm.swappiness`, `vm.vfs_cache_pressure`.

**L9** — `ip netns` creates **Network Namespaces**, which provide isolated network stacks (interfaces, routing tables, etc.). Container runtimes (like Docker) use them to ensure each container has its own private network environment.

**L10** — **SIGTERM (15):** Request to terminate; can be caught/handled. **SIGKILL (9):** Immediate termination by kernel; cannot be caught. **SIGQUIT (3):** Request to terminate and produce a core dump; can be caught.

**L11** — **stdout:** Standard output; **stderr:** Standard error; **stdin:** Standard input.
**Redirect:** `command > output.txt 2> error.txt` (to file) or `command 2>&1` (to stdout). To see stdout on terminal but redirect stderr: `command 2> error.log`.

**L12** — `755`: **7** (Owner: Read/Write/Execute), **5** (Group: Read/Execute), **5** (Others: Read/Execute).

**L13** — **Root** is the superuser with unrestricted access to everything. A **sudo** user is a regular user granted specific permissions to execute commands with root privileges via the `/etc/sudoers` file.

**L14** — A tool to install, update, and remove software.
**Debian/Ubuntu:** `apt`. **RHEL/Fedora:** `dnf` (or `yum`).

**L15** — Defines how disk partitions/filesystems are mounted at boot. If misconfigured, the system may fail to boot (dropping to emergency mode).

**L16** — **LVM** abstracts physical storage. **PV (Physical Volume):** Raw disk/partition. **VG (Volume Group):** Pool of PVs. **LV (Logical Volume):** Partition-like volume carved from a VG.
**Extend:** `lvextend -L +1G /dev/vg/lv` followed by `resize2fs` (ext4) or `xfs_growfs` (xfs).

**L17** — **mq-deadline:** Prioritizes reads over writes to reduce latency. **bfq:** Fair queuing for interactive desktop use. **none:** No scheduling (best for high-speed NVMe).
**Change:** `echo mq-deadline > /sys/block/<device>/queue/scheduler`.

**L18** — **Load Average** measures the number of processes in a runnable or uninterruptible state. High load with low CPU suggests **I/O Wait** (processes stuck waiting for disk/network).
**Diagnosis:** `top`/`htop` (check `%wa`), `iostat` (disk throughput/latency), `iotop` (which process is using disk), `nload`/`iftop` (network).

**L19** — **SELinux:** Uses labels (contexts) on files/processes to enforce access.
**Modes:** **Enforcing** (blocks), **Permissive** (logs but doesn't block), **Disabled** (off).
**Troubleshoot:** Use `sealert` or check `/var/log/audit/audit.log`. To fix a port issue, use `semanage port -a -t <type> -p tcp <port>`.

**L20** — **Page Fault:** Occurs when a process accesses a memory page not currently in the MMU. **Minor:** Page is in RAM but not mapped to the process. **Major:** Page must be fetched from disk (swap/file).
**THP:** Automatically groups pages into 2MB chunks to reduce TLB misses. **Disable if:** It causes latency spikes or "jitter" in memory-intensive databases (e.g., Redis/MongoDB).
