## .NET / C#

**DN1** — A **class** is a reference type (stored on the heap), while a **struct** is a value type (usually stored on the stack). Use a **struct** for small, immutable data structures that behave like values (e.g., a Point, Color, or complex number) where the overhead of heap allocation and GC tracking outweighs the benefits of reference semantics.

**DN2** — `IEnumerable<T>` is for in-memory iteration; it executes the query immediately or via deferred execution on the collection. `IQueryable<T>` is for out-of-memory queries (like SQL); it translates LINQ expressions into provider-specific commands (SQL). This matters because `IEnumerable` pulls all data into memory before filtering, while `IQueryable` filters at the database level.

**DN3** — `async/await` uses a state machine to suspend execution without blocking the thread. A `Task` represents an operation that returns a result (allocates an object on the heap). `ValueTask` is a struct that can represent a result without an allocation if the operation completes synchronously. Use `ValueTask` in high-performance paths where the result is often already available (e.g., reading from a buffer).

**DN4** — DI is a design pattern where objects receive their dependencies from an external source.
- **Transient**: New instance every time requested.
- **Scoped**: New instance per request (e.g., per HTTP request).
- **Singleton**: One instance for the app lifetime.
**Bug**: Injecting a Scoped service into a Singleton causes the Scoped service to be "captured" by the Singleton, living as long as the Singleton and potentially causing thread-safety issues or stale data (e.g., a DbContext being shared across multiple concurrent requests).

**DN5** — `string` is immutable; every modification creates a new string. `ReadOnlySpan<char>` is a view into a contiguous region of memory (stack, heap, or unmanaged). Use `Span<T>` for high-performance parsing (e.g., `String.Split` alternatives) to avoid unnecessary allocations by slicing the existing string instead of copying it.

**DN6** — The GC manages memory by identifying unreachable objects. **Gen 0** (short-lived objects), **Gen 1** (buffer), **Gen 2** (long-lived). The **Large Object Heap (LOH)** is for objects >85k bytes (collected less frequently). `IDisposable` is needed because the GC only manages *memory*; it doesn't know how to close file handles, database connections, or network sockets.

**DN7** — `ConfigureAwait(false)` tells the task not to resume on the original `SynchronizationContext` (e.g., UI thread or ASP.NET request context). Use it in library code to improve performance and avoid deadlocks. Do **not** use it in UI code where you need to update UI elements directly.

**DN8** — **Primary Constructors**: Define parameters in the class header. **Collection Expressions**: `int[] arr = [1, 2, 3];`. **FrozenDictionary**: An immutable, highly optimized dictionary for read-heavy lookups.
*Example:*
```csharp
public class UserService(IDbContext db) : IUserService {
    public async Task GetData() => await db.QueryAsync();
}
```

**DN9** — **Cause**: A `DbContext` is being shared across multiple threads (likely injected as a Singleton or captured by a long-running Task). **Fix**: Ensure `DbContext` is Scoped. Use `IServiceScopeFactory` to create a manual scope inside a background task or `Task.Run` to ensure each thread gets its own instance.

**DN10** — **Record**: A reference type with built-in value-based equality and non-destructive mutation (`with` expression). **Class**: Standard reference type. **Record struct**: A value type with record features. Choose **Record** for DTOs/Data models; **Class** for complex logic/entities; **Record struct** for small, immutable value types.

**DN11** — `ref`: Pass by reference, must be initialized before passing. `out`: Pass by reference, must be assigned inside the method. `in`: Pass by reference, read-only (prevents copying large structs).

**DN12** — **Nullable Reference Types**: A compile-time feature where `string?` indicates the variable *should* be null, helping catch `NullReferenceException`. **Nullable Value Types**: `int?` is a `Nullable<int>` struct that actually allows the value to be null at runtime.

**DN13** — **LINQ** (Language Integrated Query) allows querying data. **Method Syntax**: Fluent, uses extension methods. **Query Syntax**: SQL-like, easier for complex joins. **Deferred Execution**: The query isn't run until you iterate over it (e.g., `foreach` or `.ToList()`).

**DN14** — Constraints limit the type of `T`. `class` (reference), `struct` (value), `new()` (must have parameterless constructor), `IComparable<T>` (must implement comparison). Combine using `where T : class, new()`.

**DN15** — **Abstract Class**: Can have state (fields) and partial implementation. **Interface**: A contract. **Default Interface Methods** allow interfaces to have default logic, narrowing the gap, but interfaces still cannot hold instance state (fields).

**DN16** — **Middleware**: A pipeline of components. `Use()`: Executes and passes control. `Map()`: Branches the pipeline based on path. `Run()`: Terminal middleware. **Ordering**: Matters because middleware wraps the next one (e.g., Exception Handling must be first to catch everything).

**DN17** — `Channel<T>` is a high-performance, thread-safe producer-consumer queue. Unlike `BlockingCollection<T>`, it is fully `async` friendly. **Backpressure**: Use `Channel.CreateBounded<T>(capacity)`; when the capacity is reached, the producer will asynchronously wait (suspend) until space is available.

**DN18** — **Source Generators** run during compilation to generate C# code. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are "ahead-of-time." **Incremental Generators** are optimized to only re-run if the input files change, making them much faster for large projects.

**DN19** — **TPL Dataflow**: A high-level library for building pipelines. `ActionBlock` (process), `TransformBlock` (map), `BufferBlock` (queue). **Comparison**: `Channels` is lower-level and better for simple producer-consumer; `Dataflow` is better for complex graphs (branching, joining, parallelism).

**DN20** — **Minimal APIs**: Use `MapGet` etc. directly in `Program.cs`. **Trade-offs**: Faster startup, less boilerplate, but harder to organize for massive apps. **Route Groups**: `app.MapGroup("/api")`. **Endpoint Filters**: Allow logic (auth, validation) to run before/after the handler without full middleware.

## Python

**P1** — **List**: Mutable, ordered. **Tuple**: Immutable, ordered. **Set**: Mutable, unordered, unique. **Frozenset**: Immutable, unordered, unique.

**P2** — **GIL**: A mutex that prevents multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** workloads. **Workarounds**: Use `multiprocessing` (separate processes), C-extensions (releasing the GIL), or `asyncio` for I/O-bound tasks.

**P3** — **Copy**: Shallow copy (new object, same references). **Deepcopy**: New object, new nested objects. **Example**: `list_a = [[1]]`; `list_b = list_a.copy()`. If you change `list_b[0][0] = 2`, `list_a` also changes because the inner list is shared.

**P4** —
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"Time: {time.perf_counter() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to produce values one at a time, saving memory. **Returning a list** creates the entire list in memory first. `yield from` is used to delegate to a sub-generator (flattening).

**P6** — `asyncio` is single-threaded cooperative multitasking. `run()` starts the loop. `gather()` runs tasks concurrently and waits for all. `create_task()` schedules a task to run in the background. `time.sleep()` blocks the entire thread (and thus the loop); use `await asyncio.sleep()`.

**P7** — **MRO**: Method Resolution Order. Python uses **C3 Linearization**. In the example, `D` inherits from `B` then `C`. `B` is a subclass of `A`, and `C` is a subclass of `A`. The order is `D -> B -> C -> A`. Since `B` doesn't override `who`, it looks at `C`, which does. Result: `"C"`.

**P8** — **Metaclass**: A class of a class (defines how classes are created). **__init_subclass__**: A simpler way to customize class creation during inheritance. **Use Case**: Metaclass for complex registry systems; `__init_subclass__` for simple validation or registering subclasses.

**P9** — **Threading**: Good for I/O-bound (shared memory). **Multiprocessing**: Good for CPU-bound (separate memory). **Concurrent.futures**: A high-level wrapper for both. **Pickling**: Multiprocessing requires objects to be "picklable" to be sent between processes; non-picklable objects (like open files) will fail.

**P10** — `__slots__` tells Python not to use a dynamic `__dict__` for attributes. Use it to **save memory** and slightly speed up attribute access in classes with millions of instances. It prevents adding new attributes dynamically.

**P11** — **Virtual Env**: Isolates dependencies for different projects. `venv` is the standard library tool. `virtualenv` is a faster/more feature-rich third-party tool. `conda` is a package/environment manager for data science that handles non-Python dependencies.

**P12** — **Comprehensions** are generally more "Pythonic" and readable for simple logic. **Map/Filter** are functional. Prefer comprehensions for readability; use `map/filter` if you already have a pre-defined function to apply.

**P13** — `==` checks **equality** (value). `is` checks **identity** (memory address). **Interning**: Python reuses memory for small integers (-5 to 256) and some strings, which is why `a is b` can be True for `a = 10; b = 10`.

**P14** — `*args`: Variable positional arguments (tuple). `**kwargs`: Variable keyword arguments (dict). `/`: Positional-only (args before this must not be named). `*`: Keyword-only (args after this must be named).

**P15** — **Context Manager**: Handles setup/teardown. `__enter__`/`__exit__` is the standard protocol. `@contextmanager` is a decorator that turns a generator into a context manager. **Example**: A database transaction or a thread lock.

**P16** — **Type Hinting**: Static analysis for Python. `Union`: Either type. `Optional`: Type or None. `Literal`: Specific values. `TypeVar`: Generic types. `Protocol`: Structural subtyping (Static Duck Typing). `mypy` checks these at "compile" time to find bugs.

**P17** — `__repr__`: Developer-facing (unambiguous). `__str__`: User-facing (readable). `__eq__`: Equality. `__hash__`: Hashability (required for sets/dicts). `__getattr__`: Called only if attribute is missing. `__getattribute__`: Called every time. **Note**: If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors**: Objects that define `__get__`, `__set__`, or `__delete__`. When you access an attribute, Python checks if the object is a descriptor. `property` is a descriptor that manages attribute access logic. `classmethod` and `staticmethod` are also descriptors.

**P19** — **Import System**: `sys.path` is searched for modules. `PYTHONPATH` adds paths. `__init__.py` marks a directory as a package. **Namespace packages** allow multiple directories to share a package name. **Finder**: Locates the module. **Loader**: Loads the code into memory. **Relative**: `from . import x`. **Absolute**: `from pkg.mod import x`.

**P20** — **Dataclasses**: Built-in, concise. **Attrs**: More powerful, faster. **Pydantic**: Data validation and serialization (best for APIs). `__post_init__`: Logic after init. `field(default_factory=...)`: For mutable defaults. **Frozen**: Makes it immutable. **Pydantic** is chosen over dataclasses when you need strict type enforcement and automatic JSON parsing/validation.
