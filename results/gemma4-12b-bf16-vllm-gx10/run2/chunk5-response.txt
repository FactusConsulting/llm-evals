## .NET / C#

**DN1** — A **class** is a reference type (stored on the heap); a **struct** is a value type (usually stored on the stack). Use a **struct** for small, immutable data structures that behave like values (e.g., a Point, Color, or complex number) where the overhead of heap allocation and GC tracking outweighs the benefits of reference semantics.

**DN2** — `IEnumerable<T>` is for in-memory iteration; it executes the query immediately or via deferred execution on the collection. `IQueryable<T>` is for out-of-memory queries (like SQL); it translates the LINQ expression into a provider-specific query (e.g., SQL) so filtering happens at the database level. This distinction is critical for performance: `IEnumerable` pulls all data into memory before filtering; `IQueryable` filters at the source.

**DN3** — `async/await` uses a state machine to yield control back to the caller while waiting for an I/O-bound operation, avoiding thread blocking. A `Task` represents an operation that returns a result (allocates an object on the heap). `ValueTask` is a struct that can represent a result without an allocation if the operation completes synchronously. Use `ValueTask` in high-performance scenarios where the result is often available immediately (e.g., reading from a buffer).

**DN4** — DI is a design pattern where objects receive their dependencies from an external source rather than creating them.
- **Transient**: Created every time they are requested.
- **Scoped**: Created once per client request (e.g., per HTTP request).
- **Singleton**: Created once and live for the app lifetime.
**Bug**: Injecting a Scoped service (like `DbContext`) into a Singleton causes the Scoped service to be "captured" and live as long as the Singleton, leading to thread-safety issues and memory leaks because the Scoped service is not disposed of until the app shuts down.

**DN5** — `string` is immutable; every modification creates a new string. `ReadOnlySpan<char>` is a view into a contiguous region of memory (stack, heap, or unmanaged) without copying. Use `Span<T>` for high-performance parsing (e.g., `String.Split` alternatives) to reduce allocations and pressure on the GC.

**DN6** — The GC manages memory by identifying unreachable objects. **Gen 0** (short-lived objects), **Gen 1** (buffer), and **Gen 2** (long-lived objects). The **Large Object Heap (LOH)** is for objects >85KB (not compacted by default). `IDisposable` is necessary because the GC only manages *memory*; it doesn't know how to release *unmanaged resources* (file handles, DB connections, sockets).

**DN7** — `ConfigureAwait(false)` tells the task not to resume on the original `SynchronizationContext` (e.g., UI thread or ASP.NET request context). Use it in library code to improve performance and avoid deadlocks. Do **not** use it in top-level UI code where you need to update UI elements. It relates to `SynchronizationContext` because, by default, `await` captures the context to ensure the continuation runs on the same thread/context.

**DN8** — **Primary Constructors**: Define parameters in the class header. **Collection Expressions**: `int[] arr = [1, 2, 3];`. **FrozenDictionary**: An immutable, high-performance dictionary optimized for read-heavy lookups.
*Example:*
```csharp
public class UserService(IDbContext db) : IUserService {
    public async Task GetData() => await db.QueryAsync();
}
```

**DN9** — **Cause**: A `DbContext` is not thread-safe. Under high concurrency, multiple threads are likely sharing the same `DbContext` instance (likely injected as a Singleton or captured by a long-running Task). **Fix**: Ensure `DbContext` is registered as **Scoped**. Use `IServiceScopeFactory` to create a manual scope inside background tasks or multi-threaded loops to ensure each thread gets its own instance.

**DN10** — **Record**: A reference type with built-in value-based equality and non-destructive mutation (`with` expressions). **Class**: Standard reference type. **Record struct**: A value type with record features (equality/deconstruction). Choose **Record** for DTOs/Data models; **Record struct** for small, high-performance value types that need equality logic.

**DN11** — `ref`: Pass by reference, variable must be initialized. `out`: Pass by reference, variable must be assigned before returning. `in`: Pass by reference, variable is read-only. Use `ref` for swapping values, `out` for returning multiple values from a method, and `in` for passing large structs efficiently without copying.

**DN12** — Nullable Reference Types (`string?`) are a compile-time safety feature to warn developers about potential nulls; they don't change runtime behavior. Nullable Value Types (`int?`) are `Nullable<T>` structs that actually allow a value type to represent a null state at runtime.

**DN13** — LINQ (Language Integrated Query) allows querying data collections. **Method Syntax** (`.Where()`) is more fluid and common in functional styles. **Query Syntax** (`from x in...`) is more readable for complex joins/groupings. **Deferred Execution** means the query isn't executed until you iterate over it (e.g., `foreach` or `.ToList()`).

**DN14** — Constraints limit the types allowed for `T`. `class`: must be a reference type. `struct`: must be a value type. `new()`: must have a public parameterless constructor. `IComparable<T>`: must implement the interface. Combine them using commas (e.g., `where T : class, new()`).

**DN15** — **Abstract Class**: A base class that cannot be instantiated; can contain state (fields) and implementation. **Interface**: A contract of capabilities; cannot hold state. **Default Interface Methods** allow interfaces to have default implementations, narrowing the gap by allowing "optional" logic in interfaces, but they still cannot hold instance state.

**DN16** — The pipeline is a series of delegates. `app.Use()`: Executes logic and can pass to next. `app.Map()`: Branches the pipeline based on path. `app.Run()`: Terminal middleware (stops the chain). **Ordering** matters because middleware wraps the next; an Exception Handler must be first to catch errors from subsequent steps.

**DN17** — `Channel<T>` is a high-performance, thread-safe producer-consumer queue designed for `async`. `BlockingCollection<T>` is synchronous and blocks threads. **Bounded Channel Example**: `Channel.CreateBounded<int>(10)` ensures that if the buffer is full, the producer asynchronously waits (backpressure) until the consumer frees space.

**DN18** — **Source Generators** run during compilation to generate C# source code. Unlike **Reflection** (runtime overhead) or **IL Weaving** (complex post-processing), they are "ahead-of-time." **Incremental Generators** are a subset that caches results between compilation steps, making them significantly faster for large projects.

**DN19** — **TPL Dataflow** is a high-level library for building complex pipelines (blocks). `ActionBlock`: consumes data. `TransformBlock`: processes and returns data. `BufferBlock`: holds data. **Comparison**: `Channels` are lower-level primitives for simple producer-consumer; `Dataflow` is for complex graphs (branching, joining, parallelism).

**DN20** — **Minimal APIs** use a simplified routing model (lambda-based) instead of Controller classes. **Trade-offs**: Minimal APIs are faster/leaner but can become messy without organization. **Testability**: Controllers are easier to unit test via mocking; Minimal APIs often require integration tests. **Route Groups** use `MapGroup` to share prefixes/filters.

## Python

**P1** — **List**: Mutable, ordered sequence. **Tuple**: Immutable, ordered sequence. **Set**: Mutable, unordered collection of unique items. **Frozenset**: Immutable version of a set.

**P2** — The **GIL** is a mutex that prevents multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** workloads (e.g., heavy math). **Workarounds**: Use `multiprocessing` (separate memory spaces), C-extensions (releasing the GIL), or move logic to a different language/service.

**P3** — **Copy**: Shallow copy (new object, but nested objects are shared). **Deepcopy**: New object and new copies of all nested objects. **Example**: If you have a list of lists `a = [[1]]`, a shallow copy `b = a.copy()` means `b[0].append(2)` will also modify `a[0]`.

**P4** — Decorators wrap functions to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start}s")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to produce values one at a time, maintaining state. They are memory-efficient because they don't store the whole list in memory. **Yield from** is used to delegate to a sub-generator (recursive yielding).

**P6** — `asyncio` is a single-threaded cooperative multitasking loop. `run()` starts the loop; `gather()` runs multiple coroutines concurrently; `create_task()` schedules a coroutine to run in the background. `time.sleep()` blocks the entire thread (and thus the loop); `await asyncio.sleep()` yields control back to the loop.

**P7** — **MRO** is the order Python searches for methods in a hierarchy. Python 3 uses **C3 Linearization**. In the diamond inheritance: `D` inherits from `B` then `C`. `B` inherits from `A`. `C` inherits from `A`. The order is `D -> B -> C -> A`. Since `B` doesn't override `who`, it looks at `C`, which does. Result: `"C"`.

**P8** — **Metaclass**: A class of a class; defines how classes are *created*. Use for global class behavior (e.g., Singleton enforcement). **\_\_init\_subclass\_\_**: A hook called when a class is inherited. Use for simple registration or modification of attributes during inheritance without the complexity of a metaclass.

**P9** — **Threading**: Shared memory, good for I/O-bound. **Multiprocessing**: Separate memory, good for CPU-bound (bypasses GIL). **Concurrent.futures**: A high-level wrapper for both. **Serialization**: Multiprocessing requires **Pickling** (serializing objects to bytes) to move data between processes, which fails for non-picklable objects (like open files).

**P10** — `__slots__` tells Python not to use a dynamic `__dict__` for instance attributes. Use it to **save memory** and slightly speed up attribute access in classes with millions of instances. It prevents adding new attributes at runtime.

**P11** — A **Virtual Environment** isolates project-specific dependencies. `venv` is the standard library tool. `virtualenv` is a faster/more feature-rich third-party tool. `conda` is a package and environment manager that handles non-Python dependencies (like C++ libs).

**P12** — **Comprehensions** are concise ways to create collections. They are generally more "Pythonic" and faster than `map()`/`filter()` because they avoid function call overhead. Use `map()` if you already have a pre-defined function to apply.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (same memory address). **Object Interning** is where Python reuses objects for common values. Small integers (usually -5 to 256) are interned, so `a is b` returns `True` for them.

**P14** — `*args` captures positional arguments as a tuple; `**kwargs` captures keyword arguments as a dict. `/` indicates all preceding arguments must be **positional-only**. `*` indicates all following arguments must be **keyword-only**.

**P15** — **Context Managers** handle setup/teardown. Use `__enter__`/`__exit__` for class-based managers. Use `@contextmanager` with a generator for simpler logic. **Example**: A database transaction manager that commits on success and rolls back on exception.

**P16** — **Type Hinting** provides static analysis. `Union` (A or B), `Optional` (A or None), `Literal` (specific values), `TypeVar` (generics), `Protocol` (structural typing/static duck typing). `mypy` uses these to catch type errors before the code runs.

**P17** — `__repr__` is for developers (unambiguous); `__str__` is for users (readable). `__eq__` defines equality; if defined, `__hash__` must also be defined (and consistent) for the object to be used in a set/dict. `__getattr__` is called only if the attribute isn't found; `__getattribute__` is called every time.

**P18** — **Descriptors** are objects defining `__get__`, `__set__`, and `__delete__`. They manage attribute access logic. `property` is a built-in descriptor. `classmethod` and `staticmethod` are descriptors that manage how methods are bound to the class or instance.

**P19** — Python searches `sys.path` (current dir, PYTHONPATH, standard libs). **Absolute** imports start from the project root; **Relative** use `.` or `..`. `__init__.py` marks a directory as a package. **Namespace packages** allow multiple directories to share a name. A **Finder** locates the module; a **Loader** imports it into memory.

**P20** — **Dataclasses** provide boilerplate (init, repr) for data-heavy classes. **Attrs** is more powerful/flexible. **Pydantic** adds runtime validation and serialization. `__post_init__` runs after the generated `__init__`. **Frozen** makes them immutable. Choose **Pydantic** when you need strict data validation (e.g., API request parsing) or JSON schema generation.
