## .NET / C#

**DN1** — A **class** is a reference type (stored on the heap); a **struct** is a value type (usually stored on the stack). Use a **struct** for small, immutable data structures that behave like values (e.g., a Point, Color, or complex number) where the overhead of heap allocation and GC tracking outweighs the benefits of reference semantics.

**DN2** — `IEnumerable<T>` is for in-memory iteration; it executes the query immediately or via deferred execution on the collection. `IQueryable<T>` is for out-of-memory queries (like SQL); it translates the LINQ expression into a provider-specific query (e.g., SQL) so filtering happens at the database level. This distinction is critical for performance: `IEnumerable` pulls all data into memory before filtering, while `IQueryable` filters at the source.

**DN3** — `async/await` uses a state machine to suspend execution without blocking the thread. `Task` represents an operation that returns a result (allocates an object on the heap). `ValueTask` is a struct that can represent a result; use it when the result is often available synchronously (e.g., reading from a cache) to avoid the allocation of a `Task` object.

**DN4** — DI is a design pattern where objects receive their dependencies from an external source.
- **Transient**: Created every time they are requested.
- **Scoped**: Created once per client request (e.g., per HTTP request).
- **Singleton**: Created once and live for the app lifetime.
**Bug**: Injecting a Scoped service (like `DbContext`) into a Singleton causes the Scoped service to be "captured" and live as long as the Singleton, leading to thread-safety issues and memory leaks because the Scoped service is not disposed of correctly.

**DN5** — `string` is immutable; every modification creates a new string. `ReadOnlySpan<char>` is a view into a contiguous region of memory (stack, heap, or unmanaged). Use `Span<T>` for high-performance parsing or slicing (e.g., `string.Substring` vs `span.Slice`) because it avoids unnecessary allocations.

**DN6** — The GC uses a generational approach: **Gen 0** (short-lived objects), **Gen 1** (buffer), and **Gen 2** (long-lived). The **Large Object Heap (LOH)** is for objects >85KB and is collected less frequently. `IDisposable` is needed because the GC only manages memory; it doesn't know how to close file handles, database connections, or network sockets, which are unmanaged resources.

**DN7** — `ConfigureAwait(false)` tells the runtime it doesn't need to resume the continuation on the original `SynchronizationContext` (e.g., the UI thread). Use it in library code to avoid deadlocks and improve performance. Do **not** use it in UI code where you need to update UI elements directly.

**DN8** — **Primary Constructors**: Define parameters in the class header. **Collection Expressions**: `int[] arr = [1, 2, 3];`. **FrozenDictionary**: An immutable, high-performance dictionary for read-heavy scenarios.
*Example:*
```csharp
public class UserService(IDbContext db) : IUserService {
    public async Task GetData() => await db.QueryAsync();
}
```

**DN9** — **Cause**: A `DbContext` is being shared across multiple concurrent threads (likely injected as a Singleton or captured by a long-running Task). `DbContext` is not thread-safe.
**Fix**: Ensure `DbContext` is registered as **Scoped**. Use `IServiceScopeFactory` to create a manual scope inside a background task or multi-threaded loop to ensure each thread gets its own instance.

**DN10** — **Record**: A reference type with built-in value-based equality and non-destructive mutation (`with` expressions). **Class**: Standard reference type. **Record struct**: A value type with record features. Choose **Record** for DTOs/Data models; **Class** for complex logic/entities; **Record struct** for small, immutable value types.

**DN11** — `ref`: Pass by reference, variable must be initialized. `out`: Pass by reference, variable must be assigned before returning. `in`: Pass by reference, variable is read-only. Use `ref` for swapping values, `out` for returning multiple values, and `in` for passing large structs efficiently without copying.

**DN12** — **Nullable Reference Types** (`string?`) are a compile-time safety feature to indicate a variable might be null; they don't change runtime behavior. **Nullable Value Types** (`int?`) are actual wrappers (`Nullable<T>`) that allow value types to represent a null state at runtime.

**DN13** — **LINQ** is a query language for collections. **Method Syntax** uses extension methods (`.Where()`); **Query Syntax** uses SQL-like `from...where`. **Deferred Execution** means the query isn't executed until you iterate over it (e.g., `foreach` or `.ToList()`).

**DN14** — Constraints limit the type of `T`. `class` (reference type), `struct` (value type), `new()` (must have parameterless constructor), `IComparable<T>` (must implement interface). Combine using `where T : class, new()`.

**DN15** — **Abstract Class**: Can have state (fields) and implementation. **Interface**: A contract. **Default Interface Methods** allow interfaces to have default implementations, narrowing the gap, but interfaces still cannot hold instance state (fields).

**DN16** — **Middleware** is a pipeline of components. `Use()` adds a middleware that can pass control to the next; `Map()` branches the pipeline based on path; `Run()` terminates the pipeline. **Ordering** matters because middleware executes in the order registered. **Exception Handling** middleware wraps the `next()` call in a try-catch block.

**DN17** — `Channel<T>` is a high-performance, thread-safe producer-consumer queue. Unlike `BlockingCollection<T>`, it is fully `async` friendly.
*Example:* `Channel.CreateBounded<int>(100)` creates a channel where the producer will asynchronously wait (backpressure) if the buffer is full.

**DN18** — **Source Generators** execute during compilation to generate C# source code. They are faster than **Reflection** (runtime) and safer than **IL Weaving** (post-compile). **Incremental Generators** are preferred because they cache results and only re-run if inputs change, significantly improving build times.

**DN19** — **TPL Dataflow** is a high-level library for building pipelines. `ActionBlock` (process), `TransformBlock` (map), `BufferBlock` (queue). It is better for complex graphs/branching. `Channels` are lower-level and better for simple, high-throughput producer-consumer scenarios.

**DN20** — **Minimal APIs** use `MapGet/Post` directly on `WebApplication`. They are faster and less boilerplate than **Controllers**. **Trade-offs**: Controllers are better for complex logic/dependency grouping; Minimal APIs are better for microservices. **Route Groups** use `.MapGroup()`; **Endpoint Filters** allow logic (like Auth) to run before/after the handler.

## Python

**P1** — **List**: Mutable, ordered. **Tuple**: Immutable, ordered. **Set**: Mutable, unordered, unique. **Frozenset**: Immutable, unordered, unique.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** workloads (e.g., heavy math). **Workarounds**: Use `multiprocessing` (separate processes), C-extensions (releasing the GIL), or move logic to a different language/service.

**P3** — **Copy**: Shallow copy (new object, same references to nested objects). **Deepcopy**: New object, new copies of all nested objects.
*Example:* `list_a = [[1]]`; `list_b = list_a.copy()`. If you change `list_b[0][0] = 2`, `list_a` also changes because they share the inner list.

**P4** — Decorators wrap functions to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start}s")
        return res
    return wrapper
```

**P5** — **Generators** use `yield` to produce values one at a time, saving memory. They don't store the whole list in memory. `yield from` is used to delegate to a sub-generator (flattening).

**P6** — `asyncio` is single-threaded cooperative multitasking. `run()` starts the loop; `gather()` runs tasks concurrently; `create_task()` schedules a task. `time.sleep()` blocks the entire thread (and thus the loop); use `await asyncio.sleep()` instead.

**P7** — **MRO** is the order Python searches for methods. Python 3 uses **C3 Linearization**. In diamond inheritance, it ensures a class is visited before its parents.
*Result:* `C` is visited before `B` because `D(B, C)` prioritizes the first listed parent, but C3 ensures `A` is visited last. The output is `"C"`.

**P8** — **Metaclass**: A class that creates classes (the "class of a class"). Use for global class behavior (e.g., Singleton enforcement). `__init_subclass__` is a simpler way to customize class creation during inheritance without the complexity of a full metaclass.

**P9** — **Threading**: Shared memory, good for I/O. **Multiprocessing**: Separate memory, good for CPU-bound. **Concurrent.futures**: A high-level API to manage both. **Pickling**: Multiprocessing requires objects to be "picklable" (serializable) to move between processes; some objects (like open files or lambdas) cannot be pickled.

**P10** — `__slots__` tells Python not to use a dynamic `__dict__` for attributes. Use it to **save memory** and slightly increase speed when creating millions of small objects. It prevents adding new attributes dynamically.

**P11** — A **Virtual Environment** isolates project dependencies. `venv` is the standard library tool; `virtualenv` is a faster/more feature-rich third-party tool; `conda` is a package/environment manager for data science that handles non-Python dependencies.

**P12** — **Comprehensions** are concise ways to create collections. They are generally more "Pythonic" and faster than `map()`/`filter()` because they avoid function call overhead. Use `map()` if you already have a pre-defined function to apply.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (same memory address). **Object Interning** caches small integers (-5 to 256) and certain strings so that `a is b` returns `True` for these common values.

**P14** — `*args` (tuple of positional args), `**kwargs` (dict of keyword args). `/` forces all preceding arguments to be positional-only. `*` forces all following arguments to be keyword-only.

**P15** — **Context Managers** handle setup/teardown. `__enter__/__exit__` is the standard protocol. `@contextmanager` is a decorator that turns a generator into a context manager.
*Example:* A database transaction manager or a temporary lock.

**P16** — **Type Hinting** provides static analysis. `Union` (either type), `Optional` (type or None), `Literal` (specific values), `TypeVar` (generics), `Protocol` (structural subtyping/static duck typing). `mypy` uses these to catch bugs before runtime.

**P17** — `__repr__` (developer-facing, unambiguous); `__str__` (user-facing, readable). `__eq__` (equality); `__hash__` (integer for sets/dicts). `__getattr__` (called if attribute not found); `__getattribute__` (called every time). If you define `__eq__` but not `__hash__`, the object becomes unhashable (cannot be in a set).

**P18** — **Descriptors** define `__get__`, `__set__`, and `__delete__`. They allow you to customize attribute access. `property` is a descriptor that manages attribute access logic. `classmethod` and `staticmethod` are descriptors that control how methods are bound to classes/instances.

**P19** — **Imports** are handled by `sys.path`. **Absolute** (full path) is preferred. **Relative** (dots) is for internal package structure. `__init__.py` marks a directory as a package. **Namespace packages** allow multiple directories to share a name. A **Finder** locates the module; a **Loader** executes the code to create the module object.

**P20** — **Dataclasses** provide boilerplate (init, repr) for data classes. **Attrs** is more powerful/flexible. **Pydantic** adds runtime validation and serialization. `__post_init__` runs after the auto-generated init. **Frozen** makes them immutable. Choose **Pydantic** when you need to validate input data (e.g., from an API) or need complex JSON serialization.
