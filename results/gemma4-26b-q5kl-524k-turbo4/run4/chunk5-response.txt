## .NET / C#

**DN1** — **Class** is a reference type (allocated on the heap), while **struct** is a value type (usually allocated on the stack or inline). Use a **struct** for small, immutable data structures (e.g., a `Point` or `Color`) that have a small memory footprint and a short lifetime to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects); it iterates over data already in memory. **IQueryable<T>** is for out-of-memory data (LINQ-to-SQL/EF); it uses expression trees to translate queries into provider-specific language (like SQL). This distinction matters because `IQueryable` allows for "query folding," where filtering happens at the database level, whereas `IEnumerable` pulls all data into memory before filtering.

**DN3** — **async/await** allows a thread to be released to the thread pool while waiting for an I/O operation to complete, preventing thread starvation. A **Task** is a class representing an asynchronous operation (heap-allocated). A **ValueTask** is a struct. Use **ValueTask** when the result is often already available synchronously (e.g., from a cache) to avoid the heap allocation of a `Task` object.

**DN4** — **Dependency Injection (DI)** is a design pattern where objects receive their dependencies from an external source rather than creating them internally. 
- **Transient**: Created every time they are requested.
- **Scoped**: Created once per client request (e.g., per HTTP request).
- **Singleton**: Created once and shared throughout the application lifetime.
**Common Bug**: Injecting a **Scoped** service into a **Singleton**. This causes a "Captive Dependency," where the Scoped service lives as long as the Singleton, potentially leading to memory leaks or stale data/connection issues.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view into a contiguous region of memory (string, array, or unmanaged memory). Use **Span<T>** for high-performance parsing or slicing to avoid creating multiple substring allocations on the heap.

**DN6** — The **GC** manages memory automatically. **Gen 0** contains short-lived objects; **Gen 1** is a buffer for survivors of Gen 0; **Gen 2** contains long-lived objects. The **Large Object Heap (LOH)** is for objects >85,000 bytes; these are not compacted by default to avoid expensive memory moves. **IDisposable** is needed because the GC only manages managed memory; you must manually release unmanaged resources (file handles, DB connections) via `Dispose()` to prevent resource leaks.

**DN7** — **ConfigureAwait(false)** tells the runtime not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) or ASP.NET (legacy) if you need to access UI elements or `HttpContext` after the `await`.

**DN8** — **Primary Constructors** allow parameters to be defined directly in the class header. **Collection Expressions** (`[1, 2, 3]`) provide a unified syntax for initializing collections. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
*Example:*
```csharp
public class UserService(IDbContext db) // Primary Constructor
{
    private readonly IDbContext _db = db;
    public List<string> GetNames() => [ "Alice", "Bob" ]; // Collection Expression
}
```

**DN9** — The cause is likely **thread-safety violations**. `DbContext` is not thread-safe and is typically registered as **Scoped**. If multiple threads attempt to use the same `DbContext` instance simultaneously (e.g., via `Task.WhenAll` on a single request), an `ObjectDisposedException` or concurrency exception occurs. **Fix**: Ensure each thread/task gets its own scope or use a `IDbContextFactory`.

**DN10** — **record** is a reference type with built-in value-based equality. **record struct** is a value type with value-based equality. Use **record** for DTOs/immutable data models; use **record struct** for small, high-performance value types that need equality logic.

**DN11** — **ref**: Pass by reference (read/write). **out**: Must be assigned inside the method before returning. **in**: Pass by reference but read-only (prevents copying large structs).

**DN12** — **Nullable reference types** (`string?`) are compiler instructions to warn about potential nulls (static analysis). **Nullable value types** (`int?`) are actual `Nullable<T>` structures that allow a value type to represent `null` at runtime.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`); **Query syntax** uses a SQL-like structure (`from x in...`). **Deferred execution** means the query is not executed when defined, but only when the data is actually iterated (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints** restrict the types allowed for `T`. 
- `T : class` (Reference type)
- `T : struct` (Value type)
- `T : new()` (Must have a parameterless constructor)
- `T : IComparable<T>` (Must implement comparison)
Combine them: `where T : class, new()`.

**DN15** — **Abstract classes** can hold state (fields) and provide implementation. **Interfaces** define a contract. **Default interface methods** allow interfaces to provide implementation, narrowing the gap by allowing interfaces to evolve without breaking existing implementations.

**DN16** — **Middleware** is a pipeline of delegates. **app.Use()** adds a delegate that can call the next; **app.Map()** branches the pipeline; **app.Run()** is a terminal middleware. **Ordering matters**: Auth must come before Routing. **Exception handling middleware** should be placed at the very beginning of the pipeline to catch errors from all subsequent steps.

**DN17** — **Channel<T>** is an async-capable producer-consumer collection. **BlockingCollection<T>** is synchronous/thread-based. For backpressure, use a **Bounded Channel**: `Channel.CreateBounded<T>(capacity)`. When the capacity is reached, the producer's `WriteAsync` will asynchronously wait until space is available.

**DN18** — **Source Generators** create code at compile time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (post-compile modification), they are part of the compilation process. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance and build times.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumer), **TransformBlock** (processor), and **BufferBlock** (queue). **Channels** are lighter and better for simple producer-consumer; **TPL Dataflow** is better for complex, multi-stage processing pipelines with built-in buffering and concurrency management.

**DN20** — **Minimal APIs** are a lightweight way to build HTTP APIs with minimal boilerplate. **Controllers** provide more structure and convention. **Trade-offs**: Minimal APIs are faster to write and have lower overhead, but Controllers offer better organization for massive projects. **Route groups** allow logical grouping of endpoints, and **Endpoint Filters** act like middleware specifically for those endpoints.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is a mutable collection of unique, unordered elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** is a mutex that protects access to Python objects, preventing multiple native threads from executing Python bytecodes at once. It affects **CPU-bound** workloads (making multi-threading ineffective for speedup). **Workarounds**: Use `multiprocessing` to bypass the GIL by using separate memory spaces, or use C-extensions (like NumPy) that release the GIL during heavy computation.

**P3** — **copy** (shallow) creates a new container but references the same objects inside. **deepcopy** creates a new container and recursively copies all objects within. 
*Example*: If `a = [[1]]`, `b = copy.copy(a)`, then `b[0].append(2)` will also change `a` because they share the inner list.

**P4** — A decorator is a function that takes another function and extends its behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values one by one, maintaining state and being memory efficient (lazy evaluation). **yield from** is used to delegate to a sub-generator, flattening nested generators.

**P6** — **asyncio event loop** manages async tasks. **asyncio.run()** is the entry point; **asyncio.gather()** runs multiple awaitables concurrently and waits for all; **asyncio.create_task()** schedules a task to run in the background. You cannot use `time.sleep()` because it is a blocking call that halts the entire event loop; use `await asyncio.sleep()` instead.

**P7** — Python uses **C3 Linearization** for MRO. In the diamond inheritance `D(B, C)`, Python looks at `D`, then `B`, then `C`, then `A`. 
*Result*: `D().who()` prints **"C"** because `C` is the first class in the MRO after `D` and `B` that implements `who`.

**P8** — A **metaclass** is a class of a class (defines how a class is created). **\_\_init\_subclass\_\_** is a simpler way to customize class creation without a full metaclass. Use **metaclass** for deep structural changes (like registering classes automatically); use **\_\_init\_subclass\_\_** for simple inheritance-based modifications.

**P9** — **threading**: I/O-bound tasks. **multiprocessing**: CPU-bound tasks (bypasses GIL). **concurrent.futures**: High-level abstraction for both. **Multiprocessing** requires **pickling** (serialization) to send data between processes, which adds overhead.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This reduces memory usage and speeds up attribute access, but prevents adding new attributes at runtime.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party alternative; **conda** is a package/environment manager used heavily in data science for managing non-Python dependencies.

**P12** — **Comprehensions** are concise ways to create lists, dicts, or sets. They are generally more readable and faster than `map()` and `filter()` for simple transformations.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (memory address). **Object interning** caches small integers (typically -5 to 256) so that `a is b` returns `True` for the same integer value.

**P14** — `*args` collects extra positional arguments into a tuple; `**kwargs` collects extra keyword arguments into a dictionary. `/` forces arguments to be **positional-only**; `*` forces arguments to be **keyword-only**.

**P15** — **Context managers** handle setup/teardown. Use `__enter__`/`__exit__` in a class, or `@contextlib.contextmanager` with a generator. *Example*: A database transaction manager that commits on success and rolls back on exception.

**P16** — **Type hinting** provides static type information. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generic), and `Protocol` (structural/duck typing). **mypy/pyright** use these to find bugs without running the code.

**P17** — **\_\_repr\_\_** is for developers (unambiguous); **\_\_str\_\_** is for users (readable). **\_\_eq\_\_** checks value equality; **\_\_hash\_\_** allows an object to be used in sets/dicts. If you define `__eq__` but not `__hash__`, the object becomes unhashable. **\_\_getattr\_\_** is called if attribute isn't found; **\_\_getattribute\_\_** is called for *every* access.

**P18** — **Descriptors** are objects that define `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors that manage how attribute access is handled.

**P19** — **Absolute imports** use the full path from the project root; **relative imports** use `.` or `..`. `sys.path` is the list of directories searched for modules. `__init__.py` makes a directory a package. A **finder** locates the module, and a **loader** reads the code.

**P20** — **dataclasses** (std lib) provides boilerplate reduction. **attrs** is more powerful/feature-rich. **Pydantic** is focused on data validation and parsing. Use **Pydantic** for API/external data validation; use **dataclasses** for internal data structures.
