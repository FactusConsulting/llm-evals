## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored on the stack or inline). Use a **struct** for small, immutable data structures (typically < 16 bytes) that have no identity and don't require inheritance to avoid excessive copying overhead.

**DN2** — **IEnumerable<T>** is for in-memory collections (iterates via `GetEnumerator`). **IQueryable<T>** is for out-of-memory providers (like EF Core) using expression trees. This matters because `IQueryable` translates queries into SQL to be executed on the database server, whereas `IEnumerable` pulls all data into application memory before filtering.

**DN3** — **async/await** uses a state machine to allow non-blocking asynchronous operations. A **Task** represents an ongoing operation. A **ValueTask** is a value-type wrapper for a Task. Use `ValueTask` when a method frequently completes synchronously (e.g., reading from a cache) to avoid the heap allocation of a `Task` object.

**DN4** — **Dependency Injection** is a pattern where dependencies are provided to a class rather than the class creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Common Bug**: "Captive Dependency"—injecting a **Scoped** service into a **Singleton**. The Scoped service is now held by the Singleton for the app's lifetime, effectively turning it into a Singleton and potentially causing stale data or memory leaks.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view into a contiguous memory region. Use `Span<T>` for high-performance parsing/slicing to avoid creating multiple string substrings, which reduces GC pressure.

**DN6** — The **GC** manages memory automatically. **Gen 0** is for short-lived objects; **Gen 1** is the buffer; **Gen 2** is for long-lived objects. **Large Object Heap (LOH)** is for objects >85,000 bytes; these are not compacted by default to save CPU. **IDisposable** is needed to manually release **unmanaged resources** (file handles, DB connections) because the GC only tracks managed memory, not OS handles.

**DN7** — **ConfigureAwait(false)** tells the task not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. **Do NOT** use it in UI applications (WPF/WinForms) or ASP.NET (legacy) where you need to return to the original context to update the UI or access context-specific data.

**DN8** — **Primary Constructors** allow parameters in the class declaration. **Collection Expressions** (`[]`) simplify array/list creation. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Minimal Example
public class UserService(IDbContext db) { // Primary Constructor
    public void DoWork() => db.Users.ToList();
}
var service = new UserService(db);
List<int> numbers = [1, 2, 3]; // Collection Expression
```

**DN9** — The `ObjectDisposedException` under high concurrency usually means a **Scoped DbContext** is being accessed by multiple threads simultaneously (e.g., a background task trying to use a context from a finished HTTP request). **Fix**: Use `IServiceScopeFactory` to create a new scope manually within the background thread to get a fresh `DbContext`.

**DN10** — **record** is a reference type with value-based equality. **record struct** is a value type with value-based equality. Use `record` for DTOs/Data objects. Use `class` when you need inheritance or identity. Use `record struct` for small, high-performance value-based data.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only, prevents copying large structs).

**DN12** — **Nullable reference types** (`string?`) are a compile-time static analysis tool to prevent `NullReferenceException`. **Nullable value types** (`int?`) are a runtime wrapper (`Nullable<T>`) that allows a value type to hold `null`.

**DN13** — **LINQ** (Language Integrated Query) allows querying collections. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query isn't executed until you iterate over it (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (must have parameterless constructor), `T : IComparable<T>` (must implement comparison). You combine them using `where T : class, new()`.

**DN15** — **Abstract class** can have state (fields) and implementation. **Interface** is a pure contract (though C# 8+ allows default implementations). **Default interface methods** allow adding functionality to interfaces without breaking existing implementations.

**DN16** — **Middleware** is a pipeline of delegates. **app.Use()** adds middleware that can call `next()`. **app.Map()** branches the pipeline. **app.Run()** is a terminal middleware. **Ordering** is critical: Exception handling must be near the start to catch errors in subsequent steps.

**DN17** — **Channel<T>** is an async-capable producer-consumer queue. **BlockingCollection<T>** is synchronous and thread-blocking. **Bounded channels** provide backpressure: if the channel is full, the producer `await`s `WriteAsync`, preventing memory exhaustion.

**DN18** — **Source Generators** produce code at compile time. Unlike **Reflection** (runtime inspection) or **IL Weaving** (modifying existing DLLs), they are safe and visible. **Incremental Generators** are preferred because they only re-run when specific parts of the syntax tree change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumer), **TransformBlock** (processor), and **BufferBlock** (queue). **Channels** are better for simple, high-performance async streaming; **Dataflow** is better for complex directed acyclic graphs (DAGs) of processing steps.

**DN20** — **Minimal APIs** allow defining endpoints without Controllers. **Trade-offs**: Controllers offer better structure/organization for large apps; Minimal APIs offer lower overhead and faster startup. **Route groups** organize endpoints; **Endpoint filters** allow cross-cutting logic (like validation) per endpoint.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is unordered and contains unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, making Python single-threaded for CPU-bound tasks. **Workarounds**: Use `multiprocessing` for CPU tasks or use C-extensions (like NumPy) that release the GIL.

**P3** — **Shallow copy** creates a new object but references the same nested objects. **Deepcopy** creates a new object and recursively copies all nested objects. **Example**: `a = [[1]]; b = a.copy(); b[0][0] = 2` -> `a` is now `[[2]]`.

**P4** — A **decorator** is a function that wraps another.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily (one at a time), saving memory. **yield from** allows a generator to delegate to a sub-generator (flattening).

**P6** — The **event loop** manages async tasks. **asyncio.run()** is the entry point; **asyncio.gather()** runs multiple tasks concurrently; **asyncio.create_task()** schedules a task to run in the background. **time.sleep()** is blocking; it stops the entire thread, including the loop. Use `asyncio.sleep()`.

**P7** — Python uses **C3 Linearization** for MRO. In `D(B, C)`, it checks `D`, then `B`, then `C`, then `A`.
**Result**: `D().who()` prints **"C"** because `B` doesn't define `who`, so it moves to `C`.

**P8** — A **metaclass** is a class that creates classes. **\_\_init\_subclass\_\_** is a simpler hook called when a class is subclassed. Use `__init_subclass__` for simple registration; use a **metaclass** when you need to modify the class creation process itself (e.g., changing attributes).

**P9** — **Threading** (I/O bound), **Multiprocessing** (CPU bound, bypasses GIL), **concurrent.futures** (high-level abstraction over both). **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be slow and fails on non-picklable objects (like open files).

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, instead using a fixed set of attributes. This **reduces memory usage** significantly and prevents the accidental creation of new attributes.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party tool; **conda** is a package/environment manager used heavily in data science for managing non-Python binaries.

**P12** — **Comprehensions** are syntactic sugar for creating collections. They are generally more readable and faster than `map()`/`filter()`. Use comprehensions for simple transformations; use `map`/`filter` when working with existing functions.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (-5 to 256) so they point to the same memory address, which is why `a is b` returns `True` for them.

**P14** — `*args` collects extra positional arguments into a tuple; `**kwargs` collects extra keyword arguments into a dict. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context managers** handle setup/teardown. `__enter__`/`__exit__` is the class-based way; `@contextmanager` is the generator-based way. **Example**: A database transaction manager or a custom timer.

**P16** — **Type hinting** provides static analysis. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal[1, 2]` (specific values), `TypeVar` (generic), `Protocol` (structural typing/duck typing). **Mypy** uses these to catch type errors before runtime.

**P17** — `__repr__` is for developers (debugging); `__str__` is for users (readable). `__eq__` is for value equality; `__hash__` allows use in sets/dicts. `__getattr__` is called only if the attribute is missing; `__getattribute__` is called for *every* access. If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that define `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all implemented using the descriptor protocol to manage how attributes are accessed.

**P19** — **Absolute imports** use the full path from the project root; **relative** uses `.` notation. `sys.path` is the list of directories searched for modules. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** reads the code.

**P20** — **Dataclasses** provide boilerplate for data classes. **attrs** is more powerful/older; **Pydantic** is used for data validation (parsing). Use **Pydantic** when you need runtime type enforcement/validation (e.g., API requests). `__post_init__` runs after `__init__`. Use `field(default_factory=...)` for mutable defaults like lists.
