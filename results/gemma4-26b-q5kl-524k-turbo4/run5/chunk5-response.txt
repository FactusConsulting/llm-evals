## .NET / C#

**DN1** — **Class** is a reference type (allocated on the heap), while **struct** is a value type (usually allocated on the stack or inline). Use a **struct** for small, immutable data structures (typically < 16 bytes) that have a short lifetime to reduce GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects) and uses deferred execution. **IQueryable<T>** is for out-of-memory providers (like EF Core) and uses Expression Trees to translate queries into SQL. This distinction matters because `IQueryable` allows the database to filter data *before* it reaches the application, whereas `IEnumerable` would pull all data into memory first.

**DN3** — **async/await** uses a state machine to allow non-blocking I/O. A **Task** represents an asynchronous operation. A **ValueTask** is a lightweight alternative used when a result might already be available synchronously (e.g., from a cache), avoiding the heap allocation of a `Task` object.

**DN4** — **Dependency Injection (DI)** is a design pattern where objects receive their dependencies from an external source rather than creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., HTTP request).
- **Singleton**: One instance for the lifetime of the app.
**Common Bug**: Injecting a **Scoped** service into a **Singleton** (Captive Dependency). The Scoped service will live as long as the Singleton, potentially causing stale data or DB connection issues.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-only view of a contiguous memory region. Use **Span<T>** for high-performance parsing/slicing to avoid creating multiple substring allocations on the heap.

**DN6** — The **GC** manages memory using generations: **Gen 0** (newly allocated), **Gen 1** (survivors of Gen 0), and **Gen 2** (long-lived). The **Large Object Heap (LOH)** is for objects >85,000 bytes; these are not compacted by default to save CPU. **IDisposable** is needed to manually release unmanaged resources (file handles, sockets) that the GC cannot track.

**DN7** — **ConfigureAwait(false)** tells the runtime not to force the continuation back onto the original `SynchronizationContext`. Use it in library code to improve performance and avoid deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) where you need to return to the UI thread to update elements.

**DN8** — **Primary Constructors** allow parameters to be defined directly in the class header. **Collection Expressions** use `[]` for concise array/list creation. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Example using Primary Constructor
public class UserService(IUserRepository repo) { 
    public void DoWork() => repo.GetUsers(); 
}
```

**DN9** — **Cause**: `DbContext` is not thread-safe. High concurrency is likely causing multiple threads to attempt to use the same `DbContext` instance simultaneously. **Fix**: Use `IDbContextFactory<T>` to create a new context per operation, or ensure each async task creates its own scope via `IServiceScopeFactory`.

**DN10** — **record** is a class with value-based equality. **record struct** is a value type with value-based equality. Use `record` for DTOs/Data Transfer Objects; use `record struct` for small, high-performance value types that need equality logic.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only). Use `in` to avoid copying large structs.

**DN12** — **Nullable Reference Types** (`string?`) are a compile-time safety feature to prevent `NullReferenceException`. **Nullable Value Types** (`int?`) are actual `Nullable<T>` wrappers that allow a value type to represent `null`.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses SQL-like keywords (`from x in...`). **Deferred execution** means the query is not executed until you iterate over the results (e.g., via `foreach` or `.ToList()`).

**DN14** — **Generic Constraints**: `where T : class` (reference type), `where T : struct` (value type), `where T : new()` (parameterless constructor), `where T : IComparable<T>` (must implement comparison). You can combine them: `where T : class, new()`.

**DN15** — **Abstract class** can have state (fields) and implementation. **Interface** is a contract. **Default interface methods** allow interfaces to provide a default implementation, reducing breaking changes when adding methods to interfaces.

**DN16** — **Middleware Pipeline**: `app.Use()` adds a middleware that calls `next()`. `app.Map()` branches the pipeline. `app.Run()` is a terminal middleware. **Ordering** is critical (e.g., Exception Handling must be first, Auth must be before Routing).

**DN17** — **Channel<T>** is an async-native producer-consumer collection. **BlockingCollection<T>** is synchronous/blocking. For backpressure, use a **Bounded Channel**: `Channel.CreateBounded<T>(capacity)`, which makes the producer wait (asynchronously) when the capacity is reached.

**DN18** — **Source Generators** create code at compile time. Unlike **Reflection** (runtime overhead) or **IL Weaving** (post-compile modification), they are part of the compilation. **Incremental Generators** are preferred because they only re-run when specific inputs change, significantly improving IDE performance.

**DN19** — **TPL Dataflow** is an actor-based library. **ActionBlock** (consumer), **TransformBlock** (processor), **BufferBlock** (queue). Compared to **Channels**, Dataflow is better for complex, multi-stage processing pipelines with built-in buffering and parallelism management.

**DN20** — **Minimal APIs** are a lightweight way to build APIs without Controllers. **Trade-offs**: Faster startup/less boilerplate, but harder to organize massive projects. **Route Groups** allow shared prefixes/middleware, and **Endpoint Filters** allow cross-cutting concerns (like validation) per endpoint.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable and ordered. **Set** is unordered and contains unique elements; **Frozenset** is the immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, making Python single-threaded for CPU-bound tasks. **Workaround**: Use `multiprocessing` to bypass the GIL by using separate memory spaces.

**P3** — **copy** is a shallow copy (copies references to nested objects). **deepcopy** is a recursive copy. **Example**: If `a = [[1]]`, `b = copy(a)` results in `b[0]` being the same object as `a[0]`. Modifying `b[0]` affects `a`.

**P4** — **Decorators** wrap a function.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values one by one, saving memory. **yield from** is used to delegate to a sub-generator (flattening).

**P6** — **asyncio event loop** manages async tasks. `asyncio.run()` starts the loop; `gather()` runs multiple tasks concurrently; `create_task()` schedules a task to run. You cannot use `time.sleep()` because it blocks the entire thread, stopping the event loop; use `asyncio.sleep()`.

**P7** — Python uses **C3 Linearization**. In the diamond inheritance `D(B, C)`, it checks `B`, then `C`, then `A`. In the code, `D().who()` calls `B.who()`. Since `B` doesn't define `who`, it looks at `A`. However, `C` also inherits from `A`. The MRO ensures `C` is checked before `A`. The output is **"C"** because `C` is higher in the MRO than `A` for class `D`.

**P8** — A **metaclass** is a class of a class (defines how classes are created). `__init_subclass__` is a simpler hook for modifying a class during inheritance. Use `__init_subclass__` for simple attribute injection; use a **metaclass** for deep structural changes (like enforcing API contracts).

**P9** — **threading** (I/O bound), **multiprocessing** (CPU bound). **concurrent.futures** provides a high-level interface for both. **Multiprocessing** requires **pickling** (serialization) to send data between processes, which can be slow for large objects.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, saving memory by using a fixed set of attributes. It prevents the dynamic creation of new attributes.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a more feature-rich third-party alternative; **conda** is a package/environment manager used heavily in data science.

**P12** — **Comprehensions** are concise ways to create lists/dicts/sets. They are generally faster and more readable than `map()` and `filter()` for simple operations.

**P13** — `==` checks **equality** (value); `is` checks **identity** (memory address). **Object interning** caches small integers (-5 to 256) so they point to the same memory address, making `is` return `True`.

**P14** — `*args` collects positional arguments into a tuple; `**kwargs` collects keyword arguments into a dict. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context Managers** handle setup/teardown. Use `__enter__`/`__exit__` in a class or `@contextmanager` decorator on a generator. Example: A database transaction manager.

**P16** — **Type hinting** provides static analysis. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generics), `Protocol` (structural typing). **Mypy** uses these to catch type errors without running the code.

**P17** — **Dunder methods**: `__repr__` (developer-facing string), `__str__` (user-facing), `__eq__` (equality), `__hash__` (for sets/dicts), `__getattr__` (fallback for missing attributes), `__getattribute__` (always called). If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** manage attribute access via `__get__`, `__set__`, and `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors.

**P19** — **Absolute imports** use the full path from the project root; **relative** use `.` or `..`. `sys.path` is the list of directories searched. `__init__.py` makes a directory a package. A **finder** locates the module; a **loader** executes it.

**P20** — **dataclasses** (std lib, simple), **attrs** (more powerful/features), **Pydantic** (runtime validation). Use **Pydantic** when dealing with external data (like JSON APIs) because it enforces types at runtime.
