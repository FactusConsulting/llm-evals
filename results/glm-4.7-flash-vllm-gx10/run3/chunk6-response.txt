**PS14 — Medium:** **PowerShell classes** (v5+) are C#-like objects. They differ by not supporting inheritance or interfaces (mostly). Use them for complex logic or data structures where functions are insufficient.

**PS15 — Medium:** **[CmdletBinding()]** enables advanced function features like `-Verbose`, `-Debug`, and `-WhatIf`. **SupportsShouldProcess** allows the cmdlet to ask for confirmation before making changes. **Begin/Process/End** blocks define the lifecycle of the function.

**PS16 — Medium:** **Providers** abstract data stores (FileSystem, Registry, Certificate). `Get-ChildItem` works across them. Access the registry like a file system using `HKLM:\`, `HKCU:\`, etc.

**PS17 — Hard:** **Runspaces** are isolated execution environments for threading. **[runspacepool]** manages a pool of runspaces. **[powershell]** objects represent a specific runspace instance. **ForEach-Object -Parallel** (v7+) is a simplified way to run parallel loops using runspaces.

**PS18 — Hard:** **PSScriptAnalyzer** is a static code analysis tool. It enforces rules (e.g., `PSPossibleIncorrectUsageWithNullValue`). Rules have severity levels. Custom rules can be written. It integrates into CI/CD via `Invoke-ScriptAnalyzer`.

**PS19 — Hard:** **$using:** scope allows accessing variables from the local scope in remote sessions, background jobs, and `ForEach-Object -Parallel`. **Serialization limits** (CLIXML depth) can break complex objects when passing them remotely.

**PS20 — Hard:** **DSC** is a declarative configuration management system. **Configurations** are scripts, **Resources** are the building blocks, **LCM** is the engine. Windows PS uses WinRM; PS7+ uses SSH. Modern IaC tools like **Terraform** or **Ansible** have largely replaced DSC for cloud infrastructure.
