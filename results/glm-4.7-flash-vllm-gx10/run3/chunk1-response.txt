You would choose VxLAN over VLAN when you need to extend Layer 2 networks across a WAN, require more than 4,094 VLANs, or need multi-tenancy isolation over a shared physical infrastructure.

1.  **Discover:** Client broadcasts to find a server.

3.  **Request:** Client requests the offered IP.
4.  **Ack:** Server confirms and assigns the IP.

**N14 — Easy:** A **hub** is a Layer 1 device that repeats signals to all ports. A **switch** is a Layer 2 device that filters traffic based on MAC addresses. A **router** is a Layer 3 device that routes packets between different networks. They primarily operate at Layer 1, Layer 2, and Layer 3, respectively.

**N15 — Easy:** Half-duplex allows communication in one direction at a time, while full-duplex allows simultaneous transmission in both directions. Modern Ethernet links use full-duplex communication.

**N16 — Medium:** The TTL (Time To Live) field prevents packets from looping indefinitely. **Traceroute** exploits this by sending packets with incrementing TTL values (starting at 1). The first router decrements TTL to 0 and sends an ICMP "Time Exceeded" message back to the source. The source then sends a packet with TTL=2, and so on, mapping the path hop by hop.

**N17 — Medium:** A NAT gateway translates IP addresses to allow multiple devices to share a single public IP. **Static NAT** creates a permanent 1-to-1 mapping. **Dynamic NAT** maps internal IPs to a pool of public IPs on a first-come, first-served basis. **PAT (Port Address Translation)** maps multiple internal IPs to a single public IP using different port numbers.

**N18 — Hard:** ECMP routes traffic over multiple equal-cost paths based on a hash of packet headers (e.g., source/dest IP, ports). If a request takes Path A and the reply takes Path B (asymmetric flow), stateful firewalls (like NAT or state tables) will drop the reply because they expect it on the same interface as the request. This can be mitigated by using symmetric routing or stateless firewalls.

**N19 — Hard:** The problem is that the TCP Window Size (64KB) is too small for the Bandwidth-Delay Product (10MB). **N20 — Hard:** 802.1Q trunk ports carry multiple VLANs using tags. To configure a single NIC for VLANs 10, 20, and 30 on Linux, you create sub-interfaces: `ip link add link eth0 name eth0.10 type vlan id 10`, `ip link add link eth0 name eth0.20 type vlan id 20`, etc. On the wire, the frame format is: Destination MAC (6) + Source MAC (6) + 802.1Q Tag (4) + EtherType (2) + Payload (46-1500) + FCS (4).

**L1 — Easy:** A **hard link** shares the same inode and data blocks as the original file; it is essentially another name for the same file. A **symbolic link** (symlink) is a separate file that points to the path of the original file, acting like a shortcut.

**L2 — Easy:** `find /var/log -type f -size +100M`

**L3 — Medium:** State D (Uninterruptible Sleep) means the process is blocked waiting for I/O operations that cannot be interrupted (e.g., disk I/O). You **can** kill it with `kill -9` (SIGKILL), but doing so may corrupt data or leave the disk in an inconsistent state because the process is stuck waiting for a hardware operation.

**L4 — Medium:** **cgroups v1** uses separate hierarchies for different controllers (memory, cpu, etc.), making management complex. **cgroups v2** uses a unified hierarchy where all controllers share the same tree, simplifying configuration. Systemd prefers v2 because of its unified structure and easier management of resource constraints.

**L5 — Medium:** **nftables** is the modern, extensible framework replacing iptables, using netlink and a single table structure. **iptables** is the legacy framework using tables and chains. The kernel handles both simultaneously; iptables can use the nftables backend (iptables-nft) for compatibility, or the legacy iptables-legacy backend.

**L6 — Medium:** The most likely cause is that a file was deleted but is still open by a running process. `df -h` counts allocated blocks on the filesystem, while `du -sh /*` counts files on disk. If a process holds a file descriptor to a deleted file, `df` shows the space as used, but `du` does not see it.

**L7 — Hard:** The boot process is:
1.  **UEFI Firmware:** Performs POST and loads the Boot Manager.
2.  **Bootloader (GRUB):** Loads the Linux kernel and initramfs into memory.
3.  **Kernel:** Initializes hardware and mounts the root filesystem (read-only).
4.  **Initramfs:** Loads necessary drivers to access the real root filesystem.
5.  **Root:** Switches to the real root filesystem.
6.  **systemd:** PID 1, mounts filesystems, starts services, and switches to the graphical target.

**L8 — Hard:** The `available` memory calculation is `free` + `buffers` + `cached` - `slab` - `unsafe`. Even with high `buff/cache`, if `free` memory is low, `available` will be low. Additionally, if the application is pinned in RAM (not reclaimable), it reduces `available`. Kernel tunables affecting this include `vm.overcommit_memory`, `vm.overcommit_ratio`, and `vm.swappiness`.

**L9 — Medium:** `ip netns` creates isolated network namespaces, isolating the network stack (interfaces, routing tables, iptables rules). Container runtimes use this to provide each container with its own virtual network interface and routing context, allowing them to communicate with the host and each other independently.

**L10 — Medium:** **SIGTERM** is a graceful termination signal that a process can catch to clean up resources. **SIGKILL** is an immediate termination signal that cannot be caught or ignored by the process. **SIGQUIT** also terminates the process but usually generates a core dump. Only SIGTERM and SIGQUIT can be caught.

**L11 — Easy:** **Stdout** (Standard Output, file descriptor 1) is the default output stream. **Stderr** (Standard Error, file descriptor 2) is the stream for error messages. **Stdin** (Standard Input, file descriptor 0) is the default input stream. To redirect stderr to a file while keeping stdout on the terminal, use `command 2>file`.

**L12 — Easy:** `chmod 755` sets permissions:
*   **7** (Owner): Read, Write, Execute.
*   **5** (Group): Read, Execute.
*   **5** (Others): Read, Execute.

**L13 — Easy:** The **root user** is the superuser with UID 0, possessing unrestricted access to the system. A user with **sudo** privileges can execute commands as root (or another user) temporarily, requiring authentication (password) for each command, providing granular control and auditability.

**L14 — Easy:** A package manager automates the installation, updating, and removal of software. The default package managers are **apt** (for Debian/Ubuntu) and **dnf** (for RHEL/Fedora).

**L15 — Easy:** `/etc/fstab` defines filesystems to be mounted automatically at boot. If an entry is misconfigured (e.g., wrong device, bad mount options), the system may fail to boot, enter a maintenance shell, or mount the filesystem read-only.

**L16 — Medium:** **LVM** (Logical Volume Manager) abstracts physical storage. **Physical Volumes (PV)** are physical disks or partitions. **Volume Groups (VG)** are collections of PVs. **Logical Volumes (LV)** are partitions of the VG. To extend an LV on a running system, use `lvextend -L +10G /dev/vg/lv` followed by `resize2fs` (for ext4) or `xfs_growfs` (for xfs).

**L17 — Hard:** The I/O scheduler determines the order of block I/O requests to optimize throughput or latency. **mq-deadline** is a fair, low-latency scheduler suitable for HDDs and general SSDs. **bfq** (Budget Fair Queuing) is designed for interactive workloads and SSDs to ensure fairness. **none** disables scheduling, which is best for SSDs as they handle queue depth natively. Change at runtime: `echo <scheduler> > /sys/block/sdX/queue/scheduler`.

**L18 — Hard:** Load average measures the average number of processes waiting to run (runnable) or uninterruptibly sleeping (D state). High load with low CPU usage often indicates I/O wait, where processes are blocked waiting for disk operations. To diagnose, use `top` to check `%wa` (I/O wait), `iostat` to check disk utilization, and `iotop` to identify which processes are causing the I/O.

**L19 — Hard:** **SELinux** (Security-Enhanced Linux) enforces Mandatory Access Control (MAC) policies on top of the Linux DAC (Discretionary Access Control). **Enforcing** mode enforces policies and denies access. **Permissive** mode logs violations but allows access. **Disabled** mode turns off SELinux. To troubleshoot a daemon failing to bind a port, check logs with `ausearch -m avc -ts recent`, use `audit2allow` to generate policy, or use `setsebool` to adjust boolean flags.

**L20 — Hard:** The kernel handles **page faults** when a process accesses a virtual page not currently in RAM. A **minor page fault** occurs when the page is in swap or backing store and just needs to be loaded into RAM (fast). A **major page fault** occurs when the page is not in swap or backing store (e.g., file not on disk) and requires disk I/O (slow). **Transparent Huge Pages (THP)** uses 2MB pages to reduce TLB pressure and improve performance for memory-intensive apps. It should be disabled for databases or HPC systems to avoid latency spikes caused by page splitting.
