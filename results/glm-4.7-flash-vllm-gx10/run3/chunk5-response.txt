*   **`__repr__`**: Unambiguous (debugging). **`__str__`**: User-friendly.
*   **`__eq__`**: Equality. **`__hash__`**: Hashing (must be consistent with `__eq__`).
*   **`__getattr__`**: Fallback. **`__getattribute__`**: Always called.
*   **Hash:** If `__eq__` is defined without `__hash__`, the object becomes unhashable.

**P18 — Hard:** **Descriptors** implement the protocol (`__get__`, `__set__`, `__delete__`).
*   **Property:** Uses descriptors to implement getters/setters.
*   **classmethod/staticmethod:** Use descriptors to bind methods to classes.

**P19 — Hard:** **Import System**.
*   **Absolute vs Relative:** `from pkg import mod` vs `from . import mod`.
*   **sys.path / PYTHONPATH:** Search paths.
*   **`__init__.py`**: Makes a directory a package.
*   **Namespace packages:** No `__init__.py`, supports subpackages.
*   **Finder/Loader:** Protocols for importing modules.

**P20 — Hard:** **Dataclasses** generate `__init__`, `__repr__`, `__eq__`. **attrs** is a third-party alternative with more flexibility. **Pydantic** adds validation and serialization.
*   **`__post_init__`**: Init hook.
*   **Frozen:** Immutable.
*   **Field factories:** Dynamic defaults.
*   **Inheritance:** MRO issues.
*   **Choose Pydantic** for validation-heavy apps (APIs) where data integrity is critical.
