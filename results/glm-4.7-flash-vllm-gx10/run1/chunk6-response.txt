**PS10 — Easy:** **Comparison operators:** `-eq` (equal), `-ne` (not equal), `-like` (wildcard), `-match` (regex), `-contains` (exists), `-in` (exists in list). Case-sensitive variants: `-ceq`, `-clike`, etc. `-contains` checks if an item exists in a collection; `-in` checks if a value exists in a collection.

**PS11 — Easy:** A **module** is a reusable collection of functions, cmdlets, etc. **Script module** (.psm1), **Manifest module** (.psd1), **Binary module** (.dll). `Import-Module` loads the module.

**PS12 — Easy:** **String interpolation** uses `$` inside double quotes. **Single quotes** are literal. **Here-strings** (`@"..."@`) are multi-line strings that preserve formatting.

**PS13 — Easy:** **`Get-Member`** displays the properties and methods of an object. **`Select-Object`** selects specific properties. **`Where-Object`** filters objects based on a condition.

**PS14 — Medium:** **PowerShell classes** (v5+) are similar to C# classes but with some limitations (no multiple inheritance, no interfaces). Use them for complex logic or when leveraging .NET types.

**PS15 — Medium:** **`[CmdletBinding()]`** enables common parameters (Verbose, Debug, ErrorAction). **`SupportsShouldProcess`** enables `Confirm` and `WhatIf`. **`Begin/Process/End`** blocks handle input processing.

**PS16 — Medium:** **Providers** (FileSystem, Registry, Environment) expose data stores as drives. **`Get-ChildItem`** works across providers. Registry is accessed like a file system (e.g., `HKLM:\Software`).

**PS17 — Hard:** **Runspaces** are isolated execution environments. **`[powershell]`** objects represent runspace instances. **`ForEach-Object -Parallel`** (v7+) is a simplified way to run parallel tasks. Manual runspace management offers more control but is complex.

**PS18 — Hard:** **PSScriptAnalyzer** is a static code analysis tool. It enforces rules (e.g., `PSPossibleIncorrectComparisonWithNull`). **Severity levels** (Warning, Error). Custom rules can be written. Integrated via CI/CD.

**PS19 — Hard:** **`$using:`** scope allows accessing variables from the caller's scope in remote sessions/jobs. **Serialization limits** (CLIXML depth) can break complex objects. Use simple types or `ConvertTo-Json` to bypass limits.

**PS20 — Hard:** **DSC** is declarative. **Configurations** define state, **Resources** implement it, **LCM** applies it. **JSON DSC** (PowerShell 7+) replaced the old MOF-based DSC. Modern IaC tools (Terraform, Ansible) have largely superseded DSC.
