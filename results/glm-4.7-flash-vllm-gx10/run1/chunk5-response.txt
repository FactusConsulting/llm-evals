**DN1 — Easy: What is the difference between class and struct in C#? When should you use a struct?**
*   **Class:** Reference type, allocated on heap, garbage collected, supports inheritance (single).
*   **Struct:** Value type, allocated on stack (or inline in a larger object), no inheritance (except interfaces), faster for small, immutable data.
*   **Use struct:** Small, immutable data carriers (like coordinates, RGB values), performance-critical paths where allocation overhead is a concern.

**DN2 — Easy: Explain the difference between IEnumerable<T> and IQueryable<T>. Why does this distinction matter for database queries?**
*   **IEnumerable:** In-memory collection. Executes immediately (eagerly) on the client side.
*   **IQueryable:** Abstract query provider. Builds an expression tree. Executes lazily against a data source (like SQL Server) when enumerated.
*   **Why it matters:** IQueryable allows the database to do the filtering/sorting, reducing network traffic and improving performance.

**DN3 — Medium: How does async/await work in C#? What is a Task vs a ValueTask? When should you use ValueTask?**
*   **Async/Await:** Compiler magic. `await` suspends the method, returning a `Task` to the caller, and resumes on the same thread (or thread pool) when the operation completes.
*   **Task:** Represents an asynchronous operation that may or may not complete. Always allocates memory.
*   **ValueTask:** Represents an asynchronous operation that might be synchronous. Can be allocated or reused. Zero-allocation optimization.
*   **Use ValueTask:** High-performance APIs where the operation is often synchronous (e.g., reading from a memory-mapped file or a fast in-memory cache) to avoid GC pressure.

**DN4 — Medium: Explain dependency injection in .NET. What are the three service lifetimes (Transient, Scoped, Singleton), and what is a common bug when injecting a Scoped service into a Singleton?**
*   **Transient:** New instance every time requested.
*   **Scoped:** One instance per HTTP request (or DI scope).
*   **Singleton:** One instance for the entire application lifetime.
*   **Bug:** If a Singleton service holds a reference to a Scoped service, the Scoped service might be disposed while the Singleton is still using it (or the Singleton might hold onto a disposed instance). This causes `ObjectDisposedException`.

**P2 — Easy: Explain the GIL (Global Interpreter Lock). What types of workloads does it affect, and what are the workarounds?**
*   **GIL:** Mutex protecting access to Python objects. Only one thread executes Python bytecode at a time.
*   **Affects:** CPU-bound tasks in CPython.
*   **Workarounds:** Multiprocessing (separate processes), using PyPy, using C extensions (release GIL), or using `asyncio` for I/O-bound tasks.

**P3 — Medium: What is the difference between deepcopy and copy? Give an example where shallow copy causes unexpected behavior.**
*   **copy:** Shallow copy. New container, but elements are references to original objects.
*   **deepcopy:** Deep copy. New container, and recursively copies nested objects.
*   **Example:** Modifying a nested list in a shallow copy modifies the original list because the inner list is shared.

**P4 — Medium: Explain Python decorators. Write a decorator that logs the execution time of any function.**
*   **Decorator:** A function that takes another function and returns a wrapper, modifying its behavior.
*   **Example:**
    ```python
    import time
    def timer(func):
        def wrapper(*args, **kwargs):
            start = time.perf_counter()
            result = func(*args, **kwargs)
            print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
            return result
        return wrapper
    ```

**P5 — Medium: What are generators and yield? How do they differ from returning a list? What is yield from?**
*   **Generator:** Function using `yield`. Returns an iterator. State is paused/resumed.
*   **Difference:** Memory efficient. Doesn't create the whole list in memory at once.
*   **yield from:** Delegates to another generator or iterable. Used to flatten generators.

**P6 — Medium: Explain Python's asyncio event loop. What is the difference between asyncio.run(), asyncio.gather(), and asyncio.create_task()? Why can't you call time.sleep() inside an async function?**
*   **Event Loop:** Manages async tasks.
*   **run():** Creates loop, runs coroutine, closes loop.
*   **gather():** Runs multiple coroutines concurrently, returns results.
*   **create_task():** Schedules a coroutine to run in the loop.
*   **time.sleep():** Blocks the thread. Use `asyncio.sleep()` instead.

**P7 — Hard: Explain Python's MRO (Method Resolution Order). What algorithm does Python 3 use? What happens with diamond inheritance, and why does the following print what it does?**
*   **MRO:** Determines method lookup order.
*   **Algorithm:** C3 Linearization (Depth-First, Left-to-Right, consistent).
*   **Diamond:** `D(B, C)`. `B` and `C` inherit from `A`.
*   **Output:** "C". `D` looks for `who`. It checks `B` (no), then `C` (yes). It does *not* look at `A` again because `C` is the first valid hit.
