## Linux (20 questions)

**L1 — Easy:** A **Hard Link** shares the same inode and data blocks as the original file. A **Symbolic Link** (Symlink) is a separate file that points to the path of the target file.

**L2 — Easy:** `find /var/log -type f -size +100M`

**L3 — Medium:** State **D** (Uninterruptible Sleep) means the process is blocked waiting for disk I/O (e.g., reading a file from a slow disk). **kill -9** (SIGKILL) cannot interrupt this state; the process must wait for the I/O to complete or the system must be rebooted.

**L4 — Medium:** **cgroups v1** uses separate hierarchies for different resource types (cpu, memory, devices). **cgroups v2** uses a unified hierarchy where all resources are controlled in one tree. **systemd** prefers v2 for its simplicity and unified resource management.

**L5 — Medium:** **nftables** is the modern, packet-filtering framework replacing iptables. **iptables** uses legacy tables (filter, nat, mangle). The kernel handles both via the Netfilter hooks, but nftables is the recommended interface for new configurations.

**L6 — Medium:** The filesystem is likely **out of inodes**. `df` reports used blocks, while `du` reports used space by files. If there are many small files, the inode count (which is fixed at filesystem creation) can be exhausted even if disk space remains.

**L7 — Hard:** 1. **UEFI Firmware** initializes hardware. 2. **Bootloader** (e.g., GRUB) loads the kernel. 3. **Kernel** boots and mounts the **Initramfs** (temporary root filesystem for drivers). 4. **Initramfs** mounts the real root filesystem. 5. **systemd** (PID 1) takes over, starts services, and brings the system to the `multi-user.target` or `graphical.target`.

**L8 — Hard:** `available` memory is calculated as `free + buffers + cache - (shrinkable cache)`. Even with high `buff/cache`, if `free` is negative (meaning the system is overcommitted), `available` drops. The OOM killer kills based on **RSS** (Resident Set Size), not available memory. Tunables: `vm.overcommit_memory` (0/1/2) and `vm.swappiness`.

**L9 — Medium:** `ip netns` creates isolated network namespaces. Container runtimes (like Docker) use this to provide each container with its own network stack (interfaces, routing tables, iptables rules), isolating network traffic from the host.

**L10 — Medium:** **SIGTERM** (15) requests graceful termination (process can catch and clean up). **SIGKILL** (9) forces immediate termination (cannot be caught). **SIGQUIT** (3) requests termination and generates a core dump (can be caught).

**L11 — Easy:** **Stdin** (0) is standard input, **Stdout** (1) is standard output, **Stderr** (2) is standard error. To redirect stderr to a file while keeping stdout on the terminal: `command 2>error.log`.

**L12 — Easy:** `chmod 755` sets permissions:
*   **7** (rwx): Owner can read, write, execute.
*   **5** (r-x): Group can read and execute.
*   **5** (r-x): Others can read and execute.

**L13 — Easy:** The **root user** is the superuser with UID 0 and absolute control over the system. A user with **sudo** privileges is a regular user who can execute commands as root by authenticating with their own password.

**L14 — Easy:** A package manager installs, updates, and manages software dependencies. **Debian/Ubuntu:** `apt` or `dpkg`. **RHEL/Fedora:** `dnf` or `yum`.

**L15 — Easy:** `/etc/fstab` defines filesystems to mount automatically at boot. If an entry is misconfigured (e.g., wrong device or mount options), the system may fail to boot or mount specific drives, often requiring a rescue mode.

**L16 — Medium:** **LVM** abstracts physical disks into **Physical Volumes (PVs)**, which are combined into **Volume Groups (VGs)**, which are then split into **Logical Volumes (LVs)**. To extend an LV on a running system: `lvextend -L +10G /dev/vg/lv` followed by `resize2fs /dev/vg/lv`.

**L17 — Hard:** The I/O scheduler manages the queue of block I/O requests. **mq-deadline** (deadline) ensures fairness and low latency (good for databases). **bfq** (Budget Fair Queuing) ensures fairness and prevents starvation (good for HDDs). **none** disables queueing for maximum raw throughput. Change at runtime: `echo bfq > /sys/block/sda/queue/scheduler`.

**L18 — Hard:** Load average measures the number of processes waiting to run (CPU) and processes blocked on I/O (Disk). High load with low CPU usage usually indicates **I/O wait**. Diagnose using `iostat` (disk stats), `iotop` (process I/O), or `vmstat` (b/s columns).

**L19 — Hard:** **SELinux** enforces Mandatory Access Control (MAC) by labeling processes and files with security contexts. **Enforcing** mode blocks violations. **Permissive** mode logs violations but allows them. **Disabled** mode turns it off. To troubleshoot a port binding issue, check logs with `ausearch -m avc -ts recent` and use `audit2allow` to generate policy rules.

**L20 — Hard:** A **Page Fault** occurs when a process accesses a virtual memory page that is not currently in RAM. A **Minor Page Fault** is satisfied by swapping a page from disk to RAM (or using a shared page). A **Major Page Fault** requires disk I/O to load a page from disk. **Transparent Huge Pages (THP)** can improve performance by using 2MB pages instead of 4KB pages, but can cause latency spikes (Hugepages). Disable THP if latency is critical.
