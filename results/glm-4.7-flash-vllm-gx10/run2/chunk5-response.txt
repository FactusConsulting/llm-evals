**DN3 — Medium:** **Async/await** is compiler syntax that allows a method to pause execution without blocking a thread, resuming when the awaited task completes. A **Task** represents an asynchronous operation that may or may not be complete. A **ValueTask** is an optimized wrapper that can represent a completed operation synchronously to avoid allocation.
*   **Use ValueTask** when the operation is likely to complete very quickly or is already completed, as it avoids the heap allocation of a standard Task.

**DN4 — Medium:** **Dependency Injection (DI)** is a design pattern where classes receive their dependencies through constructors or properties rather than creating them directly. The three lifetimes are:

**DN6 — Medium:** The **Garbage Collector (GC)** automatically manages memory. **Generations** (Gen 0, 1, 2) optimize collection: Gen 0 contains short-lived objects (collected frequently); Gen 1 contains objects surviving Gen 0; Gen 2 contains long-lived objects (collected rarely).     *   `__str__`: User-friendly representation.
    *   `__eq__`: Equality.
    *   `__hash__`: Hash for sets/dicts. If `__eq__` is defined, `__hash__` should be defined (or set to `None`).
    *   `__getattr__`: Fallback for attribute access.
    *   `__getattribute__`: Called for *all* attribute access.

**P18 — Hard:** **Descriptors** implement the protocol `__get__`, `__set__`, `__delete__`.
*   **Usage:** `property`, `classmethod`, and `staticmethod` are implemented using descriptors under the hood to manage binding and access.

**P19 — Hard:** **Import system**:
    *   **Relative vs Absolute:** `from . import m` vs `from pkg import m`.
    *   **sys.path / PYTHONPATH:** Search paths.
    *   **__init__.py:** Marks a package, enables `from pkg import *`.
    *   **Namespace packages:** No `__init__.py`, allows merging packages.
    *   **Finder/Loader:** Protocol for importing modules (PEP 451).

**P20 — Hard:** **Dataclasses** (`@dataclass`) auto-generate `__init__`, `__repr__`, etc. **attrs** is a third-party library with more features. **Pydantic** adds validation and serialization.
*   **Features:** `__post_init__` (hook), `field` factories, frozen dataclasses.
*   **Choice:** Use Pydantic for data validation and complex schemas; use standard dataclasses for simple POJOs.
