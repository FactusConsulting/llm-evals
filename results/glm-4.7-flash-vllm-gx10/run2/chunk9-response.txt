**SC6-C**
*   **AWS Direct Connect:** Dedicated, expensive, high bandwidth (10Gbps+), private network. Fits zero-trust by providing a private, encrypted link.
*   **Second VPN Tunnel:** Cheaper, less bandwidth (1Gbps), uses ECMP. Fits zero-trust but is a shared resource.
*   **Hybrid Mesh (Tailscale/Netbird):** Software-defined, easy to manage, uses NAT traversal. Fits zero-trust by providing mTLS and consistent routing, but may not meet strict enterprise compliance requirements for on-prem connectivity.
*   **Routing Changes:**
    *   Direct Connect: Requires static routes or BGP.
    *   VPN: Requires dynamic routing (BGP).
    *   Mesh: Handles routing automatically via the mesh overlay.

**SC7-A**
1.  **Manual `tofu apply`:** Dangerous because there is no state locking. If two developers run this simultaneously, they overwrite each other's state, leading to data loss or configuration corruption.
2.  **Diverged Helm values:** The values files in staging/production are not in Git. This leads to inconsistent environments and drift from the "source of truth."
3.  **Direct `kubectl edit`:** This creates state that is not managed by IaC. If the IaC is re-applied, these changes will be lost, causing outages.
4.  **Data Loss:** Running `tofu apply` without locking can corrupt the state file.
5.  **Outage:** Inconsistent configurations between environments can lead to unexpected behavior in production.

    *   MinIO: Erasure Coding (for durability) or Replication (for DR).
