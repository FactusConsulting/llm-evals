## Networking

N1 — Easy: What is the difference between a Layer 2 switch and a Layer 3 switch?
A Layer 2 switch operates at the Data Link layer (OSI Layer 2) and forwards frames based on MAC addresses. It creates separate collision domains but a single broadcast domain. A Layer 3 switch operates at the Network layer (OSI Layer 3) and can route packets between different IP subnets, effectively creating separate broadcast domains. Layer 3 switches combine the functionality of a switch and a router.

N2 — Easy: A host has IP 10.0.5.37/20. What is the network address and broadcast address?
The network address is 10.0.0.0/20 (subnet mask 255.255.240.0). The broadcast address is 10.0.15.255.

N3 — Medium: Explain the TCP three-way handshake. What happens if the final ACK is lost?
The TCP three-way handshake establishes a connection between two hosts:
1. Host A sends a SYN (synchronize) packet to Host B.
2. Host B responds with a SYN-ACK (synchronize-acknowledge) packet.
3. Host A sends an ACK (acknowledge) packet to Host B.
If the final ACK is lost, Host B will retransmit the SYN-ACK packet. Host A will eventually time out and retransmit the ACK. If the ACK is still lost, the connection will eventually fail due to repeated timeouts.

N4 — Medium: What is the difference between SNAT and DNAT? Give a practical example of each.
SNAT (Source NAT) modifies the source IP address of outgoing packets. Example: A company uses a single public IP address for all internal hosts to access the internet.
DNAT (Destination NAT) modifies the destination IP address of incoming packets. Example: A web server behind a firewall is accessed using a public IP address, while the server itself uses a private IP address.

N5 — Medium: You run `curl -v https://example.com` and get `SSL: certificate subject name does not match target host name`. List 3 possible causes.
1. The SSL certificate is issued for a different domain name.
2. The SSL certificate is issued for an IP address instead of a domain name.
3. The SSL certificate is issued for a different subdomain or wildcard domain.

N6 — Medium: Explain the difference between a VLAN and a VxLAN. When would you choose VxLAN over VLAN?
A VLAN (Virtual LAN) is a logical segmentation of a physical network at Layer 2. It uses 12-bit VLAN IDs, limiting the number of VLANs to 4094. VxLAN (Virtual Extensible LAN) is a Layer 2 overlay network that encapsulates Ethernet frames within UDP packets. It uses 24-bit VNI (VxLAN Network Identifier) IDs, allowing up to 16 million VLANs. Choose VxLAN over VLAN when you need to extend Layer 2 networks across multiple physical networks or data centers.

N7 — Hard: A Linux host has two NICs: eth0 (10.0.0.5/24, default gw 10.0.0.1) and eth1 (192.168.1.5/24). Traffic arriving on eth1 from 192.168.1.0/24 is being replied via eth0. Why, and how do you fix it with policy-based routing?
The host uses the default gateway (eth0) for all outbound traffic, including replies to eth1 traffic. To fix this, configure policy-based routing to route traffic from 192.168.1.0/24 via eth1. This involves adding a new routing table, setting up rules to match the source IP, and updating the routing table to use eth1 for the specific subnet.

N8 — Hard: Explain how BGP path selection works. List at least 5 attributes in the correct order of preference.
BGP path selection uses a set of attributes to determine the best path. The order of preference is:
1. Weight (Cisco-specific)
2. Local Preference
3. AS Path length
4. Origin type (IGP < EGP < Incomplete)
5. Multi-Exit Discriminator (MED)
6. IGP metric (e.g., OSPF cost)
7. External BGP path vs. Internal BGP path
8. Router ID

N9 — Hard: What is the MTU implication of running VxLAN over an IPsec tunnel? Show the math for the maximum inner payload if the physical MTU is 1500.
VxLAN adds 50 bytes of overhead (8-byte UDP header + 8-byte IP header + 8-byte Ethernet header + 8-byte VxLAN header). IPsec adds 20-50 bytes of overhead (depending on the mode and options). Assuming IPsec adds 50 bytes, the total overhead is 100 bytes. The maximum inner payload is 1500 - 100 = 1400 bytes.

N10 — Medium: What is the purpose of ARP, and what problem does Gratuitous ARP solve?
ARP (Address Resolution Protocol) maps IP addresses to MAC addresses. Gratuitous ARP is used to announce a new IP address or to refresh the ARP cache of other hosts. It helps prevent IP address conflicts and ensures that the correct MAC address is associated with an IP address.

N11 — Easy: What is the difference between a public IP address and a private IP address? List the three private IPv4 ranges defined in RFC 1918.
Public IP addresses are globally unique and routable on the internet. Private IP addresses are used within private networks and are not routable on the internet. The three private IPv4 ranges are:
1. 10.0.0.0/8
2. 172.16.0.0/12
3. 192.168.0.0/16

N12 — Easy: What is DNS, and what is the difference between an A record, a CNAME record, and an AAAA record?
DNS (Domain Name System) translates domain names to IP addresses. An A record maps a domain name to an IPv4 address. A CNAME record maps a domain name to another domain name (an alias). An AAAA record maps a domain name to an IPv6 address.

N13 — Easy: What is DHCP, and what four-step process (DORA) does a client use to obtain an IP address from a DHCP server?
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network configuration parameters to devices. The DORA process is:
1. Discover: Client broadcasts a DHCP Discover message.
2. Offer: Server responds with a DHCP Offer message.
3. Request: Client sends a DHCP Request message to accept the offer.
4. Acknowledge: Server sends a DHCP Acknowledge message to confirm the assignment.

N14 — Easy: What is the difference between a hub, a switch, and a router? At which OSI layer does each primarily operate?
A hub operates at the Physical layer (OSI Layer 1) and broadcasts all incoming traffic to all ports. A switch operates at the Data Link layer (OSI Layer 2) and forwards traffic based on MAC addresses. A router operates at the Network layer (OSI Layer 3) and forwards traffic based on IP addresses.

N15 — Easy: Explain the difference between half-duplex and full-duplex communication. Which mode do modern Ethernet links use?
Half-duplex allows data to be transmitted in only one direction at a time. Full-duplex allows simultaneous two-way communication. Modern Ethernet links use full-duplex mode.

N16 — Medium: What is the purpose of the TTL field in an IP packet? How does traceroute exploit it to map the network path?
The TTL (Time to Live) field prevents packets from looping indefinitely by decrementing with each hop. When it reaches zero, the packet is discarded, and an ICMP Time Exceeded message is sent back. Traceroute exploits this by sending packets with incrementing TTL values and recording the responses from each hop.

N17 — Medium: Explain what a NAT gateway does. What is the difference between static NAT, dynamic NAT, and PAT (port address translation)?
A NAT gateway translates private IP addresses to public IP addresses for internet access. Static NAT maps a private IP to a specific public IP. Dynamic NAT maps private IPs to a pool of public IPs. PAT (Port Address Translation) maps multiple private IPs to a single public IP using different port numbers.

N18 — Hard: Explain how ECMP (Equal-Cost Multi-Path) routing works. What hashing strategies are commonly used, and what problems can arise with asymmetric flows when stateful firewalls are involved?
ECMP distributes traffic across multiple equal-cost paths to a destination. Common hashing strategies include source/destination IP, source/destination port, and source/destination MAC. Asymmetric flows can cause issues with stateful firewalls, as the return path may not match the original path, leading to dropped packets.

N19 — Hard: A TCP connection between two hosts shows high latency but packet captures show no drops. The bandwidth-delay product is 10MB but the TCP window size maxes out at 64KB. Explain the problem and how TCP window scaling (RFC 1323) solves it.
The problem is that the TCP window size is too small to fully utilize the available bandwidth-delay product. TCP window scaling allows the window size to be increased beyond 64KB by using a scaling factor, enabling the connection to fully utilize the available bandwidth.

N20 — Hard: Describe how 802.1Q trunk ports work. A server with a single NIC needs to communicate on VLANs 10, 20, and 30. Explain how to configure this on Linux using sub-interfaces and what the frame format looks like on the wire.
802.1Q trunk ports carry traffic for multiple VLANs by tagging frames with a VLAN ID. On Linux, configure sub-interfaces for each VLAN using `vconfig` or `ip link`. The frame format includes a 4-byte 802.1Q tag with a VLAN ID and a priority field, followed by the original Ethernet frame.

## Linux

L1 — Easy: What is the difference between a hard link and a symbolic link?
A hard link is a direct reference to the same inode as the original file. A symbolic link (symlink) is a file that contains the path to another file. Hard links cannot point to directories, while symlinks can.

L2 — Easy: How do you find all files larger than 100MB under /var/log?
Use the `find` command: `find /var/log -type f -size +100M`

L3 — Medium: A process is in state D (uninterruptible sleep). What does this mean, and can you kill it with kill -9?
A process in state D is in uninterruptible sleep, typically waiting for I/O. It cannot be killed with `kill -9` because it is not responding to signals. The process must be resolved by the system or the resource it is waiting for.

L4 — Medium: Explain the difference between cgroups v1 and cgroups v2. Which does systemd prefer and why?
cgroups v1 is the original implementation with separate hierarchies for different subsystems. cgroups v2 is a unified hierarchy with improved features and security. systemd prefers cgroups v2 because it provides a more consistent and secure interface for resource management.

L5 — Medium: What is the difference between nftables and iptables? How does the kernel handle both simultaneously?
nftables is a newer, more efficient, and flexible replacement for iptables. The kernel can handle both simultaneously, but nftables is the recommended tool for new configurations. iptables is still supported for backward compatibility.

L6 — Medium: You run `df -h` and see a filesystem at 100%, but `du -sh /*` totals far less. What is the most likely cause?
The most likely cause is that the filesystem has inodes that are full, not the disk space. Check the inode usage with `df -i`.

L7 — Hard: Explain the Linux boot process from UEFI firmware to a running systemd target. Cover: firmware, bootloader, kernel, initramfs, root, systemd.
1. UEFI firmware initializes hardware and loads the bootloader (e.g., GRUB).
2. The bootloader loads the kernel and initramfs.
3. The kernel initializes hardware and mounts the root filesystem.
4. The initramfs provides temporary root filesystem and runs initial setup.
5. The kernel mounts the real root filesystem and starts systemd.
6. systemd starts services and targets, bringing the system to the desired state.

L8 — Hard: A server has 64GB RAM but only 2GB swap. free -h shows 60GB used, 1GB available, 15GB of that is buff/cache. The OOM killer fires. Explain why available can be low even with high buff/cache, and what kernel tunables affect this behavior.
Available memory is the amount of memory that can be used for new allocations without swapping. High buff/cache usage can reduce available memory because the kernel may not reclaim it quickly enough. Kernel tunables like `vm.swappiness` and `vm.vfs_cache_pressure` affect how aggressively the kernel reclaims memory from buffers and caches.

L9 — Medium: What does `ip netns` do, and how is it used by container runtimes?
`ip netns` manages network namespaces, which are isolated network environments. Container runtimes use network namespaces to provide each container with its own network stack, including interfaces, routing tables, and firewall rules.

L10 — Medium: Explain the difference between SIGTERM, SIGKILL, and SIGQUIT. Which can be caught by the process?
SIGTERM is a request to terminate gracefully and can be caught. SIGKILL forces immediate termination and cannot be caught. SIGQUIT is a request to terminate and generate a core dump, and can be caught.

L11 — Easy: What is the difference between stdout, stderr, and stdin? How do you redirect stderr to a file while still displaying stdout on the terminal?
stdout (standard output) is for normal program output. stderr (standard error) is for error messages. stdin (standard input) is for user input. To redirect stderr to a file while displaying stdout on the terminal, use `command > output.txt 2>&1` or `command 2> error.txt`.

L12 — Easy: What does the chmod 755 command do? Explain what each digit represents.
`chmod 755` sets the permissions of a file or directory. The first digit (7) is for the owner (read, write, execute). The second digit (5) is for the group (read, execute). The third digit (5) is for others (read, execute).

L13 — Easy: What is the difference between the root user and a user with sudo privileges?
The root user has full administrative privileges. A user with sudo privileges can execute specific commands as root, but does not have full root access by default.

L14 — Easy: What is a package manager? Name the default package managers for Debian/Ubuntu and RHEL/Fedora.
A package manager is a tool for installing, updating, and removing software packages. Debian/Ubuntu use `apt` (Advanced Package Tool). RHEL/Fedora use `yum` (Yellowdog Updater, Modified) or `dnf` (Dandified Yum).

L15 — Easy: What is the /etc/fstab file used for? What happens if an entry is misconfigured?
The `/etc/fstab` file contains information about disk partitions and how they should be mounted at boot. If an entry is misconfigured, the system may fail to mount the partition, leading to errors or an unbootable system.

L16 — Medium: Explain what LVM (Logical Volume Manager) is. What are physical volumes, volume groups, and logical volumes, and how do you extend a logical volume on a running system?
LVM is a system for managing disk storage. Physical volumes (PVs) are physical disks or partitions. Volume groups (VGs) are collections of PVs. Logical volumes (LVs) are virtual partitions created from VG space. To extend an LV, add a new PV to the VG and then extend the LV using `lvextend`.

L17 — Hard: Explain how the Linux kernel's I/O scheduler works. Compare mq-deadline, bfq, and none schedulers. When would you choose each, and how do you change the scheduler for a block device at runtime?
The I/O scheduler manages disk I/O requests. mq-deadline is a deadline-based scheduler for multi-queue devices. bfq (Budget Fair Queueing) prioritizes interactive workloads. none is a no-op scheduler for direct access. Choose mq-deadline for SSDs, bfq for interactive workloads, and none for direct access. Change the scheduler using `echo scheduler_name > /sys/block/device_name/queue/scheduler`.

L18 — Hard: A system is experiencing intermittent high load averages but CPU usage is low. Explain what load average actually measures on Linux, why I/O wait can inflate it, and how you would diagnose whether the bottleneck is CPU, disk, or network using standard tools.
Load average measures the number of processes in the run queue or waiting for I/O. High I/O wait can inflate load average because processes are waiting for disk I/O. Diagnose using `top` (CPU usage), `iostat` (disk I/O), and `netstat` (network usage).

L19 — Hard: Explain how SELinux enforces mandatory access control. What is the difference between enforcing, permissive, and disabled modes? How do you troubleshoot a daemon that fails to bind a non-standard port due to SELinux policy?
SELinux enforces mandatory access control by defining security policies that restrict processes and users. Enforcing mode enforces policies. Permissive mode logs violations but does not enforce them. Disabled mode turns SELinux off. Troubleshoot using `audit2why` to analyze SELinux denials and `semanage` to modify policies.

L20 — Hard: Describe how the Linux kernel's virtual memory subsystem handles page faults. What is the difference between a minor and a major page fault? How does transparent huge pages (THP) affect application performance, and when would you disable it?
The virtual memory subsystem handles page faults by loading pages from disk into memory. A minor page fault occurs when the page is in memory but not in the process's address space. A major page fault occurs when the page is not in memory. THP improves performance by using larger pages, but can cause issues with memory fragmentation. Disable THP using `echo never > /sys/kernel/mm/transparent_hugepage/enabled`.
