## .NET / C#

**DN1** — **Class** is a reference type (stored on the heap); **struct** is a value type (stored on the stack or inline). Use a **struct** for small, immutable data structures (typically < 16 bytes) that have no identity and are frequently created/destroyed to avoid GC pressure.

**DN2** — **IEnumerable<T>** is for in-memory collections (LINQ-to-Objects); it iterates through the entire collection in memory. **IQueryable<T>** is for out-of-memory providers (LINQ-to-SQL/EF); it uses expression trees to translate LINQ into SQL. This matters because `IEnumerable` pulls all data into memory before filtering, while `IQueryable` filters at the database level.

**DN3** — **async/await** uses a state machine to allow non-blocking asynchronous operations. A **Task** is a class (heap-allocated) representing an ongoing operation. A **ValueTask** is a struct; use it when the result is often already available synchronously (e.g., from a cache) to avoid the overhead of allocating a `Task` object.

**DN4** — **Dependency Injection (DI)** is a design pattern where objects receive their dependencies from an external source rather than creating them. 
- **Transient**: New instance every time requested.
- **Scoped**: One instance per client request (e.g., HTTP request).
- **Singleton**: One instance for the lifetime of the application.
**Bug**: Injecting a **Scoped** service into a **Singleton** creates a "Captive Dependency," where the Scoped service lives as long as the Singleton, potentially causing stale data or `ObjectDisposedException`.

**DN5** — **string** is an immutable heap-allocated object. **ReadOnlySpan<char>** is a stack-allocated view into a contiguous memory region. Use **Span<T>** for high-performance slicing and parsing to achieve "zero-copy" operations, significantly reducing heap allocations and GC pressure.

**DN6** — .NET uses a generational GC. **Gen 0** (newest objects), **Gen 1** (buffer), **Gen 2** (long-lived). **Large Object Heap (LOH)** is for objects >85,000 bytes; it is not compacted by default to save CPU. **IDisposable** is required to manually release unmanaged resources (file handles, DB connections) because the GC only manages managed memory.

**DN7** — **ConfigureAwait(false)** tells the task not to attempt to marshal the continuation back to the original `SynchronizationContext`. Use it in library code to improve performance and prevent deadlocks. Do **NOT** use it in UI applications (WPF/WinForms) if you need to access UI elements on the main thread.

**DN8** — **Primary constructors** allow parameters in the class declaration. **Collection expressions** use `[]`. **FrozenDictionary** is an immutable, highly optimized read-only dictionary.
```csharp
// Minimal Example
public class MyService(IDbContext db) { 
    public void DoWork() => db.Save(); 
}
```

**DN9** — The `DbContext` is not thread-safe. High concurrency causes multiple threads to attempt to use the same instance simultaneously. **Fix**: Ensure `DbContext` is registered as **Scoped** (the default) and never shared across threads. If using `Task.WhenAll`, create a new scope/context per task.

**DN10** — **record** provides value-based equality for reference types. **record struct** provides value-based equality for value types. Use **record** for DTOs/Data models where equality is based on data; use **class** when identity (reference) matters.

**DN11** — **ref**: Pass by reference (read/write). **out**: Pass by reference (must be assigned inside the method). **in**: Pass by reference (read-only).

**DN12** — **Nullable reference types** (`string?`) are compiler hints for static analysis to prevent `NullReferenceException`. **Nullable value types** (`int?`) are `Nullable<T>` structs that actually allow a value to be null.

**DN13** — **LINQ** is Language Integrated Query. **Method syntax** uses extension methods (`.Where()`). **Query syntax** uses SQL-like keywords (`from...where`). **Deferred execution** means the query is not executed until you iterate over it (e.g., via `foreach` or `.ToList()`).

**DN14** — **Constraints**: `T : class` (reference type), `T : struct` (value type), `T : new()` (parameterless constructor), `T : IComparable<T>` (can be compared). Combine them to narrow the type: `where T : class, new()`.

**DN15** — **Abstract class** can have state (fields) and implementation; **Interface** is a pure contract. **Default interface methods** allow adding new methods to interfaces without breaking existing implementations, blurring the line slightly.

**DN16** — **Middleware** is a pipeline of components. **app.Use()** adds a delegate that can call the next; **app.Map()** branches the pipeline; **app.Run()** is a terminal middleware. **Ordering** is critical (e.g., Auth must come before Routing). **Exception handling** middleware should be placed early in the pipeline to catch errors from subsequent steps.

**DN17** — **Channel<T>** is an async-native producer-consumer collection. **BlockingCollection<T>** is a thread-blocking collection. For backpressure, use a **Bounded Channel**: `Channel.CreateBounded<T>(capacity)`. When the capacity is reached, the producer asynchronously waits.

**DN18** — **Source Generators** generate code at compile-time. Unlike **Reflection** (runtime) or **IL Weaving** (post-compile), they are part of the compilation process. **Incremental generators** are preferred because they only re-run when specific inputs change, significantly improving build performance.

**DN19** — **TPL Dataflow** is a library for building actor-based pipelines. **ActionBlock** (consumer), **TransformBlock** (mapper), **BufferBlock** (queue). **Channels** are lighter and better for simple producer-consumer; **Dataflow** is better for complex directed acyclic graph (DAG) pipelines.

**DN20** — **Minimal APIs** are lightweight, high-performance endpoints. **Controllers** offer more structure for large APIs. **Trade-offs**: Minimal APIs have less boilerplate but can become messy; Controllers have better built-in support for complex metadata. **Route groups** organize endpoints, and **Endpoint filters** act like middleware for specific routes.

## Python

**P1** — **List** is mutable and ordered; **Tuple** is immutable. **Set** is a mutable collection of unique elements; **Frozenset** is an immutable version of a set.

**P2** — The **GIL** prevents multiple native threads from executing Python bytecodes at once, making Python single-threaded for CPU-bound tasks. **Workarounds**: Use `multiprocessing` to bypass the GIL or use C-extensions (like NumPy) that release the GIL.

**P3** — **copy** (shallow) copies the object but keeps references to nested objects. **deepcopy** recursively copies everything. **Example**: If `a = [[1]]`, `b = copy(a)` means `b[0].append(2)` also changes `a`.

**P4** — **Decorators** wrap a function to modify behavior.
```python
import time
def log_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper
```

**P5** — **Generators** use `yield` to return values lazily (one by one), saving memory. **yield from** is used to delegate to a sub-generator (flattening).

**P6** — **asyncio.run()** starts the loop; **gather()** runs multiple coroutines concurrently; **create_task()** schedules a coroutine. You cannot use `time.sleep()` because it blocks the entire thread; use `await asyncio.sleep()`.

**P7** — Python uses **C3 Linearization**. For `D(B, C)`, the MRO is `D -> B -> C -> A -> object`. In the code, `D().who()` looks at `D` (no `who`), then `B` (no `who`), then `C` (has `who`). It prints **"C"**.

**P8** — A **metaclass** is a class of a class. **__init_subclass__** is a simpler way to customize class creation. Use `__init_subclass__` for simple attribute injection; use a **metaclass** for complex logic like automatic registration or enforcing strict API constraints.

**P9** — **multiprocessing** (separate memory, bypasses GIL), **threading** (shared memory, GIL-limited), **concurrent.futures** (high-level abstraction). **Multiprocessing** requires data to be **pickled** (serialized) to move between processes, which can be slow.

**P10** — **\_\_slots\_\_** tells Python not to use a `__dict__` for an instance, saving memory and speeding up attribute access. It prevents the creation of new attributes not defined in `__slots__`.

**P11** — A **virtual environment** isolates dependencies. **venv** is the standard library tool; **virtualenv** is a faster third-party alternative; **conda** is a package/env manager used heavily in data science for non-Python dependencies.

**P12** — **Comprehensions** (`[x for x in...]`) are more readable and often faster than `map()` or `filter()`. Use them for concise creation of lists, dicts, or sets.

**P13** — `==` checks for **equality** (value); `is` checks for **identity** (memory address). **Object interning** caches small integers (-5 to 256) so that `a is b` returns `True` for them.

**P14** — `*args` is a tuple of positional arguments; `**kwargs` is a dict of keyword arguments. `/` marks parameters that **must** be positional; `*` marks parameters that **must** be keyword-only.

**P15** — **Context managers** handle setup/teardown. Use `__enter__`/`__exit__` in a class or `@contextmanager` decorator on a generator. Example: A database transaction manager.

**P16** — **Type hinting** improves code clarity. `Union[int, str]` (either), `Optional[int]` (int or None), `Literal["a", "b"]` (specific values), `TypeVar` (generics), `Protocol` (structural typing/duck typing). **mypy** uses these for static type checking.

**P17** — `__repr__` (dev-facing), `__str__` (user-facing), `__eq__` (value equality), `__hash__` (for dict keys), `__getattr__` (fallback for missing attrs), `__getattribute__` (called for *every* access). If you define `__eq__` but not `__hash__`, the object becomes unhashable.

**P18** — **Descriptors** are objects that implement `__get__`, `__set__`, or `__delete__`. `property`, `classmethod`, and `staticmethod` are all built-in descriptors.

**P19** — **Absolute imports** use the full path; **relative** use dots (`.`). `sys.path` is the list of directories searched. `__init__.py` makes a folder a package. **Namespace packages** allow splitting a package across multiple directories.

**P20** — **dataclasses** (std lib, simple), **attrs** (more features), **Pydantic** (data validation). Use **Pydantic** when parsing external data (like JSON APIs) because it enforces types at runtime.
