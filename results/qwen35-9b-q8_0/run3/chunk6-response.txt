## JavaScript / TypeScript

**JS1**
`var` is function-scoped and hoisted (initialized to `undefined`). `let` and `const` are block-scoped and hoisted but not initialized (Temporal Dead Zone). `const` requires initialization and cannot be reassigned (though properties can be). Hoisting is the compiler behavior of moving declarations to the top of their scope.

**JS2**
The event loop continuously checks the call stack. If empty, it checks the microtask queue (Promises, `queueMicrotask`) before the macrotask queue (setTimeout, I/O). Microtasks run to completion before any macrotask. This ensures Promise resolution happens before the next tick of the main loop.

**JS3**
A closure is a function bundled with its lexical environment. Example: `function counter() { let n=0; return () => ++n; }`. The classic bug is using `var i` in a loop with a callback; all callbacks reference the same `i` variable. Fix: Use `let` (block scope) or `IIFE` (`(function(i){...})(i)`).

**JS4**
Promises represent async completion. `async/await` is syntactic sugar over Promises. Errors in `await` throw synchronously. `Promise.all` rejects if *any* promise rejects. `Promise.allSettled` waits for all to settle (fulfilled or rejected) and returns an array of results.

**JS5**
`interface` defines object shapes and can be extended; `type` unions primitives and interfaces. Use `interface` for extensible object contracts; `type` for unions/aliases. Discriminated unions use a literal type on a property to distinguish union members (e.g., `type Status = { type: 'success' } | { type: 'error' }`).

**JS6**
JS uses prototypes. `Object.create(proto)` creates an object with `proto` as its internal `[[Prototype]]`. ES6 classes are syntactic sugar over prototype chains (`class` creates a constructor function, `extends` sets up the prototype chain).

**JS7**
`this` refers to the execution context. Binding rules (priority): 1. Explicit (`obj.method()`), 2. Implicit (new `new Obj()`), 3. Default (global/window), 4. `bind()` (explicitly set). `bind()` returns a new function with `this` fixed; it can be re-bound.

**JS8**
`WeakRef` holds a weak reference to an object (garbage collectible). `FinalizationRegistry` allows cleanup when a weakly referenced object is GC'd. `WeakMap` keys must be objects (not primitives) because primitives are boxed and not suitable for weak tracking; this allows the map to be GC'd if the key is no longer referenced elsewhere.

**JS9**
V8 optimizes via hidden classes (shape of object properties) and inline caching (caching type info for property access). Deoptimization occurs when assumptions break (e.g., adding a new property to an object, changing property types), forcing the engine to revert to slower interpretation.

**JS10**
Tree-shaking removes unused code. ESM uses static `import/export` analysis for tree-shaking. CommonJS uses dynamic `require/module.exports`, making static analysis impossible, so it cannot be effectively tree-shaken.

**JS11**
`null` is an intentional empty value; `undefined` is a missing value. `==` performs type coercion (`null == undefined` is true); `===` checks strict equality. `??` returns the right operand if the left is `null` or `undefined`. `?.` safely accesses nested properties (returns `undefined` if path is missing).

**JS12**
`map()` transforms elements; `filter()` returns a subset; `reduce()` aggregates into a single value. `reduce` with an initial value avoids the first element being the accumulator. `flatMap()` maps and flattens the result one level deep (useful for nested arrays).

**JS13**
Template literals use backticks and allow multi-line strings and expressions `${expr}`. Tagged templates pass raw string segments to a function. Example: `sql` tag function receives segments to prevent SQL injection by concatenating safely.

**JS14**
Destructuring extracts values from arrays/objects. Object: `{ a, b } = obj`. Array: `[a, b] = arr`. Defaults: `{ a = 1 }`. Renaming: `{ a: x }`. Rest operator `...` collects remaining elements/properties into an array.

**JS15**
`for...in` iterates enumerable own and inherited properties (objects). `for...of` iterates iterable values (arrays, strings). Avoid `for...in` on arrays as it iterates indices and non-array properties, potentially including inherited ones.

**JS16**
Generics allow type parameters (`function<T>(x: T)`). Constraints (`extends`) limit types (e.g., `T extends string`). Conditional types (`T extends U ? X : Y`) branch based on type. `infer` extracts types from conditional types (e.g., `infer T` in `Extract`).

**JS17**
Node supports CommonJS (`require/module.exports`) and ES Modules (`import/export`). `type: "module"` in `package.json` enables ESM by default. Node handles both via dual package resolution, but mixing them requires care (e.g., `import` in CJS requires `type: "module"` or dynamic `import()`).

**JS18**
Structural typing checks shape, not declaration. Excess property checks occur at object literal creation (not assignments). `extends` checks structure + excess properties (strict). `satisfies` asserts a value conforms to a type without narrowing the variable's type. Variance (`in`/`out`) determines if a generic type parameter is covariant (output) or contravariant (input).

**JS19**
`Proxy` creates a wrapper object to intercept operations. `Reflect` provides standard behavior. Intercept access (`get`), assignment (`set`), and calls (`apply`). Example: A proxy wrapping a data object to log changes before assignment.

**JS20**
`SharedArrayBuffer` allows memory sharing between threads (Web Workers). `Atomics` provides synchronization primitives (`wait`, `notify`). Ordering guarantees ensure memory visibility across threads. `Atomics.wait` blocks until notified or timeout; `notify` wakes up waiting threads.

## Bash

**B1**
`$@` expands to all positional parameters as separate words. `$*` expands to all as a single string (space-separated). `"$@"` preserves word boundaries (safe for loops). `"$*"` treats arguments as one string.

**B2**
`set -e`: Exit on error. `set -u`: Exit on undefined variable. `set -o pipefail`: Exit if any command in pipeline fails.

**B3**
`$(command)` performs command substitution (subshell). `command` (backticks) is legacy. `$((expr))` is arithmetic expansion. `expr` is an external command for string/regex operations.

**B4**
Process substitution `<(command)` creates a named pipe (FIFO) readable by the command. Used when a command needs to read from a file-like input but the source is a command. Example: `diff <(cmd1) <(cmd2)`.

**B5**
Use `while IFS= read -r -d '' file; do ...; done < <(find . -print0)`. `for f in $(ls)` splits on whitespace, breaking filenames with spaces.

**B6**
`<<EOF` starts a here document (input stream). `<<<` is a here string (input to a command). `<<-` allows tab indentation for the delimiter.

**B7**
`cmd > file 2>&1`: Stdout to file, then stderr to stdout (file). Both in file. `cmd 2>&1 > file`: Stderr to stdout (terminal), then stdout to file. Stderr in terminal, stdout in file. `cmd &> file`: Bash-specific, both to file.

**B8**
Use `mkdir -p "$lockdir/lockname"` for locking (atomic on most filesystems). Cleanup via `trap` on `EXIT`. Race condition handled by `mkdir` failing if exists. If killed, `trap` ensures cleanup.

**B9**
Single quotes: Literal (no expansion). Double quotes: Variable expansion, command substitution. No quotes: Word splitting, globbing. Example: `echo 'a b'` (literal) vs `echo "a $b"` (expansion).

**B10**
`[ -f file ]` (file), `[ -d file ]` (dir), `[ -r file ]` (readable). `[ ]` uses word splitting; `[[ ]]` is a keyword (safer, supports regex `=~`).

**B11**
`$?`: Exit code of last command. `$$`: PID of current shell. `$!`: PID of last background process. `$#`: Number of arguments passed to script/function.

**B12**
`function foo {}` or `foo() {}`. Return values via `echo` (stdout) or `return` (exit code 0-255). `return` cannot return data, only status.

**B13**
`PATH` is a colon-separated list of directories. Bash searches `PATH` for executables. Builtins are internal (e.g., `cd`); externals are in `PATH`. Use `type command` to check.

**B14**
`trap 'cmd' signal`. `EXIT`: Always runs. `ERR`: On error. `INT`/`TERM`: Interrupt/kill. Order: `EXIT` handlers run last.

**B15**
`xargs` executes commands with arguments. `find -print0 | xargs -0` handles spaces/newlines. `xargs -P` runs parallel processes.

**B16**
Arrays: `arr=(1 2)`, `${arr[@]}`. Associative: `declare -A arr`, `arr[key]=val`. Syntax differs; associative uses string keys.

**B17**
Subshell `(...)` creates a new process (variables don't persist). Group `{ ... }` is same shell (variables persist). Piping into `while` runs in subshell, losing variable changes.

**B18**
Signals: `SIGINT` (Ctrl+C), `SIGTERM` (kill), `SIGHUP` (hangup), `SIGKILL` (unblockable). Use `trap` to handle `TERM` for graceful shutdown (kill background jobs).

**B19**
Script: `split -l 1000 log.txt part_` | `xargs -P 4 -I {} process {}` | `cat part_* > merged`. Trade-off: Parallelism vs coordination. Handle errors by checking exit codes in `xargs` or using `set -o pipefail`.

**B20**
`exec` replaces the shell process. `exec 3>file` redirects FD 3. Coprocess: `coproc NAME { command }`. Use for background processes with shared stdin/stdout.

## PowerShell

**PS1**
`Write-Output` sends object to pipeline. `Write-Host` writes to console (bypasses pipeline). Distinction matters for piping data to other commands.

**PS2**
Pipeline passes objects. `ForEach-Object` is a cmdlet (pipeline-aware). `foreach` is a statement (no pipeline). Use `ForEach-Object` for pipeline processing.

**PS3**
`[PSCustomObject]` creates objects with properties. `[hashtable]` is a generic key-value store. Convert: `[pscustomobject]$hash`. Use `[PSCustomObject]` for structured data.

**PS4**
Terminating errors stop execution. Non-terminating continue. `-ErrorAction Stop` makes errors terminating. `try/catch` handles terminating errors.

**PS5**
Splatting: `@params = @{ arg1='val' }`. `cmd @params`. Passes hashtable as named arguments. Safer than passing a single hashtable object.

**PS6**
`Invoke-Command` runs remote script. `Enter-PSSession` creates interactive session. Uses WinRM (default) or SSH (PowerShell 7+).

**PS7**
Function returning array: `$result += "one"` creates array. `$x.GetType().Name` is "Object[]". If empty, returns nothing (null). Correct pattern: Return `[PSCustomObject]` or ensure consistent array type.

**PS8**
`[scriptblock]` is a compiled block. Pass to remote via `-ScriptBlock`. Double-hop: Credential delegation fails. Solve with CredSSP or `-ArgumentList` (serializes args).

**PS9**
`@()` creates array. `[array]` is type. Force single result: `@($result)`. Indexing `$null` throws; empty array returns nothing.

**PS10**
`-eq` (equal), `-like` (wildcard), `-match` (regex). Case-sensitive variants: `-ceq`, `-clike`. `-contains` checks array membership; `-in` checks if value is in collection.

**PS11**
Module: Reusable code. `.psm1` (script), `.psd1` (manifest), binary (DLL). `Import-Module` loads manifest and script.

**PS12**
Interpolation: `"${var}"`. Single quotes: Literal. Here-string: `@"..."@` (multi-line).

**PS13**
`Get-Member` lists properties/methods. `Select-Object` selects properties; `Where-Object` filters. NoteProperties are static strings.

**PS14**
PowerShell classes (v5) are dynamic. No strict inheritance/interfaces like C#. Use classes for encapsulation; functions for logic.

**PS15**
`[CmdletBinding()]` enables advanced functions. `SupportsShouldProcess` adds `-WhatIf/-Confirm`. `Begin/Process/End` blocks for streaming.

**PS16**
Providers abstract namespaces. `Get-ChildItem` works on FileSystem, Registry, etc. Registry: `Get-ChildItem HKLM:\Software`.

**PS17**
Runspaces: `[runspace]` (thread), `[runspacepool]` (pool), `[powershell]` (instance). `ForEach-Object -Parallel` (v7+) uses pool.

**PS18**
`PSScriptAnalyzer` enforces rules (e.g., `PSUseShouldProcessForStateChangingActions`). Severity: Info, Warning, Error. Suppress via `# #`.

**PS19**
`$using:` passes variables to remote/parallel. Serialization limits (CLIXML depth) affect complex objects. Use `$args` for simple values.

**PS20**
DSC: Configuration management (resources, configurations, LCM). Legacy for Windows. Modern IaC: Terraform, Ansible, or PowerShell DSC for config.
