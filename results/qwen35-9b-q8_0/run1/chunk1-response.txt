## Networking (20 questions)

**N1**
A Layer 2 switch forwards frames based on MAC addresses within a single broadcast domain. A Layer 3 switch performs Layer 2 switching but also routes packets between VLANs or subnets using IP addresses, acting as a router for internal traffic.

**N2**
Network Address: **10.0.0.0**
Broadcast Address: **10.0.15.255**
*(Calculation: /20 mask is 255.255.240.0. The block size is 16 in the third octet. 10.0.0.0 to 10.0.15.255.)*

**N3**
The handshake is: 1. Client sends SYN. 2. Server sends SYN-ACK. 3. Client sends ACK.
If the final ACK is lost, the client retransmits the SYN-ACK (or waits for timeout). The server sees the SYN and sends a new SYN-ACK. The client eventually receives it and completes the handshake.

**N4**
**SNAT (Source NAT):** Translates the source IP of outgoing packets (e.g., internal 192.168.1.5 -> external 203.0.113.1). Used for outbound internet access.
**DNAT (Destination NAT):** Translates the destination IP of incoming packets (e.g., external 203.0.113.1:80 -> internal 192.168.1.10:80). Used for port forwarding.

**N5**
1. **DNS Mismatch:** The server resolves the hostname to a different IP than the certificate was issued for.
2. **Wrong Certificate:** The server is serving a certificate intended for a different domain.
3. **Self-Signed/Untrusted:** The certificate is self-signed and not in the client's trust store.

**N6**
**VLAN:** Layer 2 isolation using 802.1Q tags on a physical switch. Limited by physical topology.
**VxLAN:** Layer 2 over Layer 3 tunneling using UDP port 4789.
**Choice:** Choose VxLAN for overlay networks, multi-site cloud environments, or when spanning VLANs across different physical networks without physical cabling.

**N7**
**Why:** The default route points to eth0. Return traffic follows the default route regardless of ingress interface.
**Fix:** Use Policy-Based Routing (PBR).
1. Create a custom routing table (e.g., `ip route add default via 192.168.1.1 dev eth1 table 100`).
2. Add a rule: `ip rule add from 192.168.1.0/24 table 100`.
3. Ensure `192.168.1.0/24` is routed via `eth1` in that table.

**N8**
BGP selects the best path based on attributes in this order:
1. **Weight** (Cisco-specific, local preference).
2. **Local Preference** (Global within AS).
3. **AS Path** (Length).
4. **Origin** (IGP < EGP < Incomplete).
5. **MED** (Multi-Exit Discriminator).

**N9**
**Implication:** MTU reduction due to encapsulation overhead.
**Math:**
Physical MTU: 1500 bytes.
VxLAN Header: 50 bytes.
IPsec ESP Overhead: 40 bytes.
Total Overhead: 90 bytes.
Max Inner Payload: 1500 - 90 = **1410 bytes**.

**N10**
**ARP:** Maps IP addresses to MAC addresses.
**Gratuitous ARP:** A host broadcasts its own IP/MAC pair to update neighbors' ARP caches. Used for IP migration, failover, or detecting IP conflicts.

**N11**
**Public:** Globally routable, unique on the internet.
**Private:** Non-routable on the public internet, used for internal networks.
**RFC 1918 Ranges:**
1. 10.0.0.0/8
2. 172.16.0.0/12
3. 192.168.0.0/16

**N12**
**DNS:** Translates domain names to IP addresses.
**A Record:** Maps a domain to an IPv4 address.
**CNAME Record:** Maps a domain to another domain name (alias).
**AAAA Record:** Maps a domain to an IPv6 address.

**N13**
**DHCP:** Dynamic Host Configuration Protocol.
**DORA Process:**
1. **D**iscover (Client broadcasts request).
2. **O**ffer (Server offers an IP).
3. **R**equest (Client requests the offered IP).
4. **A**cknowledge (Server confirms assignment).

**N14**
**Hub:** Layer 1. Broadcasts all traffic to all ports.
**Switch:** Layer 2. Forwards frames based on MAC addresses.
**Router:** Layer 3. Routes packets based on IP addresses between networks.

**N15**
**Half-Duplex:** Communication in one direction at a time (like a walkie-talkie).
**Full-Duplex:** Communication in both directions simultaneously (like a telephone).
**Modern Ethernet:** Uses **Full-Duplex**.

**N16**
**TTL:** Time To Live. Limits the lifespan of a packet to prevent loops.
**Traceroute:** Sends packets with incrementing TTL values (1, 2, 3...). Routers decrement TTL; when it hits 0, they drop the packet and send an ICMP Time Exceeded message back, revealing the hop.

**N17**
**NAT Gateway:** Translates private IPs to public IPs.
**Static NAT:** One-to-one fixed mapping (e.g., 192.168.1.1 <-> 203.0.113.1).
**Dynamic NAT:** One-to-one mapping from a pool of public IPs.
**PAT (Port Address Translation):** Many-to-one mapping using unique source ports (NAPT).

**N18**
**ECMP:** Routes traffic over multiple paths with equal cost.
**Hashing:** Typically hashes Source IP, Dest IP, Source Port, Dest Port.
**Problem:** Asymmetric routing. If return traffic hashes differently, it takes a different path. Stateful firewalls drop return packets if they don't match the original connection state on the ingress interface.

**N19**
**Problem:** The TCP window size (64KB) is smaller than the Bandwidth-Delay Product (10MB). The pipe is underutilized; the sender stops before the buffer fills.
**Solution:** TCP Window Scaling (RFC 1323) allows the window size to be scaled by a factor (up to 1GB), enabling the sender to fill the pipe efficiently.

**N20**
**802.1Q:** Adds a 4-byte tag to the Ethernet frame to identify the VLAN.
**Linux Config:**
`ip link add link eth0 name eth0.10 type vlan id 10`
`ip link add link eth0 name eth0.20 type vlan id 20`
`ip link add link eth0 name eth0.30 type vlan id 30`
**Frame Format:** Ethernet Header (14B) + 802.1Q Tag (4B) + Payload (46-1500B) + FCS (4B).

## Linux (20 questions)

**L1**
**Hard Link:** Shares the same inode and data blocks. Cannot cross filesystems.
**Symbolic Link:** A separate file pointing to a path. Can cross filesystems. Deleting the target breaks the link.

**L2**
`find /var/log -type f -size +100M`

**L3**
**State D:** Uninterruptible sleep, waiting for I/O (e.g., disk, network).
**Kill:** `kill -9` (SIGKILL) **cannot** kill a process in state D because the kernel holds a lock on the resource. The process must wait for the I/O to complete.

**L4**
**v1:** Hierarchical, separate controllers for memory, CPU, etc.
**v2:** Unified hierarchy, unified cgroup filesystem (`cgroup2`).
**Systemd:** Prefers **v2** for unified control, simpler syntax, and better integration with systemd's resource management.

**L5**
**iptables:** Legacy netfilter framework, complex syntax, separate chains.
**nftables:** New framework, unified syntax, faster performance.
**Kernel:** Both use netfilter hooks. nftables is the new backend; iptables is a compatibility layer that translates rules to nftables.

**L6**
**Cause:** **Reserved Blocks** (default 15% of total blocks) or **Inode Exhaustion**. `df` counts allocated blocks including reserved; `du` sums file content. Check `df -i` for inodes.

**L7**
1. **UEFI:** Firmware initializes hardware.
2. **Bootloader:** GRUB loads the kernel.
3. **Kernel:** bzImage initializes hardware, mounts initramfs.
4. **Initramfs:** Contains modules/drivers to mount the real root filesystem.
5. **Root:** Mounts the actual root filesystem.
6. **systemd:** Starts as PID 1, manages services and targets.

**L8**
**Why:** `Available` = Free + Reclaimable. If OOM fires, the kernel cannot reclaim enough memory from `buff/cache` to satisfy demand.
**Tunables:** `vm.vfs_cache_pressure` (how aggressively reclaim inode cache), `vm.swappiness` (how aggressively swap to disk).

**L9**
**ip netns:** Creates and manages network namespaces.
**Containers:** Runtimes (Docker, Podman) use namespaces to isolate network interfaces, routing tables, and firewall rules for each container.

**L10**
**SIGTERM (15):** Graceful termination (default). Can be caught.
**SIGKILL (9):** Immediate termination. Cannot be caught.
**SIGQUIT (3):** Graceful termination with core dump generation. Can be caught.

**L11**
**stdout:** Standard output (file descriptor 1).
**stderr:** Standard error (file descriptor 2).
**stdin:** Standard input (file descriptor 0).
**Redirect:** `command > file 2>&1` (stdout to file, stderr to stdout then file) or `command 2> file` (stderr to file, stdout to terminal).

**L12**
**chmod 755:**
**7 (Owner):** Read, Write, Execute (rwx).
**5 (Group):** Read, Execute (r-x).
**5 (Others):** Read, Execute (r-x).

**L13**
**Root:** UID 0, full system access.
**Sudo:** User runs commands as root with elevated privileges, limited by `/etc/sudoers`.

**L14**
**Package Manager:** Installs, updates, removes software.
**Debian/Ubuntu:** `apt` (high-level) / `dpkg` (low-level).
**RHEL/Fedora:** `dnf` (high-level) / `yum` (legacy).

**L15**
**/etc/fstab:** Defines filesystem mount points and options at boot.
**Misconfig:** System fails to boot (if root is affected) or specific filesystems fail to mount.

**L16**
**LVM:** Manages storage as logical volumes.
**PV:** Physical disk partition.
**VG:** Group of PVs.
**LV:** Logical volume created from VG.
**Extend:** `lvextend -L +10G /dev/vg_name/lv_name` followed by `resize2fs` (for ext4).

**L17**
**I/O Scheduler:** Manages disk queue order.
**mq-deadline:** Low latency, good for SSDs.
**bfq:** Fairness, good for mixed workloads.
**none:** No scheduling (direct I/O), deprecated in newer kernels.
**Change:** `echo mq-deadline > /sys/block/sda/queue/scheduler`.

**L18**
**Load Average:** Number of processes in runnable or uninterruptible sleep state.
**I/O Wait:** High I/O wait inflates load average even if CPU is idle.
**Diagnose:** `top` (check %wa), `vmstat` (check `wa`), `iostat` (check `%util` and `await`).

**L19**
**SELinux:** Mandatory Access Control (MAC).
**Modes:** Enforcing (blocks), Permissive (logs), Disabled (no policy).
**Troubleshoot:** Check logs (`/var/log/audit/audit.log`), use `ausearch -m avc`, `audit2allow` to generate policy.

**L20**
**Page Fault:** Accessing a non-present page.
**Minor:** Page in from RAM (swap) or free memory.
**Major:** Page in from disk (slow).
**THP:** Uses 2MB pages. Can improve performance for large allocations but causes fragmentation and latency.
**Disable:** `echo never > /sys/kernel/mm/transparent_hugepage/enabled`.
