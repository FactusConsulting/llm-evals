## .NET / C# (20 questions)

**DN1**
Classes are reference types (allocated on the heap); structs are value types (allocated on the stack or inline). Structs are copied by value, classes by reference. Use structs for small, immutable, or POD-like data structures (e.g., coordinates, small DTOs) to avoid GC overhead and improve cache locality. Avoid structs for large objects or those requiring inheritance.

**DN2**
`IEnumerable<T>` executes immediately in memory (LINQ to Objects). `IQueryable<T>` builds an expression tree that is translated to SQL (LINQ to Entities). This distinction matters because `IQueryable` allows the provider (e.g., EF Core) to optimize database queries, whereas `IEnumerable` forces data retrieval before filtering.

**DN3**
`async/await` uses state machines to suspend execution without blocking threads. `Task` represents an async operation with overhead. `ValueTask` reduces allocation by avoiding `Task` creation when the operation completes synchronously or is very fast. Use `ValueTask` in high-throughput scenarios where you know the operation is often synchronous (e.g., `GetValue` methods).

**DN4**
Dependency Injection (DI) allows injecting dependencies rather than creating them. Lifetimes: `Transient` (new per request), `Scoped` (new per request), `Singleton` (new per app). Common bug: Injecting a `Scoped` service into a `Singleton`. The Singleton holds a reference to the Scoped service, preventing it from being disposed when the request ends, causing memory leaks.

**DN5**
`string` is immutable and UTF-16 encoded. `ReadOnlySpan<char>` is a view over memory (stack) without copying. `Span<T>` is a mutable view. Use `Span<T>` for high-performance string processing to avoid allocations and copying, especially in tight loops or when parsing unmanaged buffers.

**DN6**
GC uses mark-and-sweep. Gen 0 collects short-lived objects; Gen 1 collects medium-lived; Gen 2 collects long-lived. Large Object Heap (LOH) stores objects >85KB. `IDisposable` is needed for deterministic cleanup of unmanaged resources (files, handles) because GC is non-deterministic.

**DN7**
Default `await` captures the `SynchronizationContext` (e.g., UI thread). `ConfigureAwait(false)` suppresses this, returning to the thread pool. Use `false` in library code to avoid deadlocks in high-concurrency apps. Do NOT use `false` in UI code where you need to marshal back to the UI thread.

**DN8**
Primary constructors (C# 12) define parameters on the class line. Collection expressions (C# 12) create collections inline. `FrozenDictionary` is immutable.
Example:
```csharp
class MyService(string name) : IService
{
    public string Name { get; } = name;
}
// DI Registration
builder.Services.AddSingleton<MyService>();
```

**DN9**
Cause: A `DbContext` is likely registered as `Singleton` or injected into a `Singleton` service, but `DbContext` is `Scoped`. When the request ends, the `DbContext` is disposed, but the Singleton still holds the reference. Fix: Register `DbContext` as `Scoped` and ensure it is injected only into `Scoped` services.

**DN10**
Records are immutable by default, provide value equality, and auto-generate `Equals`/`GetHashCode`. Classes are mutable and reference-equal. `record struct` is a value type record. Use records for DTOs/POCOs where immutability and value equality are desired; use classes for mutable state or complex inheritance.

**DN11**
`ref`: Pass by reference (read/write). `out`: Pass by reference (write only, must be assigned). `in`: Pass by reference (read only). Use `ref` for large structs to avoid copy; `out` for initialization; `in` for large structs to avoid copy without modification.

**DN12**
`?` on reference types (e.g., `string?`) enables nullable reference type analysis (compile-time). `int?` is a nullable value type (runtime `Nullable<int>`). `?` does not change runtime behavior, only compiler warnings.

**DN13**
LINQ is a query language for collections. Method syntax is fluent (`list.Where(...)`); query syntax is SQL-like (`from x in list where ...`). Deferred execution means the query isn't executed until the result is enumerated (e.g., `ToList()`).

**DN14**
Constraints restrict type `T`. `class`: reference type. `struct`: value type. `new()`: parameterless constructor exists. `IComparable<T>`: implements interface. Combine constraints (e.g., `class & IComparable<T>`) to enforce multiple rules on `T`.

**DN15**
Abstract classes can have state/fields and partial implementation; interfaces are contracts (pre-C# 8). C# 8+ interfaces allow default methods, blurring the distinction. Use abstract classes for shared implementation/state; interfaces for multiple inheritance or contracts.

**DN16**
Middleware pipeline processes requests sequentially. `Use` adds middleware to the pipeline; `Map` branches the pipeline (different routes); `Run` ends the pipeline. Ordering matters (first in, first out). Exception middleware wraps the pipeline to catch errors and return 500 responses.

**DN17**
`Channel<T>` is an async, bounded collection with backpressure. `BlockingCollection<T>` is synchronous and unbounded (usually). Use `Channel<T>` for high-throughput async producer-consumer patterns where backpressure is needed to prevent memory exhaustion.

**DN18**
Source Generators compile code at build time. Faster than reflection. Incremental generators only run when source files change, unlike `ISourceGenerator` which runs on every build. Incremental is preferred for performance in large solutions.

**DN19**
TPL Dataflow creates pipelines. `ActionBlock` (sink), `TransformBlock` (process), `BufferBlock` (buffer). Compare to `Channels`: Dataflow is higher-level (handles backpressure/buffering automatically); Channels are lower-level primitives requiring manual management.

**DN20**
Minimal APIs are lightweight endpoints without controllers. Trade-offs: Less boilerplate, but harder to test (less structure), OpenAPI requires explicit configuration. Route groups organize endpoints; endpoint filters handle cross-cutting concerns (logging, auth).

## Python (20 questions)

**P1**
Lists are mutable sequences; tuples are immutable sequences. Sets are mutable unordered collections; `frozenset` is immutable. Use tuples for fixed data; lists for dynamic data. Use `frozenset` for hashable sets (e.g., dict keys).

**P2**
GIL prevents multiple threads from executing Python bytecode simultaneously on one CPU core. Affects CPU-bound workloads. Workarounds: Multiprocessing (separate processes), C extensions (Cython), or async I/O (non-blocking).

**P3**
`copy` creates a shallow copy (container copied, references shared). `deepcopy` creates a deep copy (nested objects copied). Shallow copy fails if nested mutable objects are modified (e.g., `list.append` on a copied list affects original).

**P4**
Decorators wrap functions.
```python
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time() - start:.2f}s")
        return result
    return wrapper
```

**P5**
Generators use `yield` to pause execution and return an iterator. They save memory vs returning a list. `yield from` delegates to another iterator (e.g., flattening lists).

**P6**
Event loop manages async tasks. `asyncio.run()` starts the loop; `gather()` waits for all tasks; `create_task()` schedules a task. `time.sleep()` blocks the loop; use `asyncio.sleep()` to yield control.

**P7**
MRO uses C3 Linearization. Order: D -> B -> C -> A. `who` is defined in C. `D().who()` calls `C.who()`. Output: `"C"`.

**P8**
Metaclasses control class creation. `__init_subclass__` is a hook for subclass creation (Python 3.6+). Use `__init_subclass__` for simple hooks; use metaclasses for complex runtime control (e.g., enforcing abstract methods).

**P9**
Threading shares memory (GIL limits CPU). Multiprocessing uses separate processes (no GIL). `concurrent.futures` simplifies API. Multiprocessing requires pickling objects to serialize them across processes.

**P10**
`__slots__` prevents `__dict__` creation, saving memory. Prevents dynamic attribute assignment. Use for classes with many instances or strict attribute control.

**P11**
Virtual environments isolate dependencies. `venv` (stdlib), `virtualenv` (3rd party), `conda` (env + package manager). Use `venv` for standard Python projects to avoid dependency conflicts.

**P12**
Comprehensions create lists/dicts/sets concisely. Faster than `map`/`filter`. Prefer comprehensions for readability and performance.

**P13**
`==` checks value equality; `is` checks identity (same object). Integers are interned (cached) for small values (-5 to 256), so `is` returns True for them.

**P14**
`*args` (positional), `**kwargs` (keyword). `/` marks positional-only parameters; `*` marks keyword-only parameters.
Example: `def f(a, /, b, *, c): ...`

**P15**
Context managers manage resources (`with` statement). `__enter__`/`__exit__` or `@contextmanager` (generator). Example: Database connection or file locking.

**P16**
Type hinting enables static analysis. `Union` (multiple types), `Optional` (Union with None), `Literal` (specific values), `TypeVar` (generics), `Protocol` (structural typing). Tools like `mypy` enforce these.

**P17**
`__repr__` (dev), `__str__` (user). `__eq__` (value equality), `__hash__` (dict keys). Defining `__eq__` removes `__hash__` (None) unless explicitly defined.

**P18**
Descriptors manage attribute access (`__get__`, `__set__`, `__delete__`). `property` uses descriptors. `classmethod`/`staticmethod` are descriptors that bind to the class or instance.

**P19**
Imports search `sys.path`. Relative imports use `.`; absolute use module names. `__init__.py` makes a package. Namespace packages (no `__init__.py`). Finders locate modules; loaders load code.

**P20**
`dataclasses` reduce boilerplate. `__post_init__` for logic. `frozen` for immutability. Pydantic adds validation/serialization. Use Pydantic for API data validation; dataclasses for internal data structures.
