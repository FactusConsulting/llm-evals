**DN1** — `class` is a reference type allocated on the heap, supports inheritance, and can be null. `struct` is a value type allocated inline (stack or heap), has no inheritance, and is non-nullable by default. Use `struct` for small, immutable, short-lived data that benefits from stack allocation and value semantics (e.g., `Point`, `Vector`).

**DN2** — `IEnumerable<T>` executes queries in-memory after materializing results. `IQueryable<T>` holds an expression tree that providers (like EF Core) translate to SQL. The distinction matters because `IQueryable<T>` pushes filtering/joining to the database, avoiding full table scans and network overhead.

**DN3** — `async/await` compiles into a state machine that yields control when awaiting I/O or async operations, resuming on a captured context. `Task` is a reference type (heap-allocated); `ValueTask` is a value type (stack-allocated). Use `ValueTask` when the operation often completes synchronously (e.g., cache hits) to avoid allocation overhead.

**DN4** — DI registers and resolves dependencies. `Transient`: new instance per resolution. `Scoped`: one instance per request/context. `Singleton`: one instance per app lifetime. Injecting a Scoped service into a Singleton captures the first request's scope, causing stale state, memory leaks, and thread-safety bugs. Fix by injecting `IServiceScopeFactory` or using a factory pattern.

**DN5** — `string` is immutable, heap-allocated, and GC-managed. `ReadOnlySpan<char>` is a stack-only, zero-copy view over memory. `Span<T>` enables allocation-free slicing, parsing, and buffer manipulation. Use `Span<T>` for high-throughput I/O, networking, or parsing where GC pressure is a bottleneck.

**DN6** — The GC manages heap memory via mark-and-sweep/compaction. Gen 0: short-lived, collected frequently. Gen 1: buffer between 0 and 2. Gen 2: long-lived, collected rarely. LOH: objects >85KB, compacted only on Gen 2 collections. `IDisposable` is for unmanaged resources (file handles, sockets) the GC cannot track; it ensures deterministic cleanup via `using` or explicit disposal.

**DN7** — `ConfigureAwait(false)` prevents capturing the current `SynchronizationContext`, allowing the continuation to run on any thread pool thread. Use it in libraries to prevent deadlocks and improve throughput. Do NOT use it in UI apps or code that must update UI/state on the original context. It directly interacts with `SynchronizationContext` to control continuation scheduling.

**DN8** — Primary constructors reduce boilerplate: `public record Service([FromKeyedServices("db")] IDb db);`. Collection expressions: `var arr = [1, 2, 3];`. `FrozenDictionary<K,V>` (in `System.Collections.Frozen`) provides highly optimized, read-only hash lookups for compile-time known sets. Primary constructors integrate seamlessly with DI attributes.

**DN9** — Likely cause: `DbContext` is captured in a Singleton/Transient service or disposed prematurely via `using` outside the DI scope. EF Core registers `DbContext` as Scoped by default. Fix: ensure `DbContext` is only injected into Scoped/Transient services, avoid storing it in static fields, and rely on DI for lifetime management. High concurrency exposes race conditions when scopes leak.

**DN10** — `record` is a reference type with value-based equality, immutability by default, and positional syntax. `record struct` is the value-type equivalent. Choose `record` for DTOs, domain events, or immutable data transfer. Choose `record struct` for performance-critical value types where allocation must be avoided but value semantics are desired.

**DN11** — `ref`: passes by reference, caller must initialize. `out`: passes by reference, method must assign before return. `in`: read-only reference, prevents copying large structs. Use `ref` for modifying existing values, `out` for multiple return values, `in` for large structs to avoid copy overhead while preventing mutation.

**DN12** — Nullable Reference Types (NRTs) use `?` to annotate compile-time nullability (`#nullable enable`). They are static analysis hints with zero runtime overhead. Nullable value types (`int?`) are runtime `Nullable<T>` structs that actually store a boolean flag and value. NRTs track reference nullability; value types track actual nullability.

**DN13** — LINQ is a unified query syntax for collections, databases, and XML. Method syntax (`list.Where(...)`) and query syntax (`from x in list where ...`) are compiler-equivalent; query syntax is syntactic sugar. Deferred execution means the query isn't evaluated until enumeration (`foreach`, `.ToList()`), enabling composition and lazy evaluation.

**DN14** — Generic constraints restrict `T`: `class` (reference), `struct` (value, non-nullable), `new()` (parameterless ctor), `IComparable<T>` (implements interface). Combine with commas. Use them when the type must support specific operations (e.g., cloning, comparison, instantiation) to enable safe, generic algorithms.

**DN15** — Abstract classes can have state, constructors, and partial implementation; interfaces define contracts only. C# 8+ default interface methods allow implementation in interfaces, blurring the line. Abstract classes still win for shared state/constructors; interfaces win for multiple inheritance and decoupling. Default methods enable interface evolution without breaking implementations.

**DN16** — Middleware processes requests sequentially. `app.Use()` adds middleware that can call `next()` or short-circuit. `app.Map()` branches routing by path. `app.Run()` is terminal. Ordering matters: auth/rate-limiting before routing, static files before MVC. Exception handling middleware (`UseExceptionHandler`) catches unhandled errors, logs them, and can return custom responses.

**DN17** — `Channel<T>` (in `System.Threading.Channels`) is an async, thread-safe producer-consumer queue with built-in backpressure. `BlockingCollection<T>` is synchronous and older. Example: `var ch = Channel.CreateBounded<int>(100);` Producers `await ch.Writer.WriteAsync()` (blocks when full); consumers `await ch.Reader.ReadAsync()` (blocks when empty). Enables scalable, memory-safe pipelines.

**N18** — Source Generators run at compile-time via Roslyn, generating C# code. Unlike reflection (runtime overhead) or IL weaving (post-compile binary manipulation), they integrate cleanly with IDEs and debugging. Incremental generators cache results and only regenerate when inputs change, drastically improving build times vs legacy `ISourceGenerator`.

**N19** — TPL Dataflow is a message-passing library. `ActionBlock<T>` processes items with no output. `TransformBlock<TIn,TOut>` processes and transforms. `BufferBlock<T>` stores items without processing. Channels are simpler, lower-level, and better for async pipelines. Dataflow offers richer routing, completion propagation, and built-in backpressure, at the cost of complexity.

**N20** — Minimal APIs map routes directly to functions, reducing boilerplate vs controllers. Trade-offs: less structured for complex apps, harder to test middleware-heavy flows, OpenAPI requires Swashbuckle/NSwag. Route groups (`app.MapGroup("/api")`) organize endpoints and apply shared middleware/filters. Endpoint filters (`IEndpointFilter`) enable per-route cross-cutting logic (auth, validation) without full middleware.

**P1** — `list` is mutable, ordered, and allows duplicates. `tuple` is immutable, ordered, and hashable. `set` is mutable, unordered, unique elements. `frozenset` is immutable. Use tuples for fixed records, frozensets as dictionary keys or set members.

**P2** — The GIL is a mutex allowing only one thread to execute Python bytecode at a time. It severely limits CPU-bound multithreading. Workarounds: `multiprocessing` (bypasses GIL), C extensions releasing the GIL, `asyncio` for I/O concurrency, or alternative runtimes (PyPy, Jython).

**P3** — `copy()` creates a shallow copy (new container, references to nested objects). `deepcopy()` recursively copies all nested objects. Shallow copy causes unexpected mutation: `a = [[1]]; b = copy(a); b[0].append(2); a[0]` becomes `[1, 2]`.

**P4** — Decorators wrap functions. Example:
```python
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.perf_counter()-start:.4f}s")
        return result
    return wrapper
```

**P5** — Generators use `yield` to produce values lazily, preserving state between yields. Returning a list eagerly computes and stores all items in memory. `yield from` delegates to another generator, flattening iteration without manual loops.

**P6** — The asyncio event loop schedules coroutines cooperatively. `asyncio.run()` starts the loop. `asyncio.gather()` runs coroutines concurrently and waits for all. `asyncio.create_task()` schedules a coroutine to run concurrently immediately. `time.sleep()` blocks the entire loop; use `await asyncio.sleep()` to yield control.

**P7** — Python 3 uses C3 linearization for MRO. For `D(B, C)`, MRO is `D → B → C → A`. `B` has no `who()`, so it falls through to `C`, which returns `"C"`. C3 ensures consistent left-to-right, depth-first resolution without diamond ambiguity.

**P8** — A metaclass controls class creation (`__new__`/`__init__`). `__init_subclass__` is a simpler, instance-level hook called when a class is subclassed. Use `__init_subclass__` for plugin registries or auto-registration. Use metaclasses for global class transformation, validation, or ORM-like field injection.

**P9** — `multiprocessing` bypasses GIL with separate processes (heavy, pickling required). `threading` shares memory, GIL-bound, ideal for I/O. `concurrent.futures` provides a high-level `Executor` API for both. Multiprocessing requires picklable objects; lambdas, DB connections, and locks often fail serialization.

**P10** — `__slots__` restricts instances to a fixed set of attributes, eliminating `__dict__`. Use it when creating millions of instances to save memory and prevent typos. Memory impact: ~40-50% reduction per instance, but prevents dynamic attribute addition.

**P11** — A virtual environment isolates project dependencies. Prevents version conflicts. `venv` (stdlib, basic), `virtualenv` (third-party, more flags), `conda` (package + env manager, handles binary deps, standard in data science).

**P12** — Comprehensions (`[x for x in y]`, `{k:v for ...}`, `{x for ...}`) create collections concisely. `map()`/`filter()` return iterators. Prefer comprehensions for readability and slight performance gains. Use `map`/`filter` for functional pipelines or when lazy evaluation is explicitly needed.

**P13** — `==` checks value equality; `is` checks object identity. Python interns small integers (-5 to 256) and short strings for memory/performance optimization. `a is b` returns `True` for interned objects because they reference the same cached instance.

**P14** — `*args` packs extra positional args into a tuple; `**kwargs` packs keyword args into a dict. `/` marks parameters as positional-only (C API compatibility). `*` marks parameters as keyword-only (clarity/safety). Use `/` for C extensions, `*` for explicit API contracts.

**P15** — Context managers ensure resource cleanup (`with`). Implement via `__enter__`/`__exit__` (classes) or `@contextmanager` (functions using `yield`). Example: database transaction management, file locks, or temporary directory creation.

**P16** — Type hinting adds static annotations. `Union`/`Optional` (multiple types), `Literal` (exact values), `TypeVar` (generic constraints), `Protocol` (structural subtyping). `mypy`/`pyright` parse annotations for static analysis without runtime overhead, catching type errors before execution.

**P17** — `__repr__` (dev, unambiguous), `__str__` (user, readable). `__eq__` defines equality; `__hash__` defines hashability. Defining `__eq__` without `__hash__` sets `__hash__ = None`, making instances unhashable. `__getattr__` is fallback; `__getattribute__` is always called.

**P18** — Descriptors control attribute access via `__get__`, `__set__`, `__delete__`. `property` is a data descriptor. `classmethod`/`staticmethod` are non-data descriptors. Under the hood, they're descriptors stored on the class, invoked by the attribute lookup protocol.

**P19** — Imports search `sys.path`/`PYTHONPATH`. Absolute imports use full package path; relative use `.`/`..`. `__init__.py` marks packages (optional in 3.3+ for namespace packages). Namespace packages split across paths. Finders locate modules; loaders execute them.

**P20** — `dataclasses` auto-generates `__init__`, `__repr__`, etc. `attrs` offers more features; `Pydantic` adds validation/serialization. `__post_init__` runs after init. `field()` enables factories. `frozen=True` makes instances immutable. Choose `Pydantic` for API validation, config parsing, or JSON serialization; `dataclasses` for simple, fast DTOs.
