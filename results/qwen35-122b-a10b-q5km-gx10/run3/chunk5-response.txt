## .NET / C#

**DN1 — Easy: What is the difference between class and struct in C#? When should you use a struct?**
Classes are reference types (allocated on the heap, passed by reference). Structs are value types (allocated on the stack or inline, passed by value). Use structs for small, immutable data types representing a single value (e.g., `Point`, `Coordinate`) to reduce GC pressure. Avoid structs for large data or types requiring inheritance/polymorphism.

**DN2 — Easy: Explain the difference between IEnumerable<T> and IQueryable<T>. Why does this distinction matter for database queries?**
`IEnumerable<T>` executes queries in-memory (client-side). `IQueryable<T>` stores the query as an expression tree and executes it on the provider (e.g., SQL Server). This matters for performance: `IQueryable` allows server-side filtering (SQL `WHERE`), reducing data transfer. `IEnumerable` pulls all data then filters, causing performance issues.

**DN3 — Medium: How does async/await work in C#? What is a Task vs a ValueTask? When should you use ValueTask?**
`async/await` compiles into a state machine that suspends execution until a task completes, freeing the thread. `Task` is a reference type (heap allocation). `ValueTask` is a struct (stack allocation) that can represent a completed task without allocation. Use `ValueTask` in high-frequency hot paths (e.g., caching layers) to avoid GC pressure when the operation often completes synchronously.

**DN4 — Medium: Explain dependency injection in .NET. What are the three service lifetimes, and what is a common bug when injecting a Scoped service into a Singleton?**
DI manages object creation and wiring. Lifetimes: **Transient** (new instance every request), **Scoped** (one instance per HTTP request), **Singleton** (one instance per app lifetime). **Captive Dependency Bug:** Injecting a Scoped service into a Singleton causes the Scoped service to live as long as the Singleton (app lifetime), potentially causing memory leaks or stale state (e.g., DbContext disposed too late or too early).

**DN5 — Medium: What is the difference between string and ReadOnlySpan<char> for string processing? When would you use Span<T> and why?**
`string` is immutable, heap-allocated, and null-terminated. `ReadOnlySpan<char>` is a stack-only view over contiguous memory (no allocation). Use `Span<T>` for high-performance parsing, slicing, or processing large text buffers without creating intermediate string allocations.

**DN6 — Medium: Explain how the .NET garbage collector works. What are generations? What is the Large Object Heap? What is IDisposable and why do you need it if you have a GC?**
GC manages memory reclamation. **Gen 0** (short-lived), **Gen 1** (buffer), **Gen 2** (long-lived). **LOH** stores objects >85KB (Gen 2, rarely compacted). `IDisposable` is for deterministic cleanup of **unmanaged resources** (file handles, DB connections, native memory) which the GC cannot track or free immediately.

**DN7 — Hard: What is the difference between ConfigureAwait(false) and the default behavior? When should you use it, and when should you NOT? How does this relate to SynchronizationContext?**
Default `await` captures the current `SynchronizationContext` (e.g., UI thread or legacy ASP.NET request context) to resume on it. `ConfigureAwait(false)` does not capture context, allowing continuation on any thread pool thread. **Use:** Library code (performance, avoid deadlocks). **Do NOT use:** UI apps or legacy ASP.NET where context is required for thread-affine operations. ASP.NET Core has no SynchronizationContext by default, making it less critical but still good practice for libraries.

**DN8 — Hard: Explain the new .NET 8/9 features: primary constructors, collection expressions, and FrozenDictionary. Write a minimal example using primary constructors with DI.**
**Primary Constructors:** Parameters on class definition injected directly. **Collection Expressions:** `[]` syntax for arrays/lists. **FrozenDictionary:** Immutable, optimized for read-only lookups.
```csharp
public class MyService(string connectionString) : IService {
    public void Run() => Console.WriteLine(connectionString);
}
// DI Registration
builder.Services.AddSingleton<IService, MyService>();
```

**DN9 — Hard: You have a .NET API that works fine under low load but throws ObjectDisposedException on the DbContext under high concurrency. Diagnose the likely cause and explain the fix. How does EF Core's DbContext lifetime interact with DI scoping?**
**Cause:** Captive Dependency. A Scoped `DbContext` is likely injected into a Singleton service or static variable, causing it to be disposed while still in use by other requests, or the `DbContext` is being disposed prematurely due to incorrect DI registration.
**Fix:** Ensure `DbContext` is registered as Scoped (`AddDbContext`). Ensure no Singleton service holds a reference to a Scoped `DbContext`. Use `IServiceScopeFactory` if a Singleton must create scoped services dynamically.

**DN10 — Medium: What is the difference between record and class in C#? What about record struct? When would you choose each?**
`record` provides value-based equality (structural equality) and immutability features (`with` expressions). `class` uses reference equality. `record struct` is a value-type record. Choose `record` for DTOs, domain values, or immutable data. Choose `class` for entities with identity/behavior or mutable state.

**DN11 — Easy: What is the difference between ref, out, and in parameter modifiers in C#? When would you use each?**
`ref`: Pass by reference, variable must be initialized before call. `out`: Pass by reference, must be assigned inside method. `in`: Pass by reference (read-only), avoids copy for large structs. Use `in` for performance optimization on large structs passed to methods that don't modify them.

**DN12 — Easy: Explain nullable reference types in C# (the ? annotation and #nullable enable). How do they differ from nullable value types (int?)?**
**NRT:** Compiler warnings for potential null references on reference types (e.g., `string?`). It is metadata, not runtime enforcement. **Nullable Value Types:** `int?` is `Nullable<int>`, a struct wrapper allowing `null` for value types. NRT does not change runtime behavior; `Nullable<T>` does.

**DN13 — Easy: What is LINQ? Explain the difference between method syntax and query syntax. What is deferred execution?**
LINQ (Language Integrated Query) queries data collections. **Method:** `list.Where(x => x > 5)`. **Query:** `from x in list where x > 5 select x`. Both compile to the same IL. **Deferred Execution:** Query is not executed until enumerated (e.g., `foreach`, `ToList()`). Changes to data after query definition affect results.

**DN14 — Easy: What are generic constraints in C#? Explain where T : class, where T : struct, where T : new(), and where T : IComparable<T>. When would you combine multiple constraints?**
Constraints limit types allowed for `T`. `class`: reference type. `struct`: value type. `new()`: must have public parameterless constructor. `IComparable<T>`: must implement interface. Combine to enforce specific capabilities (e.g., `where T : class, new()` requires a reference type with a default constructor).

**DN15 — Easy: What is the difference between abstract class and interface in C#? How did default interface methods (C# 8+) change this distinction?**
**Abstract:** Can have state (fields), constructors, and partial implementation. **Interface:** Contract only (no state, no constructors pre-C# 8). **Default Interface Methods:** Allow interfaces to provide implementation, reducing breaking changes when adding members, but still cannot hold state.

**DN16 — Medium: Explain the middleware pipeline in ASP.NET Core. What is the difference between app.Use(), app.Map(), and app.Run()? How does ordering matter, and how does exception handling middleware work?**
Pipeline is a chain of delegates. `Use()`: Adds middleware that can call `next`. `Map()`: Branches pipeline based on path. `Run()`: Terminal middleware (no `next`). **Order:** Critical (first in = first out). **Exception Handling:** Must be registered early (e.g., `UseExceptionHandler`) to catch exceptions from downstream middleware.

**DN17 — Medium: What is Channel<T> in .NET? How does it compare to BlockingCollection<T>? Give an example of using bounded channels for producer-consumer backpressure.**
`Channel<T>` is an async producer-consumer queue. `BlockingCollection` is synchronous (blocking). `Channel` supports `async` reads/writes. **Bounded Channel:** Limits capacity. If full, writers await (backpressure).
```csharp
var channel = Channel.CreateBounded<int>(10);
await channel.Writer.WriteAsync(item); // Awaits if full
```

**DN18 — Hard: Explain Source Generators in .NET. How do they differ from reflection and IL weaving? What is an incremental generator, and why is it preferred over ISourceGenerator?**
**Source Generators:** Compile-time code generation (C# to C#). **Reflection:** Runtime (slow). **IL Weaving:** Post-build (complex). **Incremental Generator:** Caches analysis results, only re-runs on changed files. Preferred for performance in large solutions compared to the older `ISourceGenerator` which re-runs on every build.

**DN19 — Hard: What is the System.Threading.Tasks.Dataflow library (TPL Dataflow)? Explain ActionBlock, TransformBlock, and BufferBlock. How does it compare to System.Threading.Channels for pipeline processing?**
**TPL Dataflow:** High-level pipeline library. `ActionBlock` (consume), `TransformBlock` (map), `BufferBlock` (queue). **Comparison:** Dataflow is higher-level, built-in backpressure, and linking. Channels are lower-level, more flexible, and generally preferred for new async code due to lighter weight and better integration with `async/await`.

**DN20 — Hard: What are Minimal APIs in .NET? How do they differ from controller-based APIs? What are the trade-offs in terms of testability, middleware, and OpenAPI support? How do route groups and endpoint filters work?**
**Minimal APIs:** `app.MapGet` style, no controllers/classes. **Difference:** Less boilerplate, faster startup. **Trade-offs:** Slightly harder to organize large apps, testability is similar (integration tests), OpenAPI requires explicit configuration (e.g., `AddEndpointsApiExplorer`). **Route Groups:** `app.MapGroup("/api")` prefixes routes. **Filters:** `EndpointFilter` allows cross-cutting logic per endpoint.

## Python

**P1 — Easy: What is the difference between a list and a tuple? What about a set vs a frozenset?**
**List:** Mutable, ordered. **Tuple:** Immutable, ordered. **Set:** Mutable, unordered, unique elements. **Frozenset:** Immutable version of set (hashable, can be dict key).

**P2 — Easy: Explain the GIL (Global Interpreter Lock). What types of workloads does it affect, and what are the workarounds?**
GIL allows only one thread to execute Python bytecode at a time. Affects **CPU-bound** multithreading (no parallelism). **Workarounds:** `multiprocessing` (separate processes), C-extensions (release GIL), `asyncio` (I/O bound), or alternative interpreters (PyPy, Jython).

**P3 — Medium: What is the difference between deepcopy and copy? Give an example where shallow copy causes unexpected behavior.**
`copy` (shallow): Copies container, references nested objects. `deepcopy`: Recursively copies all nested objects. **Example:** `list_a = [[1]]; list_b = copy(list_a); list_b[0].append(2)`. `list_a` becomes `[[1, 2]]` because inner list is shared.

**P4 — Medium: Explain Python decorators. Write a decorator that logs the execution time of any function.**
Decorators wrap functions to modify behavior.
```python
import time, functools
def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__} took {time.time()-start}")
        return res
    return wrapper
```

**P5 — Medium: What are generators and yield? How do they differ from returning a list? What is yield from?**
Generators produce items lazily using `yield`. Differ from lists by saving memory (one item at a time). `yield from` delegates to another generator/sub-iterator, flattening the yield chain.

**P6 — Medium: Explain Python's asyncio event loop. What is the difference between asyncio.run(), asyncio.gather(), and asyncio.create_task()? Why can't you call time.sleep() inside an async function?**
**Event Loop:** Manages async tasks. `run()`: Starts loop. `gather()`: Waits for multiple coroutines. `create_task()`: Schedules coroutine. `time.sleep()` blocks the thread, freezing the loop. Use `await asyncio.sleep()` to yield control.

**P7 — Hard: Explain Python's MRO (Method Resolution Order). What algorithm does Python 3 use? What happens with diamond inheritance, and why does the following print what it does?**
**MRO:** C3 Linearization. Ensures consistent order. **Diamond:** Resolves ambiguity by visiting base classes in order.
```python
# MRO: D -> B -> C -> A
# D().who() checks D (no), B (no), C (yes -> "C")
print(D().who()) # Output: "C"
```

**P8 — Hard: What is a metaclass? When would you use __init_subclass__ vs a metaclass? Give a practical use case for each.**
**Metaclass:** Class of a class (controls class creation). **`__init_subclass__`:** Hook called when a class is subclassed (simpler). **Use Case:** Metaclass for ORM model registration (e.g., Django). `__init_subclass__` for enforcing subclass constraints (e.g., abstract base classes).

**P9 — Hard: Explain the difference between multiprocessing, threading, and concurrent.futures in Python. When would you use each? What are the serialization implications of multiprocessing (pickling)?**
**Threading:** I/O bound, shared memory, GIL limited. **Multiprocessing:** CPU bound, separate memory, bypasses GIL. **concurrent.futures:** High-level API for both. **Pickling:** Multiprocessing requires arguments/return values to be picklable (serialized) to pass between processes.

**P10 — Medium: What is __slots__? When should you use it, and what does it prevent? What is the memory impact?**
`__slots__` declares fixed attributes, preventing `__dict__` creation. **Use:** Memory optimization for millions of instances. **Prevents:** Dynamic attribute assignment. **Impact:** Significant memory reduction, slightly faster attribute access.

**P11 — Easy: What is a virtual environment, and why should you use one? What is the difference between venv, virtualenv, and conda?**
**Venv:** Isolated Python environment for dependencies. **Why:** Avoid conflicts between projects. **venv:** Standard library (Python 3.3+). **virtualenv:** Third-party, older, more features. **conda:** Package manager + env manager (non-Python packages too).

**P12 — Easy: Explain list comprehensions, dict comprehensions, and set comprehensions. How do they relate to map() and filter()? When would you prefer one over the other?**
Comprehensions: `[x for x in list]`, `{k:v}`, `{x}`. **Relation:** Often faster and more readable than `map()`/`filter()`. **Prefer:** Comprehensions for readability and performance in most cases; `map`/`filter` for functional pipelines or lazy iterators.

**P13 — Easy: What is the difference between == and is in Python? What is object interning, and why does a is b sometimes return True for small integers?**
`==`: Value equality. `is`: Identity (same memory address). **Interning:** Python caches small integers (-5 to 256) and some strings. `a is b` is True for these cached objects because they point to the same memory.

**P14 — Easy: Explain Python's *args and **kwargs. How do positional-only (/) and keyword-only (*) parameter markers work in function signatures?**
`*args`: Tuple of positional args. `**kwargs`: Dict of keyword args. `/`: Parameters before must be positional. `*`: Parameters after must be keyword.
`def f(a, /, b, *, c):` -> `a` pos-only, `b` any, `c` keyword-only.

**P15 — Easy: What are context managers (with statement)? How do you write one using __enter__/__exit__ vs @contextmanager? Give an example beyond file handling.**
Manages setup/teardown (resources). **Class:** Implement `__enter__`, `__exit__`. **Decorator:** `@contextmanager` with `yield`. **Example:** Database transaction commit/rollback, Timer, Lock acquisition.

**P16 — Medium: What is type hinting in Python? Explain typing.Union, Optional, Literal, TypeVar, and Protocol. How does mypy or pyright use these for static analysis?**
Hints describe types without runtime enforcement. `Union[A, B]`: A or B. `Optional[A]`: A or None. `Literal["x"]`: Specific value. `TypeVar`: Generic type. `Protocol`: Structural subtyping. **Mypy/Pyright:** Analyze code statically to catch type errors before runtime.

**P17 — Medium: Explain Python's data model (dunder methods). What are __repr__ vs __str__, __eq__ vs __hash__, and __getattr__ vs __getattribute__? What happens if you define __eq__ but not __hash__?**
`__repr__`: Developer/debug string. `__str__`: User string. `__eq__`: Equality. `__hash__`: Hash value. `__getattr__`: Called on missing attr. `__getattribute__`: Called on all attr access. **Hash:** Defining `__eq__` makes `__hash__` None by default (object becomes unhashable) unless explicitly defined.

**P18 — Hard: What are descriptors in Python? Explain the descriptor protocol (__get__, __set__, __delete__). How do property, classmethod, and staticmethod use descriptors under the hood?**
Descriptors manage attribute access on classes. Protocol: `__get__(self, obj, type)`, `__set__`, `__delete__`. **Property:** Uses descriptor to implement getter/setter. **classmethod/staticmethod:** Descriptors that bind methods to class or return function directly.

**P19 — Hard: Explain Python's import system in detail. What is the difference between relative and absolute imports? How does sys.path, PYTHONPATH, __init__.py, and namespace packages work? What is a finder and a loader?**
**Import:** Finds module, loads it. **Relative:** `from . import x`. **Absolute:** `from pkg import x`. **sys.path:** Search paths. **PYTHONPATH:** Env var to extend path. **__init__.py:** Marks package (empty or init code). **Namespace:** Packages without `__init__.py` (split across dirs). **Finder:** Locates module. **Loader:** Loads code into memory.

**P20 — Hard: What is dataclasses and how does it compare to attrs and Pydantic? Explain __post_init__, field factories, frozen dataclasses, and how dataclasses interacts with inheritance. When would you choose Pydantic over dataclasses?**
**dataclasses:** Auto-generate `__init__`, `__repr__`, etc. **attrs:** More features (validators). **Pydantic:** Runtime validation + serialization. **`__post_init__`:** Logic after init. **Field factories:** `field(default_factory=list)`. **Frozen:** Immutable. **Inheritance:** Works like normal classes. **Choose Pydantic:** When runtime type validation and JSON serialization are required (e.g., API inputs).
