DN1 — **Class vs Struct:** Classes are reference types (allocated on heap, passed by reference); structs are value types (allocated on stack or inline, passed by value). Use structs for small, immutable data types representing a single value (e.g., `Point`, `Coordinate`) to reduce GC pressure. Avoid structs for large data or mutable state to prevent unintended copying.

DN2 — **IEnumerable vs IQueryable:** `IEnumerable<T>` executes queries in memory (LINQ to Objects); `IQueryable<T>` builds an expression tree translated to SQL (LINQ to Entities/SQL). Distinction matters for performance: `IQueryable` filters data on the database server before fetching, whereas `IEnumerable` fetches all data then filters client-side.

DN3 — **Async/Await & Task vs ValueTask:** `async/await` compiles to a state machine. `Task` is a reference type (allocates heap); `ValueTask` is a struct (stack-allocated, no allocation if completed synchronously). Use `ValueTask` in high-frequency hot paths (e.g., caching layers) to avoid GC pressure, but prefer `Task` for standard APIs to avoid complexity (e.g., multiple awaits).

DN4 — **Dependency Injection Lifetimes:** Transient (new instance per request), Scoped (one instance per HTTP request), Singleton (one instance per app lifetime). **Bug:** Injecting a Scoped service into a Singleton creates a "Captive Dependency," where the Scoped service lives as long as the Singleton, potentially holding stale state or resources.

DN5 — **string vs ReadOnlySpan<char>:** `string` is immutable, heap-allocated, and null-terminated. `ReadOnlySpan<char>` is a stack-only view over contiguous memory (no allocation). Use `Span<T>` for high-performance string manipulation (parsing, slicing) to avoid allocations and copies.

DN6 — **GC & IDisposable:** GC manages memory via generations: Gen 0 (short-lived), Gen 1 (medium), Gen 2 (long-lived). LOH (Large Object Heap) stores objects >85KB (rarely compacted). `IDisposable` is needed for unmanaged resources (file handles, DB connections) because the GC doesn't know when to release them deterministically.

DN7 — **ConfigureAwait(false):** Default `await` captures the `SynchronizationContext` (e.g., UI thread or ASP.NET request context). `ConfigureAwait(false)` releases it, allowing continuation on any thread pool thread. Use `false` in library code to avoid deadlocks and improve scalability. Do NOT use in UI/ASP.NET Core controllers if you need to access the current context (e.g., `HttpContext`).

DN8 — **.NET 8/9 Features:** Primary constructors allow constructor parameters on the class definition. Collection expressions (`[1, 2, 3]`) replace `new[]`. `FrozenDictionary` is an immutable, high-performance lookup. **Example:** `public class MyService(string connStr) : IService { }` (injected via DI).

DN9 — **ObjectDisposedException Diagnosis:** Likely caused by a Captive Dependency (Scoped `DbContext` injected into Singleton) or using `DbContext` after the request scope ends. **Fix:** Ensure `DbContext` is registered as Scoped. If using Singleton services, inject `IServiceScopeFactory` to create a scope for the `DbContext`.

DN10 — **record vs class:** `record` provides value-based equality (structural) and immutability features (`with` expressions). `record struct` is a value-type record. Use `record` for DTOs, domain models, or immutable data; use `class` for entities with identity or mutable state.

DN11 — **ref, out, in:** `ref` passes by reference (must be initialized before call). `out` passes by reference (must be assigned inside method). `in` passes by reference but read-only (prevents copying large structs). Use `in` for large structs to avoid copy overhead without allowing mutation.

DN12 — **Nullable Reference Types:** `?` on reference types (e.g., `string?`) enables compiler warnings for potential nulls (static analysis). `int?` is `Nullable<int>`, a value type wrapper. NRTs do not enforce null checks at runtime; they are compile-time hints.

DN13 — **LINQ:** Language Integrated Query. Method syntax uses lambdas (`list.Where(x => x > 5)`); query syntax is SQL-like (`from x in list where x > 5`). **Deferred Execution:** Query is not executed until iterated (e.g., `foreach` or `ToList()`).

DN14 — **Generic Constraints:** `where T : class` (ref type), `where T : struct` (val type), `where T : new()` (public parameterless ctor), `where T : IComparable<T>` (interface). Combine constraints to enforce specific capabilities (e.g., `where T : class, IDisposable`).

DN15 — **Abstract vs Interface:** Abstract class can have state (fields) and implementation; interface defines a contract. C# 8+ allows default interface methods, blurring the line. Use abstract for shared base behavior; use interface for polymorphic capabilities across unrelated types.

DN16 — **Middleware Pipeline:** `app.Use()` adds middleware that can call `next()`. `app.Map()` branches the pipeline based on path. `app.Run()` is terminal (no `next`). Order matters: request flows top-down, response bottom-up. Exception middleware wraps others to catch errors.

DN17 — **Channel<T>:** Async producer-consumer queue. `BlockingCollection` is blocking/synchronous. **Bounded Channel:** `Channel.CreateBounded` limits capacity; producers await when full (backpressure). Prevents memory exhaustion under high load.

DN18 — **Source Generators:** Compile-time code generation (C# 9+). Faster than reflection (no runtime cost). Incremental generators cache results between compilations for speed. Preferred over IL weaving (PostSharp) as it integrates into the standard build pipeline.

DN19 — **TPL Dataflow:** High-level pipeline library (`ActionBlock`, `TransformBlock`, `BufferBlock`). Handles throttling, linking, and propagation. Channels are lower-level primitives; Dataflow is better for complex pipeline orchestration, while Channels are better for simple producer-consumer.

DN20 — **Minimal APIs:** `app.MapGet` style endpoints. Less boilerplate than Controllers. Trade-offs: Harder to unit test (integration tests preferred), less built-in OpenAPI support (requires Swashbuckle), but excellent for microservices. Route groups (`MapGroup`) organize endpoints; Endpoint filters apply logic across routes.

P1 — **List vs Tuple, Set vs FrozenSet:** List is mutable, ordered. Tuple is immutable, ordered. Set is mutable, unordered, unique. FrozenSet is immutable, hashable (can be dict key). Use tuples for fixed data structures; sets for membership testing.

P2 — **GIL:** Global Interpreter Lock prevents multiple threads from executing Python bytecode simultaneously. Affects CPU-bound multithreading. Workarounds: Use `multiprocessing` for CPU tasks, `asyncio` or threads for I/O-bound tasks.

P3 — **Deep vs Shallow Copy:** `copy` (shallow) copies references to nested objects. `deepcopy` recursively copies everything. **Example:** `a = [[1]]; b = copy(a); b[0].append(2)` modifies `a` too. Use `deepcopy` when nested mutability matters.

P4 — **Decorators:** Wrapper function that modifies behavior. **Example:**
```python
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        res = func(*args, **kwargs)
        print(f"{func.__name__}: {time.time()-start}")
        return res
    return wrapper
```

P5 — **Generators:** Functions using `yield` return iterators lazily. Differ from lists by not storing all data in memory. `yield from` delegates to a sub-generator, flattening iteration.

P6 — **Asyncio:** Event loop manages coroutines. `asyncio.run()` starts the loop. `gather()` waits for multiple tasks. `create_task()` schedules a coroutine. `time.sleep()` blocks the loop; use `await asyncio.sleep()` to yield control.

P7 — **MRO:** Method Resolution Order uses C3 Linearization. `D(B, C)` -> MRO: `D, B, C, A`. `D().who()` looks in D (no), B (no), C (yes). Prints "C". Diamond inheritance resolves ambiguity by prioritizing left-to-right in base classes.

P8 — **Metaclass:** Class of a class. `__init_subclass__` hooks subclass creation (simpler, no metaclass needed). Metaclass (`type`) controls class creation logic. **Use Case:** `__init_subclass__` for auto-registering plugins; Metaclass for enforcing strict API contracts or ORM magic.

P9 — **Multiprocessing vs Threading:** Threads share memory (GIL limited); Processes have separate memory (true parallelism). `concurrent.futures` abstracts both. **Serialization:** Multiprocessing requires pickling arguments/return values (cannot pass lambdas or open files).

P10 — **__slots__:** Declares fixed attributes, preventing `__dict__` creation. Saves memory (up to 40%) and speeds up access. Prevents dynamic attribute assignment. Use for memory-intensive classes with fixed attributes.

P11 — **Virtual Environment:** Isolated Python environment for dependencies. `venv` (stdlib), `virtualenv` (third-party, faster), `conda` (package manager + env, handles non-Python libs). Use one to avoid dependency conflicts.

P12 — **Comprehensions:** Concise syntax for creating lists/dicts/sets (`[x for x in y]`). Faster than loops. Prefer over `map()`/`filter()` for readability in Pythonic code.

P13 — **== vs is:** `==` checks value equality; `is` checks identity (same memory address). **Interning:** Python caches small integers (-5 to 256) and some strings, so `a is b` may be True for them.

P14 — **args/kwargs:** `*args` collects positional args; `**kwargs` collects keyword args. `/` marks positional-only params (before it). `*` marks keyword-only params (after it). Enforces API clarity.

P15 — **Context Managers:** `with` statement ensures setup/teardown. `__enter__`/`__exit__` (class) or `@contextmanager` (generator). **Example:** Database transaction commit/rollback or acquiring a lock.

P16 — **Type Hinting:** Static analysis annotations. `Union[A, B]` (A or B), `Optional[A]` (A or None), `Literal[1]` (specific value), `TypeVar` (generic), `Protocol` (structural typing). `mypy`/`pyright` check types without running code.

P17 — **Data Model:** Dunder methods. `__repr__` (developer/debug), `__str__` (user). `__eq__` defines equality; defining it sets `__hash__` to None (unhashable) unless explicitly defined. `__getattr__` (missing attr), `__getattribute__` (all attr access).

P18 — **Descriptors:** Objects defining `__get__`, `__set__`, `__delete__`. `property` is a data descriptor. `classmethod`/`staticmethod` are non-data descriptors. Descriptors enable attribute logic (validation, caching) on classes.

P19 — **Import System:** `sys.path` searches for modules. Absolute (full path), Relative (`.`). `__init__.py` marks packages. Namespace packages allow splitting packages across directories. Finders locate modules; Loaders execute them.

P20 — **Dataclasses:** Auto-generate `__init__`, `__repr__`, etc. `__post_init__` for logic after init. `frozen=True` makes immutable. **Pydantic:** Adds validation and serialization (JSON). Choose Pydantic for API models/validation; dataclasses for internal data structures.
