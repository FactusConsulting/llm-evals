## Networking

N1 — A **Layer 2 switch** forwards frames based on MAC addresses within a single local network segment. A **Layer 3 switch** has the ability to perform routing between different subnets (VLANs) using IP addresses, combining the functionality of a switch and a router.

N2 — For **10.0.5.37/20**: The subnet mask is `/20` ($255.255.240.0$).
Network Address: **10.0.0.0**
Broadcast Address: **10.0.15.255**

N3 — The TCP three-way handshake consists of: **SYN $\rightarrow$ SYN-ACK $\rightarrow$ ACK**. If the final **ACK** is lost, the server will not receive confirmation and will retransmit the **SYN-ACK** packet multiple times until it receives an acknowledgment or a timeout occurs.

N4 — **SNAT (Source NAT)** changes the source IP of outgoing packets; used in outbound internet access from a private network. **DNAT (Destination NAT)** changes the destination IP/port of incoming packets; used for port forwarding (e.g., mapping a public IP's port 80 to an internal web server).

N5 — 1. The client connected to the wrong IP address (DNS poisoning or misconfiguration). 2. The server is hosting a certificate for a different domain name. 3. A load balancer is presenting a default "self-signed" certificate instead of the intended one.

N6 — A **VLAN** isolates traffic at Layer 2 within a physical switch. **VxLAN** is an overlay tunnel that encapsulates Layer 2 frames into Layer 3 UDP packets, allowing for massive scalability across different physical locations (Layer 3 boundaries). Choose VxLAN when you need to scale beyond the 4,096 VLAN limit or require multi-tenancy over a large data center fabric.

To fix this with Policy-Based Routing (PBR), create a specific route for the `192.168.1.0/24` source and set its next hop via `eth1`, or use `ip rule` to associate the source IP with a custom routing table.

N8 — BGP path selection order:
1. Weight (Cisco proprietary)
2. Local Preference
3. AS_Path
4. Origin
5. MED

N9 — VxLAN adds 50 bytes of overhead; IPsec adds additional headers (variable, but typically ~50+ bytes). If the physical MTU is 1500, the inner payload must be reduced to account for both encapsulations. Calculation: $1500 - 50 (\text{VxLAN}) - 50 (\text{IPsec}) = \mathbf{1400}$ **bytes** max inner payload.

N10 — **ARP** maps an IP address to a MAC address. **Gratuitous ARP** is used to announce a host's presence on the network; it helps detect IP conflicts and allows switches to update their MAC tables when a VM moves to a new host (HA failover).

N11 — Public IPs are reachable from the internet; Private IPs are reserved for internal networks. RFC 1918 private ranges:
1. 10.0.0.0/8
2. 172.16.0.0/12
3. 192.168.0.0/16

N12 — **DNS** resolves names to IPs. **A record**: Maps name to IPv4. **CNAME**: An alias (maps one name to another). **AAAA**: Maps name to IPv6.

N13 — **DHCP** automatically assigns IPs. The DORA process: **D**iscover, **O**ffer, **R**equest, **A**cknowledge.

N14 — A **Hub** broadcasts all traffic to all ports (Layer 1). A **Switch** forwards frames based on MAC addresses (Layer 2). A **Router** forwards packets based on IP addresses (Layer 3).

N15 — **Half-duplex** allows communication in only one direction at a time (like a walkie-talkie); **Full-duplex** allows simultaneous two-way communication. Modern Ethernet uses full-duplex.

N16 — **TTL (Time To Live)** prevents packets from looping forever by decrementing the hop count. **Traceroute** sends packets with incrementing TTLs; when a packet's TTL hits 0, the router drops it and returns an ICMP "Time Exceeded" message, allowing us to map each hop.

N17 — A **NAT Gateway** translates private internal IPs to a public IP for internet access.
*   **Static NAT:** One-to-one mapping of a private IP to a public IP.
*   **Dynamic NAT**: Maps a private IP to any available IP from a pool.
*   **PAT (Port Address Translation)**: Maps multiple private IPs to a single public IP using unique source ports.

N18 — **ECMP** distributes traffic across multiple paths with equal costs by hashing header fields (Source/Dest IP, Ports). Asymmetric flows cause issues because stateful firewalls track connection states; if the return path takes a different physical path than the outbound path, the firewall may drop the packet as "out of state."

N19 — The problem is that the TCP window size is too small to fill the Bandwidth-Delay Product ($10\text{MB} \times \text{Latency}$). Without scaling, the max window is $64\text{KB}$. **TCP Window Scaling (RFC 1323)** allows the window size to be scaled up to much larger values, enabling high throughput on high-latency links.

N20 — **802.1Q** adds a 4-byte tag containing the VLAN ID to the Ethernet frame. On Linux, you create sub-interfaces (e.g., `eth0.10`, `eth0.20`). Each sub-interface has its own IP and acts as a virtual member of that specific VLAN.

## Linux

L1 — A **hard link** is an additional directory entry pointing to the same inode as the original file. A **symbolic link** (symlink) is a separate file that contains a path string pointing to another file's name.

L2 — `find /var/log -size +100M`

L3 — State D means the process is in **uninterruptible sleep**, usually waiting for a hardware I/O operation or a kernel lock. It cannot be killed with `kill -9` until it completes the requested I/O operation.

L4 — **Cgroups v2** provides a unified hierarchy where all controllers are available in one tree. Systemd prefers **v2** because it simplifies resource management and ensures consistent behavior across different subsystems like memory and CPU limits.

L5 — **nftables** is the successor to iptables; it uses a more efficient bytecode engine. The kernel handles both via the **Netfilter** framework; `iptables` commands are translated into netfilter rules, while `nftables` interacts with the kernel using its own specialized expressions.

L6 — This occurs when a large file was deleted but is still being held open by a running process. The filesystem sees the space as "used" because the file handle is active, even though `du` no longer sees the directory entry. Use `lsof | grep deleted`.

L7 — 1. **Firmware (UEFI)** initializes hardware. 2. **Bootloader (GRUB)** loads the kernel. 3. **Kernel** starts and mounts the **initramfs**. 4. **Initramfs** contains drivers to mount the real **root** filesystem. 5. Kernel executes `/sbin/init`, which starts **systemd** to bring up targets.

L8 — Memory used for **buff/cache** is reclaimed automatically if needed. However, if the system has high I/O wait or many processes in state D, the OOM killer might trigger if the *actual* free memory falls below a threshold. Tunables: `vm.min_free_kbytes` and `vm.swappiness`.

L9 — `ip netns` creates isolated network namespaces. Container runtimes use them to provide each container with its own private routing table, IP addresses, and firewall rules.

L10 — **SIGTERM**: Request to stop (caught). **SIGQUIT**: Request to stop + core dump (caught). **SIGKILL**: Immediate termination by kernel (cannot be caught).

L11 — **stdout**: Standard output; **stderr**: Error output; **stdin**: Standard input. To redirect stderr while keeping stdout on terminal: `command 2> /tmp/error.log`.

L12 — `chmod 755`:
- Owner: Read, Write, Execute ($4+2+1=7$)
- Group: Read, Execute ($4+1=5$)
- Others: Read, Execute ($4+1=5$)

L13 — The **root user** has UID 0 and unrestricted access to all files and commands. A **sudo user** is a standard user granted permission to execute specific commands as root via the `/etc/sudoers` file.

L14 — A package manager handles installation, updates, and dependency resolution. Debian/Ubuntu: **apt**. RHEL/Fedora: **dnf** (or yum).

L15 — **/etc/fstab** defines persistent mount points for disks/filesystems at boot. If misconfigured (e.g., wrong UUID or options), the system may fail to boot into a single-user mode or hang during the mounting phase.

L16 — **LVM** provides logical abstraction of physical storage.
*   **PV**: Physical disk partition.
*   **VG**: Pool of PVs.
*   **LV**: Logical "partition" from the VG.
Extend online: `lvextend -L +1G /dev/vg_name/lv_name -r` (the `-r` resizes the filesystem automatically).

L17 — I/O Schedulers manage the order of block I/O requests.
*   **mq-deadline**: Good for general purpose; prioritizes reads over writes.
*   **bfq**: Fair queuing; good for desktop/interactive workloads.
*   **none**: No scheduling; best for high-speed NVMe SSDs where hardware parallelism is maximized. Change via `echo [scheduler] > /sys/block/[device]/queue/scheduler`.

L18 — Load average measures processes in **Running (R)** and **Uninterruptible Sleep (D)** states. High load with low CPU usage usually indicates an **I/O bottleneck**. Diagnose using `iostat` (disk), `top`/`htop` (CPU), and `netstat`/`ss` (network).

L19 — SELinux uses Mandatory Access Control (MAC) to restrict process capabilities based on security contexts.
*   **Enforcing**: Policy active.
*   **Permissive**: Logs violations but allows actions.
*   **Disabled**: Security checks off.
Troubleshoot: Use `ausearch -m avc` or `getsebool` to check if a specific boolean needs to be toggled to allow a port binding.

L20 — A **page fault** occurs when the CPU accesses a memory page not currently mapped in the MMU.
*   **Minor**: Page is in RAM but not mapped to this process's space.
*   **Major**: Page must be fetched from disk.
**THP (Transparent Huge Pages)** reduces TLB misses by using 2MB pages instead of 4KB, but can cause memory fragmentation and latency spikes for some databases; disable it via `/sys/kernel/mm/transparent_hugepage/enabled`.
